# 미니피아 디자인 참고 자료

1. 사용자 지시와 현재 페이즈의 `*-SPEC.md`, `*-CONTEXT.md`, `*-UI-SPEC.md`, `*-PLAN.md`에서 참고 자료와 피해야 할 예시를 찾는다. 승인된 화면과 에셋은 `design/`의 사본에서 확인한다.
2. 참고 이미지와 에셋을 직접 연다. 이미지가 많은 폴더에서는 대표 이미지 최대 10장을 본다. 열 수 없는 경로는 산출물에 기록한다.
3. 색·글꼴·간격·밀도·질감·캐릭터 스타일 중 적용할 요소를 고른다. 해당 UI-SPEC, 계획 또는 UI 검토 문서의 참고 자료 표에 원래 경로와 적용 요소를 적는다. 자료와 다른 선택이 필요하면 근거를 기록한다.
4. 제공된 에셋을 사용하고, 규격이 다르면 원본을 보존한 채 변환본을 만든다. 필요한 에셋이 없으면 크기·상태·파일명 규격을 정하고 교체 가능한 임시 에셋으로 표시한다.
5. 참고 자료가 없으면 프로젝트의 기존 디자인 시스템과 제품 분위기를 기준으로 진행하고 방향을 한두 줄로 기록한다. 보라·파랑 그라데이션, 장식용 유리 효과, 반복 카드, 이모지 아이콘으로 화면을 채우기보다 제품의 기존 시각 언어를 따른다.
6. 검토할 때는 승인된 참고 자료에서 가져오기로 한 요소가 화면에 반영됐는지 확인한다.
