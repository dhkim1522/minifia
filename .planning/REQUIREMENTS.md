# Requirements: minifia

**Defined:** 2026-11-07
**Core Value:** 링크 하나로 모인 친구들이 설명 없이 정통 마피아 한 판(평균 10~15분, 참고 목표)을 끝까지 마치는 것
**입력:** `docs/playtest-v2.0-feedback.md` (v3.0 세부 결정 16건, 사용자 확정 2026-11-07)

## v3.0 Requirements

### 기본판 낮 흐름 (FLOW)

- [x] **FLOW-01**: 낮이 토론 → 투표 → 최후 변론 → 찬반 → 처형 순서로만 진행된다
- [x] **FLOW-02**: 투표는 산 사람 모두가 동시에 한 명을 고르고, 최다 득표 1명이 최후 변론에 선다. 동점이거나 아무도 고르지 않으면 그 낮은 처형 없이 밤으로 간다(결선 없음)
- [ ] **FLOW-03**: 직업 주장 배지·귓속말·순차 지목·동점 결선·마지막 3인 결전이 화면과 서버 흐름에 나타나지 않는다. 코드는 지우지 않고 한 곳의 설정으로 끈다
- [ ] **FLOW-04**: 찬반 기록 카드는 그대로 모두에게 공개된다
- [x] **FLOW-05**: 테스트 방 봇이 새 낮 흐름으로 한 판을 자동 완주한다

### 사회자 진행 (HOST)

- [ ] **HOST-01**: 단계가 바뀔 때마다 헤더 아래 자막 띠에 정통 사회자 존댓말 한 줄("밤이 되었습니다. …")이 "무슨 일이 일어나는지 + 내 할 일"을 알린다
- [ ] **HOST-02**: 자막이 바뀔 때 합성 알림음이 울리고, 소리 끄기 단추를 따른다(음성 낭독 없음)
- [ ] **HOST-03**: 지금 내가 누를 대상(이름표·단추·장소)이 빛나고, 할 일이 없는 사람에게는 지금 무슨 시간인지만 알린다
- [ ] **HOST-04**: 사회자가 도구를 부를 때("유언을 남길 수 있어요" 등) 그 도구 단추가 함께 빛난다
- [ ] **HOST-05**: 자막 문구는 받는 사람의 역할에 맞게 다르지만, 다른 사람의 역할을 드러내는 정보는 서버가 보내지 않는다

### 도구 이름표 (TOOL)

- [ ] **TOOL-01**: 화면의 모든 도구(채팅·유언·내 역할·동작·소리 등)에 한 단어 이름표가 항상 붙어 있다(결정 0051 보완)
- [ ] **TOOL-02**: 남은 시간이 막대와 숫자(초)로 항상 함께 보인다
- [ ] **TOOL-03**: 역할 확인 화면과 역할 카드에 내 목표가 한 줄로 보인다

### 낮 심부름과 목격 기록 (ERRAND)

- [ ] **ERRAND-01**: 토론 전에 40초 심부름 단계가 있고, 산 사람마다 지도 위 장소 3곳 목록을 받는다
- [ ] **ERRAND-02**: 장소 근처로 가서 누르면 처리되고, 내 진행(n/3)과 다음 장소가 보인다
- [ ] **ERRAND-03**: 심부름 중 다른 사람의 위치는 내 근처에 있을 때만 보인다. 서버가 근처 사람의 위치만 보낸다
- [ ] **ERRAND-04**: 마피아도 같은 모양의 가짜 목록을 받아 겉보기에 구분되지 않는다(방해 행동 없음)
- [ ] **ERRAND-05**: 3곳을 모두 처리한 사람은 토론 때 내 화면에 심부름 중 내 근처를 지나간 사람(장소·순서) 목격 기록을 받는다. 못 마치면 기록이 없고, 기록은 본인에게만 간다(마피아도 같은 규칙)

### 밤 흔적 (TRACE)

- [ ] **TRACE-01**: 밤에 산 사람 모두가 같은 방식으로 한 명을 고른다(시민은 효과 없는 고르기). 겉보기와 네트워크로는 역할이 구분되지 않는다
- [ ] **TRACE-02**: 피해자가 나온 아침에 사회자가 그 밤 피해자를 고른 사람 중 한 명의 흔적 하나를 공개한다. 흔적은 확정 증거가 아니고(마피아일 수도 다른 역할일 수도 있다) 역할을 드러내지 않는다
- [ ] **TRACE-03**: 아무도 죽지 않은 아침에는 흔적이 없다

### 배포 (DEPLOY)

- [ ] **DEPLOY-03**: v3.0 이 `v3` 브랜치에서 Worker `minifia-v3`(https://minifia-v3.dhplay.workers.dev)로 배포되고 v1.0·v2.0 주소는 그대로 남는다. 누설 검사가 새 메시지·단계로 넓어진 채 통과한다

## Out of Scope

| Feature | Reason |
|---------|--------|
| 음성 채팅 | 비용이 크고 친구끼리는 통화로 대신할 수 있다 |
| 실시간 액션 살해 | 짧은 판·턴제를 유지하고 증거 장치만 빌린다 |
| 판 종류 이름·고르기 화면 | 기본판 하나로 확정(세부 결정 5·8) |
| 기능 코드 삭제 | 끄기만 한다. 정통 판을 나중에 되살릴 수 있게 남긴다 |
