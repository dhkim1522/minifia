# Requirements: minifia

**Defined:** 2026-11-07
**Core Value:** 링크 하나로 모인 친구들이 설명 없이 정통 마피아 한 판(평균 10~15분, 참고 목표)을 끝까지 마치는 것
**입력:** `docs/playtest-v2.0-feedback.md` (v3.0 세부 결정 16건, 사용자 확정 2026-11-07)

## v3.0 Requirements

### 기본판 낮 흐름 (FLOW)

- [x] **FLOW-01**: 낮이 토론 → 투표 → 최후 변론 → 찬반 → 처형 순서로만 진행된다
- [x] **FLOW-02**: 투표는 산 사람 모두가 동시에 한 명을 고르고, 최다 득표 1명이 최후 변론에 선다. 동점이거나 아무도 고르지 않으면 그 낮은 처형 없이 밤으로 간다(결선 없음)
- [x] **FLOW-03**: 직업 주장 배지·귓속말·순차 지목·동점 결선·마지막 3인 결전이 화면과 서버 흐름에 나타나지 않는다. 코드는 지우지 않고 한 곳의 설정으로 끈다
- [x] **FLOW-04**: 찬반 기록 카드는 그대로 모두에게 공개된다
- [x] **FLOW-05**: 테스트 방 봇이 새 낮 흐름으로 한 판을 자동 완주한다

### 사회자 진행 (HOST)

- [x] **HOST-01**: 단계가 바뀔 때마다 헤더 아래 자막 띠에 정통 사회자 존댓말 한 줄("밤이 되었습니다. …")이 "무슨 일이 일어나는지 + 내 할 일"을 알린다
- [x] **HOST-02**: 자막이 바뀔 때 합성 알림음이 울리고, 소리 끄기 단추를 따른다(음성 낭독 없음)
- [x] **HOST-03**: 지금 내가 누를 대상(이름표·단추·장소)이 빛나고, 할 일이 없는 사람에게는 지금 무슨 시간인지만 알린다
- [x] **HOST-04**: 사회자가 도구를 부를 때("유언을 남길 수 있어요" 등) 그 도구 단추가 함께 빛난다
- [x] **HOST-05**: 자막 문구는 받는 사람의 역할에 맞게 다르지만, 다른 사람의 역할을 드러내는 정보는 서버가 보내지 않는다

### 도구 이름표 (TOOL)

- [x] **TOOL-01**: 화면의 모든 도구(채팅·유언·내 역할·동작·소리 등)에 한 단어 이름표가 항상 붙어 있다(결정 0051 보완)
- [x] **TOOL-02**: 남은 시간이 막대와 숫자(초)로 항상 함께 보인다
- [x] **TOOL-03**: 역할 확인 화면과 역할 카드에 내 목표가 한 줄로 보인다

### 낮 심부름과 목격 기록 (ERRAND)

- [x] **ERRAND-01**: 토론 전에 40초 심부름 단계가 있고, 산 사람마다 지도 위 장소 3곳 목록을 받는다
- [x] **ERRAND-02**: 장소 근처로 가서 누르면 처리되고, 내 진행(n/3)과 다음 장소가 보인다
- [x] **ERRAND-03**: 심부름 중 다른 사람의 위치는 내 근처에 있을 때만 보인다. 서버가 근처 사람의 위치만 보낸다
- [x] **ERRAND-04**: 마피아도 같은 모양의 가짜 목록을 받아 겉보기에 구분되지 않는다(방해 행동 없음)
- [x] **ERRAND-05**: 3곳을 모두 처리한 사람은 토론 때 내 화면에 심부름 중 내 근처를 지나간 사람(장소·순서) 목격 기록을 받는다. 못 마치면 기록이 없고, 기록은 본인에게만 간다(마피아도 같은 규칙)

### 밤 흔적 (TRACE)

- [x] **TRACE-01**: 밤에 산 사람 모두가 같은 방식으로 한 명을 고른다(시민은 효과 없는 고르기). 겉보기와 네트워크로는 역할이 구분되지 않는다
- [x] **TRACE-02**: 피해자가 나온 아침에 사회자가 그 밤 피해자를 고른 사람 중 한 명의 흔적 하나를 공개한다. 흔적은 확정 증거가 아니고(마피아일 수도 다른 역할일 수도 있다) 역할을 드러내지 않는다
- [x] **TRACE-03**: 아무도 죽지 않은 아침에는 흔적이 없다

### 단추 정리 (TOOL·BTN) — 16페이즈, 결정 0077

- [x] **TOOL-04**: 아이콘 단추 아래 글 이름표가 어느 화면에도 없고, 모든 아이콘 단추에 비어 있지 않은 접근성 이름이 있다(TOOL-01 을 대체)
- [x] **BTN-01**: 머리에는 정사각 44 단추만 있고(대기실 나가기·공유 / 게임 기록·내 역할), 입력줄 단추는 48 원이다
- [x] **BTN-02**: 소리·맵(방장)·봇(방장)·옷장이 오른쪽 세로 한 줄의 52 원이고 자막 띠 주변은 비어 있다. 손님에게는 맵·봇이 없다

### 심부름 화면과 컬러 에셋 (ERRAND·ASSET) — 16페이즈

- [x] **ERRAND-06**: 심부름 시작 2초 카드가 내 장소 3곳을 컬러 그림으로 보여 준다
- [x] **ERRAND-07**: 해야 할 장소가 64 타일로 보이고 가장 가까운 곳에 빛·방향 화살표가 있으며, 닿으면 그 장소 위에 [처리]가 뜨고 진행은 점 3개로 보인다(아래 독 없음)
- [x] **ASSET-01**: 장소 16·흔적 조각 9 아이콘이 승인 컬러 에셋 A 이고(다시 그리지 않고 이식) id·이름이 1:1 이다

### 심부름 증거 (ERRAND·EVID) — 16페이즈

- [x] **ERRAND-08**: 마피아가 받는 목록에 처리되지 않는 장소 1곳이 있고, 마크업·네트워크 모양·응답이 시민과 같다(0074 D-03 을 바꾼다)
- [x] **EVID-01**: 아침 흔적과 같은 옷을 입은 산 사람의 이름표에 표시가 붙고 그 낮이 끝날 때까지 유지된다
- [x] **EVID-02**: 피해자를 마지막으로 근처에서 본 사람(+장소)이 모두에게 공개된다
- [x] **EVID-03**: 사회자 문구가 근거(같은 옷·엇갈린 목격)를 가리킨다

### 튜토리얼 "첫 사건" (TUT) — 17페이즈, 결정 0078

- [ ] **TUT-01**: 첫 화면(방 코드 없는 화면)의 큰 카드 "튜토리얼 진행"으로 혼자 첫 사건을 시작하고, 끝나거나 [건너뛰기]하면 첫 화면으로 돌아온다. 한 번 본 사람에게는 작은 단추로 줄어든다
- [ ] **TUT-02**: 방장이 대기실에서 "튜토리얼 후 진행"을 켜고(첫 판 켜짐·다시 하기 꺼짐) 시작하면 모두 튜토리얼을 마친 뒤(또는 150초가 지나면) 역할 배정으로 넘어가고, 끄면 바로 시작한다
- [ ] **TUT-03**: 첫 사건이 오프닝 → 심부름·목격 → 아침 흔적↔같은 옷↔목격 → 이름표 투표·정답 → 직업 카드 4종 순으로 이어지고, 직접 누르는 곳마다 대상에 램프 빛 4px 깜빡임 테두리가 있으며 사회자는 파형+자막 띠로 말한다(배경 흐림·포인터 없음)
- [ ] **TUT-04**: 사회자 웅얼 목소리와 새 효과음이 Web Audio 합성으로만 나고(외부 파일 0), 소리 설정·소리 단추와 모션 줄이기를 따른다
- [ ] **TUT-05**: 튜토리얼은 서버 게임 상태·역할 값을 읽지도 바꾸지도 않는다. 혼자 하기는 네트워크 요청 0건, 함께 진행은 끝났음 메시지 한 가지만 보낸다

## Out of Scope

| Feature | Reason |
|---------|--------|
| 음성 채팅 | 비용이 크고 친구끼리는 통화로 대신할 수 있다 |
| 실시간 액션 살해 | 짧은 판·턴제를 유지하고 증거 장치만 빌린다 |
| 판 종류 이름·고르기 화면 | 기본판 하나로 확정(세부 결정 5·8) |
| 기능 코드 삭제 | 끄기만 한다. 정통 판을 나중에 되살릴 수 있게 남긴다 |
