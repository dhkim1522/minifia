# Requirements: minifia

**Defined:** 2026-10-21
**Core Value:** 링크 하나로 모인 친구들이 설명 없이 정통 마피아 한 판(6~10분)을 끝까지 마치는 것

> 2026-10-21 결정 0005 로 비대면 게임으로 바뀌었다: 앱 안 소통(빠른 메시지·이모티콘), 세로 폰 폭 화면, 링크 공유 참가.
>
> 원천은 `docs/product.md`(기획서)와 `docs/architecture.md`(설계서)에서 추린 `.planning/intel/` 이다. 원천에는 인수 기준이 없어서, 아래 문장은 사람이 화면에서 확인할 수 있는 동작으로 다시 썼다. 원천 ID 와의 대응은 맨 아래 "원천 대응표" 에 있다.

## v1 Requirements

MVP 요구사항. 핵심 흐름(방 만들기·참가 → 역할 확인 → 밤 → 낮 토론·투표 → 최후 변론 → 결과)을 처음부터 끝까지 잇는 데 필요한 것만 넣었다. 모든 항목은 로드맵 페이즈 하나에 대응한다.

### 방과 참가 (ROOM)

- [x] **ROOM-01**: 방장이 방을 만들면 4자리 방 코드와 참가 링크가 나오고, 공유 버튼(Web Share, 지원하지 않으면 링크 복사)으로 카카오톡 등에 바로 보낼 수 있다.
- [x] **ROOM-02**: 다른 사람은 링크나 4자리 코드로, 앱 설치나 로그인 없이 닉네임만 입력해 같은 방에 들어오고 대기실 참가자 목록에 바로 나타난다.
- [x] **ROOM-03**: 방은 4~8명을 받는다. 방장은 연결된 사람이 4명 이상일 때만 게임을 시작할 수 있고(결정 0012, 끊긴 사람도 자리에 있으면 역할을 받는다), 8명이 차면 더 들어올 수 없다.

### 연결과 재접속 (CONN)

- [x] **CONN-01**: 참가할 때 서버가 플레이어 토큰을 발급해 브라우저에 저장한다. 화면이 꺼지거나 연결이 잠깐 끊겼다가 같은 폰으로 다시 열면 같은 자리·같은 역할로 현재 단계 화면을 이어서 본다.
- [x] **CONN-02**: 연결이 끊긴 채 돌아오지 않는 플레이어가 있어도 게임은 서버 타이머대로 진행된다. 마감까지 못 보낸 투표(처형 여부·후보 선택)는 무효표로 던진 표에서 빼고, 밤 행동은 행동 없음, 직업 공개는 말 안 함으로 처리하며 이월하지 않는다(결정 0023·0034). 끊긴 사람도 생존자 수(승패 판정)에 든다. 끊긴 사람은 테이블에서 흐릿하게 보인다 (1페이즈 논의에서 확정, 4페이즈 결정 0034 로 투표 처리 개정).
- [ ] **CONN-03**: 게임 중 Screen Wake Lock 을 요청해 폰 화면이 저절로 꺼지는 것을 줄인다. 지원하지 않는 기기에서는 생략한다.

### 배포 (DEPLOY)

- [x] **DEPLOY-01**: `wrangler deploy` 한 번으로 웹 정적 파일과 서버가 Cloudflare 의 같은 주소에 배포·갱신되고, 주소는 바뀌지 않는다. 테스터는 링크만 열면 Android·iPhone 구분 없이 참가한다.

### 사회자 진행 (GAME)

- [x] **GAME-01**: 단계 전환과 타이머는 서버(방 Durable Object)가 정하고, 클라이언트는 서버가 보낸 마감 시각으로 남은 시간만 보여 준다. 정통 마피아 순서를 따르되 역할 확인 다음은 낮부터 시작한다(역할 배정 → 역할 확인 → 직업 공개 → 낮 토론 → 처형 여부 투표 → 후보 선택 투표 → 최후 변론 → 처형 → 밤 → 아침 → 직업 공개…, 결정 0007·0034), 이 요구사항은 단계 전환 틀과 첫 두 단계(역할 배정 약 3초, 역할 확인 15초)를 다룬다. 역할 배정 단계에는 모든 폰에 "직업을 배정하고 있습니다…" 가 같은 시각에 나온다 (결정 0006). 1페이즈는 역할 확인 다음 "낮" 단계 화면에서 멈추고, 나머지 단계는 아래 DAY·NIGHT·VOTE 가 같은 틀에 얹는다.

### 역할 (ROLE)

- [x] **ROLE-01**: 게임이 시작되면 서버가 인원에 맞는 구성으로 역할을 무작위 배정한다. 4명: 마피아 1·경찰 1·의사 0·시민 2 / 5명: 1·1·1·2 / 6명: 2·1·1·2 / 7명: 2·1·1·3 / 8명: 2·1·1·4. 구성표는 서버 한 곳에 두어 나중에 방장 조정(v2 ROLEX-01)으로 바꾸기 쉽게 한다.
- [x] **ROLE-02**: 역할 확인(15초) 동안 각자 폰에서 자기 역할 카드만 본다. 마피아는 같은 마피아 동료도 함께 본다. 서버는 다른 사람의 역할을 클라이언트로 보내지 않는다(화면에서 숨기는 것으로 대신하지 않는다).

### 밤과 아침 (NIGHT)

- [x] **NIGHT-01**: 밤(30초)에 마피아는 함께 한 명을 지목한다. 의견이 갈리면 표가 많은 쪽, 같으면 무작위로 정한다.
- [x] **NIGHT-02**: 경찰은 밤에 한 명을 골라 마피아인지 알아낸다. 결과는 본인 화면에만 보인다.
- [x] **NIGHT-03**: 의사는 밤에 한 명(자신 포함)을 골라 지킨다. 마피아 지목과 같으면 그 사람은 살아난다.
- [x] **NIGHT-04**: 밤 화면은 역할에 맞게 구성한다. 마피아는 동료 표시와 동료가 고른 대상을 보고, 경찰·의사는 대상을 고르고, 시민은 안내 문구만 본다. 옆에서 화면을 훔쳐보거나 캡처를 공유하는 것은 플레이어 매너에 맡긴다(결정 0018). 역할 카드의 활동 기록 탭에서 경찰은 수사일지, 마피아는 암살일지(사망/생존), 의사는 치료일지를 본인에게만 본다(결정 0026·0027).
- [x] **NIGHT-05**: 행동이 일찍 끝나도 밤은 30초 타이머가 끝날 때까지 이어진다.
- [x] **NIGHT-06**: 아침(5초)에 지난밤 결과가 모든 화면에 발표된다. 탈락자가 있으면 그 사람, 없으면 "아무 일도 없었습니다".

### 탈락 (ELIM)

- [x] **ELIM-01**: 탈락한 플레이어는 이후 투표·밤 행동·메시지 보내기를 할 수 없다. 탈락하면 유령 그림이 되고 **게임 전체를 관전한다**: 모든 사람의 실제 직업, 밤 행동(지목·조사·보호), 마피아 밤 채팅을 볼 수 있다(탈락자에게만 서버가 보낸다, 결정 0021). 살아 있는 사람은 다른 사람의 역할을 게임이 끝나기 전까지 받지 않는다. 탈락자의 테이블에서는 살아 있는 다른 사람이 실제 직업 캐릭터로 보인다(결정 0021, 3.1).

### 낮 토론과 처형 (DAY, VOTE)

- [x] **DAY-02**: 낮마다 낮 토론 전에 직업 공개 단계가 있다. 생존자가 자리 순서대로 한 명씩(한 명당 8초, 시작하는 사람은 날마다 바뀜) 직업 선택지와 [말 안 함] 중 하나를 주장하고, 시간 안에 안 고르면 말 안 함이다. 주장은 채팅에 말로 올라오고, 낮에 캐릭터를 탭하면 유저 기록 카드에서 날짜별 주장을 본다. 서버는 참·거짓을 확인하지 않는다(결정 0023이 결정 0007·0015의 동시 공개·말 바꿈 표시를 대체).
- [x] **DAY-01**: 낮 토론(90초) 동안 생존자 목록과 남은 시간이 보인다. 토론은 서버 타이머대로 끝난다(방장 연장·넘기기는 결정 0017 로 없앴다).
- [x] **VOTE-01**: 처형 여부 투표(10초)에서 생존자 전원이 찬성·반대를 고르고, 찬성·반대 수가 실시간으로 보이며 마감 전까지 번복할 수 있다. 누가 무엇을 골랐는지는 공개하지 않는다(익명, 서버는 집계 수만 보냄). 던진 표 중 찬성이 과반이면 후보 선택으로, 아니면 바로 밤으로 간다. 기권 버튼은 없고 시간 초과·연결 지연으로 못 보낸 표는 무효표로 세지 않는다. 던진 표가 없으면 처형하지 않는다(결정 0034).
- [x] **VOTE-02**: 후보 선택 투표(15초)에서 생존자 전원이 자기 자신을 뺀 한 명을 고른다. 던진 표 중 최다 득표자가 후보가 되고, 동률이면 처형 없이 밤으로 간다. 마감 뒤 누가 누구를 골랐는지 화살표와 표수로 한 명씩 차례로(무작위 순서, 서버가 순서를 정함) 공개한다.
- [x] **VOTE-03**: 최후 변론(10초) 동안 후보가 테이블 가운데로 이동해 스포트라이트를 받고 나머지 화면은 시간대에 맞게 흐려지고 어두워진다. 변론은 변론 메시지(COMM-03)로 한다.
- [x] **VOTE-04**: 처형(5초)에 후보가 탈락하고 결과가 모든 화면에 발표된다(변론 뒤 찬반은 없다). 처형된 사람의 직업은 판이 끝날 때까지 비공개다. 투표 내역은 유저 기록 카드에 날짜별로 쌓인다.

### 낮 소통 (COMM)

- [x] **COMM-01**: 낮 토론과 처형 여부·후보 선택 투표 중 생존자는 빠른 메시지를 보낸다. 템플릿에 대상 플레이어·직업을 골라 채운다(의심·신뢰, 조사 결과 주장, 변호, 투표 제안 — 직업 주장은 직업 공개 단계가 맡는다, 결정 0015). 주장의 참·거짓은 확인하지 않는다. 받은 메시지는 화면의 채팅(최근 세 줄과 채팅 내역)에 보이고 보낸 사람 이름표가 잠깐 반전된다. 서버는 메시지를 보관하지 않는다(결정 0017).
- [x] **COMM-02**: 같은 단계에서 이모티콘(6~8개)을 보내면 보낸 사람 캐릭터 위에 잠깐 떴다 사라진다.
- [x] **COMM-03**: 최후 변론(10초) 중에는 후보만 변론 메시지(템플릿 5~6개, 한 번에 하나)를 보내고, 나머지 생존자는 이모티콘만 보낸다.
- [x] **COMM-04**: 서버는 템플릿 ID 와 고른 값만 받아 단계·생존 여부·형식을 검증한 뒤 방 전체에 보낸다. 자유 텍스트는 받지 않는다. 아침·처형 중과 탈락자의 메시지는 거부하고, 밤에는 살아 있는 마피아끼리만 밤 전용 템플릿과 이모티콘을 주고받는다(다른 사람에게는 전달하지 않는다, 결정 0019). 그 밖의 사람이 밤에 보낸 메시지는 거부하고, 한 사람당 2초에 한 번으로 제한한다(화면은 보낸 뒤 2초 잠금, 서버 한도는 지터 여유로 1.8초 — 결정 0016-6, G-02-2).

### 승패와 결과 (END)

- [x] **END-01**: 밤 결과와 처형이 끝날 때마다 승패를 판정한다. 마피아가 모두 탈락하면 시민 팀 승리, 살아 있는 마피아 수가 나머지 생존자 수와 같거나 많아지면 마피아 팀 승리. 아직 아니면 다음 밤으로 이어진다.
- [x] **END-02**: 게임이 끝나면 결과 화면에 승리 팀과 모든 사람의 역할이 공개되고, 처음 화면으로 돌아가 새 방을 만들 수 있다. 같은 사람들로 바로 다시 하기는 v2.

### 분위기·캐릭터·안내 (LOOK, CHAR, UX)

- [ ] **LOOK-01**: 어두운 배경과 긴장감 있는 단계 전환 연출(밤·아침·처형 등)로 무거운 분위기를 낸다.
- [ ] **CHAR-01**: 플레이어마다 외형이 다른 단순한 2D 캐릭터를 하나씩 무작위로 받는다(한 방 안에서 겹치지 않으므로 최소 8종). 대기실·투표·결과 화면에서 닉네임과 함께 보인다. 게임 능력 차이는 없다.
- [ ] **UX-01**: 모든 단계 화면에 지금 할 일이 한 문장으로, 남은 시간과 함께 보인다.
- [ ] **UX-02**: 화면은 세로, 폰 폭(360~430px) 기준으로 짜여 한 화면 안에서 스크롤 없이 지금 할 일과 메시지 입력이 보인다. PC 브라우저에서는 가운데에 폰 폭으로 보인다.

### 플레이테스트 (PLAY)

- [ ] **PLAY-01**: 기본 타이머로 4~8명이 한 판을 마치는 데 6~10분이 걸린다(역할 확인·결과 화면 포함, 보통 2~3라운드).
- [ ] **PLAY-02**: 마피아를 처음 하는 사람도 사회자의 말로 된 설명 없이 화면 안내만으로 한 판을 따라온다.
- [ ] **PLAY-03**: 친구 4명 이상이 각자 폰으로 배포된 주소에 들어와 한 판을 끝까지 마치고, "다시 하고 싶은지"와 불편한 점을 기록한다. 그 결과로 규칙 수치(타이머·역할 구성)를 조정하고, 아래 v2 후보 중 무엇을 올릴지 정한다.

## v2 Requirements

MVP 이후 후보. 추적만 하고 현재 로드맵에는 넣지 않는다. 올릴 때는 플레이테스트 피드백(PLAY-03)이나 결정 기록을 근거로 고른다.

### 관전 (WATCH)

- **WATCH-01**: 탈락하면 관전 화면으로 바뀌고 모든 사람의 역할을 본다. 서버는 탈락자에게만 전체 역할을 보낸다. 말로 힌트를 주지 않는 것은 플레이어 매너에 맡긴다.

### 다시 하기 (REMATCH)

- **REMATCH-01**: 한 판이 끝나면 같은 사람들로 바로 다음 판을 시작한다. ("다시 하고 싶어 한다" 가 확인되면 가장 먼저 올릴 후보)

### 역할 구성 조정 (ROLEX)

- **ROLEX-01**: 방장이 대기실에서 인원별 역할 구성(마피아·경찰·의사 수)을 세부 조정한다. 기본값은 자동 구성표다 (결정 0006).

### 사운드 (SOUND)

- **SOUND-01**: 대기실·밤·낮·결과 화면별로 분위기에 맞는 배경음이 나온다.
- **SOUND-02**: 역할 공개, 밤·아침 전환, 투표 선택, 처형, 승리·패배에 효과음이 나온다.
- **SOUND-03**: 각자 폰에서 소리를 끌 수 있다.
- **SOUND-04**: 소리는 각자 폰에서 낸다(결정 0005). iOS 는 방 참가 버튼에서 오디오를 깨운다.

### 소통 확장 (COMMX)

- **COMMX-01**: 낮 토론 중 자유 채팅(글자 수 제한, 도배 방지). 플레이테스트에서 "말하고 싶은데 못 했다" 는 피드백이 나오면 올린다 (결정 0005).
- **COMMX-02**: 마피아끼리 밤에 쓰는 비밀 메시지.

### 캐릭터 확장 (CHARX)

- **CHARX-01**: 캐릭터마다 성격이 드러나는 소개 문구를 보여 준다. 게임 능력에는 영향을 주지 않는다.
- **CHARX-02**: 플레이어가 캐릭터를 직접 고른다.
- **CHARX-03**: 캐릭터 애니메이션(Rive 또는 Lottie, 디자인 방향을 정한 뒤 결정).

### 연결 보강 (CONNX)

- **CONNX-01**: 방장이 나가거나 오래 돌아오지 않으면 방장 권한을 다른 사람에게 넘긴다.
- **CONNX-02**: 오래 돌아오지 않는 플레이어를 자동으로 정리한다.

### 정식 출시 (LAUNCH) — 마지막 별도 마일스톤

- **LAUNCH-01**: 정식 이름을 정하고 상표를 확인한다.
- **LAUNCH-02**: 도메인을 정한다.
- **LAUNCH-03**: 같은 웹 코드를 Capacitor 로 감싸 Android·iOS 앱을 낸다. 웹 링크 참가는 유지한다.
- **LAUNCH-04**: 앱에 진동, 공유 시트, 알림 같은 기기 기능을 붙여 iOS 심사에 대비한다.
- **LAUNCH-05**: 스토어 심사를 거쳐 공개한다.
- **LAUNCH-06**: 수익화 여부와 방식을 정한다 (앱에서 유료 아이템을 팔면 스토어 인앱 결제를 써야 한다).

## Out of Scope

명시적으로 제외한다. 범위가 늘어나는 것을 막기 위해 이유를 적는다.

| Feature | Reason |
|---------|--------|
| 자유 채팅 (v1) | 폰 세로 화면에서 90초 토론 중 타이핑은 흐름을 끊는다. 빠른 메시지·이모티콘으로 시작하고 피드백으로 정한다 (v2 COMMX-01, 결정 0005) |
| 음성 채팅 | 비대면이지만 앱만으로 하는 것이 전제다. 음성은 범위 밖 |
| 사회자 내레이션 음성 | 원천에서 없다고 정했다. 단계 안내는 화면 문구로 한다 |
| 계정·로그인 | 닉네임만으로 참가한다. 설치·가입 없이 바로 들어오는 것이 목표다 |
| 웹 푸시 알림 | iOS 에서는 홈 화면에 추가한 경우에만 동작해서 MVP 에서 쓰지 않는다 |
| 진동 | iOS Safari 에서 동작하지 않는다. 앱으로 감쌀 때 Capacitor 로 붙인다 (LAUNCH-04) |
| TestFlight·스토어 심사·Apple 개발자 계정 | 웹 URL 공유로 플레이테스트하므로 앱 출시 단계까지 필요 없다 |
| 무거운 3D·고급 그래픽 | 웹을 감싼 앱으로는 어렵다. 2D 캐릭터·애니메이션 범위만 다룬다 |
| 능력이 다른 캐릭터 | MVP 에서 캐릭터는 외형 차이만 있고 게임 능력 차이는 없다 |
