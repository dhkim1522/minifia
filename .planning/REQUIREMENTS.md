# Requirements: minifia v2.0 같은 공간

**Defined:** 2026-10-30
**Core Value:** 링크 하나로 모인 친구들이 설명 없이 정통 마피아 한 판(6~10분)을 끝까지 마치는 것. v2.0 은 그 한 판을 "같은 공간에서 움직이고 떠들고 몸짓하며" 하게 만든다.

범위 원천: `docs/decisions/0044-v2-same-space.md`(1~24항). 리서치: `.planning/research/SUMMARY.md`. v1.0 요구사항(검증됨)은 `.planning/milestones/v1.0-REQUIREMENTS.md`.

## v2.0 Requirements

### 배포 (DEPLOY)

- [ ] **DEPLOY-02**: v2.0 은 v1.0 과 다른 Worker(`minifia-v2`)에 배포되고, 배포·검사 스크립트가 v1.0 주소를 덮어쓰거나 검사하지 않는다

### 맵과 이동 (MAP)

- [ ] **MAP-01**: 방에 들어오면 내 캐릭터가 로비 맵에 생기고, 같은 방의 모든 사람이 서로의 캐릭터와 닉네임을 본다
- [ ] **MAP-02**: 맵을 터치하면 내 캐릭터가 그곳까지 걸어가고, 다른 사람 폰에서도 같은 경로·속도로 움직여 보인다(목적지만 보내고 서버가 경로를 정한다)
- [ ] **MAP-03**: 맵은 폰 한 화면보다 조금 넓고 카메라가 내 캐릭터를 따라간다
- [ ] **MAP-04**: 단계마다 이동 가능 여부를 서버가 정한다 — 로비·낮 토론은 자유, 지목·변론·찬반은 정지, 밤은 마피아만
- [ ] **MAP-05**: 화면이 꺼졌다 켜지거나 재접속해도 모든 캐릭터가 지금 위치로 이어진다
- [ ] **MAP-06**: 방장이 로비에서 맵(지하 재즈 바 · 시계탑 광장 · 랜덤)을 고르고, 기본값은 랜덤이다. 랜덤은 서버가 게임 시작 때 정해 모두에게 같은 맵을 보낸다 (결정 0050)

### 채팅 (CHAT)

- [ ] **CHAT-01**: 로비와 낮(토론·지목·변론·찬반·처형·아침)에 살아 있는 사람 모두 하단 채팅창으로 자유 채팅한다
- [ ] **CHAT-02**: 밤에는 살아 있는 마피아끼리만 채팅하고, 그 내용과 입력 중 표시는 시민 편에게 네트워크로도 가지 않는다
- [ ] **CHAT-03**: 탈락자는 탈락자끼리만 채팅하고, 산 사람에게는 네트워크로도 가지 않는다
- [ ] **CHAT-04**: 채팅을 입력하는 동안 내 캐릭터 머리 위에 "…" 가 뜬다(같은 채널을 보는 사람에게만)
- [ ] **CHAT-05**: 서버가 글자 수·도배를 제한하고, 막힌 메시지는 보낸 사람에게 알린다. 한글 입력(조합 중 Enter)과 iOS 키보드가 채팅창을 가리지 않는다
- [ ] **CHAT-06**: v1.0 의 순차 직업 주장·빠른 메시지·텍스트 이모티콘을 없앤다

### 캐릭터와 동작 (AVTR)

- [ ] **AVTR-01**: 캐릭터는 1번 시안의 구·원통 조립 3D 인물(세트 C 인물 5명 + 머리·옷·소품 교체, 관절 동작)로, three.js 아이소메트릭 3D 맵 안에 선다 (결정 0046·0047)
- [ ] **AVTR-02**: 걸을 때 캐릭터가 걷는 동작을 하고 이동 방향으로 좌우를 돌아본다
- [ ] **AVTR-03**: 동작 목록에서 고르면 내 캐릭터가 그 자리에서 동작(목 긋기·나 아니야·박수·엉엉·악수·손가락질·최고·깜짝·춤 9종, 결정 0048 캐릭터 원본)을 하고, 같은 공간을 보는 모두에게 보인다. 이동하면 동작이 끊기고 서버가 연타를 막는다
- [ ] **AVTR-04**: 로비에서 여러 직업 의상을 눌러 갈아입고, 고른 외형은 게임 중에도 유지된다. 의상은 실제 역할과 관계없다
- [ ] **AVTR-05**: 이동을 막는 구간(지목·변론·찬반)에도 제자리 동작과 채팅은 된다

### 낮과 처형 (DAY)

- [ ] **DAY-03**: 낮 토론 중 살아 있는 사람의 과반이 "토론 끝내기" 를 누르면 바로 지목으로 넘어간다
- [ ] **DAY-04**: 지목이 시작되면 모두 가운데로 모이고, 각자 한 명을 골라 손가락으로 가리킨다. 누가 누구를 가리키는지 실시간으로 모두에게 보이고 마감 전까지 바꿀 수 있다(자기 자신은 안 됨)
- [ ] **DAY-05**: 최다 지목자 한 명이 최후 변론을 하고, 시선이 변론자에게 모인다. 동률·0표면 처형 없이 밤으로 간다
- [ ] **DAY-06**: 변론 뒤 찬반 투표로 처형 여부를 정하고, 찬성이 과반이면 처형된다
- [ ] **DAY-07**: 단계 시간 시작값은 토론 90초·지목 15초·변론 20초·찬반 10초·밤 30초이고, v1.0 의 처형 여부 → 후보 선택 → 한 표씩 공개 흐름과 고정 테이블을 없앤다

### 밤 (NIGHT)

- [ ] **NIGHT-07**: 밤이 되면 각자 토론이 끝난 자리로 돌아가고, 마피아만 맵을 움직인다. 시민 편 화면은 깜깜하고 다른 사람이 보이지 않으며, 마피아 위치는 시민 편에게 네트워크로도 가지 않는다
- [ ] **NIGHT-08**: 마피아는 대상에게 다가가 암살한다. 살아 있는 마피아가 모두 같은 대상을 골라야 확정되고, 맞추지 못하면 그 밤에는 아무도 죽지 않는다
- [ ] **NIGHT-09**: 경찰·의사는 깜깜한 화면에 비친 얼굴 목록에서 대상을 고른다
- [ ] **NIGHT-10**: 시민 편 깜깜한 화면에 발소리·심장 소리 같은 긴장 연출이 나온다. 연출은 실제 마피아 움직임과 무관하다
- [ ] **NIGHT-11**: 암살당한 사람은 깜깜한 화면에서 암살 이펙트를 본다(밤 판정이 끝난 뒤)
- [ ] **NIGHT-12**: 마피아는 확정된 암살에 익명 쪽지를 남길 수 있다

### 아침 (MORN)

- [ ] **MORN-01**: 아침에 희생자가 쓰러진 자리에 분필 윤곽이 그날 낮 동안 남는다
- [ ] **MORN-02**: 아침에 희생자의 유언과 마피아 쪽지가 공개되고, 채팅창에 카드로 남아 낮에 다시 읽을 수 있다
- [ ] **MORN-03**: 의사가 살렸으면 "누군가 살아났습니다" 만 알린다(누구인지는 비공개)
- [ ] **MORN-04**: 아침 길이는 서버가 내용에 맞춰 정한다(아무 일 없으면 짧게, 유언·쪽지가 있으면 길게)

### 유언 (WILL)

- [ ] **WILL-01**: 누구나 역할과 관계없이 언제든 유언을 쓰고 고칠 수 있고, 죽을 때(처형·암살) 모두에게 공개된다. 쓰는 동안 다른 사람에게 아무 신호도 가지 않는다

### 유령 (GHOST)

- [ ] **GHOST-01**: 탈락하면 반투명 유령이 되어 맵을 자유롭게 떠다니고, 유령은 산 사람에게 보이지 않는다(네트워크로도)
- [ ] **GHOST-02**: 유령은 모든 사람의 역할과 밤 행동을 관전한다(결정 0021 유지)

### 끝 (END)

- [ ] **END-03**: 결과 화면에서 마피아 밤 채팅과 유령 채팅이 모두에게 공개된다
- [ ] **END-04**: 판이 끝나면 서버 기록으로 재미있는 칭호를 주는 시상식이 열리고, 모두 하나 이상 받는다
- [ ] **REMATCH-01**: 결과 화면에서 "준비" 한 사람들로 같은 방에서 바로 다음 판을 시작한다(의상 유지)

### 소리 (SOUND)

- [ ] **SOUND-01**: 로비·낮·밤·결과에 분위기에 맞는 배경음이 나온다
- [ ] **SOUND-02**: 밤·아침 전환, 지목·찬반, 처형, 암살, 승패, 동작에 효과음이 나온다
- [ ] **SOUND-03**: 각자 폰에서 소리를 끄고 켤 수 있고, iOS 는 참가 버튼(재접속 때는 "소리 켜기")에서 오디오를 깨운다. 소리로만 알리는 정보는 없다

### 연결 (CONN)

- [ ] **CONNX-01**: 방장이 나가거나 30~60초 넘게 돌아오지 않으면 가장 먼저 들어온 연결자에게 방장이 넘어간다
- [ ] **CONNX-02**: 로비에서 오래 돌아오지 않는 사람을 자동으로 정리한다
- [ ] **CONN-04**: 보류한 연결 계층 경고(WR-01~04)를 고친다

## Future Requirements

다음 마일스톤 이후 후보. v2.0 팀 테스트 피드백으로 고른다.

- **ROLEX-01**: 방장이 역할 구성을 세부 조정한다
- **ROLEX-02**: 새 역할(영매·기자·연인 등)
- **CHARX-01**: 캐릭터 성격 소개 문구
- **AWARDX-01**: 플레이어끼리 투표하는 칭호
- **MODX-01**: 신고·차단·욕설 필터(공개 서비스 전)
- **LAUNCH-01~06**: 정식 출시(이름·상표, 도메인, Capacitor 앱, 기기 기능, 스토어, 수익화) — 마지막 별도 마일스톤

## Out of Scope

| Feature | Reason |
|---------|--------|
| 외부 3D 모델 파일(glTF 등) | 캐릭터는 코드로 조립한 3D 인물로 만든다 (결정 0047) |
| 상대에게 가는 동작·수락형 동작(악수 요청 등) | 동작은 모두 혼자 실행한다 (결정 0044-7) |
| 귓속말(1:1 채팅) | 사용자가 고르지 않음 |
| 근접 채팅·음성 채팅 | 앱 안 텍스트만 쓴다는 전제 (결정 0005) |
| 머리 위 말풍선에 채팅 내용 표시 | 채팅 내용은 하단 채팅창에만, 머리 위는 "…" 만 (사용자 결정) |
| 캐릭터끼리 몸 충돌·밀치기 | 좁은 폰 화면에서 길막이 된다 |
| 게임 중 의상 변경 | 의상은 로비에서만 고르고 게임 중 유지 |
| 유령과 산 사람의 상호작용 | 정보 누출 |
| 위치에 연동된 심장 소리 | 마피아 위치가 샌다 |
| 게임 중 스스로 나가기 | 승패 계산이 흔들린다. 끊김은 v1.0 처리 |
| 햅틱·진동 | 앱 전환 때 (메모리: 앱 전용 기능은 앱 전환 때) |
| 역할 구성·규칙 변경 | v2.0 은 표현 방식만 바꾼다 |
