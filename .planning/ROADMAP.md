# Roadmap: minifia

## Milestones

- 🚧 **v1.0 MVP** - Phases 1-5 (진행 중)
- 📋 **v1.1 피드백 확장** - 플레이테스트 후 REQUIREMENTS.md 의 v2 후보(다시 하기, 사운드, 관전 등)에서 골라 올린다 (후보, 페이즈 미정)
- 📋 **v2.0 정식 출시** - 정식 이름·상표, 도메인, Capacitor 앱, 스토어 심사, 공개, 수익화 결정. 마지막 별도 마일스톤 (페이즈 미정)

## Overview

폰 한 대씩 든 친구들이 링크로 들어와 정통 마피아 한 판을 끝까지 하게 만든다. 먼저 Cloudflare 에 배포된 주소에서 폰 여러 대가 같은 방에 들어가 역할을 받는 걷는 뼈대를 세우고(1), 밤과 아침(2), 낮 토론·처형·승패(3)를 차례로 얹어 한 판이 끝까지 돌아가게 한다. 그다음 무거운 분위기와 캐릭터, 설명 없이 따라올 수 있는 안내를 입히고(4), 실제 친구들과 해 보며 규칙 수치를 조정한다(5). 모든 페이즈의 검증은 배포된 주소에서 한다. v1.0 에는 사운드, 관전, 다시 하기를 넣지 않았다. 친구들의 반응을 보고 v1.1 에서 고른다.

## Phase Details

### Phase 1: 걷는 뼈대
**Goal**: 방장이 만든 방에 다른 사람들이 링크·QR·코드로 들어오고, 시작하면 각자 폰에서 자기 역할 카드만 보는 흐름이 Cloudflare 에 배포된 주소에서 돌아간다.
**Depends on**: Nothing (first phase)
**Requirements**: ROOM-01, ROOM-02, ROOM-03, CONN-01, DEPLOY-01, GAME-01, ROLE-01, ROLE-02
**Success Criteria** (what must be TRUE):
  1. Cloudflare에 배포된 주소로 폰 2대 이상이 같은 방에 들어가 역할을 받는다.
  2. 방장이 방을 만들면 4자리 코드와 QR·링크가 나오고, 다른 사람은 그중 하나로 설치·로그인 없이 닉네임만 입력해 들어와 대기실 목록에 바로 나타난다.
  3. 4명 이상 모인 방에서 방장이 시작하면 인원 구성표대로 역할이 배정되고, 각자 자기 역할 카드만 본다. 마피아는 동료 마피아도 본다. 다른 폰의 화면은 물론 네트워크 메시지에서도 남의 역할은 확인할 수 없다.
  4. 역할 확인 15초 카운트다운이 모든 폰에서 같은 시각에 끝난다. 폰 화면을 껐다 켜거나 탭을 새로고침해도 같은 자리·같은 역할로 돌아온다.
  5. 코드를 고치고 `wrangler deploy` 를 다시 하면 주소는 그대로이고 새 버전이 보인다.

**Notes**: 계획 때 정할 것 — 패키지와 버전 확정, 이탈 플레이어 처리 정책 확인(CONN-02 의 서버 타이머 진행·기권 처리 제안, PROJECT.md Key Decisions 참고). 이 페이즈의 화면은 최소한으로 둔다. 분위기와 캐릭터는 4페이즈.

### Phase 2: 밤과 아침
**Goal**: 밤이 되면 모든 폰이 같은 모양의 선택 화면을 보이고, 마피아·경찰·의사의 행동이 서로 모르게 처리되어 아침에 결과가 발표된다.
**Depends on**: Phase 1
**Requirements**: NIGHT-01, NIGHT-02, NIGHT-03, NIGHT-04, NIGHT-05, NIGHT-06, ELIM-01
**Success Criteria** (what must be TRUE):
  1. 밤 30초 동안 모든 생존자 화면이 같은 모양이고, 시민도 한 명을 눌러야 한다. 옆 사람 폰을 훔쳐봐도 누가 어떤 역할인지 알 수 없다.
  2. 마피아가 함께 한 명을 지목한다(의견이 갈리면 다수, 같으면 무작위). 경찰은 조사한 사람이 마피아인지 자기 화면에서만 본다. 의사가 지킨 사람이 마피아 지목과 같으면 그 사람은 살아난다.
  3. 모두가 일찍 골라도 밤은 30초가 다 지나야 끝난다.
  4. 아침 5초 동안 모든 화면에 탈락자 이름 또는 "아무 일도 없었습니다"가 나온다. 탈락한 사람은 선택 화면 대신 "탈락" 화면과 공개된 진행만 본다.

### Phase 3: 낮 토론, 처형, 승패
**Goal**: 아침 뒤 낮 토론, 처형 투표, 최후 변론, 찬반 투표, 처형을 거치고 승패가 나면 모든 역할이 공개되는 결과 화면으로 가서, 한 판이 끝까지 돌아간다.
**Depends on**: Phase 2
**Requirements**: DAY-01, VOTE-01, VOTE-02, VOTE-03, VOTE-04, CONN-02, END-01, END-02
**Success Criteria** (what must be TRUE):
  1. 낮 토론 90초 동안 생존자 목록과 남은 시간이 보이고, 방장만 한 번 +30초 연장하거나 토론을 넘길 수 있다. 다른 사람이 누르면 아무 일도 없다.
  2. 투표 20초에 생존자가 후보 한 명을 고르거나 기권한다. 동률이거나 기권이 최다면 후보 없이 밤으로 넘어가고, 아니면 최다 득표자가 최후 변론 20초 동안 모든 화면에 크게 보인다.
  3. 찬반 10초는 후보를 뺀 생존자만 고르고, 처형 5초에 찬성이 반대보다 많으면 탈락, 같거나 적으면 생존이 모든 화면에 발표된다. 시간 안에 고르지 않으면 기권이며, 폰을 꺼 둔 사람이 있어도 각 단계는 제때 마감된다.
  4. 마피아가 모두 탈락하면 시민 팀 승리, 마피아 수가 나머지 생존자 수와 같거나 많아지면 마피아 팀 승리로 판이 끝난다. 아직 아니면 다음 밤으로 이어진다.
  5. 결과 화면에 승리 팀과 모든 사람의 역할이 공개되고, 처음 화면으로 돌아가 새 방을 만들 수 있다.

### Phase 4: 분위기와 캐릭터
**Goal**: 화면이 무거운 분위기로 바뀌고, 플레이어마다 외형이 다른 캐릭터를 받으며, 처음 하는 사람도 설명 없이 지금 할 일을 알 수 있다.
**Depends on**: Phase 3
**Requirements**: LOOK-01, CHAR-01, UX-01, CONN-03
**Success Criteria** (what must be TRUE):
  1. 어두운 배경과 긴장감 있는 연출이 대기실부터 결과까지 이어지고, 밤·아침·처형 같은 단계가 바뀔 때 분위기가 눈에 띄게 달라진다.
  2. 8명이 한 방에 있어도 모두 서로 다른 외형의 캐릭터를 하나씩 받고, 대기실·투표·결과 화면에서 닉네임과 함께 보인다. 캐릭터에 따라 게임 능력이 달라지지는 않는다.
  3. 모든 단계 화면에 지금 할 일이 한 문장과 남은 시간으로 보인다.
  4. 지원하는 기기에서는 게임 중 폰 화면이 저절로 꺼지지 않고, 지원하지 않는 기기에서도 게임은 정상적으로 돈다.

### Phase 5: 친구 플레이테스트
**Goal**: 친구들이 각자 폰으로 배포된 주소에 들어와 실제로 한 판을 끝까지 하고, 다시 하고 싶은지와 불편한 점을 확인해 규칙 수치를 조정한다.
**Depends on**: Phase 4
**Requirements**: PLAY-01, PLAY-02, PLAY-03
**Success Criteria** (what must be TRUE):
  1. 친구 4명 이상이 각자 폰(iPhone Safari와 Android Chrome 모두 포함)으로 배포된 주소에 들어와 한 판을 끝까지 마친다.
  2. 기본 타이머로 한 판이 6~10분 안에 끝난다 (실제 소요 시간을 기록한다).
  3. 마피아를 처음 하는 사람이 사회자의 말로 된 설명 없이 화면 안내만으로 한 판을 따라온다.
  4. 참가자가 "다시 하고 싶은지"와 불편한 점을 남기고, 그에 따른 규칙 수치(타이머·역할 구성) 조정이 배포본에 반영된다. v1.1 에 올릴 후보도 정해진다.
