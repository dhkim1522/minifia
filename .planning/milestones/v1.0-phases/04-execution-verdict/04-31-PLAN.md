## 페이즈 목표

낮 토론 뒤 처형 여부 투표, 후보 선택 투표, 최후 변론, 처형을 거치고 승패가 나면 모든 역할이 공개되는 결과 화면으로 가서, 한 판이 끝까지 돌아간다 (결정 0034).

화면 E2E 의 **브라우저 쪽**: 새 화면에서 값을 읽고(readVerdict) 조작하는(투표·후보 선택·봇 투표 고정) 도우미를 만든다. 04-29·04-30 의 순수 검사가 이 값을 먹고, 04-32·04-33 의 흐름이 이 도우미를 쓴다. 배포하지 않는다(D-26).

## Claude 재량 결정

- **단일 evaluate:** 읽기는 한 번의 `page.evaluate` 에서 끝낸다(시간 경쟁 없음). 짧게 사라지는 카드(1.6초)는 폴링하지 않고 MutationObserver 로 처음·사라진 시각을 붙잡는다(`armIntroWatch` 와 같은 방식).
- **색은 토큰에서 읽는다:** 진홍·회색 색값은 문서의 CSS 변수(`--crimson-*`, `--gray-300` 등)를 브라우저가 계산한 rgb 문자열로 바꿔 lib 검사에 넘긴다 — 색 값을 스크립트에 하드코딩하지 않는다.
- **조작은 서버 확인까지:** `voteAs`·`pickCandidate`·`setBotVote` 는 클릭 뒤 추적 view(`tracker`)에서 서버가 값을 반영했는지까지 기다린다(기존 `chooseRole` 선례).
- 기존 `resetAndLeave` 는 건드리지 않는다(`ended` 에서는 쓰지 않는다 — 결과 화면은 `leaveFromResult`).
