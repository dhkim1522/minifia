## 페이즈 목표

화면이 무거운 분위기로 바뀌고, 플레이어마다 외형이 다른 캐릭터를 받으며, 세로 폰 화면에서 처음 하는 사람도 설명 없이 지금 할 일을 알 수 있다 (ROADMAP 5페이즈). 성공 기준 5: 지원하는 기기에서는 게임 중 폰 화면이 저절로 꺼지지 않고, 지원하지 않는 기기에서도 게임은 정상적으로 돈다.

이 계획은 **보이지 않는 동작 하나**(Screen Wake Lock)를 방 화면 루트에 붙인다. 화면·문구·서버는 바꾸지 않는다. 미지원 환경 E2E(`WL1`)와 요청 스파이(`WL2`)는 05-07 이 만든다.

## Claude 재량 결정

- **대기실부터 건다(P5-7 기본값, 확인 대기):** 대기실에서 화면이 꺼지면 소켓이 끊겨 친구에게 "나갔다" 로 보인다. `active` 조건 한 줄이라 바꾸기 쉽다. 05-08 이 결정 0038 에 적는다.
- **재요청은 visibilitychange 한 곳뿐:** sentinel 의 `release` 이벤트는 "잠금이 풀렸다" 는 표시(참조를 비움)로만 쓰고 재요청 트리거로 쓰지 않는다. 시스템이 탭을 가릴 때 푸는 경우는 visible 복귀에서 다시 잡힌다.
- **중복 요청 막기:** 요청이 진행 중인 동안(pending) 또는 살아 있는 sentinel 이 있는 동안 다시 요청하지 않는다.
- **오류는 삼킨다:** `request` 를 `try` 로 감싸고 거부는 `.catch` 로 받아 아무것도 하지 않는다. 로그를 남기지 않는다(E2E G4 "콘솔 오류" 가 지킨다).
