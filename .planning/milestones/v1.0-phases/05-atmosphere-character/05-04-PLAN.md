화면이 무거운 분위기로 바뀌고, 플레이어마다 외형이 다른 캐릭터를 받으며, 세로 폰 화면에서 처음 하는 사람도 설명 없이 지금 할 일을 알 수 있다 (ROADMAP 5페이즈). 성공 기준 2(8명이 서로 다른 캐릭터·닉네임과 함께)·4(폰 폭 세로 화면에서 스크롤 없이 지금 할 일과 메시지 영역).

## Claude 재량 결정

- **압축 배율 식(UI-SPEC "방식은 기하가 정한다"):** `FIT_SPAN = 2·SEAT_RY + FIG_H·DEPTH_K0 = 276.8`, 장면 높이 H < 299 이면 `f = clamp((H − TAG_H) / FIT_SPAN, TABLE_FIT_MIN_SCALE, 1)`, `ry = SEAT_RY·f`, `cy = max(ry + FIG_H·DEPTH_K0·f, H − TAG_H − ry)`(맨 앞 이름표가 장면 아래끝에 닿고 맨 뒤 머리가 0 — 하한 아래에서는 머리를 지킨다), 면 `top = cy − FELT_CY_OFFSET·f`·`height = FELT_H·f`, 캐릭터 배율 `(DEPTH_K0 + (1 − DEPTH_K0)·depth)·f`. H ≥ 299 이면 f = 1 이고 지금 식 그대로다. H = 299 에서 두 식이 cy 177 로 이어진다.
- **하한 0.78(UI-SPEC 권장 0.8 과 다름):** 권장 0.8 은 장면 240 에서 맨 앞 이름표가 3.4px 넘친다(276.8×0.8 + 22 = 243.4). 수용 기준(장면 240 에서 넘침 0)을 우선해 `(240 − 22)/276.8 ≈ 0.7876` 아래의 0.78 로 둔다. 05-08 이 결정 0038 에 차이와 이유를 적는다.
- **광장 축소 방식(P5-4, 실행자 재량):** 앉은 사람 5명 이상일 때만 수정자 `mf-join__seated--many` 를 붙여 인물 그림을 같은 비율로 줄이고(예: 48×64) 광장·입력 카드 사이 여백을 4의 배수로 줄인다. 이름표 글자 14px·최대 폭 규칙·4열 줄바꿈은 그대로다. 목표 수치: 7명일 때 360×640 문서 높이 733 → 640 이하(93px 이상 줄임), 390×664 는 69px 이상. 실제 판정은 브라우저 E2E `UX2-J`(05-06)이고, 거기서 모자라면 05-06 실행자가 이 CSS 값만 조정한다.
- **CHAR-01 은 시험만:** UI-SPEC §10 결론(고칠 것 없음)을 화면 렌더 시험으로 고정한다. 결과 화면이 직업 그림 4종을 쓰는 것(P5-8)은 바꾸지 않는다 — 시험은 결과 화면에서 "닉네임 + 자리 색 점 + 그림" 이 자리마다 있음을 본다.
