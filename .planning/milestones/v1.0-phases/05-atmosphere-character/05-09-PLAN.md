## 페이즈 목표

화면이 무거운 분위기로 바뀌고, 플레이어마다 외형이 다른 캐릭터를 받으며, 세로 폰 화면에서 처음 하는 사람도 설명 없이 지금 할 일을 알 수 있다 (ROADMAP 5페이즈).

**마지막 계획이다.** 5페이즈 결과를 개인 Cloudflare 계정에 배포하고, 배포본에서 스모크·테스트 방 UAT·화면 E2E 로 이 페이즈를 증명한 뒤, 증명이 끝난 요구사항만 완료로 표시한다. 실기기 확인은 사용자 결정대로 모든 개발이 끝난 뒤 한 번에 하므로 목록으로만 남긴다(통과 표시 없음).

## Claude 재량 결정

- **배포 체크포인트 없음:** 3·3.1페이즈 마지막 배포 계획(03-12·03.1-14)과 같이 자동으로 배포한다. 4페이즈의 go-ahead 체크포인트는 서버 웨이브 단독 배포를 막는 D-26 때문이었고 이 페이즈에는 서버 변경이 없다. 배포 계정·Worker 이름 확인이 precondition 이다.
- **긴 실행은 백그라운드로:** 스모크(인원별 3~4분)·E2E(네 크기 + 고정 흐름, 약 8~12분)는 Bash 한 호출 제한(10분)에 닿을 수 있어 백그라운드로 돌리고 완료 알림 뒤 결과 줄만 읽는다.
- **실패 시:** 앱 결함이면 `fix(05-09): …` 로 고치고 시험을 더한 뒤 재배포 한 번(이 계획의 연장, SUMMARY 기록), 영향받은 검사를 다시 돈다. 두 번째 재배포부터는 멈추고 사용자에게 알린다. 도착 편차·소켓 끊김 같은 이 PC 네트워크 간헐 실패는 같은 검사를 단독으로 최대 두 번 더 돌리고 모든 결과를 적는다(한도 500ms 불변, 04-35). 기준 수치는 낮추지 않는다.
