## Phase Goal

로비부터 자유롭게 채팅하고, 밤 마피아 채팅과 탈락자 채팅이 다른 편 폰으로는 네트워크로도 가지 않는다(입력 중 표시 포함, 성공 기준 1·2).

이 계획은 서버의 트레이서다. 새 와이어 메시지 하나(입력 중)를 보낸 사람 상태 → 채널 → audience → deliver → 소켓까지 한 길로 잇고, 위치(world) 전송도 같은 길로 옮긴다. 07-11 이 이 길 위에 채팅 줄을 얹는다.

<objective>
`typing` 클라이언트·서버 메시지를 와이어 유니온·스키마에 넣고, DO 에 `deliver(ids, msg)`·`handleTyping`(단계 키 대조·채널 결정·1.5초 간격)·`emitWorld` 의 audience 전환을 더한다. buildView 에 `me.chat` 을 싣고, 연결 훅의 세 곳에 typing 을 더한다. 누설 검사를 입력 중과 me.chat 으로 넓힌다.

Purpose: CHAT-04(입력 중 "…", 같은 채널에만)와 audience 아키텍처를 채팅 줄보다 먼저 끝까지 증명한다.
Output: 와이어·DO·뷰·연결 훅 변경, worker 테스트 파일 신규, 누설 검사 확장.
</objective>
