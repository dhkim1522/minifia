## Phase Goal

낮 토론이 맵 위에서 열리고 지목 → 변론 → 찬반 → 처형이 정통 순서로 돌며, 처형된 사람은 유령이 되어 끝까지 지켜본다.

이 계획은 유령 화면이다(성공 기준 5): 탈락한 사람은 반투명 유령으로 맵을 떠다니며 모든 사람의 역할을 보고, 산 사람 화면에는 유령의 흔적이 없다. 서버 쪽 전송 분리는 08-09 가 증명했다.
