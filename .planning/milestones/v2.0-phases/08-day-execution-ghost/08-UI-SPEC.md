# Phase 8 — UI Design Contract (낮 처형과 유령)

> 화면·상호작용 계약서. 요구사항 DAY-03, DAY-04, DAY-05, DAY-06, DAY-07, MAP-04, GHOST-01, GHOST-02 의 화면 몫.
> 범위는 **(1) 낮 토론·지목·최후 변론·찬반·처형이 3D 맵 위에서 도는 게임 화면 틀(v1.0 고정 테이블 화면을 지우고 6페이즈 맵 틀로 교체), (2) 토론 끝내기·지목(손가락 + 득표 배지 + 선두·과반 연출 + 위 알림 + 채팅 기록)·변론·찬반·결과 알림·처형 연출, (3) 유령(반투명·떠다님·모든 역할이 보임·유령 채널), (4) 테이블 삭제로 갈 곳이 사라지는 밤·아침의 임시 맵 틀**이다. 마피아가 맵을 걷는 밤, 시민 편 어둠, 아침 현장·유언·쪽지, 동작(캐릭터 몸짓), 결과 화면 탭·시상식은 9~11페이즈 몫이고 이 문서가 정하지 않는다(자리만 남긴다).
> **가장 중요한 규칙(결정 0051, CLAUDE.md)**: 글은 최소로, 보고 누르는 조작 중심. 이 페이즈의 정보는 **장면(모이는 자리·조명·손가락·표정) → 숫자 배지·점·아이콘 → 글** 순서로 보여 준다. 새로 읽게 하는 글은 단계 이름 + 안내 한 줄, 결과 알림 한 줄(36px), 채팅 기록 짧은 줄뿐이다. 지목은 이름표를 **직접 누르고**, 찬반은 **엄지 두 개**, 토론 끝내기는 **아이콘 + 점**이다.

디자인 방향 한 줄: 6~7페이즈 "같은 공간의 스산한 밤"을 그대로 잇는다. 낮이어도 명도·채도를 낮게 두고(`sky-overcast`·재즈 바 실내), 단계는 밝기가 아니라 **조명 상태**(영업 중 → 무대 조명 → 실내등 절반 → 한 줄기 빛)로 나눈다. 놋쇠는 공개 투표(배지·도장·선두 줄)에만, 진홍은 이 페이즈의 낮 화면에 쓰지 않는다(마감 5초 숫자만 예외).

참고 자료와 다르게 하는 곳(이유 포함)
1. 승인 지목 이름표 버튼은 안쪽 여백 8 / 바깥 -8 이다. 제품은 **11 / -11** 로 한다. 이유: 이름표 높이 약 24 + 8×2 = 40 이라 누르기 최소 44(`tap-min`)에 모자란다. 6페이즈 `.mf-world__kick` 과 같은 값이다(이름표 모양은 그대로).
2. 승인 `Vote` 보드는 처음 3초 깜빡임을 **매 지목마다** 보인다. 제품은 **그 사람이 처음 보는 지목 한 번만** 보인다(`localStorage` 키 `mf-hint-point`, 6페이즈 `mf-hint-walk` 와 같은 방식). 이유: 결정 0051-5 "처음 하는 사람에게만 손짓". 기록이 없거나 저장이 안 되면 보인다.
3. 승인 `Ghost` 보드 제목은 '유령' 이다(밤 화면). 제품은 낮 단계에서 **단계 제목을 그대로 두고** 안내 줄만 유령 문구로 바꾼다. 이유: 유령도 지금이 지목인지 찬반인지 알아야 한다.
4. 승인 보드의 시간 링·단계·문구는 시연용 순환(`reset()`)이다. 제품은 **서버 단계와 마감 시각만 따른다**(화면은 스스로 단계를 넘기지 않는다).
5. 승인 보드의 채팅 기록은 최근 5줄 시안이다. 제품은 7페이즈의 고정 `LOG_H`(96/152)와 100줄 흐름을 그대로 쓴다.
6. 승인 `README` 의 채팅 문장 예시("민준 님이 도윤 님을 지목했어요")는 쓰지 않고 **승인 `Vote` 보드와 결정 0049-3·0051-7 의 짧은 형식("민준 → 도윤")** 을 쓴다. 이유: 글 최소, 8명이 15초 안에 몰리면 문장은 기록 칸을 밀어낸다.

- 가운데 고정 단계의 구도 규칙: 8명의 **이름표 상자**(뒤 캐릭터 머리 꼭대기 − 쌓임 높이 ~ 앞 캐릭터 머리 꼭대기)를 스테이지 사각형 가운데에 둔다. 몸까지 들어가면(스테이지 ≥ 약 380) 앞 캐릭터 발까지 포함한 상자를 가운데에 둔다. 이름표가 몸보다 우선이다 — 지목은 이름표를 눌러야 하기 때문이다. 근사 치수(58.2 px/unit, 카메라 고도 약 35°, 모이는 원 반지름 2.5): 원의 세로 폭 약 170, 캐릭터 키 약 80, 쌓임 높이는 지목 중 산 사람 최대 약 122(입력 중 26 + 도장 32 + 배지 40 + 이름표 24), 유령 화면 최대 약 154. 이름표 상자 최대 약 295(유령 약 327).
- 위 표에서 스테이지가 300 이상이면 지목·변론에서 8명의 이름표가 모두 들어간다(지목·변론은 채팅 패널이라 360×560 도 310). 300 미만은 알려진 한계다 — 찬반 투표자 360×560 의 199 가 그렇다. 다만 찬반은 이름표를 누르지 않고 쌓임도 이름표 + 체크 + 입력 중(약 50)뿐이라 필요한 상자가 약 220 이고, 360×640(279)부터는 들어간다.
- 폭: 8명 둘레의 가로 폭 약 290 + 양끝 이름표 반폭 → 폭 360 폰에서 양끝 이름표가 가장자리에서 잘릴 수 있다(8자 이름표 약 174~202). 6~7페이즈 "이름표 폭 일단 허용"과 같은 알려진 한계로 두고 고치지 않는다(진행에 지장 없음).

### 지목 (DAY-04, MAP-04)

모이기
- 지목이 시작되면 서버가 산 사람 각자의 자리를 정해 구간으로 보낸다. 화면은 평소 이동과 같은 걷기로 가운데 둘레 8곳(최대)에 서는 것을 보여 준다. 걷는 동안 이름표는 따라간다. 가운데 둘레에 선 뒤 몸은 가운데를 향한다. 카메라는 가운데로 `dur-slow` 이동.
- 이동 요청은 서버가 막는다. 화면은 맵 탭에 목적지 링을 띄우지 않는다(입력 면은 비활성). 맵 탭은 키보드만 닫는다(7페이즈 D4).

지목 조작
- **이름표 = 버튼**(`<button type="button">` 안에 `HeadStack`): 누르기 영역 44×44 이상(안쪽 여백 11·바깥 -11, 이름표 모양은 그대로). 나를 뺀 **산 사람**만 버튼이다. 내 이름표는 일반 이름표(안쪽 테두리 `me`)다. 유령에게는 모두 일반 이름표다.
- 누르면 즉시 내 이름표를 가리킨 사람 표시로 바꾸고(`mine`: 이름표 면 `gray-100`, 글자 `night-900`) 이전에 고른 사람은 `mine` 을 푼다. 같은 사람을 다시 눌러도 변하지 않는다(취소 없음 — 바꾸기만). 마감 전까지 얼마든지 바꿀 수 있다.
- 접근성: 버튼 이름 "{닉네임} 님 가리키기", 내가 고른 버튼 `aria-pressed="true"`. 8개 버튼을 `role="group"` `aria-label="지목"` 으로 묶는다.
- 처음 보는 지목 한 번만: 누를 수 있는 이름표가 처음 3초 깜빡인다(`blink`, 0.9초 × 3). 한 번 보고 나면 `mf-hint-point` 에 기록해 다시 보이지 않는다. 내가 누르면 즉시 멈춘다.

손가락
- 누가 누구를 고르면 **고른 사람 캐릭터가 지목받은 사람 쪽으로 몸을 돌려 손가락을 뻗는다**(`point` 손 모양). 고른 사람은 마감까지 가리킨 채 유지한다. 바꾸면 새 대상으로 `dur-fast`(180ms) 안에 돌려 가리킨다. 앉는 자리는 몸을 돌리지 않는다(승인 결정 0049-1 — 여기서는 서 있으므로 몸을 돌린다). 다른 사람에게 보이는 이 동작은 서버가 보낸 지목 상태에서 그린다(내 것은 눌렀을 때 즉시 그리고 서버 값과 다르면 되돌림).
- 지목을 한 번도 안 한 사람은 손을 내린 채 선 모습이다. 바닥 선·머리끼리 잇는 선·투표 장치는 맵에 없다.

득표 배지 · 선두 · 과반 (결정 0049)
- 지목받은 사람 머리 위 쌓임에 `VoteBadge`(1표 이상). 면 `overlay-ink-strong`, 테두리 `brass-400` 2px, 반경 12, 숫자 크림 `cream-100` 명조 22 + "표" `brass-400` 12. 처음 나타날 때 `dur-pop`(260ms)에 튀어나온다. 숫자가 바뀔 때는 같은 자리에서 숫자만 바뀐다(재등장 없음).
- **선두**(최다 득표가 **한 명**): 그 배지가 1.18 ↔ 1.34 로 `dur-pulse`(1.1초)마다 뛰고 크림 빛 번짐. 그 사람 위로 점광(0.9)이 모이고, 그 캐릭터가 **당황 표정 + 손사래(`deny`) 한 번**(선두가 그 사람으로 바뀔 때마다 한 번). 동점이면 선두 효과를 푼다(배지는 평범한 크기로 남음). 선두가 바뀌면 효과가 새 선두로 넘어간다.
- **과반**(득표 ≥ `⌊산 사람 ÷ 2⌋ + 1`): 선두 배지 위에 **"유력" 도장**(`SureStamp`, 명조 15 `brass-200`, 테두리 `brass-400`, -10° 기울임, `dur-med`(420ms) 동안 떨어지며 찍힘) + 실내등 절반 + 카메라 다가감(스테이지가 충분할 때). 과반이어도 마감까지 계속 바꿀 수 있고, 과반이 풀리면(바꿔서) 도장·조명이 원래대로 돌아온다(A3).
- `z-index`: 선두 이름표를 다른 이름표 위로(`z-tags` + 10).
- 위 연출은 모두 산 사람과 유령이 똑같이 본다(공개 정보). 역할마다 같아야 하므로 진홍·역할 표식이 없다(유령 화면의 `RoleChip` 제외).

위 알림 · 채팅 기록
- 지목이 생길 때마다 `TopToast` 한 줄: 아이콘 `point` + "민준 → 도윤"(바꾸면 "민준 → 도윤 (바꿈)"), `dur-toast`(1.5초). 쌓지 않는다. 몰릴 때: 400ms 안에 **같은 대상**을 가리킨 표는 "지호·민준 → 도윤" 으로 합친다(이름은 최대 3명 뒤 "…"), 서로 다른 대상이 대기하면 줄을 세워 하나씩 보여 주고 대기가 2건 이상이면 건당 0.8초로 줄인다(대기 최대 4건, 넘치면 토스트에서만 건너뛰고 채팅 기록에는 모두 남긴다).
- 채팅 시스템 줄: `vote` 종류, 앞에 `point` 아이콘, "민준 → 도윤"(바꿈은 "(바꿈)"). 선두가 바뀔 때 `hot` 줄 "{이름} 님이 앞서요", 과반 달성 때 `hot` 줄 "{이름} 님 과반". 동점이 되어 선두가 사라지면 줄을 만들지 않는다. 이 줄들은 **공개 정보에서 화면이 만든다**(입장·퇴장 줄과 같은 방식). 재접속 때 복원되지 않는다(7페이즈 시스템 줄 규칙과 같음).
- 지목 시작 시스템 줄: "지목 시작"(`system`, 아이콘 없음). 마감 때 결과 줄은 "최후 변론" 단계의 첫 줄이 이어받는다(아래).

마감
- 마감에 득표 최다 **한 명**이면 최후 변론으로. 동점이거나 0표면 "처형 없음"(아래 "처형 없음 경로")으로 밤으로 간다.

### 최후 변론 (DAY-05)

- 변론자가 가운데 무대로 걸어 나와 선다. 나머지는 둘레에 선 채 가운데를 바라본다. 실내등 5% + `light-spot` 한 줄기 + 원뿔 빛(시선이 변론자에게 모임). 카메라는 가운데 고정.
- 변론자 이름표 위: **"5표" 배지 + "유력" 도장 유지**(지목 때 받은 득표). 다른 이름표의 배지·도장은 사라진다(승인 `trialOthers` 보드와 같음).
- 헤더 안내: 변론자 아닌 사람 "{닉네임} 님의 변론", 변론자 본인 "해명할 시간이에요", 유령 "모두의 직업이 보여요".
- 채팅 첫 줄: `hot` "{이름} 님 {N}표 · 최후 변론". 아래 패널은 채팅(변론자 포함 모두 쓴다. 변론자의 줄도 평범한 `player` 줄이다 — 별도 강조 없음). 행동 줄 없음. 변론자는 채팅으로 호소한다(감정표현은 10페이즈).
- 유령은 평소처럼 읽고 유령 채널로 쓴다.

### 찬반 (DAY-06)

- 변론자가 가운데에 선 채(`toCenter`), 긴장 1단계. 아래 패널 위쪽:
  - **변론자가 아닌 산 사람**: `VerdictPicker` — 엄지 위 "찬성"(`thumbUp`) / 엄지 아래 "반대"(`thumbDown`) 2칸, 높이 84, 아이콘 32 + 한 단어, 고른 쪽 면 `gray-100` + 글자 `night-900`, 안 고른 쪽 `night-700`. 마감 전까지 바꿀 수 있다. 그 아래 `DotProgress`(`label` "투표한 사람", total = 산 사람 − 1). 진홍·놋쇠 색 금지(찬반은 역할마다 같아야 함).
  - **변론자 본인 · 유령**: `VerdictPicker` 없이 `DotProgress` 만. 헤더 안내는 변론자 "결과를 기다려요", 유령 "모두의 직업이 보여요".
- **투표한 사람 표시**: 투표를 마친 사람의 이름표에 체크(`check` 16, `label` "투표함")가 붙는다. 무엇을 골랐는지는 어디에도 나오지 않는다. 내가 고른 것은 내 화면의 `VerdictPicker` 에만 보인다.
- 모두 투표했거나 마감이 되면 **결과 알림 "찬성 5 · 반대 2"**(36px, 숫자만 — 누가 무엇을 골랐는지 없음)과 채팅 `hot` 줄 같은 내용. 투표가 끝난 뒤 `VerdictPicker` 는 `disabled`(불투명도 0.45).
- 찬성이 변론자를 뺀 산 사람의 절반을 넘으면 처형, 아니면 "처형 없음".

### 결과 알림 · 처형 (DAY-06)

- **결과 알림** 틀(모든 단계 공용): 화면 가운데 위 240 에 36px 700 `gray-50` 한 줄, 뒤 맵을 `night-950` 62% 로 어둡게(`dur-med`), `role="status"`, 나타날 때 `translateY(10px)` → 0 + 페이드 600ms. 한 줄은 폭 358 에 들어가는 문구뿐이다(가장 긴 "찬성 5 · 반대 2", "{8자 닉네임} 님 처형"이 36px 로 한 줄이 안 되면 28px 로 줄이지 말고 두 줄로 감는다 — `keep-all`).
- 알림 종류: "낮이 되었습니다"(낮 시작), "찬성 {n} · 반대 {m}"(찬반 결과), "{닉네임} 님 처형"(처형), "처형 없음"(처형이 안 된 경우), 밤·아침 임시 틀의 알림(아래).
- **처형**(5초): 처형 알림이 뜨는 동안 변론자 캐릭터가 **반투명(불투명도 0.6)으로 변하며 위로 떠오른다**(+1.2 단위, 1.4초) → 이어서 2.4초까지 불투명도 0 으로 사라진다. 이름표도 같이 흐려지며 사라진다. 이 연출은 처형 이벤트 하나로 화면이 직접 그린다 — **서버가 산 사람에게 유령의 위치·움직임을 보내는 것이 아니다**. 연출이 끝나면 산 사람 화면에는 그 사람이 영영 없다(GHOST-01).
- **역할은 알리지 않는다**(결정 0053-2): 알림·채팅·이름표 어디에도 역할이 없다. 처형된 본인은 이 순간 유령이 되어 모든 역할을 보게 된다(아래 유령).
- 채팅 `hot` 줄 "{이름} 님 처형". 찬성·반대 줄은 찬반 결과 때 이미 남겼으므로 처형 때 다시 만들지 않는다.
- 처형 단계 끝에 밤(임시 틀)으로.

### 처형 없음 경로

- 지목 동률·0표 → 지목 마감 직후 결과 알림 **"처형 없음"**(1.4초) + 채팅 시스템 줄 "처형 없음" → 밤. 찬반 부결 → 결과 알림 "찬성 2 · 반대 5" 다음 **"처형 없음"**(1.4초) + 같은 줄 → 밤.
- 알림 시간은 서버 단계 마감을 해치지 않는 안(단계 끝 1.4초 또는 다음 단계 시작 1.4초)으로 플래너가 정한다. 화면은 서버가 보낸 결과(처형 여부, 찬성·반대 수)가 오면 바로 알림을 띄운다.
- 변론자(부결 시)는 가운데에서 둘레 자리로 돌아와 밤을 맞는다(걷기 연출, 서버가 구간으로 보냄).

## 유령 (GHOST-01, GHOST-02)

산 사람 화면에는 이 절의 어떤 것도 만들어지지 않는다(DOM·메시지 모두). 서버가 유령 audience 에게만 보낸다.

### 모양 (승인 `Ghost` 보드 그대로)

| 항목 | 값 |
|------|----|
| 불투명도 | 캐릭터와 이름표 판 모두 0.6 (`away` 0.55 와 같은 방식). 글자 대비가 4.5:1 에 모자라면 이름표 면만 0.8 로 올린다 — 검증 단계에서 측정(`H` 묶음) |
| 떠다님 | 땅에서 +0.35 단위 띄우고 `sin(2t) × 0.08` 로 흔들림(주기 약 3.1초). 모션 줄이기면 띄우기만, 흔들림 없음 |
| 발밑 | 그림자 타원 없음(떠 있음) |
| 자기 자신 | 내 이름표는 일반 `me` 안쪽 테두리. 내 캐릭터는 다른 유령과 똑같이 반투명 |
| 이름표 쌓임 | 모든 이름표 위에 `RoleChip`(지름 28, 마피아만 `crimson-400` 테두리 + `crimson-300` 페도라, 나머지 `gray-300` 테두리). 쌓임 순서 입력 중 → 직업 → 도장 → 배지 → 이름표 |

### 움직임 · 입력 (A4)

- 유령은 **모든 단계에서 맵을 걸어 다닐 수 있다**(탭 → 목적지 링, 6페이즈와 같은 입력). 걷기 가능 칸(벽·가구 마스크)은 산 사람과 같고 사람 캐릭터와는 겹쳐도 된다. 유령끼리의 위치·움직임만 서로 보인다.
- 카메라: 낮 시작·낮 토론·아침·밤은 내 유령을 따라가고, 지목·변론·찬반·처형은 가운데 고정(산 사람과 같음). 걷고 있어도 고정 카메라는 안 따라간다.
- 지목·찬반·토론 끝내기 버튼 없음. 이름표는 일반 이름표(누를 수 없음). 감정표현 칸 없음(승인 `Ghost` 보드 `emotes` 비움).
- 채팅은 7페이즈 그대로: 입력줄 "유령끼리만 보여요" + `ghost` 아이콘, 기록은 산 사람 `all` 줄 + 밤 마피아 줄(진홍 이름 + `roleMafia`) + 유령 줄(`ghost` 아이콘)이 시간순 한 흐름. 유령의 입력 중 "…" 도 유령끼리만 보인다.

### 유령이 되는 순간

- **처형**: 위 처형 연출 동안 본인 화면이 먼저 바뀐다. 알림 "{내 닉네임} 님 처형"을 보고, 이름표들 위에 `RoleChip` 이 `dur-med` 에 나타나며, 채팅에 시스템 줄 `ghost` + "유령 채팅 · 산 사람에게 안 보여요"(7페이즈 문구), 헤더 안내는 "모두의 직업이 보여요"(2.5초). 하단 패널은 유령 채널 입력으로 바뀐다(`view.me.chat` 이 기준).
- **밤에 당함**(임시 틀): 아침 알림을 본 뒤 같은 모양으로 바뀐다(밤 암살당한 사람의 깜깜한 화면 연출은 9페이즈).
- 본인이 처형된 순간 이전 판 진행 중 채팅 기록은 그대로 남고, 새 줄만 유령 규칙을 따른다.

### 산 사람 쪽 규칙 (UI 계약, 검사 대상)

- 산 사람 DOM 에 `[data-ghost-seat]`·`[data-role-chip]` 가 0건이어야 한다. 산 사람 화면의 이름표는 산 사람 것뿐이다.
- 산 사람 화면 번들 문자열·DOM 에 유령 채널 문구("유령끼리만 보여요", "유령 채팅")를 미리 넣지 않는다 — 유령 분기 안에서만 꺼낸다(7페이즈 T-07-08 방식).
- 유령이 입력 중이어도, 걸어도, 가만히 있어도 산 사람 소켓이 받는 프레임 열이 같다(메타모픽 비교는 서버 테스트 몫).

## 밤 · 아침 임시 틀 (A1, 9페이즈가 대체)

테이블이 사라지므로 밤·아침도 맵 위에서 돌아야 판이 끝까지 돈다. 이 페이즈는 **v1.0 밤 규칙을 그대로 쓰고 화면만 맵으로 옮기는 최소 틀**이다. 마피아가 걷는 밤, 시민 편 어둠, 분필 윤곽, 유언·쪽지, 의사 구출 공개 변경은 9페이즈다.

밤
- 맵을 밤 조명으로 바꾼다. 아무도 걷지 않는다(이동 막힘). 헤더 제목 '밤', 시간 30초 링.
- 대상 선택은 **이름표 직접 누르기**(지목과 같은 이름표 버튼·`mine` 표시·발밑 고리). 행위자는 산 마피아(채팅 패널 + 헤더 안내 "없앨 사람을 눌러요"), 산 경찰·의사(아래 알약 `NightPanel` 의 v1.0 문구 그대로). 마피아의 선택은 같은 마피아 본인 화면에만 보이는 발밑 고리(진홍 `crimson-500`)로, 경찰은 `seat-1` 색 고리, 의사는 `seat-3` 색 고리(승인 `Ghost` 보드 값 그대로)다. 시민은 선택이 없고 아래 알약 "밤이 되었어요 / …"(v1.0 문구).
- 선택 가능한 대상은 v1.0 규칙을 따른다(서버). 서버가 선택을 거절하면 `TopToast` "보내지 못했어요. 다시 해 보세요" 후 서버 값으로 되돌림.
- **유령은 밤 행동을 본다**(GHOST-02): 서버가 유령에게만 보내는 선택(`spectate.picks`) 만큼 해당 대상 발밑에 같은 색 고리가 뜬다. 산 사람 화면에는 고리가 없다.
- 하단: 산 마피아 = 채팅(마피아 채널, 7페이즈), 유령 = 채팅(유령 채널), 산 시민·경찰·의사 = `NightPanel` 알약(채팅 없음, 7페이즈 규칙).

아침
- 맵을 아침 조명으로 바꾸고 36px 알림 한 줄. 문장은 v1.0 `morningCardText` 를 그대로 쓴다("{닉네임}님이 …" / "아무 일도 없었습니다"). 분필·유언·쪽지는 없다.
- 하단: 채팅(산 사람 `all`, 탈락자 유령 채널 — 서버가 이미 받는다, 07 D1 이월 해소).
- 밤에 당한 사람은 아침 알림 뒤 유령이 된다. 산 사람 화면에서 그 캐릭터는 알림과 함께 사라진다(떠오름 연출 없음, 암살 이펙트는 9페이즈).
- 이 임시 틀의 문구는 모두 v1.0 문구 표(`NIGHT_PANEL_TEXT`·`eliminationText`)에서 가져온 것으로 새 문구를 만들지 않는다.

## 머리 위 쌓임 (HeadStack 확장)

위에서부터: `typing`(입력 중 알약, 22 + 간격 4) → `RoleChip`(**유령 화면만**, 28 + 4) → `SureStamp`(약 28 + 4) → `VoteBadge`(약 36 + 4) → 이름표(약 24). 바닥 가운데를 캐릭터 머리 꼭대기에 `translate(-50%, -100%)`. 이름표 층 위치·순위는 6페이즈 런타임이 쓴다(내 이름표 맨 위, 나머지 발 y 순서, 겹친 맨 앞 하나만 `overlay-ink-strong`). 선두 이름표는 `z-tags` + 10.

| 속성 | 켜지는 때 | 모양 |
|------|-----------|------|
| `typing` | 7페이즈 규칙 | 알약 |
| `role` | 유령 화면의 모든 이름표 | `RoleChip`. 접근성 이름은 유령 분기 안에서만 만든다(예: "마피아") |
| `sure` | 지목 과반, 최후 변론 중 변론자 | "유력" 도장 |
| `count` / `lead` | 지목 득표 ≥ 1 / 최다 한 명, 변론 중 변론자의 득표 | 배지 / 맥박 |
| `mine` | 지목·밤 선택에서 내가 고른 이름표 | 면 `gray-100`, 글자 `night-900` |
| `done` | 찬반에서 투표를 마친 사람 | 이름표 뒤 체크 16 |
| `blink` | 처음 보는 지목의 처음 3초 | 이름표 깜빡임 |

- 닉네임은 말줄임 없음(nowrap, 6페이즈). 쌓임이 길어지면(유령 최대 약 154) 위로만 늘고 이름표 아래 끝 위치는 변하지 않는다.
- 접근성: 이름표 층 전체가 `aria-hidden` 이다(7페이즈). 지목 단계의 이름표 버튼과 `RoleChip` 의 읽을 이름만 예외로 `aria-hidden` 밖에 둔다(버튼은 그룹으로 읽힘).

## Copywriting Contract

해요체, 짧게, 마침표 없음, 진행 중은 `…`, 이모지·느낌표 없음, 사람은 "{닉네임} 님". **3초 규칙**: 한 화면에서 읽을 글은 단계 이름 + 안내 한 줄뿐이고, 나머지는 장면·숫자·아이콘이다.

|---------|------|

| Primary CTA — 지목 | 글자 없음. 이름표를 직접 누른다. 접근성 이름 "{닉네임} 님 가리키기" |
