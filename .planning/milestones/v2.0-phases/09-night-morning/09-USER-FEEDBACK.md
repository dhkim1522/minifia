# 9페이즈 사용자 테스트 피드백 (2026-11-03, 배포본 b0b9b3dd)

> 처리 방식: 묶음 A(편의·버그)는 9페이즈 보완 계획으로, 묶음 B(연출·에셋)는 시안을 거쳐 별도 페이즈로 한다. 코드 리뷰 WR-01·WR-02·IN-01(`09-REVIEW.md`)도 묶음 A 와 함께 고친다.

## 묶음 A — 편의·버그 (9페이즈 보완 계획)
1. 채팅 입력 중일 때 말풍선 "…" 이 안 떠서 입력 중인지 알 수 없다
2. 시작 버튼: 참여 인원을 "n / n" 으로 보이게 하고, 시작 인원 전에는 회색 비활성, 최소 인원이 되면 활성
3. 역할 카드를 고를 때 배경이 v1 배경 에셋으로 나온다
4. 모든 시간대의 남은 시간을 역할 카드처럼 노랑 → 빨강으로 임박 표시
6. 게임 종료 후 [처음으로] 등 버튼이 스크롤을 내려야 보인다 → 한 화면에
7. 역할 카드 하단 공백이 크다 → 보이는 영역까지만 카드가 올라오게
10. 봇 닉네임을 1~8자 규칙 안에서 길이를 랜덤으로
11. 낮 유언 버튼 위치 → **입력줄 오른쪽 끝** `[입력칸][▶][✎]`
13. 인원 카운팅 UI 를 점(채움/빈 점)에서 **숫자 "1 / 5"** 로 모든 곳에서 일괄 변경

## 묶음 B — 연출·에셋 (시안 → 별도 페이즈)
5. 낮 처형 투표가 갑작스럽고 너무 빨리 지나간다 → 화면 전환 → 가운데 모임 → **실제로 한 명씩 차례로 지목**. 한 명 8초(기본값), 못 고르면 기권, 봇은 즉시. 규칙 변경이므로 새 결정 기록이 필요하다
8·9. 죽으면 불투명 대신 **직업 의상을 입은 유령**으로 변한다(머리 위 표식 대신). 3D 의상 4종(마피아·경찰·의사·시민)을 재사용하고, 유령 3D 에셋은 디자인 캔버스에서 만든다
12. 암살 뒤 유언 공개는 채팅 로그가 아니라 **메인 중앙에 크게** 띄운다. 유서·유언 형태의 에셋을 디자인 캔버스로 만든다

## 정해진 것
- 시간 지침: 한 판 **평균 10~15분은 참고 목표**이고 고정 제한이 아니다(커밋 `e784d59`, 이후 문구 정리 포함). 단계 시간(지목 8초 등)은 기본값이며 플레이테스트 후 조정한다
- 360×560 경찰 밤 8자 이름 줄바꿈(이름표 약 20px 상승)은 그대로 둔다
- 사람 마피아가 있는 판은 마피아 전원이 같은 대상을 골라야 아침에 탈락이 난다(결정 0061, 의도한 규칙)
