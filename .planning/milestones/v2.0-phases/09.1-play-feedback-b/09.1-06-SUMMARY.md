# Phase 09.1 Plan 06: 순차 지목 화면의 순수 재료 Summary

순차 지목 화면의 값과 문장이 서버 공개 정보(day.turn·day.points·players)만으로 정해지는 순수 모델(`turnLook`·`turnTopLine`)로 모였고, 시안에 없는 8페이즈 지목 연출(위 알림 대기열·선두/과반 줄·카메라 확대·긴장 조명)을 걷어 냈다. 차례 알약 같은 화면 부품은 09.1-07.

## 한 일

- **Task 1 (트레이서)**: `pickTurn.ts` — `turnLook` 이 단계(gather·turn·done·end), `n / N`, 차례 주인 좌석·이름, 남은 ms·올림 초·막대 비율, 시간 색(`timerTone(초 × 1000, 8000)` 한 호출, warn 없음), 내 차례 여부를 정한다. 확정된 차례는 `endsAt − doneAt` 에서 멈추고 기권은 0초·calm. `turnTopLine` 이 위 한 줄 문장(모이는 중·가리킴·기권·끝 알림 '모두 골랐어요 · {이름} 님 {k}표' / 동률·0표 '모두 골랐어요')을 만든다. 시험 26개(경계 5000/5001·8000·1·0, role·spectate 만 바꾼 결과 동일 포함). 유닛 시험이 단독으로 끝까지 이어져 트레이서 게이트(자동 검증)를 통과했다.
- **Task 2**: `dayEvents` 가 지목 줄마다 vote 줄 '{이름} → {대상}'(바꿈 표시 없음)과 새 기권 차례 vote 줄 '{이름} · 기권'만 만들고, 선두·과반 hot 줄과 `toasts` 키가 없다. `headerFor` 가 순차 안내를 낸다. `PointToast`·`ToastQueue`·`TOAST_*`·`ToastShow`, `DAY_COPY.leadLine/majorityLine`, `useDayFx` 의 `toast` 상태·`PointToastShow`, `GameMap` 의 지목 알림 효과와 prop, `RoomScreen` 의 전달을 지웠다. `useTopToast` 와 거절 알림 문구("지금은 고를 수 없어요"·"보내지 못했어요. 다시 해 보세요")는 그대로다.
- **Task 3**: `cameraModeOf` 가 지목 과반에서도 확대 1, `tensionOf` 가 지목에서 항상 0. `coversNext` 는 지목이면 `day.turn.i >= order.length`(끝 알림)이고 단독 최다가 없을 때만 true — 차례 중·모이는 중에는 차례 마감이 와도 덮지 않고, `day.turn` 이 없으면 덮지 않는다. 처형·밤은 그대로. 손사래(`leaderShift`)·`lightingOf`(지목 vote)는 그대로.

## 이월 메모 (뒤 계획용)

**09.1-07(화면 부품)이 쓸 이름과 위치**
- `src/game/pickTurn.ts`: `turnLook(view, serverNow): TurnLook | null` — `{ stage: "gather"|"turn"|"done"|"end", no, total, seat?, name?, remainingMs, seconds, ratio, tone: "calm"|"urgent", myTurn }`. 알약은 `TURN_COPY.count(no,total)`·`TURN_COPY.turnOf(name)`·`TURN_COPY.seconds(seconds)`. `turnTopLine(view): string | null`(차례 중에는 null — 위 한 줄은 높이 360 이상 스테이지에서만 그린다). 시각이 필요 없는 곳은 `turnStageOf(view)`·`isMyTurn(view)`.
- 서버 시각: `serverNow` 인자는 `Date.now() + offset`(clock.ts 규칙). 알약은 `useCountdown` 처럼 250ms 마다 다시 그리되 값은 `turnLook` 에서 얻는다. 헤더 링(`PhaseHeader`)은 지목에서 단계 마감이 아니라 차례 마감(`day.turn.endsAt`, 길이 8초 = `PICK_TURN_MS`)과 `look.tone` 을 써야 알약·막대와 색이 같다. 지목 단계의 `phaseDurationMs`(3000/8000/900/2000)는 세부 단계 길이라 링 비율에 쓰면 안 된다.
- done 단계(확정 뒤 0.9초)의 남은 시간은 멈춘 값이고 `ratio` 도 그 값에서 멈춘다. end 단계·gather 단계에는 알약·막대가 없다(`remainingMs` 0).
