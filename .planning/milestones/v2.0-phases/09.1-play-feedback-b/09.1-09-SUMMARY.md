# Phase 09.1 Plan 09: 직업 의상 안개 유령 Summary

탈락한 사람이 유령 시점(spectate 를 받은 화면)에서 직업 의상(마피아·경찰·의사·시민은 코트)을 입은 옅은 안개(불투명도 0.26, 발광 #d8e4ff 0.85)로 떠다니고, 산 사람 화면에는 의상 재료가 어떤 경로로도 없다. 유령 이름표는 불투명이 되어 직업 칩이 직업을 알린다.

## 한 일

- **Task 1 (트레이서)**: `ghostOutfit.ts`(직업 → 의상 한 표·`GHOST_MIST`), `visibleSeats` 가 spectate 가 있을 때만 탈락 좌석에 `outfit` 을 싣는다. 시험: 표 한 장, 유령 viewer 의 탈락 좌석만 의상(산 좌석·spectate 없는 유령·산 사람 viewer·처형 연출 좌석은 키 없음), 화면 시험(장면 표 의상 있음/없음, DOM `[data-ghost-outfit]` 0). 트레이서 게이트(관련 시험 2개 파일 119 통과 + typecheck) 통과로 확장.
- **Task 2**: `character.setGhost(on, opacity, glow?)` 가 복제 재질(ghostMat 하나)에 `emissive`·`emissiveIntensity` 를 준다. `CharacterHandle.applyOutfit?` 를 더했고(시험 가짜 호환 optional), 런타임이 outfit 이 있는 ghost 좌석에 같은 프레임에 `applyOutfit` → `setGhost(true, 0.26, 발광)` 을 바뀔 때만 한 번씩 부른다. 꾸민 의상(detective) 위에 직업 의상이 덮이고 이후 의상이 바뀌어도 안개 재질이 유지된다(시험). 산 사람 화면(outfit 없음)은 `applyOutfit` 0회, 처형 연출은 coat·0.6 → 0 그대로. 바뀔 때만 `onGhostOutfits(map)` 알림.
- **Task 3**: `window.__mfGhostOutfits`(`installGhostOutfitsHook`, 처음엔 빈 표, 언마운트 때 다른 설치가 덮어썼으면 지우지 않음)를 `worldTestHooksEnabled` 문맥에서만 설치. `.mv-tag.is-ghost` 의 불투명도 규칙 삭제. E2E ghost 흐름에 GH13~GH15 추가.
