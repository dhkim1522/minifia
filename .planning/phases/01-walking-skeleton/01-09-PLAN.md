## Phase Goal

**As a** 친구 모임의 플레이어, **I want to** 링크로 방에 모여 내 역할 카드만 받아 보기, **so that** 서로의 역할을 모른 채 각자 폰으로 한 판을 시작할 수 있다.

이 계획은 방 Durable Object 를 완성한다: 친구들이 링크로 들어오고 나가고, 끊겼다 돌아오고, 연결된 사람이 4명 이상일 때 방장이 시작하면 서버 시각대로 단계가 넘어가며 각자 자기 역할만 받는다.

<objective>
01-04·01-07 의 순수 규칙을 Room DO 와 Worker 라우트에 배선한다: 미리보기·참가 HTTP, leave·kick, hello 재접속(기기 교체·하이버네이션·게임 중 복귀), start(연결자 4명, 거절 시 state 재전송) → 알람 다중화(단계 마감 + 방 만료) → tick → 방송, 속도 제한. 각 배선은 workerd 통합 테스트로 먼저 실패를 확인하고 붙인다.

Purpose: ROOM-02·ROOM-03·CONN-01·GAME-01·ROLE-01·ROLE-02 의 서버 쪽을 실제 런타임(workerd)에서 증명한다. 규칙은 순수 코어가 판정하므로 이 계획은 "저장·소켓·알람" 배선만 한다(DO 는 얇은 어댑터, PATTERNS Shared Pattern 2·5). 화면 계획(01-06·01-10·01-13)이 부르는 라우트·메시지가 여기서 처음 실제로 동작한다.
Output: Worker 라우트 2개, 완성된 Room DO, 워커 통합 테스트 6개와 도우미.
