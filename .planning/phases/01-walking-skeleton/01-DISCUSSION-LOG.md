## 그리는 방식(3D)

사용자 질문: 게임이 모두 2D 인가, 5페이즈에서 그럴듯한 UI/UX 와 캐릭터 에셋을 갖춘 3D 로 만들 수 있는가, 캐릭터별 프레임 PNG 에셋을 만들고 싶고 쓸 만한 스킬이 있으면 쓰고 싶다, 처음부터 완성된 3D 를 뽑고 고정해야 하는가.
답변 요지: 가벼운 3D 는 웹에서 가능하고 어려운 것은 에셋 제작. Claude 는 래스터 이미지를 직접 생성하지 못하고, 이 환경에 캐릭터 PNG 생성 스킬은 없음(공개 스킬은 미확인). 3D 모델 → Blender 스크립트 렌더링 프레임 PNG 경로 제안. 완성 에셋을 먼저 고정할 필요는 없지만 실시간 3D 여부는 화면 구조를 정하므로 지금 정해야 함.
