## Design System

| Property | Value |
|----------|-------|
| Tool | none |
| Preset | not applicable |
| Component library | none (직접 만든 React 부품 + 일반 CSS 파일) |
| Icon library | none — 인라인 SVG 를 직접 그린다(왕관, 역할 문양, 카드 뒷면 마름모). 이모지·아이콘 폰트 금지 |
| Font | 시스템 글꼴 `--font-ui`(system-ui, -apple-system, "Apple SD Gothic Neo", "Noto Sans KR", "Malgun Gothic", sans-serif). 웹 폰트 내려받기 없음 |

shadcn 을 쓰지 않는 이유: `components.json` 이 없고, 이미 확정된 계획(01-05·01-06·01-09)이 "새 패키지 설치 없음" 을 위협 모델(T-01-SC)로 못박았으며, 화면은 2.5D 테이블·카드처럼 일반 UI 키트에 없는 부품이 중심이다. 일반 CSS + `src/styles/tokens.css` 변수가 디자인 시스템이다. 나중에 폼 부품이 많이 늘면(2페이즈 빠른 메시지 이후) 그때 다시 판단한다.

스타일 규칙: 색·간격·글자 값은 `tokens.css` 변수로만 쓴다(화면 CSS 에 hex 직접 쓰기 금지, 아래 "토큰 목록" 의 장면 전용 값은 변수로 선언한 뒤 쓴다). 애니메이션은 `transform`·`opacity` 만. 사용자 문자열(닉네임)은 React 텍스트로만 그린다.

## Spacing Scale

값은 모두 4의 배수.

| Token | Value | Usage |
|-------|-------|-------|
| xs | 4px | 아이콘·점 사이, 이름표 안쪽 세로 여백 |
| sm | 8px | 버튼 안 요소 사이, 입력 라벨과 칸 사이, 인접 버튼 사이 |
| md | 16px | 기본 요소 간격, 화면 좌우 안쪽 여백 최소값, 입력칸 안쪽 가로 여백 |
| lg | 24px | 화면 좌우 안쪽 여백(입장 화면), 시트 안쪽 여백, 구역 사이 |
| xl | 32px | 큰 구역 사이(제목과 폼) |
| 2xl | 48px | 입장 화면 위쪽 여백, 큰 단락 구분 |
| 3xl | 64px | 쓸 일이 드물다(위쪽 바 높이 등 레이아웃 최소 높이) |

예외(레이아웃 치수이며 간격이 아니다):
- 손가락 누르기 영역은 최소 44px(`--tap-min`). 자리 누르기 영역은 자리가 작게 보여도 44×44px 이상이 되도록 투명 영역으로 넓힌다.
- 컨트롤 높이: 입력칸 48px, 버튼 52px(둘 다 4의 배수). 보조 버튼은 높이 44px 이상.
- 테이블 장면 안쪽(자리·판·조명)은 장면 폭 대비 퍼센트 좌표를 쓴다(`seatLayout`). Figure 논리 크기 64×96.
- 기존 값 12px·14px·20px 은 쓰지 않는다. `screens.css` 의 해당 값은 화면을 다시 쓰는 계획(01-05, 01-06)에서 위 스케일로 바꾼다.

화면 틀: `#root` 폭 최대 430px 가운데 정렬(PC 에서도 폰 폭). 360px 에서 좌우 여백 md(16px), 입장 화면은 lg(24px). 위·아래 여백은 `env(safe-area-inset-*)` 를 더한다. 게임 화면(대기실·배정·역할 확인·낮)은 360×640 에서도 세로 스크롤 없이 한 화면에 들어간다(`100dvh`, 테이블이 줄어든다). 입장 화면은 키보드가 올라오면 스크롤을 허용한다.

## Typography

글자 크기 4개, 굵기 2개.

| Role | Size | Weight | Line Height | 쓰는 곳 |
|------|------|--------|-------------|---------|
| Body | 16px | 400 | 1.5 | 안내 문장, 입력칸 글자(16px 미만이면 iOS 가 확대한다), 버튼 글자는 700 |
| Label | 14px | 400 | 1.4 | 입력 라벨, 보조 설명, 이름표(700), 상태 문장, 버전 표시, 오류 문장 |
| Heading | 24px | 700 | 1.2 | 화면 제목("○○님의 방", "당신의 직업"), 오류 화면 문장, 시트 제목, 타이머 숫자, 배정 문구 |
| Display | 36px | 700 | 1.2 | 앱 제목 minifia, 방 코드, "낮이 되었습니다", 카드 앞면 역할 이름 |

- 굵기는 400 과 700 만 쓴다(기존 800 은 700 으로).
- 버튼 글자: Body 16px 700. 보조 버튼도 같다.
- 한글 줄바꿈은 `word-break: keep-all` 을 기본으로 한다(단어 중간에서 끊기지 않게). 닉네임·코드는 예외로 `break-all` 허용.
- 방 코드는 Display 에 `letter-spacing: 0.12em`(오른쪽 여백 보정 `padding-left: 0.12em`), 숫자 정렬 `font-variant-numeric: tabular-nums`.
- 타이머 숫자는 Heading 크기에 `tabular-nums`(초가 바뀌어도 폭이 흔들리지 않게).
- 이름표(Label 700)는 장면 안 자리 크기와 무관하게 항상 14px 이다(자리가 작아져도 같이 줄지 않는다).

| Role | Value | Usage |

| Accent (10%) | `--crimson-500` #C8102E | 아래 "진홍 예약 목록" 에 적힌 곳뿐 |
| Destructive | `--crimson-500` #C8102E | 1페이즈에는 진홍으로 그리는 파괴 버튼이 없다(아래 설명) |

보조 면과 글자: 글자 기본 `--gray-100` #E6E8EE, 강한 글자 `--gray-50` #F1F2F5, 보조 글자 `--gray-300` #A9AEBB. 주 버튼은 `--gray-100` 면 + `--night-900` 글자(진홍 아님). 보조 버튼은 `--gray-800` 면 + `--gray-700` 테두리 + `--gray-50` 글자.

**Accent reserved for(진홍 예약 목록, D-20 — 이 목록에 없는 곳에 쓰지 않는다):**
1. 타이머 마지막 5초: 막대 채움 `--crimson-500`, 숫자 `--crimson-400`(큰 글자라 대비 3:1 이상이면 된다)
2. 마피아 본인 화면의 동료 표시: 발밑 타원 링 `--crimson-500` + 머리 위 작은 마름모
3. 마피아 역할 카드 앞면의 문양과 "동료: ○○" / "이번 판 마피아는 당신 혼자입니다" 줄(작은 글자라 `--crimson-300`)
4. 카드 뒷면 가운데 마름모 문양(모든 사람에게 같다 — 역할 정보가 아니다)
5. 입력 오류·요청 실패 문장(`--crimson-300`, Label 14px)

진홍을 쓰지 않는 곳: 버튼 면, 포커스 링, 방장 왕관·배지, 링크, 아이콘, 장식. 포커스 링은 `--gray-100` 2px, 오프셋 2px.

Destructive 설명: [나가기]·[내보내기] 확인 버튼은 01-06 이 정한 대로 이 화면에서 진홍을 쓰지 않는다(진홍의 의미를 마피아·위험 순간·마지막 5초로 좁게 지키기 위해). 확인 시트에서는 취소가 눈에 띄는 쪽(`--gray-100` 면), 파괴 동작이 `--gray-800` 면이다. 4페이즈(처형)에서 파괴 색을 다시 정한다.

신규·보정 토큰(아래 "토큰 목록" 에서 `tokens.css` 에 더한다):
- `--crimson-300` #F2556A — 어두운 바탕 위 작은 진홍 글자용. 기존 `--crimson-400` #E0344B 는 `--night-900` 위에서 대비 약 4.2:1 로 14~16px 본문 기준(4.5:1)에 못 미친다. #F2556A 는 약 5.5:1.

- 확인한 대비(근사): `--gray-100`/`--night-900` 약 15:1, `--gray-300`/`--night-900` 약 8:1, 주 버튼 글자 `--night-900` on `--gray-100` 약 15:1.

### 4) 대기실 Lobby (D-08~D-11, D-16, D-17, 01-06)

- 가운데: Table(장면 폭 = min(100%, 가용 높이 × 0.8), 비율 4:5).
- 아래쪽 바(면 `--night-800`, 위 경계 `--gray-700` 1px, 안쪽 여백 md): "{n}/8명"(Label `--gray-300`)과 한 문장 상태(Body `--gray-100`) → 방장이면 [게임 시작](주 버튼 52px), 아니면 버튼 없음 → 작은 [나가기](텍스트 버튼, 높이 44, Label `--gray-300`, 밑줄 없음).

- 참가자: "방장이 시작하기를 기다리는 중…".
- 자리 누르기: 방장이 연결이 끊긴 다른 사람을 누르면 내보내기 시트. 그 밖에는 아무 일도 없다(연결된 사람·본인·참가자의 누르기).

### 5) 테이블 Table·Figure·Seat — 이후 모든 단계가 재사용(D-08, D-09, D-21~D-24)

## 접근성·상호작용 규칙

- 누르기 영역 44px 이상(`--tap-min`). 인접한 누르기 대상 사이 8px 이상.
- 키보드: 모든 버튼·입력칸에 `:focus-visible` 링(`--gray-100` 2px). 카드 뒷면·[내 역할] 은 Space/Enter 로 동작.
- 입력칸: 글자 16px(iOS 확대 방지), 닉네임 `autocomplete="off" autocapitalize="off" autocorrect="off" spellcheck="false"`, 코드 `inputMode="numeric" pattern="[0-9]*"`, 4자리 넘으면 자른다. 라벨은 `<label>` 로 입력칸과 연결.
- 상태 안내: 보이지 않는 `aria-live="polite"` 영역 하나가 단계가 바뀔 때만 문장을 읽는다("직업을 배정하고 있습니다", "낮이 되었습니다"). 오류 문장은 `role="alert"`.
- 제출 중복 방지: 요청 중 버튼 disabled, 시작 버튼은 2초 잠금.
- 역할 비노출: 역할을 보기 전 화면(배정, 카드 뒷면, [내 역할] 버튼, 낮 화면 구성)은 역할과 무관하게 같은 마크업이다. 다른 점은 마피아 본인 화면의 동료 표시(D-14)뿐이다. 화면 캡처·녹화는 막을 수 없고 수용한다(D-19).
- 문자열 안전: 닉네임·이름은 React 텍스트와 `title` 로만 그린다(HTML 주입 API 금지).
- 대비: 본문 글자는 `--night-900` 위에서 4.5:1 이상(`--gray-300` 이상), 큰 글자(24px 700 이상)와 UI 경계는 3:1 이상.
- 전환 시 스크롤: 단계가 바뀌면 화면 맨 위로(게임 화면은 스크롤이 없다).

## Copywriting Contract
