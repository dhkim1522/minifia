## Claude 재량 결정

- **동사는 DayTable 이 고르지 않는다.** `pickVerb?: string` 을 장면이 넘긴다(역할 이름을 부품에 넣지 않기 위해). 없으면 기본 "선택".
- **끊김 중 입력 꺼짐은 테이블 단위 `pickDisabled`.** UI-SPEC "connection.canSend 가 false 면 disabled" — 버튼 노드는 그대로 두고 disabled 속성만 켠다.
- **실제 직업 아랫줄은 `{ kind: "real"; job: RoleId }` 하나.** UI-SPEC 표는 키를 `role` 로 적었지만 기존 주장 줄과 같은 `job` 으로 쓴다(역할 키 이름 금지 규칙과 부딪히지 않게 — 의미는 같다). 직업 글자는 `claimName` 이 만든다. 이 값은 장면이 탈락자 전용 `view.spectate` 에서만 만든다(03-08) — 부품은 출처를 모른다.
- **관전 배지 입력은 UI-SPEC 이름 그대로 `spectatorPicks?: readonly ("mafia" | "police" | "doctor")[]`.** 마피아 화면의 동료 선택은 `pick.ally` 로 따로 둔다(읽기 이름이 다르다: 동료 배지는 장식, 관전 배지는 role=img).
- **마름모 읽기 이름은 `allyMarkLabel`(기본 "동료").** 관전 화면은 모든 마피아에게 링·마름모를 그리고 "마피아" 로 읽게 넘긴다(UI-SPEC N-6).
- **배지 쌓기:** 캐릭터 상자 안 DOM 순서를 경찰 → 의사 → 마피아(--ally) → 내 링 → 내 배지로 두고, 내 것에 z-index 를 가장 크게 준다(내 선택이 항상 위). 가로 위치는 시안 값(경찰 -13, 의사 -4, 마피아 +4, 나 -13)이다.
- **탈락 + 끊김:** 유령 그림에 끊김 흐림을 더하고 접근성 이름에도 ', 연결 끊김' 을 남긴다(UI-SPEC 대응표·장면·UI Considerations 가 이 규칙으로 맞춰졌다 — 흐림은 끊김 전용, 결정 0021).
