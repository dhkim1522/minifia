## 페이즈 목표

낮 다음 밤이 되면 각 폰이 역할에 맞는 선택 화면을 보이고(마피아는 전용 채팅 포함), 마피아·경찰·의사의 행동이 서로 모르게 처리되어 아침에 결과가 발표된다.

이 계획은 3페이즈를 배포본으로 증명한다: 스모크·봇 스크립트를 밤·아침·관전에 맞게 고치고, 개인 Cloudflare 계정으로 배포한 뒤 배포본에서 돌리고, HANDOFF 를 갱신해 push 한다. 실기기 확인은 사람이 하는 목록으로 남긴다(두 기종 실기기 정식 확인은 6페이즈 — CONTEXT Deferred).

## Claude 재량 결정

- **스모크 한도 300초.** 시작 → 2일차 dayAnnounce 가 약 162초(배정 3 + 역할 15 + 발표 2 + 공개 15 + 연출 2 + 토론 90 + 밤 30 + 아침 5)라 지금 240초는 여유가 78초뿐이다(RESEARCH 부록 A).
- **4·5·8명 세 번.** 4명판은 의사가 없고 마피아가 하나라 다른 경로다(Pitfall 8).
- **스모크의 밤 행동은 결정적:** 마피아 전원 → 가장 작은 시민 seat X, 경찰 → 가장 작은 마피아 seat, 의사 → 자신. 그래서 아침 탈락자는 X 여야 한다.
- **uat-night 의 "마감 뒤 pick"** 은 배포본에서 정확한 순간을 맞추기 어려워 "아침 state 를 받은 뒤 보낸 pick → WRONG_PHASE" 로 확인한다(같은 거부 경로, 서버가 단계를 먼저 넘긴다).
