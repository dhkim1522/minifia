# Phase 3 — UI Design Contract (밤과 아침)

> 화면·상호작용 계약서. 요구사항 NIGHT-01~06, ELIM-01, COMM-04(밤 마피아 채팅)의 화면 몫.
>
> **시각 디자인은 이미 사용자가 승인한 시안이다. 이 문서는 새 모양을 만들지 않고 승인 시안을 토큰·부품·상태표로 옮긴 계약이다.** 시안에 없는 것은 "지금 앱 동작 그대로"이고, 시안이 없어서 최소 형태로 정한 곳은 `시안 없음` 표시와 함께 "확인 필요"에 모았다.

## Design System

| Property | Value |
|----------|-------|
| Tool | none |
| Preset | not applicable |
| Component library | none — 직접 만든 React 부품 + 일반 CSS. 참고 구현은 `design/design-system/components/` |
| Icon library | none — 인라인 SVG(`src/components/Icon.tsx`). 이 페이즈에서 아이콘 1개 추가(`target` 표적). 이모지·아이콘 폰트 금지 |
| Font | 시스템 글꼴 `--font-ui`. 웹 폰트 내려받기 없음 |

shadcn 을 쓰지 않는 이유는 1·2페이즈와 같다(새 패키지 없음, 중심 화면이 2.5D 테이블). 이 페이즈도 새 패키지를 설치하지 않는다. `components.json` 없음(확인: `ls components.json` → 없음, 2026-10-24).

스타일 규칙(1·2페이즈 그대로)
- 색·간격·크기·모션 값은 `tokens.css` 변수로만. 화면 CSS 에 hex 를 쓰지 않는다(시안의 hex·rgba 는 아래 "시안 값 → 토큰" 대응표를 따른다). 새 토큰 필요 없음.
- 애니메이션은 `transform`·`opacity`(그리고 인물 상태의 `filter`)만.
- 닉네임·문구는 React 텍스트로만 그린다. 탈락 발표 문장은 서버가 문장을 보내지 않고 **문구 번호 + 탈락자 seat** 로 보내며 화면이 문장을 만든다(낮 메시지와 같은 원칙).
- 서버 view 에 없는 값(남의 역할 등)을 화면이 추측해 그리지 않는다.

예외(레이아웃 치수, 간격이 아니다 — 모두 승인 시안 값)
- 누르기 영역 최소 44px(`--tap-min`): `.pk` 높이(min), 조사 팝업 [확인], 캐릭터 누르기 영역(캐릭터 상자 `72×96 × scale(0.8~1)` ≥ 57.6×76.8).

- 아침 카드: 폭 252, 위 168, 안쪽 12 16. 조사 팝업: 좌우 24, 위 190. 표적 배지 26px, 발밑 선택 링 폭 124%·높이 20%·3px. 모두 시안 값(지역 상수, R18 방식).
- 높이 계산(하단 157 안): 안쪽 위 10 + 제목 29(24px×1.2) + 간격 8 + 안내 2줄 40 + 간격 8 + 알약 44 + 안쪽 아래 12 = **151 ≤ 157**. 안내가 3줄이 되는 폭(360폰 328px)에서도 알약이 없는 화면(탈락)은 10+29+8+60+12 = 119 로 든다. 알약이 있는 화면(경찰·의사·시민)의 안내가 3줄이 되면 171 이라 넘치므로 **그 세 안내는 360 폰에서 2줄 안**이어야 한다(실기기 확인 항목).

## Color

시안의 hex·rgba 는 모두 `tokens.css` 변수로 옮긴다. 새 토큰은 없다.

| Role | Value | Usage (이 페이즈) |
|------|-------|-------------------|
| Dominant (60%) | `--night-900` #0E1326 + 밤 장면 `bg_game_night.svg`(아침은 `bg_game_day.svg`) | 앱 바탕, 장면 |
| Secondary (30%) | `--night-800`(하단 패널·조사 팝업 카드 면), `--night-700`(`.pk`·채팅 면·조사 결과 알약), `--night-600`(카드·팝업 테두리), `--gray-800`·`--gray-700`(보조 버튼) | |
| Accent (10%) | 밝은 면 `--gray-50`/`--gray-100` + 글자 `--night-900` | 아래 "밝은 면 예약"에 적힌 곳뿐 |
| Destructive | 없음 | 이 페이즈에 파괴 동작 확인이 없다(밤 대상은 마감 전 자유 변경, 탈락은 서버 결과) |

글자: 제목 `--gray-50`, 본문 `--gray-100`, 보조 `--gray-300`. 포커스 링 `--gray-100` 2px, 오프셋 2px.

**밝은 면 예약**(이 페이즈의 "지금 눈에 띄어야 하는 것"):
1. 내가 고른 대상: 발밑 링(`--gray-50` 3px + 빛) + 머리 위 표적 배지(`--gray-50` 면, `--night-900` 아이콘)
2. 주 버튼([빠른 메시지], 조사 팝업 [확인])
3. 이모티콘 원(`--gray-100` 면), 방금 말한 사람 이름표 윗줄 반전(낮과 같음)

**진홍 예약**(이 페이즈에 해당하는 것만, 전부 `--crimson-400`):
1. 타이머 마지막 5초(밤 30초의 끝). **아침 5초 전체는 마지막 5초지만 진홍을 쓰지 않는다**(가정, 아래 "확인 필요" 4)

| 1 | `[○○] 지목해요` | 필요 | `{닉네임} 지목해요` |

### N-6 탈락자 화면 (시안 E1)

- 탈락한 사람(나)의 화면. 테이블에서 **나(맨 아래)** 가 흑백 + 이름표 회색, 아랫줄 `탈락`. 헤더·테이블은 살아 있는 사람과 같다(밤이면 밤 헤더+배경).
- **밤 하단**: 제목 `탈락했어요`, 안내 `남은 진행을 지켜볼 수 있어요. 메시지는 보낼 수 없고, 다른 사람의 직업은 게임이 끝나야 볼 수 있어요`. 알약 없음, 채팅·보내기 줄 없음. 탈락한 마피아도 같다(밤 채팅은 보이지 않는다).
- 밤에 캐릭터를 탭해도 아무 일 없다(선택 불가, 버튼으로 그리지 않음).
- **낮 토론 하단**: 채팅 세 줄을 읽기만 한다 — `MessageLog` 만 그리고 [빠른 메시지][이모티콘] 줄은 없다(하단 높이 157 유지, 줄 아래 빈 면은 `--night-800`). ^ 버튼의 채팅 내역 모달은 열린다.
- 낮 직업 공개·공개 연출 하단: 탈락자는 칩을 고를 수 없으므로 위 밤 하단과 같은 `탈락했어요` 패널을 그린다(시안 없음, 가정 — "확인 필요" 3).
- 탈락자에게도 서버는 남의 역할을 보내지 않는다(결정 0002). [내 역할] 버튼은 그대로 열린다(내 역할은 본인 정보).
- 아침 발표는 탈락자도 모두와 같은 카드를 본다.

### 단계 전환·재접속

- 단계가 바뀌면 위쪽 바·하단 패널만 `mf-dayscene__enter`(300ms 페이드)로 바뀌고 테이블·카드는 그대로다. 열려 있던 시트(빠른 메시지·이모티콘·채팅 내역)는 패널이 언마운트되며 닫히고 고른 내용은 버려진다. [내 역할] 시트는 `RoomScreen` 이 쥐므로 단계가 바뀌어도 열린 채다.
- 밤 중간 재접속: 서버 view 에서 내 현재 선택(마피아는 동료 선택 포함)을 복원해 링·배지·알약이 그려진다. 마피아 채팅은 재접속 이후 받은 줄만 보인다. 조사 팝업은 결과가 이미 보내진 뒤라면 아직 `night` 단계이고 [확인] 전이면 다시 열린다(결과를 서버가 본인에게 다시 보내는지는 계획이 정함).
- 아침 중간 재접속: 카드는 같은 번호로 그려진다(서버 값). 선택 흔적 없음.

## Motion (기본형, 결정 0006)

시안에 애니메이션이 없으므로 승인 범위는 "기존 부품의 전환 그대로"이다. 아래는 새로 정하지 않고 기존 값을 이름만 붙인 것이다.

| 이름 | 어디 | 길이·곡선 | 속성 |
|------|------|-----------|------|
| phase-enter | 위쪽 바·하단 패널 | 300ms (`mf-dayscene__enter`) | opacity |
| card-enter | 아침 카드·조사 팝업 카드·가림막 | 300ms, 같은 `mf-phase-enter` 키프레임 재사용(가정) | opacity |
| 선택 표시 | 링·표적 배지 | 즉시(전환 없음) | — |
| 탈락 표시 | 흑백·이름표 | 즉시(전환 없음) | — |
| emoji | 마피아 이모티콘 | 낮과 같음(2000ms, `mf-dt-emoji`) | opacity·transform |

## 접근성·상호작용 규칙

1·2페이즈 규칙을 따르고 아래를 더한다.

- 단계 전환 안내(`PHASE_ANNOUNCE` 확장, 내 폰에서만 읽음): `night` → `{N}일차 밤. ` + (마피아 `함께 지목하세요` / 경찰·의사 하단 제목 / 시민 `밤이 되었어요` / 탈락자 `탈락했어요`), `morning` → `아침이 밝았습니다. ` + 카드 제목(+보조).
- 대상 캐릭터는 `<button aria-pressed>`(밤·행동 역할·생존자만). 탈락자·시민·아침·낮에는 눌리지 않는 노드.
- 하단 `.pk` 는 `role="status"` 로 선택 변화를 읽는다. 마피아 채팅 로그는 `role="log"`.
- 조사 팝업은 `role="dialog" aria-modal`, 열리면 [확인]에 포커스, 뒤 장면 `inert`.
- 탈락 이름표는 자리 그룹 `aria-label` 에 `, 탈락` 을 더한다(예 "서연, 탈락"). 선택 대상은 `, 선택됨`을 더하지 않고 `aria-pressed` 가 읽는다.
- 대비: 승인 시안이 정한 `--gray-500` 글자(마피아 안내 줄, 탈락 이름표)는 `#6b7180` 대 `#1e2847`·`#0e1326` 으로 4.5:1 에 못 미친다(시안 승인 예외, 정보는 `aria-label`/`aria-live` 로도 전달). 나머지 글자는 `--gray-300` 이상.
- 역할 비노출: 밤 화면이 역할마다 다른 것은 결정 0018 이 허용한다. 서버는 여전히 남의 역할을 보내지 않고 마피아 동료 seat 만 마피아에게 보낸다. **화면 컴포넌트에 남의 역할 필드를 넘기지 않는다.** 조사 결과·동료 선택·밤 채팅은 각각 본인·마피아 소켓에서만 온 값으로 그린다.

## 화면이 서버 뷰에서 필요로 하는 값 (형식은 계획이 정한다)

- 단계: `night`(30초), `morning`(5초). 일차 `day.n`(밤 N, 아침 표시 N+1). `PHASE_DEFS`·`ON_ENTER` 행 추가(결정 0016).
- 자리별 공개: `alive`(탈락 여부, 이미 `PublicPlayer.alive?`). 밤·아침에도 그날 낮 `claims`(주장·말 바꿈)를 계속 싣는다(지금은 `claimReveal`·`discussion` 에서만).
- 내 값(본인에게만): 내 현재 밤 선택(seat 또는 없음). 마피아에게만: 동료들의 현재 선택(seat→대상 seat). 경찰에게만: 조사 결과(대상 seat + 마피아 여부)와 누적 기록.
- 아침 공개: 탈락자 seat(없으면 없음) + 문구 번호 1~8. 의사가 지킨 경우는 탈락자 없음과 구별되지 않는다.
- 이벤트: 마피아 소켓에만 밤 `chat`·`emoji`(저장 안 함, 밤이 끝나면 폐기). 템플릿 ID 는 밤 전용 3개 추가.
- 누출 테스트에 "마피아가 아닌 소켓은 밤 chat·emoji 프레임을 받지 않는다", "비경찰은 조사 결과를 받지 않는다", "동료 선택은 마피아에게만 간다" 포함(계획).

## 확인 필요 (시안이 정하지 않은 곳 — 계획이 가정으로 두거나 사용자 확인)

1. **조사 결과 읽는 시간**(위 phase-change ⚠): 서버 단계 구성에 따라 팝업이 보이는 시간이 달라진다. 이 계약은 "팝업이 열린 동안 [확인]으로 닫을 수 있고 아침 시작 시 자동으로 닫힌다"까지만 정한다.
2. **팝업이 안 뜨는 경우**: 경찰이 아무도 안 골랐거나 탈락한 경우 팝업을 열지 않는다(가정).
3. **탈락자의 낮 직업 공개 하단**: 칩을 고를 수 없어 `탈락했어요` 패널을 그린다(가정, 시안은 밤 E1·낮 토론만 있음).
4. **아침 5초 타이머 색**: 5초 전체가 "마지막 5초"라 진홍이 되지 않게 `Timer` 의 urgent 를 아침에는 끈다(가정).
5. **내 선택과 동료 선택이 같은 대상**: 시안 좌표(내 배지 중앙 −13, 동료 +4)대로 겹쳐 그리고 내 배지가 위. 겹침이 거슬리면 디자인 세션 확인.
6. **조사 기록 시트 모양**: 시안 없음. 위 N-5b 가 최소 형태.
7. **선택 해제**: 같은 대상 재탭은 무시(해제 없음, 가정).
