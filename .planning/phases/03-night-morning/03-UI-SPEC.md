# Phase 3 — UI Design Contract (밤과 아침)

> 화면·상호작용 계약서. 요구사항 NIGHT-01~06, ELIM-01, COMM-04(밤 마피아 채팅)의 화면 몫.
>
> **시각 디자인은 이미 사용자가 승인한 시안이다. 이 문서는 새 모양을 만들지 않고 승인 시안을 토큰·부품·상태표로 옮긴 계약이다.** 시안에 없는 것은 "지금 앱 동작 그대로"이고, 시안이 없어서 최소 형태로 정한 곳은 `시안 없음` 표시와 함께 "확인 필요"에 모았다.

## Design System

| Property | Value |
|----------|-------|
| Tool | none |
| Preset | not applicable |
| Component library | none — 직접 만든 React 부품 + 일반 CSS. 참고 구현은 `design/design-system/components/` |
| Icon library | none — 인라인 SVG(`src/components/Icon.tsx`). 이 페이즈에서 아이콘 2개 추가(`target` 표적, `notebook` 수첩). 이모지·아이콘 폰트 금지 |
| Font | 시스템 글꼴 `--font-ui`. 웹 폰트 내려받기 없음 |

shadcn 을 쓰지 않는 이유는 1·2페이즈와 같다(새 패키지 없음, 중심 화면이 2.5D 테이블). 이 페이즈도 새 패키지를 설치하지 않는다. `components.json` 없음(확인: `ls components.json` → 없음, 2026-10-24).

스타일 규칙(1·2페이즈 그대로)
- 색·간격·크기·모션 값은 `tokens.css` 변수로만. 화면 CSS 에 hex 를 쓰지 않는다(시안의 hex·rgba 는 아래 "시안 값 → 토큰" 대응표를 따른다). 새 토큰 필요 없음.
- 애니메이션은 `transform`·`opacity`(그리고 인물 상태의 `filter`)만.
- 닉네임·문구는 React 텍스트로만 그린다. 탈락 발표 문장은 서버가 문장을 보내지 않고 **문구 번호 + 탈락자 seat** 로 보내며 화면이 문장을 만든다(낮 메시지와 같은 원칙).
- 서버 view 에 없는 값(남의 역할 등)을 화면이 추측해 그리지 않는다.

## Color

시안의 hex·rgba 는 모두 `tokens.css` 변수로 옮긴다. 새 토큰은 없다.

| Role | Value | Usage (이 페이즈) |
|------|-------|-------------------|
| Dominant (60%) | `--night-900` #0E1326 + 밤 장면 `bg_game_night.svg`(아침은 `bg_game_day.svg`) | 앱 바탕, 장면 |
| Secondary (30%) | `--night-800`(하단 패널·수사 기록 시트 면), `--night-700`(`.pk`·채팅 면·수사 기록 목록 면), `--night-600`(아침 카드 테두리·수사 기록 점선), `--gray-800`·`--gray-700`(보조 버튼, [수사 기록] 버튼) | |
| Accent (10%) | 밝은 면 `--gray-50`/`--gray-100` + 글자 `--night-900` | 아래 "밝은 면 예약"에 적힌 곳뿐 |
| Destructive | 없음 | 이 페이즈에 파괴 동작 확인이 없다(밤 대상은 마감 전 자유 변경, 탈락은 서버 결과) |

글자: 제목 `--gray-50`, 본문 `--gray-100`, 보조 `--gray-300`. 포커스 링 `--gray-100` 2px, 오프셋 2px.

**밝은 면 예약**(이 페이즈의 "지금 눈에 띄어야 하는 것"):
1. 내가 고른 대상: 발밑 링(`--gray-50` 3px + 빛) + 머리 위 표적 배지(`--gray-50` 면, `--night-900` 아이콘)
2. 주 버튼([빠른 메시지])
3. 이모티콘 원(`--gray-100` 면), 방금 말한 사람 이름표 윗줄 반전(낮과 같음)
4. 새 기록 표시: [수사 기록] 버튼 점 `.dot`(`--gray-50` 면, 2px `--gray-800` 테두리), 수사 기록 알림 테두리(`1px --gray-100`)·글자(`--gray-50`), 가장 새 줄의 `NEW` 알약(`--gray-50` 면, `--night-900` 글자)

**진홍 예약**(이 페이즈에 해당하는 것만, 전부 `--crimson-400`):
1. 타이머 마지막 5초(밤 30초의 끝). **아침 5초 전체는 마지막 5초지만 진홍을 쓰지 않는다**(가정, 아래 "확인 필요" 7)
2. 마피아 본인 화면의 동료 링(3px)·마름모 — 낮과 같다. 밤·아침에도 유지
3. **(추가) 마피아 화면에서 동료가 고른 대상 배지**: `--night-900` 면, 2px `--crimson-400` 테두리, 아이콘 `--crimson-400`. 마피아 화면에만 그린다
4. **(추가) 수사 기록 시트의 결과 `마피아`**: 글자 `--crimson-400` 굵게(700). 경찰 본인 화면에만 있다. `마피아 아님` 은 `--gray-300` 보통 굵기(400)이다

진홍을 쓰지 않는 곳: `마피아 아님`, [수사 기록] 버튼과 점·알림·`NEW`, 탈락 표시, 아침 카드, 오류·안내 문장, 내 선택 표시. 결과를 도장·테두리 상자로 칠하지 않는다(시안: 도장 없음).

### N-1 밤: 대상 탭 선택 (마피아·경찰·의사 공통)

- 테이블의 **캐릭터를 직접 탭**한다(D-01). 누를 수 있는 대상은 역할별로 다르다(D-02 개정, 승인 SPEC):

| 역할 | 누를 수 있는 자리 | 눌러도 반응 없는 자리 |
|------|--------------------|------------------------|
| 마피아 | 살아 있는 **마피아가 아닌** 사람 | **자신, 동료**(`me.allies`), 탈락자 — 버튼이 아니라 눌리지 않는 이전 마크업. 서버도 무효 |
| 경찰 | 자신을 포함한 모든 생존자 | 탈락자 |
| 의사 | 자신을 포함한 모든 생존자 | 탈락자 |

- 반응 없는 자리는 눌러도 선택 표시·토스트·진동 등 어떤 변화도 없다(`disabled` 버튼이 아니라 일반 노드로 그려 포커스 순서에도 넣지 않는다).
- **마감까지 자유롭게 바꾼다**(D-06). 마지막 선택이 적용된다. 일찍 골라도 밤은 30초가 끝나야 끝난다(NIGHT-05) — 화면에 "완료"로 끝내는 버튼이 없다.
- **이미 고른 대상을 다시 눌러도 무시한다**(선택 해제 없음, 확정 — D-02 개정). 서버에도 같은 메시지를 다시 보내지 않는다.
- 눌림은 낙관적으로 즉시 표시하고 새 서버 view 가 오면 서버 값을 따른다(`ClaimPanel` 의 `pending` 방식 그대로). 화면은 서버가 돌려준 현재 선택만 그린다.
- 누르기 영역: 캐릭터 상자(72×96 × scale). 이름표는 계속 클릭을 가로채지 않는다(`pointer-events: none`). 좌석이 겹치는 5명 이상에서는 앞쪽 자리(z 높은 쪽)가 눌린다.
- 마감 직후(`WRONG_PHASE`)·연결 끊김 중에는 눌러도 표시 없이 무시(`connection.canSend` 가 false 면 `disabled`).
- 접근성: 누를 수 있는 캐릭터 상자가 `<button aria-pressed>` 이고 `aria-label` 이 `{닉네임}{ (나)}, {동사} 대상`(동사: 마피아 `지목`, 경찰 `조사`, 의사 `보호`; 예 "지호, 조사 대상"). 선택 상태는 색만이 아니라 `aria-pressed` + 링 + 배지로 표시한다.

### N-2 마피아 밤 화면 (시안 N1)

- 헤더 `밤` / `N일차 · 함께 지목하세요`. 테이블에 동료 링·마름모(D-03)와 동료가 고른 대상 배지(D-07 실시간 합의).
- 하단(높이 157): 낮 토론과 **같은 구성** — 채팅 세 줄(`MessageLog`) + 오른쪽 ^ 버튼(채팅 내역 모달) + [빠른 메시지][이모티콘 44×44] 한 줄.
  - 채팅 세 줄은 night-700 면. **로그의 첫 줄(0번)은 시스템 안내 `마피아끼리만 보여요`**, 글자 `--gray-500`(항상, 최신 줄이어도 `--gray-100` 로 밝아지지 않음 — 시안 `.lg li.sys` 가 `.latest` 뒤에 있음). 점·이름 없이 본문만. 나머지 줄은 낮 채팅 줄과 같은 모양(8px 자리 색 점 + 굵은 이름(나는 "나") + 본문, 본문만 말줄임, 최신 줄 `--gray-100`).
  - 세 줄 창은 로그의 마지막 3줄이다. 채팅이 쌓이면 안내 줄은 창 밖으로 밀리지만 ^ 모달 맨 위에는 계속 있다. 메시지가 아직 없으면 안내 줄 하나만 보이고 낮의 "아직 메시지가 없어요" 줄은 쓰지 않는다. 높이는 3줄 고정(출렁임 없음).
  - 로그 `aria-label="마피아 채팅"`. 모달 제목은 `채팅 내역` 그대로.
- 밤 채팅은 **살아 있는 마피아끼리만** 오간다. 서버가 마피아 소켓에만 보낸다. 서버는 저장하지 않고 밤이 끝나면 비운다 → 화면도 밤이 끝나면(단계가 `night` 를 벗어나면) 로그를 비운다. 재접속하면 그 연결에서 받은 줄만 남는다(낮과 같은 원칙, 결정 0017-7).
- 문구는 밤 전용 3개(자유 텍스트 없음), 칩 순서 고정:

| 템플릿 | 칩 글자 | 대상 칸 | 문장 |
|--------|---------|---------|------|

### 단계 전환·재접속

- 단계가 바뀌면 위쪽 바·하단 패널만 `mf-dayscene__enter`(300ms 페이드)로 바뀌고 테이블·카드는 그대로다. 열려 있던 시트(빠른 메시지·이모티콘·채팅 내역)는 패널이 언마운트되며 닫히고 고른 내용은 버려진다. [내 역할] 시트와 [수사 기록] 시트는 `RoomScreen` 이 쥐므로 단계가 바뀌어도 열린 채다.
- 밤 중간 재접속: 서버 view 에서 내 현재 선택(마피아는 동료 선택 포함)을 복원해 링·배지·알약이 그려진다. 마피아 채팅은 재접속 이후 받은 줄만 보인다. 경찰은 [수사 기록] 시트의 지난 기록이 복원되고(서버 값 또는 폰 메모리), 아직 열어 보지 않은 기록이 있으면 점이 켜진다. 이미 지난 알림 토스트는 다시 띄우지 않는다.
- 아침 중간 재접속: 카드는 같은 번호로 그려진다(서버 값). 선택 흔적 없음.

시안에 애니메이션이 없으므로 승인 범위는 "기존 부품의 전환 그대로"이다. 아래는 새로 정하지 않고 기존 값을 이름만 붙인 것이다.

## 접근성·상호작용 규칙

1·2페이즈 규칙을 따르고 아래를 더한다.

- 단계 전환 안내(`PHASE_ANNOUNCE` 확장, 내 폰에서만 읽음): `night` → `{N}일차 밤. ` + (마피아 `함께 지목하세요` / 경찰·의사 하단 제목 / 시민 `밤이 되었어요` / 탈락자 `탈락했어요`), `morning` → `아침이 밝았습니다. ` + 카드 제목(+보조).
- 대상 캐릭터는 `<button aria-pressed>`(밤·행동 역할·누를 수 있는 생존자만). 마피아 화면의 자신·동료, 탈락자, 시민, 아침, 낮에는 눌리지 않는 노드(포커스 순서에도 없음).
- 하단 `.pk` 는 `role="status"` 로 선택 변화를 읽는다. 마피아 채팅 로그는 `role="log"`.
- [수사 기록] 버튼은 `aria-label="수사 기록"`(새 기록이 있으면 `수사 기록, 새 기록`), 점은 `aria-hidden`. 알림은 `role="status"`. 시트는 `Sheet`(`<dialog>`)의 기본 접근성(포커스 가두기·Esc)을 따르고 목록은 줄마다 `{N}일차 밤, {이름}, {결과}`를 읽는다.
- 탈락 이름표는 자리 그룹 `aria-label` 에 `, 탈락` 을 더한다(예 "서연, 탈락"). 선택 대상은 `, 선택됨`을 더하지 않고 `aria-pressed` 가 읽는다.
- 대비: 승인 시안이 정한 `--gray-500` 글자(마피아 안내 줄, 탈락 이름표)는 `#6b7180` 대 `#1e2847`·`#0e1326` 으로 4.5:1 에 못 미친다(시안 승인 예외, 정보는 `aria-label`/`aria-live` 로도 전달). 나머지 글자는 `--gray-300` 이상.
- 역할 비노출: 밤 화면이 역할마다 다른 것은 결정 0018 이 허용한다. 서버는 여전히 남의 역할을 보내지 않고 마피아 동료 seat 만 마피아에게 보낸다. **화면 컴포넌트에 남의 역할 필드를 넘기지 않는다.** 조사 결과·동료 선택·밤 채팅은 각각 본인·마피아 소켓에서만 온 값으로 그린다.

## Copywriting Contract

말투·표기 규칙은 1·2페이즈와 같다(해요체, 짧게, 이모지·느낌표 없음). 이 페이즈의 문구는 모두 승인 시안 그대로다.

| Element | Copy |
|---------|------|
| Primary CTA (경찰 헤더) | 수사 기록 (보조 버튼, 시트를 연다) |
| Primary CTA (마피아 하단) | 빠른 메시지 (이모티콘 버튼은 아이콘만, `aria-label="이모티콘"`) |

| 마피아 채팅 안내(첫 줄) | 마피아끼리만 보여요 |

| 의사 하단 | 지킬 사람을 고르세요 / 나 자신도 고를 수 있어요 · 마감까지 바꿀 수 있어요 |
| 선택 알약 | `선택 ●{이름}` / 자신: `선택 ●나` / 선택 전: `선택 안 함` |

| 상황 | Copy | 어디 · 다음 행동 |
|------|------|------------------|

## 화면이 서버 뷰에서 필요로 하는 값 (형식은 계획이 정한다)

- 단계: `night`(30초), `morning`(5초). 일차 `day.n`(밤 N, 아침 표시 N+1). `PHASE_DEFS`·`ON_ENTER` 행 추가(결정 0016).
- 자리별 공개: `alive`(탈락 여부, 이미 `PublicPlayer.alive?`). 밤·아침에도 그날 낮 `claims`(주장·말 바꿈)를 계속 싣는다(지금은 `claimReveal`·`discussion` 에서만).
- 내 값(본인에게만): 내 현재 밤 선택(seat 또는 없음). 마피아에게만: 동료들의 현재 선택(seat→대상 seat). 경찰에게만: 수사 기록 목록(밤 `day.n`, 대상 seat, 마피아 여부 — 최신 포함 전부), 아직 열어 보지 않은 기록이 있는지(점), 방금 밤이 끝나 새 결과가 생겼는지(알림). 밤과 아침 사이에 추가 단계·시간이 없다. 마피아 화면의 자신·동료 탭 불가는 `me.allies` 로 정한다.
- 아침 공개: 탈락자 seat(없으면 없음) + 문구 번호 1~8(조사는 항상 `님이` 라 받침 정보 필요 없음). 의사가 지킨 경우는 탈락자 없음과 구별되지 않는다.
- 이벤트: 마피아 소켓에만 밤 `chat`·`emoji`(저장 안 함, 밤이 끝나면 폐기). 템플릿 ID 는 밤 전용 3개 추가.
- 누출 테스트에 "마피아가 아닌 소켓은 밤 chat·emoji 프레임을 받지 않는다", "비경찰은 수사 기록·새 기록 알림을 받지 않는다", "동료 선택은 마피아에게만 간다" 포함(계획).
