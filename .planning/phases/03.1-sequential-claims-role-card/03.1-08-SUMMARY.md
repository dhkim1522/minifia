# Phase 3.1 Plan 08: 유저 기록 카드와 낮 캐릭터 탭 Summary

낮(claim·discussion·morning)에 캐릭터를 누르면 그 사람의 날짜별 주장 기록 카드(`{닉네임} 기록`)가 최신 위로 열리고, 밤에는 열리지 않으며, 카드는 공개 정보 `claimLog` 만 입력으로 받는다.

## 한 일

**Task 1 — UserRecordSheet** (RED `cad1a1e` / GREEN `6a6ac57`)

- `Sheet` 틀(`showClose`, `mf-sheet--urecord`) 위에 제목 한 줄(색깔점 12px `var(--seat-N)` + 닉네임)과 `ol.mf-urecord__list`. 입력 배열을 바꾸지 않고 seat 로 거른 뒤 뒤집어 일차 내림차순·같은 일차는 기록 역순으로 그린다.
- 행: `N일차` | `<b>직업</b>{CLAIM_JOSA} 주장했어요`, none 은 `말하지 않았어요`(b 없음), 기록이 없으면 목록 면은 그대로 두고 `아직 주장 기록이 없어요`. 직업 이름·조사는 `roleText.ts` 표(`ROLE_TEXT`·`CLAIM_JOSA`·`CLAIM_NONE_LINE`)를 쓰고 새 문장표를 만들지 않았다.

- 테스트 17건: 시트 이름·제목·닫기, 행 순서·조사 표·b·none·역순·원본 불변·타 seat 제외, 빈 상태, `처형`·`탈락`·`투표` 부재, HTML 닉네임 글자 처리(T-03.1-23), 소스에 `spectate`·`me.role`·`RoomView` 없음(T-03.1-22), CSS 규약.

**Task 2 — 낮 탭 연결** (RED `63d8bdc` / GREEN `ba2c549`)

- `DayScene`: `inspectSeat` 상태, 낮 세 단계에서 모든 자리에 `onInspect: () => setInspectSeat(seat)`, 밤에는 키 자체를 주지 않음. 밤이 되면 렌더 중 `setInspectSeat(null)`. 장면 끝에 `<UserRecordSheet seat nickname claimLog={view.day?.claimLog ?? []} />`.
