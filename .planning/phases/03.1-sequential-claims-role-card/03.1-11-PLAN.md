## Claude 재량 결정

- **클래스 이름은 03.1-09 의 E2E 계약과 같다:** 버튼 `mf-rolecard-btn`, 점 `mf-rolecard-btn__dot`, 알림 `mf-rolecard-toast`(버튼 요소, 바깥 `div[role=status]` 래퍼 안). 이름을 바꾸면 E2E 스냅숏이 null 을 읽는다.
- **NEW 개수 = 이번에 새로 본 줄 수:** 활동 기록 탭이 보이는 순간의 안 읽은 수(`len − seen`)를 `newCount` 로 잡고 시트를 닫을 때 0 으로 되돌린다. 탭이 열려 있는 동안 새 기록이 오면 그만큼 더해진다. 03-11 의 "맨 위 한 줄만 NEW" 에서 넓어진 UI-SPEC D 의 규칙이다.
- **알림은 DayScene 에 둔다(03-11 선례):** 같은 epoch 에서 길이가 늘 때만 띄우는 판단이 `connection.epoch` 와 view 를 모두 보는 DayScene 에 이미 있다. 시트 열림 여부와 "누르면 활동 기록 탭" 은 RoomScreen 이 props(`roleCardOpen`, `onOpenActivity`)로 넘긴다.
- **헤더 버튼이 정확히 하나:** `headerExtra` 가 모든 역할에서 `[역할 카드]` 하나(테스트 방 방장은 앞에 [테스트]가 붙는 기존 규칙 그대로 — 장면에서는 닻이라 헤더 밖). 경찰 전용 분기를 지운다.
- **기록 보기 읽음 키는 그대로:** `minifia:records:{방코드}`(03-11 과 같은 키)를 쓴다. 03-11 에서 저장한 값이 있으면 경찰은 그대로 이어서 읽음 처리된다.
- **옛 시트·옛 CSS 삭제:** `MyRoleSheet`·`RecordsSheet`(+`RecordsButton`)·`RecordsToast`·`records.css` 와 `phase.css` 의 `.mf-myrole-sheet*` 를 이 계획에서 지운다(03.1-06 이 대체 부품을 이미 만들어 두었다).
