<domain>
## Phase Boundary

Phase 3(밤과 아침) 배포본에서 나온 사용자 피드백과 `npm run e2e` 결함(72건 실패)을 한 묶음으로 해결한다.

- 직업 공개 단계를 **한 명씩 차례로**(8초) 진행하고 주장은 **평문 채팅**으로 올린다. 이름표는 이름 한 줄, 낮에 캐릭터를 탭하면 **유저 기록 카드**(날짜별 주장 내역).
- 헤더 [내 역할] → **[역할 카드]**. 시트에 `내 역할 | 활동 기록` 탭. 활동 기록은 경찰 수사일지, 마피아 암살일지(사망/생존), 의사 치료일지. 안 읽은 기록은 앰버 점.
- 헤더의 [수사 기록] 버튼과 시트를 없앤다(경찰 헤더 제목 줄바꿈 D1 해소).
- 겹침 수정: 이름표를 캐릭터 아래 층으로, 아침 카드 연출(팝 + 어둡게 층 + 유령 강조), [테스트] 버튼 위치는 왼쪽 위 유지(완화된 검사).
- 관전자(탈락자) 테이블은 살아 있는 다른 사람을 **실제 직업 캐릭터**로 그린다.
- 테스트 봇과 UAT·E2E 스크립트를 새 규칙에 맞춘다. `npm run e2e` 전부 통과(승인된 완화 3건 제외).

이 페이즈가 하지 않는 것: 4페이즈(투표·처형·승패), 일지의 래스터 일러스트(데스크톱 몫, SVG 로 먼저 만든다), 6~8명판 이름표 머리 위 배치(폐기), 큰 화면 테이블 세로 가운데(별도).
</domain>

<decisions>
## Implementation Decisions (모두 확정)

### 순차 주장 (결정 0023)
- **D-01** 직업 공개 단계는 자리 순서(시계 방향)로 한 명씩 진행한다. 시작 자리는 날마다 한 칸씩 이동한다. 1일차 시작 자리는 서버 규칙으로 계획이 정한다(방장부터 또는 임의, 기본은 방장).
- **D-02** 한 명당 8초. 일찍 고르면 바로 다음 사람. 탈락자는 건너뛴다. 시간 초과는 "말 안 함"이며 **어제 주장을 이어 가지 않는다**.
- **D-03** 지금 차례인 사람에게만 직업 고르는 화면(이번 판 직업 + 말 안 함)이 뜬다. 나머지는 기다리며 이모티콘만 보낼 수 있다(UI-SPEC K1~K4).
- **D-04** 주장은 평문 채팅("저는 경찰이에요" / "말하지 않았어요")으로 올라온다. 이름 옆 대괄호, 직업 배지, 이름표 아랫줄 주장, ↺ 말 바꿈, "탈락" 글자는 없다.
- **D-05** 날짜별 주장 내역은 서버가 공개 정보로 보관해 모두에게 보낸다. 채팅은 그날만 폰 메모리에 두고 서버에 저장하지 않는다(결정 0017-7).
- **D-06** 낮에 캐릭터를 탭하면 유저 기록 카드(모달)가 열린다. 밤에는 탭이 대상 선택만 한다(관전자는 밤에 아무 일 없음). 아침 5초에도 열린다.
- **D-07** `claimReveal` 단계의 운명(없애는지, 짧은 대기로 남기는지)은 계획이 정한다. 와이어 계약 변경은 결정 0020 방식으로 새 결정 기록(0027)에 적는다.

### 역할 카드와 일지 (결정 0026)
- **D-08** [역할 카드] 버튼, 시트 제목 "역할 카드", 탭 `내 역할 | 활동 기록`. 시민은 탭 없이 기존 시트(같은 128×160 액자 구조).
- **D-09** 일지는 역할별: 경찰 수사일지(`마피아`/`마피아 아님`), 마피아 암살일지(`사망`/`생존`, 의사가 살려도 `생존`으로만), 의사 치료일지(보호한 사람 + `보호`, 구출 성공 여부는 적지 않는다). 밤은 암살, 낮 투표는 처형으로 용어를 나눈다.
- **D-10** 서버는 일지 데이터를 **본인에게만** 보낸다(`me.records` 일반화). 마피아에게는 동료가 같이 알 수 있는 지목 결과(사망/생존)만, 의사에게는 자기가 보호한 대상만. 다른 사람·살아 있는 다른 역할·일반 브로드캐스트에 새지 않는다(전수 누출 테스트 필수).
- **D-11** 안 읽은 기록: [역할 카드] 버튼 모서리 앰버 점(12px), 활동 기록 탭 앰버 점(10px). 숫자 없음. 탭을 열면 읽음 처리되고 읽은 개수를 폰 메모리(`minifia:records:{방코드}`)에 저장한다. 다른 기기에서는 다시 보일 수 있다.
- **D-12** 밤 끝 알림은 눌리는 버튼(높이 44 이상, 4초). 문구는 역할별 일지 이름. 누르면 활동 기록 탭이 열린다.
- **D-13** 일지 그림은 SVG 로 직접 그려 `public/journals/journal_{police,mafia,doctor}_{cover,page,icon}.svg` 슬롯에 둔다. 나중에 래스터로 바꿀 때는 `src/net/assets.ts` 의 `journalArt(role, slot)` 만 고친다. 새 색 토큰 12개(앰버 + 일지 색)는 `design/tokens.json` → `npm run tokens`.

### 화면 겹침·연출 (UI-SPEC F1~F8)
- **D-14** 이름표는 한 줄(이름만)이고 모든 캐릭터 **아래 층**에 둔다(z-index 이름표 1~11, 캐릭터 12~22). 가려질 수 있는 쪽은 이름표다. 7·8명판 최소 55%까지 수용.
- **D-15** 아침 카드는 지금 위치(테이블 위 가운데, top 168, 폭 252) 그대로 두고 연출을 더한다: scale .92→1 팝(300ms), 뒤 장면 어둡게 층(night-900 45%, 이름표·헤더·패널은 제외 범위는 UI-SPEC F절), 탈락자 유령 맥동(400ms). 어둡게 층은 탭을 통과시킨다.
- **D-16** [테스트] 버튼은 왼쪽 위 유지(상자와 14×1.5px 겹침 수용, 눌림은 `elementFromPoint` 로 확인).
- **D-17** 관전자(탈락한 본인) 화면: 살아 있는 다른 자리를 `public/characters/roles/{job}_default` 로 그린다. 살아 있는 사람 화면에는 어떤 `roles/*` 그림도 남에게 쓰지 않는다. 탈락자 자리는 유령. 관전자 이름표도 한 줄.
- **D-18** E2E 완화 3건(M1 아침 카드, D3 이름표 층, D4 테스트 버튼)은 사용자가 승인했다. 다른 기준(0.5px, 1.6배, 45% 등)은 낮추지 않는다.

### 운영·검증
- **D-19** 서버가 규칙을 정한다(결정 0002). 클라이언트는 받은 상태를 보여 주고 행동만 보낸다. 다른 사람의 역할은 살아 있는 사람에게 보내지 않는다(관전자 예외, 결정 0021).
- **D-20** 봇(`shared/game/bots.ts`)은 `botClaimChoice` 단일 함수와 `botPlanKey`(차례 번호 추가)를 바꿔 차례제를 따른다. 봇 시나리오 UAT 는 5·8명판으로 갱신한다.
- **D-21** TDD: 서버 규칙·누출 테스트를 먼저 쓴다. 타입체크·전체 테스트(1,486건 이상)·`npm run e2e` 통과 후 개인 계정(`npx wrangler whoami` 가 `dhkim1522@naver.com`)으로 Worker `minifia` 만 배포하고 배포본에서 smoke·봇 UAT·E2E 를 돌린다.
- **D-22** HANDOFF.md 갱신 + push. 실기기 확인 목록(iPhone Safari·Android Chrome 가독성, 애니메이션 부드러움, 다기기 타이밍)을 남긴다.

### 사용자 확인 대기(기본값으로 진행)
- UI-SPEC "확인 필요" 1~15번(헤더 실측 119.2, 탭 줄 모양, 간격 6→4/8 조정, [역할 카드] 버튼 14px, NEW 앰버 등)은 기본값으로 진행하며 사용자가 바꾸라고 하면 그 줄만 고친다.
