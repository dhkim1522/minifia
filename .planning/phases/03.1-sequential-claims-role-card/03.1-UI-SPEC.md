# Phase 3.1 — UI Design Contract (순차 주장과 역할 카드)

> 화면·상호작용 계약서. 요구사항 DAY-02(차례 주장), NIGHT-04(역할별 화면: 일지), ELIM-01(관전)의 화면 몫이고, 성공 기준 4(실제 폰 화면에서 겹침·줄바꿈 없음)의 **수치 계약**이다.
>
> **시각 디자인은 사용자가 승인한 시안이다(`design/screens/claim-turns-v1/`, `design/screens/role-card-v1/`).** 이 문서는 새 모양을 만들지 않고 시안을 토큰·부품·상태표·좌표로 옮긴다. 시안이 정하지 않은 곳(탭 모양, 배치 규칙, 좌표)과 시안과 **달라지는 곳**은 "시안과 달라지는 곳"과 "확인 필요"에 모았다. 달라지는 곳은 모두 **계산으로 이유를 댄다**(승인 시안대로는 E2E 결함이 남기 때문).
>
> **결정 0028 개정(quick 261025-qvx, 2026-10-25).** 실기기 피드백으로 이 문서의 ① 밤 끝 알림(R6·S10·S13·F4)을 **폐기**하고, ② 차례 링을 뒤쪽 호/앞쪽 호 두 층으로 나누고, ③ 테이블·캐릭터 기하를 승인 시안 P2(`design/screens/table-v1/`)로 **모든 단계(대기실·역할 배정·낮·밤·아침)에서 고정**하고(폭별 규칙, 장면 상자 통일), ④ 밤 시작 문구를 더했다. 아래 본문에서 「폐기」「결정 0028」 표시가 있는 곳이 개정된 곳이다.
>
> 1·2·3페이즈 계약(`../01-walking-skeleton/01-UI-SPEC.md`, `../02-day-discussion/02-UI-SPEC.md`, `../03-night-morning/03-UI-SPEC.md`)의 토큰·글자·간격·접근성 규칙을 그대로 물려받고, 이 문서에 적힌 것만 덮어쓴다.

## 화면 기하 (수치 계약의 기준)

모든 좌표는 `src/game/dayTable.ts` 와 같은 공식으로 계산했다(**결정 0028: 승인 시안 P2 로 고정 — 대기실·역할 배정·낮·밤·아침에서 같은 기하**). 자리 `k`(나 = 0, 시계 방향), 인원 `n`: `θ = π/2 + 2πk/n`, 발 위치 `x = cx + rx·cosθ`, `y = cy + ry·sinθ`, 깊이 `d = (sinθ+1)/2`, 배율 `s = 0.8 + 0.2d`, 캐릭터 상자(배율 적용 후) 폭 `72s`·높이 `96s`, 왼쪽 `x − 36s`, 위 `y − 96s`. **얼굴 영역 = 상자 위 45%**(E2E `FACE_RATIO`). 테이블 인물 8종 PNG 의 알파 경계를 재 보니 머리는 가로 8~92%, 세로 6~16%에서 44% 에 있어 이 영역이 머리를 거의 정확히 덮는다(투명 여백이 아니다).

- **대기실**: n 명이 좌석 번호 순서의 등간격 타원에 앉는다(내가 맨 아래 가운데, 2명 마주 봄, 3명 삼각 — E2E **L6**). 사람이 들어오고 나가면 나머지가 `var(--dur-med) var(--ease-out)` 전이로 새 자리로 미끄러진다(`.mf-dt--slide`; 축소 모션에서는 전이 없음). 방장 왕관·끊김 흐림·끊긴 사람 내보내기 누르기·입장/퇴장 전이·내 링은 그대로다. 서버 좌석 번호·낮 차례 순서는 바뀌지 않는다.
- **역할 배정**: 같은 `DayTable` 위에 어두운 막과 안내를 얹는다. 머리 제목 `역할 배정` 하나, 하단 패널은 비어 있되 높이 157. 마크업은 역할·동료를 읽지 않는다(마피아 view 와 역할 없는 view 의 innerHTML 동일).
- 세 크기(와 375) 모두 장면 높이 ≥ 332 라 cy = 210 고정(`cy = max(177, min(210, 장면높이 − 122))`). 보장 하한: 장면 높이 ≥ 299 (뷰포트 높이 ≥ 576).
- 430×932 는 테이블 아래에 약 297px 빈 배경이 남는다(관찰, 이 페이즈에서 바꾸지 않음 — "확인 필요" 6).

E2E D2·G2 는 폭 전체인 `.mf-dayscene__scene` 와 `left ≥ −0.5` 로 재므로 99px 이름표까지 통과하지만, 5글자 이름표가 실기기 글꼴에서 99px 을 넘으면 폰 가장자리에 걸린다. 대안은 이름표 여유 `RX_TAG_HALF` 49 → 50(상수 하나: 390폭 rx 145·면 214·간격 6.7). - **D3b (가독성 바닥)**: 이름표의 보이는 비율이 인원별 바닥 이상 — 4·5명 99.9 %, 6명 ≥ 85 %, 7명 ≥ 50 %, 8명 ≥ 55 %. 위 표의 최소값보다 약간 낮게 잡은 회귀 방지선이다(바닥은 결정 0028 에서도 낮추지 않았다). 측정은 페이지 안에서 각 캐릭터 `<img>` 를 오프스크린 canvas 에 그려 알파를 읽고, 위 0.5px 격자 방식으로 계산한다(상자 기준은 투명 여백 때문에 7명판 35~41 % 로 과하게 비관적이라 쓰지 않는다).
- 기준 수치 0.5px·45%·1.6배 등 다른 검사는 건드리지 않는다.

### F. 아침 카드 배치와 연출 (사용자 결정: 카드는 장면 위, 하단 패널 안이 아님)

**배치 (3페이즈 그대로)**
- 카드는 `.mf-dayscene` 루트 기준 `position:absolute; z-index:70; left:50%; top:168px; transform:translateX(-50%); width:252px`. 루트 원점이 페이지 맨 위라 장면 기준으로는 y 48.8 이다. 안쪽 12 16, 모서리 16, 면 `color-mix(in srgb, var(--night-900) 92%, transparent)`, 1px `--night-600`, 그림자 `0 10px 28px var(--shadow)`. 제목 24px 굵게 gray-50, 보조 14px/20 gray-300(위 4). 문구는 `morningCardText` 그대로(탈락 문구 8개 `님이` / 무사 `아무 일도 없었습니다` + `모두 무사해요`). 탈락자·관전자 화면에도 똑같이 보인다. 클릭을 막지 않는다(`pointer-events:none`).
- 하단 패널은 3페이즈 그대로: 제목 `아침이 밝았습니다`(24px) + 안내 `곧 낮 토론이 시작돼요`(14px/20 gray-300), 알약·채팅·버튼 없음. 패널 높이 157 불변(8 + 28.8 + 8 + 20 = 64.8 ≤ 157).
- 카드 높이: 제목 1줄 52.8 / 2줄 81.6 / 3줄 110.4(안쪽 24 포함), 무사 문구 105.6(제목 2줄 + 보조). 폭 252 → 글자 영역 220(24px 약 9자). 모든 문구는 `keep-all` 로 최대 3줄.
- 카드 좌표(페이지): x = `뷰포트폭/2 ± 126` → 360폭 54~306, 390폭 69~321, 430폭 89~341. y = 168 ~ 168 + 높이 → 최대 278.4. 하단 패널 위(483/507/775)와 내 캐릭터 상자 위(페이지 y 333.2) 위쪽이라 **패널·내 캐릭터·내 이름표와는 겹치지 않는다**(여유 54.8).

**정직한 한계: 카드는 이 5초 동안 뒷자리 얼굴을 가린다.** 위 좌표를 얼굴 영역(상자 위 45%)과 계산하면(세 크기 같음, 나 제외):

| 인원 | 제목 1줄 카드(52.8)가 얼굴을 덮는 자리 | 제목 3줄 카드(110.4)가 덮는 자리 |
|------|------------------------------------------|-------------------------------------|
| 4명 | 2 | 1, 2, 3 |
| 5명 | 2, 3 | 1, 2, 3, 4 |
| 8명 | 3, 4, 5 | 2, 3, 4, 5, 6 |

8명판은 얼굴 사이 빈 가로 띠가 높이 28.1([95.5,123.6])·25.0([162.5,187.5])뿐이라 어떤 위치·크기의 카드도 테이블 위에서는 얼굴을 피할 수 없다(5명판도 빈 띠 65.7 < 2줄 카드 81.6). 그래서 이 5초에 한해 얼굴 가림을 허용하고, 대신 **어둡게 층으로 가려진 뒷자리를 의도적으로 뒤로 물리고** 카드·탈락자에 시선을 모은다. 5초가 끝나면 카드와 층이 사라지고 다음 낮 장면의 D3·D4 는 그대로 0(엄격)이다.

**연출 (결정 0006 기본형, 소리·진동 없음)**
1. **카드 등장**: `scale .92 → 1` + `opacity 0 → 1`, 300ms `var(--ease-out)`. 가운데 `translateX(-50%)` 를 건드리지 않도록 개별 속성 `scale` 로 애니메이션한다(`mf-dt-pop` 선례). 축소 모션: `opacity` 만(scale 없음).
2. **어둡게 층 `.mf-dt__dim`**: `DayTable` 루트(= 장면 상자) 안에 `position:absolute; inset:0` 로 장면 상자 전체(좌우 여백 포함: `left/right: calc(-1 * 장면 좌우 여백)`)를 덮는다. 면 `color-mix(in srgb, var(--night-900) 45%, transparent)`, `z-index:30`(캐릭터 12~22·이름표 1~11 모두 위 → 둘 다 함께 어두워진다. 이름표 글자 gray-50 은 어두워진 뒤에도 night-900 위 5.61:1 이고, 누가 탈락했는지는 카드 제목이 이름으로 알려 준다), `opacity 0→1` 300ms `var(--ease-out)`. **헤더와 하단 패널은 덮지 않는다**(장면 상자 밖). `pointer-events:none` 이라 탭이 캐릭터로 통과한다 → 아침(5초)에도 유저 기록 카드가 열린다(확인 필요 #9 유지). `aria-hidden`.
3. **퇴장**: 카드와 층이 함께 `opacity 1 → 0`, 300ms, `animation-delay = 아침 길이 − 300ms`(= 4.7s, 길이는 `view.phaseDurationMs`). 단계가 바뀌면 장면이 새 화면으로 바뀌므로 어느 쪽이든 다음 낮에 남지 않는다.
4. **탈락 유령 강조**(탈락자가 있을 때만, 방금 탈락한 자리 하나): 어둡게 층 시작과 같은 순간. ① 그 자리의 상자에 `z-index:31`(층 위)을 주어 **아침 내내 유령은 어두워지지 않는다**(이름표는 어두워진 채). ② 400ms 한 번 맥동: 개별 속성 `scale: 1 → 1.12 → 1`(40% 지점이 정점, 발 기준 `transform-origin: 50% 100%` 그대로)과 그림 `img` 의 `filter: brightness(1 → 1.3 → 1)`, `var(--ease-out)`, 끝나면 `filter` 없음(탈락 표시에 흑백·흐림을 쓰지 않는다는 3페이즈 규칙과 충돌하지 않는 일시 효과). 축소 모션: 맥동 없음(① 만 유지). 밤 → 아침 전환을 이 화면이 직접 본 경우에만 켠다(재접속·처음 마운트에서는 ①만).
5. 재접속으로 아침 중간에 들어오면 카드·층은 같은 애니메이션이 처음부터 돌고 남은 시간만큼만 보인다(퇴장 지연은 남은 시간 기준). 허용된 단순화.

### H. 관전자 테이블 — 직업 캐릭터 (사용자 아이디어, F6 — 시안 없음, 글로만 정의)

탈락한 사람이 관전할 때(결정 0021) **다른 살아 있는 사람들의 테이블 캐릭터가 중립 인물(`fig1..8`) 대신 실제 직업 캐릭터로 그려진다.** 탭할 필요가 없다. 이름표는 모든 화면에서 이름 한 줄이다(F5).

- **대상과 조건**: `meDead && view.spectate` 인 화면의 **살아 있는 다른 자리**만. 직업은 `view.spectate.seats[].job` 에서만 읽는다(서버가 탈락자에게만 보내는 값). 살아 있는 사람의 화면에는 이 값도, 이 그림을 쓰는 코드 경로도 없다 — **살아 있는 사람이 남의 역할을 받지 않는다는 불변은 그대로**다(결정 0002·0021).
- **그림**: `public/characters/roles/{mafia|police|doctor|citizen}_default@2x.png`(srcSet `@2x 1x, @4x 2x`, 기존 `roleArtSrc(job)`)를 중립 인물과 같은 72×96 상자에 `object-fit: contain` 으로 그린다. 규격 근거: `design/characters/ASSET_SPEC.md` §1(72×96, 발 끝은 아래에서 2px 위, 가로 가운데)과 §5(직업 인물)이며, 실제 PNG 도 144×192 로 같고 알파 경계가 세로 4~6 % ~ 97 %, 가로 3~8 % ~ 91~96 % 로 중립 인물(세로 6~16 % ~ 97 %)과 거의 같다. 그래서 상자 크기·발 위치·이름표 위치·층 순서(이름표 아래)는 **그대로**다. 모든 역할 그림은 이미 입장 때 미리 받아 두므로(`assets.ts` 미리 받기 목록) 추가 요청으로 역할이 드러나지 않는다.
- **잃는 것**: 중립 인물의 넥타이 좌석색(`--seat-1..8`)이 직업 그림에는 없다. 좌석 구분은 **한 줄 이름표의 색깔점 `.mf-dt__dot`(8px, `var(--seat-N)`)이 유일한 단서**가 된다 — 이름표 한 줄 마크업(`.mf-dt__name` 안 점 + 닉네임)에 점이 그대로 있음을 확인했다(변경 없음). 채팅 줄·기록 카드 제목의 색깔점도 같은 색이다.
- **그대로인 것**: 탈락한 다른 사람은 유령 그림 그대로(직업 그림 아님). 내 자리는 유령 그대로이고 따로 다르게 보이지 않는다. 마피아 링·마름모, 직업별 표적 배지(`spectatorPicks`), 방장 왕관, 내 링, 끊김 흐림 모두 그대로.
- **바뀌는 순간**: 내 탈락이 발표되어 내 view 에 `spectate` 가 처음 실리는 state(보통 아침)부터 모든 단계(낮·밤·아침)에서 유지. 교체 연출은 기존 장면 진입과 같은 `opacity` 페이드 300ms 하나뿐이고 축소 모션이면 없음(즉시). 재접속해도 `spectate` 가 있으면 처음부터 직업 그림. 판이 끝난 뒤의 모습은 이 페이즈에서 바꾸지 않는다(4페이즈).
- **상호작용**: 낮에 직업 그림을 눌러도 다른 사람과 같은 기록 카드(주장 기록만). 밤에는 아무 일도 없다.
- **접근성**: 그림은 장식(`alt=""`)이고 자리 `aria-label` 이 `{닉네임}, {직업}` 으로 읽는다(탈락한 본인 화면 한정).
- **[테스트] 영향**: 경찰 그림은 머리 윗끝이 상자 위 4 % 라 배율 0.8 에서 3.1px 아래다. E 의 깊이 규칙(≤ 3px)은 그대로이고 실측 겹침은 1.5px 라 그림은 덮이지 않는다.

## 접근성·상호작용 규칙

- 누르기 영역 ≥ 44: 위 "Spacing 예외" 목록. 탭·[역할 카드]·칩·닫기 모두.
