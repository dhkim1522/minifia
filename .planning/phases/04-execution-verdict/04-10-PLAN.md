## Claude 재량 결정

- **스모크는 여부 투표 미통과 경로**를 탄다(클라이언트 다수가 반대): 기존 밤·아침·2일차 검사를 그대로 살리면서 여부 투표 방송·익명·처형 무효 이유를 본다. 처형 경로와 종료는 새 uat-vote 가 맡는다(스모크 한 판이 너무 길어지지 않게).
- **uat-vote 는 전지적**이다(각 클라이언트의 me.role 로 마피아를 안다). 두 판을 차례로 돌고 결과 표를 낸다. 직업 공개는 자기 차례에 none 을 바로 보내 시간을 줄인다(uat-night 방식).
- **아침 문구 번호 상한은 상수로:** 스크립트는 TS 를 import 하지 않으므로 `MORNING_PHRASE_COUNT = 7`(shared/protocol.ts 와 같은 값이라는 주석)을 파일 상단에 두고 범위 검사가 그 상수를 쓴다(smoke.mjs 772행의 하드코딩 8 등).
- **로컬 dev 서버 규칙(03.1-13 선례):** 이 계획이 띄운 프로세스만 다룬다. `npm run dev > "$LOG" 2>&1 & DEV_PID=$!` 로 띄우고 PID 를 스크래치 파일에 적으며, 끝나면 `pkill -P $DEV_PID; kill $DEV_PID` 로 그 PID 와 자식만 끈다. 이름으로 찾아 죽이는 방식은 쓰지 않는다. 긴 실행(3~6분)은 백그라운드로 돌리고 완료 뒤 결과를 읽는다.
