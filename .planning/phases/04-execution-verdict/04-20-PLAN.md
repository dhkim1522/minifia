## Claude 재량 결정

- **화살표 이동은 CSS dash 가 아니라 프레임 보간이다** (UI-SPEC 8.3): dash 는 머리가 처음부터 끝에 있다. 끝점(x2,y2)을 프레임마다 시작점에서 끝점으로 `ease-out`(세제곱)으로 보간한다. 서버 시각은 `Date.now() + connection.offset` 이다.
- **P-14(사용자 확인 대기):** 느린 박동 주기는 CONTEXT D-31 의 약 1.2초 + 진폭 작게(캐릭터 1 → 1.04 → 1, 칩 1 → 1.1 → 1)로 구현한다. 시안 `dk-slow 2.2s` 는 참고만 한다(어긋나면 CONTEXT 가 이긴다).
- **진동(`navigator.vibrate`)은 구현 재량으로 켠다**: 지원하지 않거나 예외가 나면 무시한다. 상수 `CLINCH_VIBRATE_MS`(30)는 04-13 의 `verdict.ts` 에 있다.
- 칩 톤 `beat` 는 확정 순간 두근 동안만, 이후는 `lead` + `slow` 플래그(작은 박동)다.
