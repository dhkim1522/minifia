## 페이즈 목표

낮 토론 뒤 처형 여부 투표, 후보 선택 투표, 최후 변론, 처형을 거치고 승패가 나면 모든 역할이 공개되는 결과 화면으로 가서, 한 판이 끝까지 돌아간다 (결정 0034).

04-25 의 결과 화면에 **공개 연출**을 얹는다: 모든 카드가 한꺼번에 실제 직업 카드로 뒤집히는 순간이 이 판의 마지막 클라이맥스다(D-17). 배포하지 않는다(D-26).

## Claude 재량 결정

- **상태기계:** `neutral`(0~300ms) → `flip`(300~900ms) → `done`(900ms~). 타이머 두 개(300·900)로 `data-stage` 를 바꾸고 CSS 가 단계별로 보임·전이를 정한다. 시간 값은 04-13 의 `RESULT_*` 상수를 읽는다.
- **직업 그림 요청:** 직업 그림은 대기실·배정 때 이미 모두 미리 받아 두었다(`rolePreloadList`). 연출 때 새 요청이 생기지 않는다.
- **모션 줄이기:** 전역 축소 모션 규칙이 애니메이션 길이를 `0.01ms` 로 줄이므로 별도 분기 없이 처음부터 `done` 으로 시작한다(시간표 자체를 돌리지 않는다).
- **P-6(사용자 확인 대기):** 카드를 한꺼번에(순서 없이) 뒤집는 타이밍.
