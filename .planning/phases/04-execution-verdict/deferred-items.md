# 4페이즈 미룬 항목

## 04-08 에서 발견 (범위 밖이라 고치지 않음)

- `scripts/uat-test-bots.mjs` 와 `scripts/e2e/browser.mjs` 는 봇이 낀 테스트 방에서 `testSkip` 으로 낮을 건너 `night` 에 닿는다고 가정한다.
  04-08 부터 넘기기가 여부 투표·후보 선택 단계에서 안 던진 봇 표를 먼저 채우므로, 봇 표가 통과하면 후보 선택·변론·처형을 지나고
  방장이 처형되거나 판이 `ended` 로 끝날 수 있다(무작위). 이 스크립트들은 배포본을 대상으로 하는 수동·E2E 용이라 이번 계획에서 돌리지 않았다.
  화면 웨이브 계획에서 E2E 를 4페이즈 흐름에 맞출 때 같이 고친다(여부 투표에서 방장이 반대 표를 먼저 던지거나, 처형을 단계 진행으로 받아들이게).
- 같은 이유로 워커 테스트 `test/worker/bots.test.ts` 의 밤 두 테스트는 `skipDayToNight` 로 고쳐 결정적으로 만들었다(아래 SUMMARY 편차 1).
