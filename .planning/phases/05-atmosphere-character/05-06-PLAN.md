## 페이즈 목표

화면이 무거운 분위기로 바뀌고, 플레이어마다 외형이 다른 캐릭터를 받으며, 세로 폰 화면에서 처음 하는 사람도 설명 없이 지금 할 일을 알 수 있다 (ROADMAP 5페이즈).

화면 E2E 의 **브라우저 쪽**(04-31·04-32 선례): 05-01·05-03·05-04 가 만든 화면을 실제 Chrome 좌표로 읽어 05-05 의 순수 검사에 넣고, **기존 흐름**에 배선한다. 새 흐름(PC·Wake Lock)은 05-07 이다. 배포하지 않는다 — 로컬 dev 서버로 확인한다.

## Claude 재량 결정

- **칠 순서 확인:** 두 층은 `pointer-events: none` 이라 `elementFromPoint` 가 건너뛴다. 그래서 `readAtmosphere` 는 원래 `pointer-events` 값을 먼저 기록한 뒤, 그 evaluate 안에서만 층의 `pointer-events` 를 잠시 `auto` 로 바꿔 내 인물 그림 가운데(비네팅)·내 이름표 가운데(밝아짐)를 `elementFromPoint` 로 찍고 곧바로 되돌린다. 층이 위에 칠해져 있으면 층이 돌아오고, 아래면 인물·이름표가 돌아온다.
- **짧은 단계의 읽기:** 배정(3초)은 `startGame` 의 `onAssigning` 창에서 읽고, 읽는 동안 단계가 바뀌었으면 기록하지 않고 넘어간다(기존 "이미 지났으면 건너뛴다" 규칙). 낮 시작(2초)은 `dayIntro` 의 기존 규칙대로 단계가 바뀌면 `SetupError` 다.
- **링크 참가 probe 는 대기실 흐름 끝:** 이미 테스트 시트로 봇을 다루는 흐름이라 방 하나를 더 만들지 않는다. 손님 컨텍스트에는 세션 init 스크립트가 없어 링크 참가 화면이 뜨고, 참가하지 않고 닫는다(방에 사람을 더하지 않는다).
