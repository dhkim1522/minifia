## 페이즈 목표

화면이 무거운 분위기로 바뀌고, 플레이어마다 외형이 다른 캐릭터를 받으며, 세로 폰 화면에서 처음 하는 사람도 설명 없이 지금 할 일을 알 수 있다 (ROADMAP 5페이즈). 성공 기준 4 후반(PC 브라우저 가운데 폰 폭)·5(미지원 기기에서도 게임 정상).

화면 E2E 에 **새 흐름 두 개**를 더한다: PC 창 한 흐름(D-11)과 Wake Lock 미지원·스파이 흐름(D-13). 둘 다 폰 크기와 무관하므로 크기 하나로 한 번만 돈다. 배포하지 않는다.

## Claude 재량 결정

- **크기 고정 흐름:** `FLOWS` 항목에 선택 속성 `size: { w, h, label, mobile? }` 를 두고 `run.mjs` 가 그런 흐름은 크기 목록과 곱하지 않고 작업 하나로 만든다. `pc` 는 `1280x800`(모바일 아님), `wakelock` 은 `360x640`. `--only` 는 그대로 동작한다.
- **API 지우기·가짜:** `openHostPage` 에 선택 인자 `initScripts`(문자열 함수 목록)를 더해 세션 스크립트 뒤에 붙인다. 미지원은 `Navigator.prototype` 의 `wakeLock` 속성을 지운다(앱 스크립트보다 먼저). 스파이는 `navigator.wakeLock` 을 `request` 호출 수를 `window.__mfWakeLock` 에 세고 `EventTarget` 기반 가짜 sentinel(`released`, `release()`)을 돌려주는 객체로 바꾼다. 가려짐은 `document.visibilityState` 게터를 바꾸고 `visibilitychange` 를 보내 흉내 낸다.
- **PC 흐름은 모바일 아님:** `openHostPage` 의 `mobile` 인자(기본 참)를 거짓으로 줘 데스크톱 창처럼 연다. 홈(`/`)은 방 없이 연다.
