# Phase 9 — UI Design Contract (밤과 아침)

> 화면·상호작용 계약서. 요구사항 NIGHT-07, NIGHT-08, NIGHT-09, NIGHT-10, NIGHT-11, NIGHT-12, MORN-01, MORN-02, MORN-03, MORN-04, WILL-01 의 화면 몫(GHOST-02 밤 관전 유지).
> 범위는 **(1) 8페이즈 밤·아침 임시 틀(A1)을 지우고 진짜 밤으로 교체: 마피아가 맵을 걷고 대상에게 다가가 확정하는 화면, 시민 편의 깜깜한 화면과 긴장 연출, 경찰·의사의 얼굴 목록, 암살당한 사람의 암살 이펙트, 유령의 밤 관전, (2) 아침: 분필 윤곽, 공개 알림, 유언·쪽지 카드, 의사 구출 공개, 서버가 정하는 아침 길이, (3) 유언 쓰기(깃펜 + 유언 시트)와 마피아 쪽지, 처형된 사람의 유언 공개, (4) 낮→밤→아침 장면 전환과 위치 되돌림**이다. 캐릭터 몸짓·의상(10페이즈), 결과 화면 탭·시상식(11페이즈), 소리(12페이즈)는 이 문서가 정하지 않는다(자리만 남긴다).
> **가장 중요한 규칙(결정 0051, CLAUDE.md)**: 글은 최소로, 보고 누르는 조작 중심. 이 페이즈의 정보는 **장면(조명·어둠·분필·발밑 고리) → 얼굴·아이콘·숫자·도장 → 글** 순서로 보여 준다. 새로 읽게 하는 글은 단계 이름 + 안내 한 줄, 36px 알림 한 줄, 채팅 카드(유언·쪽지) 뿐이다. 마피아는 **대상을 직접 눌러 다가가고**, 경찰·의사는 **얼굴을 누르고**, 시민은 **아무것도 안 해도 된다**(원하면 유언).
> **가장 중요한 불변식 (결정 0002·0021, ROADMAP 성공 기준 1)**: 서버가 시민 편에게 보내는 밤 메시지는 마피아가 움직이든 가만히 있든 **같다**. 시민 편 화면의 긴장 연출은 **클라이언트가 혼자 만드는 연출이고, 받은 어떤 프레임에서도 시작·강도·시각이 정해지지 않는다.** 화면에서 숨기는 방식으로 정보를 감추지 않는다 — 서버가 안 보낸다.

디자인 방향 한 줄: 6~8페이즈 "같은 공간의 스산한 밤"을 그대로 잇는다. 밤의 시민 편은 **거의 깜깜한 화면 + 가장자리에서 뛰는 진홍 맥박** 하나로 불안을 만들고(새 장식을 더하지 않는다), 아침은 해뜰녘의 낮은 명도·채도 그대로 **분필 윤곽과 카드 두 장**으로 사건을 알린다. 아침이어도 밝은 색면을 만들지 않는다. 진홍은 마피아 본인·죽음·시간 끝에만 쓰고 역할을 가리는 화면(지목·찬반·얼굴 목록·시민 편 밤)에는 쓰지 않는다 — 단, 시민 편 맥박은 **모든 시민 편 역할(시민·경찰·의사)에 똑같이** 뛰어서 역할을 알리지 않는다.

참고 자료와 다르게 하는 곳(이유 포함)
1. 승인 `Morning` 보드의 문구 "…당했어요"·"아무 일도 없었어요" 는 **"{닉네임} 님이 당했습니다"·"아무 일도 없었습니다"** 로 한다. 이유: 디자인 시스템 README "사회자 문구는 정통 마피아 그대로"("낮이 되었습니다"·"아무 일도 없었습니다")와 8페이즈 결과 알림 문체를 맞춘다. "누군가 살아났습니다" 는 보드와 같다. 암살당한 본인 알림도 같은 이유로 "암살당했습니다". 또 v1.0 아침 탈락 문구 7가지(`ELIMINATION_TAILS`, "…끝내 아침을 맞지 못했습니다" 등)는 36px 에서 두 줄 이상이 되고 결정 0051 의 3초 규칙에 맞지 않아 **쓰지 않는다**(문구 번호 `phrase` 는 서버·와이어에서 지우는 일을 플래너가 확정한다. 변주가 아쉬우면 사용자가 되살린다).
2. 승인 `NightMafia` 보드의 [쪽지] 버튼은 진홍 면(`rgba(138,15,34,.35)`)·테두리 `#8a0f22`·글자 `#f1a5b0` 이다. 제품은 **`night-700` 면 + `gray-100` 글자의 일반 행동 버튼**으로 하고 `note` 아이콘만 `crimson-300` 으로 둔다. 이유: 디자인 시스템 README "진홍·놋쇠 버튼은 만들지 않는다"가 보드보다 위다. 쪽지를 쓰는 시트(`WillSheet tone="mafia"`)의 진홍 테두리는 부품 사양이라 그대로.

스타일 규칙
- 색·간격·크기·모션 값은 `tokens.css` 변수로만 쓴다. 화면 CSS 에 hex 를 직접 쓰지 않는다. **이 페이즈의 새 토큰은 없다.** 맥박 비네트·번쩍임·가림막의 색은 `color-mix(in srgb, var(--crimson-700) 55%, transparent)`·`var(--crimson-700)`·`var(--night-950)` 로 만든다.

### 밤으로 들어가기 (낮 → 밤, 모든 역할 같음)

1. 처형 단계(5초)가 끝나면 **장면 전환 막**이 `dur-med`(420ms) 동안 `night-950` 100% 로 덮는다.
2. 막이 가장 진할 때: 서버가 보낸 **위치 스냅샷**이 적용된다 — 산 사람 전원이 각자의 `home`(낮 토론이 끝나 모이기 전 자리)에 서고, 조명이 밤 상태로 바뀌고, 지난 낮의 분필이 지워진다. 이 스냅샷도 모든 소켓에 같은 내용이다(시민 편에게는 남의 위치가 이후 한 번도 안 오므로, 이 시점 이전 낮에 이미 알던 위치와 같다).
3. 막이 `dur-slow` 에 걷히면서 36px 알림 **"밤이 되었습니다"**(1.6초)가 뜬다. 시민 편은 걷히는 막 뒤로 거의 깜깜한 화면과 내 캐릭터가 보인다.
4. 마피아·유령은 걷는 연출 없이 한 번에 `home` 에 서 있다(막 뒤). 처형으로 유령이 된 사람은 그 자리에서 유령으로 계속 있다(8페이즈).
- 모션 줄이기면 막이 즉시 덮고 즉시 걷힌다(알림은 그대로).

### 밤 · 마피아 (NIGHT-07, NIGHT-08, NIGHT-12)

- **보이는 것**: 산 사람 전원(시민 편 캐릭터는 `home` 에 서 있음)과 동료 마피아 이름표 위 `RoleChip`(진홍 테두리, 마피아 본인 화면에서 동료에 한해). 죽은 사람(유령)은 안 보인다.

### 유언 쓰기 (WILL-01)

- **깃펜 위치(결정 0054)**: 채팅 입력줄 **왼쪽**(8페이즈가 비워 둔 48 + 간격 8 자리). 48×48 아이콘 버튼 `quill`, 면 `night-700`·`gray-100` 아이콘·반경 `radius-badge`(채팅 보내기 버튼과 같은 계열), 접근성 이름 "유언 쓰기"(저장된 유언이 있으면 "유언 쓰기, 저장됨"), 열려 있으면 `aria-pressed="true"`. 저장된 유언이 있으면 오른쪽 위에 `gray-100` 8px 점(본인에게만, 앰버 아님). **산 사람에게만** 있고 로비·유령·역할 확인에는 없다. 입력줄이 없는 시민 편 밤(시민·경찰·의사)에는 아래 행동 줄의 [유언] 버튼이 대신한다(52 높이, `quill` 22 + 글자 "유언" 16px 700, 눌리면 `gray-100` 면 + `night-900` 글자).
- **시트**: `WillSheet` — 폭 = 화면 − 20(좌우 10), 반경 `radius-lg`, 면 `night-800`, 테두리 `night-600`, 안쪽 12, 간격 10. 제목줄(아이콘 `quill` + "유언" 16px 700, 오른쪽 닫기), 3줄 `textarea`(16px, 100자, placeholder "죽으면 모두에게 보여요"), 아래줄(왼쪽 "n/100" 14px `gray-300`, 오른쪽 [저장] 48 높이 `gray-100` 면 → 저장되면 "저장됨" 비활성 `night-700`). 위치: 아래 패널 위 끝에서 8 위. 키보드가 열리면 패널과 함께 올라가고(7페이즈 `--mf-kb-lift`), **패널 + 시트가 키보드 위 가용 높이(`visualViewport` 높이 − 헤더 62)를 넘으면 패널을 숨기고 시트만 키보드 위에 붙인다.** `visualViewport` 높이가 300 미만이면 `textarea` 를 2줄로 줄인다.
- **쓰는 동안 신호 없음**: 시트의 입력은 채팅 입력 중("…") 경로·`typing` 메시지를 쓰지 않는다. 열기·닫기·고치기·저장 어느 것도 다른 사람에게 가는 메시지가 아니다. 시트를 여는 순간에도 내 입력 중 알약은 뜨지 않는다.
- **저장**: [저장] 과 시트 닫기(바뀐 내용이 있으면 함께 저장) 두 길이 같은 한 메시지를 보낸다. 한글 조합 중에 저장·닫기를 눌러도 조합이 끝난 값으로 보낸다(7페이즈 IME 규칙, 조합 꼬리 방지). 저장 실패(연결 끊김·거절)는 위 알림 "보내지 못했어요. 다시 해 보세요" 후 시트는 열려 있고 "저장됨"으로 바뀌지 않는다. 같은 값은 다시 보내지 않는다. 저장 속도 제한은 서버(플래너)가 정하고 초과는 조용히 폐기된다(7페이즈 방식).
- **다시 열기·재접속(A4 ①)**: 서버가 본인 소켓에만 보낸 내 유언(`me.will`)으로 시트를 채운다. 죽으면 본인의 깃펜은 사라진다. 죽은 뒤 유언을 고칠 수 없다.
- 유령·로비에는 깃펜이 없다. 유령 화면에는 어떤 유언 UI 도 만들지 않는다.

Declared values (multiples of 4) — 6~8페이즈와 같은 토큰:

| md (`space-md`) | 16px | 패널·헤더 좌우, 결과 알림 좌우 |
| lg (`space-lg`) | 24px | (이 페이즈 신규 사용 없음) |
| xl (`space-xl`) | 32px | (이 페이즈 신규 사용 없음) |
| 2xl (`space-2xl`) | 48px | 깃펜·입력칸·보내기·[저장] 높이(`control-input`) |
| 3xl (`space-3xl`) | 64px | (이 페이즈 신규 사용 없음) |

글자 크기 4개, 굵기 2개(400·700), 승인 토큰 그대로. 이 페이즈는 크기를 더하지 않는다.

## 접근성 · 모션 · 입력

- 장면 전환 막·맥박 비네트·번쩍임·베기 `aria-hidden`. 결과 알림 `role="status"`. 시간 링 `role="timer"`. 얼굴 칸·이름표 버튼 `aria-pressed`, 묶음 `aria-label`. 유언 시트 `role="dialog"`(`aria-label` = 제목), 열릴 때 `textarea` 로 초점 이동, 닫으면 열었던 버튼으로 초점 복귀.

## 쓰지 않을 것

- 시민 편 화면에 마피아의 위치·움직임·채팅·동작·고리·선택·확정을 보이게 하는 것, 받은 뒤 화면에서 거르는 방식으로 숨기는 것(서버가 안 보낸다).
- 시민 편 긴장 연출을 서버 이벤트·프레임·마피아 수·방 시드에 묶는 것. 밤 조기 종료. 아침 길이를 비공개 사실로 정하는 것.
- 아침에 마피아의 밤 위치를 그대로 보이게 하는 것(A1 ①을 따르는 한).
- 의사가 살린 사람에게 개별 알림을 주는 것, 누구를 살렸는지 알리는 것, 쪽지를 살린 밤에 공개하는 것(결정 0044-22).
- 처형 때 역할 공개, 유언 공개 때 역할 공개. 유언을 쓰는 동안 입력 중 알약·저장 신호·"쓰는 중" 표시.
- 마피아 합의에 다수결·무작위 동률(v1.0 판정) 쓰기.
- 진홍·놋쇠 행동 버튼(승인 보드의 진홍 [쪽지] 버튼 포함), 진홍 얼굴 목록, 역할마다 다른 어둠·맥박.
- 새 장식 효과(안개·별·번개·핏자국 등 보드에 없는 연출). 소리·햅틱·진동. 감정표현·동작(10페이즈), 채널 탭·밤별 구분선·시상식(11페이즈).
- 시민 편 밤 채팅(읽기·쓰기 모두).
- 아침에 밝은 색면(흰 배경·크림 면)을 만드는 것. 이모지 아이콘, 의미 없는 유리 효과, 보라·파랑 그라데이션, 앰버.
- 화면 전체를 덮는 깜빡임을 1초에 3번 이상 하는 것.
- 캔버스 크기를 키보드나 패널에 맞춰 바꾸기.
