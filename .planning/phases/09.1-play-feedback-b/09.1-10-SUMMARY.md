**09.1-11 이 알아 둘 것**
- `src/styles/penFont.css` 를 편지 부품 CSS 가 import 해야 글꼴이 실제로 불린다. 글꼴 이름은 `"Nanum Pen Script"`, 대체는 `var(--font-serif)` 700. 조각이 93개 unicode-range 라 편지 글자에 필요한 조각만 받는다.
- 글꼴 대기: 편지 시작 전 `document.fonts.load('46px "Nanum Pen Script"', 본문)` 를 `LETTER_FONT_WAIT_MS`(1000)와 경주시키고, 넘으면 대체 글꼴로 진행(C-3).
- `useWillLetter` 는 편지를 `t0`(Date.now 기준)가 **미래**일 때도 곧바로 돌려준다. 화면은 `t0` 까지 편지지를 숨기고 `t0 - 지금` 만큼 기다렸다 등장시키거나, 훅이 돌려준 시점부터 알림을 위로 올릴지 정해야 한다(알림 위치 이동은 `letter.announce` 시각 = T0). 편지 수명은 훅이 `t0 + 5420` 에 null 로 돌려준다(탭이 가려졌다 돌아오면 지난 구간은 setTimeout 이 건너뛰므로 막대·애니메이션은 `t0` 기준 경과 시간으로 위치를 계산할 것).
- 줄 수 측정은 화면이 한다: `chooseTier(measure, 편지지높이 - 56)` 로 단계를 고르고, 보이는 줄 문자열 배열을 `writeSchedule` 에 넘겨 줄별 `at/ms/steps` 를 받는다. 편지지 높이는 `paperHeight(가용)` (가용 높이 공식은 UI-SPEC C-2). 3단계로도 넘으면 `overflow: true` → 가용 높이까지 키운다.
- 훅과 `useChat` 은 **같은 ChatStore 인스턴스**여야 한다(RoomScreen 이 쥔 것). 편지가 있는 아침의 카드 두 장은 `t0 + 5000` 에 `visibleLines` 로 나타난다. 접힘 애니메이션이 카드 도착과 맞도록 `LETTER_FOLD_AT_MS` 를 쓰라.
- 훅은 본문을 카드에서만 읽는다(`liveCard("will", 탈락 좌석)`). 처형된 사람의 유언(M-11)은 카드 그대로이며 훅이 편지를 만들지 않는다.

- `prefers-reduced-motion`: 애니메이션만 끄고 시각(`t0 + 5000` 카드 도착, 5.42초 제거)은 그대로다 — 훅이 이미 시각을 쥐고 있으므로 화면은 CSS 만 분기하면 된다.
