# 09.1 묶음 B — 자동 확인 기록 · 실기기·팀 테스트 확인 이월 (09.1-12)

> 09.1(순차 지목·직업 의상 유령·유언 편지) 결과물의 자동 확인 기록과, 실기기·사람 눈으로 확인할 목록이다. 표 A 는 에이전트 자동 확인이고, 표 B 는 사람이 **모든 개발이 끝난 뒤 한꺼번에** 채운다(사용자 결정 2026-11-02). 이 목록은 09.1 완료를 막지 않는다. **에이전트는 어떤 기기 칸도 통과로 적지 않는다.**
> 관련 결정: [0063](../../../docs/decisions/0063-v2-play-feedback-b.md)(묶음 B) · [0064](../../../docs/decisions/0064-v2-play-feedback-b-plan-values.md)(계획 값) · [0055](../../../docs/decisions/0055-v2-phase6-prep.md)(확인 기기 = iPhone 16 Pro, 고사양 숫자만으로 성능 통과 선언 금지).
> 계약서: [09.1-UI-SPEC.md](./09.1-UI-SPEC.md). 9페이즈 목록 `09-DEVICE-CHECKS.md`(ROADMAP 백로그 999.6)와 같이 돈다.
