## 이월 메모 (뒤 계획용)

### 새 이름
- 와이어(`shared/protocol.ts`): `ClientMessage` 에 `{ t:"whisper"; to:number; text:string }`. `ChatLineWire.k` 는 `"will"|"note"|"whisper"|"whispered"`, `ChatLineWire.to?: number`(귓속말 줄에만). `MyInfo.whisperUsed?: true`.
- 스키마: `z.strictObject({ t:"whisper", to:int 0..7, text:string 1..200 })`.
- 상태(`shared/game/room.ts`): `WhisperRecord {n:일차, from:seat, to:seat, text:정리된 본문, at}`, `RoomState.whispers?: WhisperRecord[]`(서버 전용, 어떤 view 에도 없음, 11페이즈 입력). `resetToLobby` 는 허용 목록 리터럴이라 자동으로 빠진다.
- 규칙(`shared/game/whisper.ts`): `WHISPER_MAX_GRAPHEMES`(30)·`WHISPER_PER_DAY`(1)·`WHISPER_PHASES`(discussion)·`whisperUsedToday(state, seat)`·`sendWhisper(state, actorId, toSeat, rawText, now)` -> `{ok,state,record}|{ok:false,error}`. 검사 순서: 단계 -> 행위자(방에 있고 산 사람) -> 대상(정수·산 사람·자기 자신 아님) -> 오늘 횟수 -> 본문(`sanitizeChatText` + 30자소).
- 보관(`shared/game/chatLog.ts`): `ChatKind`, `ChatRecord.to?`, `appendWhisperPair(log, {seat,to,text,at,n,partyMask,othersMask})` -> `{log, body, fact, evicted}`. `toWire` 는 `to` 를 있을 때만 복사한다. `parseRecord` 는 새 종류를 받고 귓속말 종류는 `to`(0..7) 필수, will·note 에 붙은 `to` 는 버린다.
- DO(`worker/room.ts`): `handleWhisper`/`applyWhisper`. 성공 시 `storage.put("room")` -> 두 레코드 `storage.put(chatKey(g))` -> 당사자 `deliver(body)` + 나머지 `deliver(fact)` -> 보낸 사람에게만 `sendViewTo([playerId])`. `persistAndBroadcast` 는 부르지 않는다. 거절은 `sendRejection`(보낸 소켓에만 `error`+`state`).

### 동작 사실(화면·다음 계획이 기대해도 되는 것)
- 어느 소켓이든 그 채널 seq 에 줄이 정확히 하나다: 당사자는 본문 줄, 나머지(유령 포함)는 사실 줄. 재접속 복원도 같다(`replayFor` 가 마스크로 고름).
- 사실 줄에도 `seat`(보낸 사람)·`to`(받는 사람)는 실린다 — 누가 누구에게 보냈는지는 공개 사실, 본문만 비공개다. `at` 은 두 줄이 같다.
- `me.whisperUsed` 는 discussion 단계의 산 본인이 오늘 이미 보냈을 때만, 보낸 사람 본인 view 에만 생긴다. 보낸 직후 그 소켓만 state 를 한 번 받는다. 다른 소켓엔 state 가 가지 않는다.
- 하루 1번은 서버가 `state.day`(없으면 1)로 센다. 같은 낮 두 번째·유령·자기 자신·죽은 대상·방에 없는 좌석·빈 글·31자소는 전부 `BAD_MESSAGE`(오라클 금지, 시험으로 프레임 열 구별 불가를 고정). 단계가 토론이 아니면 `WRONG_PHASE`.
- 귓속말 줄은 채팅 보관 all 채널 상한(100줄)에 다른 줄처럼 밀려 지워질 수 있다. 본문 자체는 `RoomState.whispers` 에 남는다(시험으로 고정).
- 소켓 속도 제한은 기존 연결당 초당 20개 한도가 그대로 적용된다(귓속말 전용 간격 없음 — 하루 1번 서버 계수가 연타를 막는다).
