# Phase 10 — UI Design Contract (캐릭터·동작·의상)

> 화면·상호작용 계약서. 범위는 **(A) 제자리 동작(감정표현) 고르기와 재생, (B) 로비 의상 갈아입기와 게임 중 유지, (C) 걷기·방향 확인, (D) 8명 성능 예산, (E) 에셋 제작 방식**이다. 결과 화면의 직업 의상·동작 통계(11페이즈), 효과음·진동(12페이즈·앱 전환)은 정하지 않는다.
> **가장 중요한 규칙(결정 0051)**: 글은 최소로, 보고 누르는 조작 중심. 동작은 **그림 아이콘 + 한 단어**로 고르고, 보이는 결과는 **캐릭터의 몸**이다. 새로 읽게 하는 글은 없다.
> **사용자 결정 2026-11-05(결정 0064-16)**: 감정표현은 **몸 동작만**이다. 머리 위 표시(말풍선·아이콘·이모지·글자·이펙트)를 어떤 형태로도 두지 않는다. 동작마다 붙던 반짝임·땀·눈물·속도선(결정 0047-2)도 이 페이즈에서 **만들지 않는다**.
> **가장 중요한 불변식(결정 0002·0021·0037)**: 동작과 의상은 역할 정보를 나르지 않는다. 의상은 **고른 대로** 나오고 실제 역할의 함수가 아니다. 동작을 받을 사람은 서버가 정한다(밤 마피아 동작은 마피아·유령에게만, 유령 동작은 유령에게만). 화면에서 거르지 않는다.

## 시안(승인 디자인 시스템)과 다르게 하는 곳

1. **감정표현 줄 9칸 한 줄 → 5+4 두 줄 판.** 승인 CSS(`.mv-chat__emotes`)는 9열이라 폭 360 에서 칸 폭이 약 33px 이다. 누르기 대상 44 미만이다(`tap-min`). 두 줄(칸 폭 59 이상)로 바꾼다.
2. **꾸미기 시트 3열 × 3행 → 한 줄 가로 카드 띠.** 승인 `.mv-dress__outfits` 3×3 은 폭 328 에서 높이가 약 466 이라 로비 패널(250)에 들어가지 않고 무대를 가린다. 카드 한 줄(72×112)로 줄이고 가로 스크롤 스냅으로 넘긴다. 방장용 [맵 | 의상] 탭은 11페이즈(맵 선택)가 더한다 — 이 페이즈는 의상만이라 탭이 없다.
3. **효과(반짝임·땀·눈물·속도선) 없음.** 결정 0047-2 의 효과는 0064-16(머리 위 표시 없음)과 부딪치는 것이 많고 드로우콜을 늘리므로 몸 동작만 한다.
4. **동작 아이콘의 보이는 이름은 3글자 이하로 줄인다**(14px 한 줄). 접근성 이름은 기존 `EMOTE_LABEL` 그대로.

# A. 동작 (제자리 몸 동작)

## A-1. 진입 버튼

- **위치(D-1)**: 채팅 패널 입력줄 **맨 왼쪽** 48×48 버튼(승인 `ChatPanel` 구조). 아이콘 `face`, 접근성 이름 "동작 고르기", `aria-expanded`, `data-emote-button`. 떠 있는 버튼 묶음(배지·귓속말·꾸미기, 오른쪽 16)과 **같은 자리를 쓰지 않는다**.
- 입력줄 폭: `[동작 48][8][입력칸][8][보내기 48][8][깃펜 48]` — 폰 폭 360 에서 입력칸 **160**(깃펜이 없는 로비·유령은 216). 입력칸 placeholder 는 이 폭에 한 줄로 들어가는 기존 문구 그대로. 검사 `EP2`: 입력칸 폭 150 이상.
- **언제 보이나**: 채팅 입력줄이 있는 모든 화면 = 로비 · 낮 시작 · 낮 토론 · 지목 · 결선 · 마지막 3인 · 변론 · 찬반 · 처형 · 아침 · 밤 마피아 · 유령(모든 단계). 입력줄이 없는 **밤의 산 시민·경찰·의사**에는 버튼이 없다(수신자가 비어 있다 — 어둠 속에 나만 서 있다). 서버는 그 단계의 그들 메시지를 조용히 버린다.
- 눌림: 판이 열려 있는 동안 `aria-pressed`, 안쪽 테두리 2px `gray-100`. 연결이 끊기면 `aria-disabled`(불투명도 0.45).
- 버튼 `mousedown` 은 기본 동작을 막아 입력칸 포커스를 뺏지 않는다. 단, 판을 열 때는 입력칸을 `blur` 해 키보드를 닫는다(스테이지 높이 보호).

## A-2. 판 (`EmoteTray`)

- 열림: 입력줄 윗변에서 8px 위, 좌우 16, 위로 자란다. `z-overlay`+1. 폭 = 폰 폭 − 32. 닫기: 버튼 다시 누름 · 판 바깥 누름 · Esc · 동작 하나 고름(고르면 **즉시 닫혀** 캐릭터가 보인다).
- 판이 열려 있는 동안 떠 있는 버튼 묶음은 숨긴다(`visibility: hidden`, 판과 겹침 방지). 닫으면 돌아온다.
- 모양: 면 `night-700`, 테두리 1px `night-600`, 모서리 `radius-badge`(승인 값), 안쪽 8, 칸 사이 8. **5열 × 2행**, 아래 줄 4칸은 가운데 정렬. 칸 폭 = (판 폭 − 16 − 32) / 5 → 폰 360 에서 59.2, 430 에서 73. 칸 높이 56, 누르기 대상은 칸 전체.
- 칸 안: 아이콘 24(`gray-100`) + 이름 14px 700 한 줄 가운데. 이름은 3글자 이하.
- 판 높이 = 8 + 56 + 8 + 56 + 8 = 136(+ 테두리). 키보드가 열려 있을 때는 열리지 않고 키보드를 먼저 닫는다.

## A-3. 보내기·재생 규칙 (서버가 권위)

| 항목 | 규칙 |
|------|------|
| 클라이언트 → 서버 | `{ t: "emote", id: EmoteId, pk: string }` — 동작 종류와 단계 키뿐. **좌석·채널·수신자·시각을 보내지 않는다.** 채널은 서버가 보낸 사람 상태로 정한다(`channelOf`) |
| 서버 → 받는 사람 | `{ t: "emote", seat: number, id: EmoteId, n: number }` — 방 전체에서 하나씩 늘어나는 번호 `n`. 채널·역할·시각·id(player)를 싣지 않는다. 받는 사람 = `audience(state, {k:"emote", ch})` (보낸 사람 포함) |
| 단계 키 | `pk` 가 서버 단계와 다르면 **폐기**한다(더 넓은 채널로 돌리지 않는다). 채팅 `pk` 규칙과 같다 |
| 보낼 수 있는 단계 | `CHAT_PHASES` 와 같다 + 산 사람 · 탈락자. 밤은 산 마피아와 탈락자만(`channelOf`). 그 밖은 조용히 버림 |
| 이동 중 | 서버가 보낸 사람의 이동 구간이 아직 끝나지 않았으면 버린다. 이동 요청을 받으면 그 사람의 동작 기록(`lastEmote`)을 지운다 |
| 연타 방지 | 한 사람은 **앞 동작이 끝나기 전에는** 새 동작을 낼 수 없다(재생 길이 `EMOTE_MS`, 아래). 최소 간격 1000ms. 10초 창에 5번까지. 어기면 **조용히 버린다**(오류 프레임·알림 없음, 상태는 메모리뿐) |
| 보낸 사람 표시 | **서버가 돌려준 프레임으로만** 재생한다(낙관적 재생 없음, D-9). 보낸 사람도 같은 프레임을 받는다 |
| 재접속·복원 | 동작은 사건이라 `state`·`chatLog`·스냅샷에 싣지 않는다. 재접속하면 재생 중이던 동작은 사라진다 |
| 끊김 | 끊긴 사람(`setDim`)의 캐릭터에도 동작 프레임은 재생한다 |

재생 길이 `EMOTE_MS`(키프레임 표에서 계산, 서버용 상수는 `shared/game/emote.ts`, 값이 어긋나면 단위 시험이 실패한다): `throat` 1780 · `deny` 1320 · `clap` 1280 · `cry` 1760 · `handshake` 1380 · `point` 1700 · `praise` 1280 · `surprise` 1060 · `dance` 2080 (ms).

클라이언트 재생: `playEmote(id)`(기존). 걷기 시작하면 끊김(기존). **`stopEmote()`** 를 추가해 상한 초과·단계 전환·이동 프레임에서 120ms 에 걸쳐 서 있는 자세로 돌린다. 방향(yaw)은 동작 중 바뀌지 않는다.

## A-4. 동시 재생 상한 (렌더)

- **`EMOTE_RENDER_MAX = 4`**: 한 화면에서 동시에 재생하는 동작은 4개까지. 5번째 프레임(`n` 가장 큼)이 오면 **가장 오래된 `n`** 의 동작을 `stopEmote()` 로 끝낸다. 새 동작은 항상 재생된다(거절 없음).
- 시스템이 시키는 반응(`deny` — 선두가 바뀔 때)은 그 좌석이 사람 동작을 재생 중이면 건너뛴다. 상한 계산에 넣지 않는다.
- 첫 사용 때 표정 머리 병합 비용을 피하려고 동작이 쓰는 표정(`angry`·`sus`·`surprise`·`happy`·`cry`)을 **유휴 시간(`requestIdleCallback`)** 에 미리 병합한다. 지원하지 않는 브라우저는 첫 사용 때 병합한다.

# C. 걷기·방향 (AVTR-02)

이미 구현됨. 이 페이즈는 **실제 의상으로 확인**하고 기준값을 문서에 못 박는다.

| 항목 | 값 |
|------|----|
| 걷기 사이클 | 위상 증가 `WALK_PHASE_RATE = 11 × MOVE_SPEED / 1.245` rad/s(발이 미끄러지지 않음). 팔 ±0.5, 다리 ±0.6 rad, 몸 위아래 ≤ 0.06 |
| 서기↔걷기 섞기 | `POSE_BLEND_MS = 120` |
| 방향 | 이동 방향(`atan2(dx, dz)`)으로 회전, `YAW_TURN_RATE = π/0.12` rad/s(90° 약 60ms, 가까운 쪽으로). 서 있을 때 마지막 방향 유지 |
| 동작 중 방향 | 바꾸지 않는다 |
| 이름표 | 머리 꼭대기 `headY` 를 따라간다. `surprise` 의 뛰어오름(y 0.4)이 이름표를 같이 올린다(겹침 없음) |

확인 방법: 포즈 스트립 디버그 화면(E-4)에서 5명 × 9의상의 서기·걷기 4프레임·방향 4방향.

# E. 에셋 제작 방식 (디자이너 없음)

## E-1. 원칙

- 외부 3D 파일(glTF 등)은 쓰지 않는다. 캐릭터는 **프리미티브 지오메트리 조립**이다: 구 18 · 원통 13 · 박스 7 · 토러스 6 · 원뿔 · 링 · 원 · 모자 챙용 커스텀 `BufferGeometry`(`src/world/character.ts` `bakeFig`).
- 출발점은 `design/v2.0/3d/mf3d.js` 가 **아니다**. 그 파일의 모자·머리카락·귀·눈썹은 결정 0048 이전 방식이다. 현재 구현 `src/world/character.ts`(원본 `design/v2.0/blockout/character.js`)가 기준이다.
- 부품 한 개 = 지오메트리 + 태그(`kind:name`) + 색 슬롯(`coat`·`shirt`·`tie`·`pants`·`shoe`·`skin`·`hand`·`hair`) 또는 고정색. 관절(몸통·머리·팔 2·다리 2)별로 **정점 색 하나의 메시로 병합**한다. 의상은 `OUTFITS` 표의 색·모자·배지·소품·액세서리 이름이다. 조명 재질은 공유 하나.

## E-2. 이 페이즈에 필요한 새 에셋

| 필요 | 상태 | 만드는 방법 |
|------|------|-------------|
| 의상 9종 × 인물 5명 3D 부품 | **이미 있다** — 새 부품 0개 | 포즈 스트립으로 45조합 시각 확인(E-4) |
| 동작 9종 키프레임 | **이미 있다** — 새 동작 0개 | 확인만 |
| 아이콘 11개 | 승인 `bundle.js` 에 있고 앱 `V2Icon` 에 없음 | 경로 데이터를 그대로 옮긴다 |
| 의상 카드 그림 9장 | 승인 `outfit-*.png`(1번 인물) 있음 | `public/` 으로 복사, `ASSET_VERSION` 올림. 인물별 45장은 만들지 않는다(O-3) |
| 표정 10종·손 모양 4종(결정 0047) | 표정 7종·손 한 모양만 구현 | 이 페이즈에서 **만들지 않는다**(O-4). 동작 9종이 쓰는 표정은 모두 있다 |
| 시상식·결과 화면 직업 의상 | 11페이즈 | 해당 없음 |

새 소품이 필요해지면(O-4 예외) 규칙: 박스·원통·구·토러스만, 부품 ≤ 6개, 한 관절에 붙임, 삼각형 +800 이하, 진홍(`#8e0b21`)·선글라스는 마피아 의상 전용, 총기류·무기 소품 금지(스토어 심사, `ASSET_SPEC` §7-6).

## E-3. 출처 기록 (`manifest.json`)

`design/characters/manifest.json` 에 항목 한 줄을 더한다: `figure-3d` — 출처 "저장소 자체 코드 조립(원본 아티팩트 NP1XfUrYTTqQ5nAB1HKYT5)", 외부 에셋·약관 의존 **없음**, 포함 파일 `src/world/character*.ts`·의상 카드 그림(예: `public/outfits/*.png`, 위치는 계획이 정한다).

## E-4. 검사 스크립트와 포즈 스트립

- `scripts/check-character.mjs`: 5명 × 9의상 조합이 모두 만들어지고, 메시 ≤ 8, 삼각형 ≤ 15,000, 높이 1.5 ~ 1.9, NaN 없음, 동작 표의 키가 모두 `EMOTE_KEYS` 안, `EMOTE_MS` 와 동작 표가 일치함을 확인한다. `npm run` 스크립트와 단위 시험 하나로 건다(`vitest`, WebGL 없이 node).
- 포즈 스트립 디버그 화면 `?pose-strip=1`: 개발 빌드와 `?e2e=1` 에서만 열린다(`?perf=1`·`?chat-mock=1` 과 같은 게이트, 지연 로드). 격자: 행 = 동작 9종 + 서기 + 걷기, 열 = 4 샘플 시각. 인물·의상은 선택 상자로 바꾼다. 제품 번들에 따로 들어가지 않는다.

- 판이 열리면 첫 칸으로 초점이 가고(`preventScroll`), 닫으면 동작 버튼으로 돌려준다. 시트는 열리면 선택된 카드로 초점이 가고 닫으면 꾸미기 버튼으로 돌려준다.
- 키보드(PC): Tab 순서 = [역할 카드] → 채팅 입력 앞의 [동작] → 입력 → 보내기 → 깃펜 → 떠 있는 버튼. 판 안은 화살표키로 칸 이동, Enter·Space 로 선택, Esc 로 닫기. 시트의 카드 띠도 화살표키.
- 모션 줄이기(`prefers-reduced-motion: reduce`): 판·시트 등장 애니메이션 없음, 카드 스냅은 즉시. **다른 사람의 동작은 정보라 재생한다** — 단, 반복 횟수를 2회로 줄이고 `surprise` 뛰어오름·`dance` 몸 위아래 진폭을 절반으로 한다(O-5). 걷기는 이동 자체라 유지.
- 햅틱·진동·소리 없음(12페이즈·앱 전환).

선택지: (a) 정적 예산 단위 시험을 매 계획, 실측은 마지막 한 번 · (b) 매 계획 실측 · (c) 실측 생략.
**추천 (a).** 사용자가 실행 시간을 줄이라 했고, 새 메시·조명이 0 이라 정적 예산이 회귀를 잡는다. 합격선은 낮추지 않는다.

**D-16 에셋 제작 방식.**
선택지: (a) 현행 절차적 프리미티브 조립 유지·새 부품 0개 · (b) 새 의상·소품을 더 만듦 · (c) 외부 3D 모델.

**D-17 동작 효과(반짝임·땀·눈물·속도선).**
선택지: (a) 만들지 않음 · (b) 몸에 붙는 효과만 · (c) 모두.

**D-18 시험 범위.**

**D-19 동작 메시지 보호.**
선택지: (a) 채팅과 같이 `pk` 를 싣고 불일치는 폐기 · (b) `pk` 없이 서버 현재 단계 사용 · (c) 클라이언트가 채널 지정.

선택지: (a) 버튼 없음 · (b) 있지만 보낼 때 버려짐 · (c) 자기에게만 재생.
