# 12페이즈 · v2.0 실기기·팀 테스트 모음 (모든 개발이 끝난 뒤 한꺼번에)

> 목적: v2.0 개발이 끝난 뒤 사람이 한 번에 처리할 실기기·팀 확인을 이 한 장에 모았다(사용자 결정 2026-11-02). 칸의 원문은 옮기지 않고 한 줄 요약 + 출처만 적었다. 자세한 절차·기대값은 출처 파일의 같은 번호 칸이다. **에이전트는 어떤 기기·팀 칸도 통과로 적지 않는다.** 이 목록은 12페이즈 완료를 막지 않는다.
> 배포본 주소: `https://minifia-v2.dhplay.workers.dev` (Worker `minifia-v2`).
> 역할 분담: **Claude 가 하는 일** = 모든 계획이 끝난 뒤 배포, 배포본 smoke full 과 새 소리 흐름을 배포본으로 돌리는 것(표 A 배포본 칸). **사람이 하는 일** = 기기·팀 관찰(표 B), 아침 듣기(아래 「아침에 할 일」), 사람용 TO-DO(맨 아래).
> 관련 결정: [0070](../../../docs/decisions/0070-v2-sound-polish.md) · [0055](../../../docs/decisions/0055-v2-phase6-prep.md)(확인 기기 = iPhone 16 Pro, 고사양 숫자만으로 성능 통과 선언 금지).

## 아침에 할 일 — 소리를 직접 들어 보기

1. Mac 에서 `npm run dev` 를 켠다(`--host` 가 이미 들어 있다).
2. 같은 와이파이의 폰에서 `http://<Mac IP>:5173/?sound-lab=1` 을 연다.
3. 56개를 ▶ 로 하나씩 듣는다. 마음에 들지 않는 id 를 알려 주면 `src/audio/recipes.ts` 의 레시피 한 줄만 고친다(레벨이 문제면 gainDb, 길이면 dur, 음높이면 f0·f1). 모든 소리 레벨·침대 레벨은 **첫 초안**이다.
4. 무음 스위치(옆면)를 켠 채와 끈 채로 한 번씩 들어 본다(표 B ③).
