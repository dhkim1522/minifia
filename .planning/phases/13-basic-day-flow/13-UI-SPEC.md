### 투표 (FLOW-01·02, 08 "지목"을 되살림)

모이기 · 카메라
- 시작과 함께 산 사람이 가운데 둘레로 걸어 모인다(08 모이기 규칙, 서버 구간). 카메라는 가운데로 `dur-slow` 이동 후 고정. **어둡게 막·차례 고리·알약·막대·위 한 줄 없음.**
- 맵 탭은 목적지 링 없이 키보드만 닫는다. 이름표 층·누르기 영역은 아래 그대로.

이름표 = 버튼
- 나를 뺀 **산 사람** 이름표가 `<button type="button">` 안의 `HeadStack`. 누르기 영역 44×44 이상(안쪽 11 / 바깥 -11). 내 이름표와 유령 쪽 이름표는 버튼이 아니다.
- 누르면 즉시 내 `mine`(면 `gray-100`, 글자 `night-900`)이 그 사람으로 옮겨지고 이전 사람은 풀린다. 마감 전까지 바꿀 수 있다. 서버 값이 기준이고 어긋나면 서버 값으로 되돌린다.
- 접근성: 버튼 이름 "{닉네임} 님 가리키기", 내가 고른 것 `aria-pressed="true"`, 8개를 `role="group"` `aria-label="투표"` 로 묶는다. 키보드가 열려도 눌린다(`mousedown` 기본 동작 막기).
- U-6 깜빡임: 시작 3초, 누르면 즉시 멈춤. `prefers-reduced-motion` 이면 깜빡임 없이 정지 상태.

공개 표시 (모두 산 사람·유령에게 같게 — 공개 정보가 증거가 된다)
- **손가락**: 고른 사람 캐릭터가 대상 쪽으로 몸을 돌려 `point` 손(바꾸면 `dur-fast` 안에 새 대상). 고르지 않은 사람은 손을 내린 채.
- **득표 배지**(`VoteBadge`): 1표 이상만, 처음엔 `dur-pop`, 이후 같은 자리에서 숫자만 변경. 표가 옮겨가면 줄어든다.
- **선두**(최다가 한 명): 그 배지 맥박(1.18 ↔ 1.34, `dur-pulse`) + 점광 + 당황 표정·손사래 한 번. **동점이면 효과를 푼다.**
- **과반**(≥ `⌊산 사람 ÷ 2⌋ + 1`): "유력" 도장 + 실내등 절반 + 카메라 8%(스테이지 높이 ≥ 360 일 때만). 바꿔서 풀리면 원래대로. 과반이어도 15초를 다 채운다.
- **위 알림**: `TopToast` 한 줄 `point` + "민준 → 도윤"(바꾸면 "(바꿈)"), `dur-toast`, 새 표가 이전 것을 바꾼다(U-5).
- **채팅 시스템 줄**: `vote` 종류 "민준 → 도윤"·"(바꿈)", 선두가 바뀔 때 `hot` "{이름} 님이 앞서요", 과반 때 `hot` "{이름} 님 과반", 시작 시 "투표 시작". 공개 정보에서 화면이 만들며 재접속에 복원하지 않는다.
- 진홍·역할 색·역할 표식 없음(역할마다 화면이 같아야 함).

마감
- 최다 득표가 **한 명**이면(과반 아니어도) 최후 변론으로. **동점(둘 이상)·0표면 결선 없이** 알림 "처형 없음"(U-7) → 밤. 표를 안 던진 사람은 기권(수에 안 들어감).
- 재접속 첫 스냅샷은 이펙트 없이 현재 표·선두·과반·`mine` 을 바로 그린다(등장 모션·위 알림·채팅 줄 새로 만들지 않음).

### 끄는 장치 (FLOW-03, D-05) — 화면 쪽 계약

한 설정(기본판 설정 상수, 위치는 플래너가 `shared/game/` 에 정함)이 꺼짐이면, 아래가 **어느 단계·어느 프레임에도 나타나지 않는다.** 서버가 view 에 키를 싣지 않으므로 화면은 "숨기는" 것이 아니라 "받은 적이 없어서" 그리지 못한다.

| 장치 | 그리지 않는 것 | 검사 선택자 / 키 |
|------|----------------|------------------|
| 직업 주장 배지(0066) | 낮 [주장] 플로팅 버튼, 시트, 이름표 위 주장 칩·팝·알림, 스크린리더 알림 | `[data-float="claim"]`·`[data-claim-sheet]`·`[data-claim-chip]`·`[data-claim]`·`[data-badge-live]`, `players[].badge` |
| 귓속말(0066) | [귓속말] 플로팅 버튼, 대상 고르기 깜빡임, 한 줄 시트, 받은 알림, 귓속말 채팅 줄 | `[data-float="whisper"]`·`[data-line-sheet]`, 귓속말 키 |
| 순차 지목(0063-1) | 차례 알약·막대·위 한 줄·인용 카드·어둡게 막·차례 고리·`n / N` | `[data-turn-block]`·`[data-turn-*]`, `day.turn` |
| 동점 결선(0066-4) | 결선 후보 무대·투표 창·결과 | `day.runoff`, `phase === "runoff"` |
| 마지막 3인 결전(0066-5) | 한마디 시트·핀 조명 한마디·동시 공개 | `[data-speak-sheet]`·`[data-showdown-step]`, `day.showdown` |

- 낮 토론 행동 줄: `FloatActions` 컨테이너 자체를 만들지 않는다. 아래 패널 높이·스테이지 사각형 계산에서 플로팅 줄 높이는 0으로 친다(옛 줄 때문에 패널 위에 빈 띠가 남지 않게).
- 기록 탭·하루 상세·결과 화면·상 이름(`awardText`·`resultText`·`timelineView`)에 꺼진 장치의 줄·상·빈 제목이 생기지 않는다. 데이터가 없으면 줄이 없다(빈 칸 표시 금지).
- 헤더 안내의 "모드 안내"(귓속말 `hintOverride`)와 결선·결전용 안내 문구는 쓰지 않는다.
- 소리: 새 소리 없음(14페이즈). 꺼진 장치의 소리 신호(`audio/script`·`director` 의 주장·귓속말·차례·결선·결전)가 한 번도 울리지 않는지만 확인한다.

## Copywriting Contract

해요체, 짧게, 마침표·느낌표·이모지 없음, 사람은 "{닉네임} 님". **3초 규칙**: 한 화면에서 읽을 글은 단계 이름 + 안내 한 줄뿐.

| Element | Copy |
|---------|------|
| Primary CTA — 토론 | `skip` 아이콘 + "토론 끝내기" + 점 진행(접근성 이름 "토론 끝내기") |
| Primary CTA — 투표 | 글자 없음, 이름표를 직접 누른다. 접근성 이름 "{닉네임} 님 가리키기", 그룹 "투표" |
| Primary CTA — 찬반 | `thumbUp` "찬성" / `thumbDown` "반대" |
| 투표 제목 · 안내 | 투표 · 의심되는 사람을 눌러요 |
| 결과 알림(36px) | 찬성 {n} · 반대 {m} / {닉네임} 님 처형 / 처형 없음 |
| 위 알림 | {닉네임} → {닉네임} · {닉네임} → {닉네임} (바꿈) |
| 채팅 시스템 줄 | 투표 시작 / {닉네임} → {닉네임} / (바꿈) / {이름} 님이 앞서요 / {이름} 님 과반 / {이름} 님 {N}표 · 최후 변론 / 처형 없음 |
| Empty state | 없음 — 0표면 배지가 없고 손은 내린 채. 기록 칸은 빈 칸이 다음 할 일. 글을 넣지 않는다 |
| Error — 단계 어긋남 | 지금은 고를 수 없어요 (TopToast, 서버 거절 후 표시는 서버 값으로 복귀) |
| Error — 그 밖의 거절 | 보내지 못했어요. 다시 해 보세요 (TopToast) |
| 연결 끊김 | 새 문구 없음 — 재접속 띠가 안내. 끊긴 동안 투표·찬반·토론 끝내기 버튼은 `aria-disabled` |
| Destructive confirmation | 없음 — 이 페이즈에 지우기·나가기·신고가 없고, 처형은 투표 결과이며 확인 시트를 두지 않는다 |

**쓰지 않는 문구**: 지목 관련 "{이름} 님 차례"·"모이는 중"·"고르지 못했어요", 주장·귓속말·결선·결전 문구 전부(`DAY_COPY.nominationGatherHint`·`WHISPER_TEXT`·`SHOWDOWN_COPY` 는 호출되지 않게 둔다). 문구 상수는 지우지 않고 끈다(D-05).

## 접근성 · 모션 · 입력

- 누르기 44 이상: 이름표 버튼 44(안쪽 11), 토론 끝내기 52, 찬반 84, [역할 카드] 44×44. 포커스 링 `gray-100` 2px.
- Tab 순서: [역할 카드] → (투표 단계) 이름표 8개 → 채팅 입력 → 보내기 → 행동 줄. 이름표는 Enter·Space.
- `prefers-reduced-motion`: 배지 등장·선두 맥박·도장 떨어짐·깜빡임·카메라 전환을 끈다. 선두는 배지 1.18 고정 + 크림 빛, 과반은 도장이 그냥 보임.
- 온라인 기준(결정 0018): 엿보기는 설계 제약이 아니다. 찬반 선택은 다른 폰으로 가지 않는다(서버 규칙, 변경 없음).
- 햅틱·진동 없음.

### 검사 가능하게 둘 것 (E2E)

- 기존 선택자 그대로: `data-game-stage`(`data-phase`), `data-announce`, `data-end-discussion`, 이름표 `data-seat`·`data-count`·`data-lead`·`data-sure`·`data-mine`, 이름표 버튼 `data-pick="{seat}"`, `data-verdict="yes|no"`.
- **부재 검사(필수)**: 봇 방 한 판 전체(로비 → 밤 → 결과) 동안 위 "끄는 장치" 표의 선택자가 0건이고, 받은 view 에 `players[].badge`·`day.turn`·`day.runoff`·`day.showdown`·귓속말 키가 0건이다. 서버는 꺼진 메시지(주장·귓속말·차례 밖 지목·결선·결전)를 상태 변경 없이 조용히 거절한다.
- **흐름 검사**: 토론 → 투표(동시) → 최후 변론 → 찬반 → 처형이 순서대로 돈다(FLOW-01). 동점·0표는 변론 없이 "처형 없음" → 밤(FLOW-02). 찬반 기록 카드가 모두에게 공개된다(FLOW-04). 봇 방이 한 판을 완주한다(FLOW-05).
- 투표 단계에서 이름표 버튼 8개가 각각 44×44 이상이고 서로 가려지지 않는다(4자 이름, 폰 6종). 묶음 G(글자 14px 이상·가로 넘침·콘솔 오류 없음)·H(헤더 대비)를 투표 화면에 적용한다.
- 성능: 6페이즈 게이트(5분 평균 55fps)를 8명 동시 가리키기·배지 맥박 구간에서 다시 잰다. 합격선은 낮추지 않는다. 실기기는 모든 개발이 끝난 뒤 한꺼번에(사용자 결정).
- 스테이지 높이(키보드 닫힘, 채팅 패널): 360×640 → 390, 390×664 → 414, 430×932 → 626, 360×560 → 310. 모두 300 이상이라 8명 이름표가 들어간다(차례 알약이 없어져 09.1의 360×560 모자람도 해소).
