# Phase 14 — UI Design Contract (사회자 진행과 도구 이름표)

> 새 화면은 없다. 모든 방 화면(대기실·역할 확인·낮·밤·아침·유령·결과) 위쪽에 **자막 띠 하나**가 붙고, 아이콘만 있던 단추에 **한 단어 이름표**가 붙는다.
> 결정 0051 보완: "글 최소"는 유지하되 기능 이름은 한 단어로 붙이고, 남은 시간은 숫자로 함께 보인다. 읽을 글은 단계 이름 + **띠 한 줄**뿐(3초 규칙) — 기존 단계 안내 줄(헤더 hint)은 띠로 합쳐 없앤다.
> 심부름·목격 기록·밤 흔적의 사회자 줄은 15페이즈가 더한다. 여기서는 문구 표·빛남 대상 함수·알림음 훅만 열어 둔다.

## 자막 띠 계약 (HOST-01·02·03)

모양(시안 A)
- 면 `overlay-ink-strong`, 모서리 `radius-badge`(12), 왼쪽 줄 4px `brass-400`, 안쪽 `8 16 8 16`, 그림자 `shadow-badge`. 1행: 종(`bell`, 16, `brass-200`) + 문장(Label 14/400, `gray-50`, `keep-all`, 1~2줄) + 오른쪽 끝 "{n}초"(Body 16/700 숫자 + 14/400 "초", `tabular-nums`, 최소 폭 40). 2행: 막대(높이 8, `radius-pill`, 트랙 `night-600`, 채움 `gray-100`, `scaleX` 왼쪽 기준, 1초 선형) — 시간이 있을 때만. 막대 색은 기존 `timerTone` 하나: 평소 `gray-100` → 마지막 10초 `brass-400` → 마지막 5초 `crimson-400`(숫자도 같은 색, 진홍은 낮 화면에서 여기뿐).
- 문장은 `<p data-host-line data-guide>` 하나. 시간은 `role="timer"` `aria-label="남은 시간 {n}초"`(초마다 읽지 않음). 띠 전체는 `role="status"` `aria-live="polite"` — 문장이 **단계가 바뀔 때만** 바뀌므로 읽는 횟수가 적다. 같은 단계 안에서 문장은 바뀌어도 되지만(예: 역할 확인에서 카드를 연 뒤) 다시 읽히지 않게 `aria-atomic="false"`.
- 바뀔 때 연출: 문장 `opacity` 0 → 1 (`dur-med`), 종이 `transform: rotate` ±8° 한 번 흔들림(`dur-pop`). 모션 줄이기면 즉시 교체·흔들림 없음.
- 어느 단계에서도 같은 자리·같은 모양. 단계 이름(제목)은 헤더 그대로("낮 토론"·"투표"…). 역할·좌석 값을 DOM 속성에 싣지 않는다(`data-host-line` 은 값 없는 표식).

동작
- 문장은 클라이언트가 **자기 view 만으로** `hostLineOf(view)` 로 만든다(아래 HOST-05). 서버 응답·메시지에 새 필드를 더하지 않는다.
- 할 일이 있는 사람: "무슨 일 + 내 할 일" + 빛남. 할 일이 없는 사람: 지금 무슨 시간인지만(HOST-03). 유령은 관전 줄.
- 띠는 누를 수 없다(장식 아님·단추 아님). 탭은 맵으로 통과한다(`pointer-events: none`).

## 빛남 계약 (HOST-03·04)

규칙
- 빛남 = 대상에 `data-call` + 클래스 `is-call`: `light-lamp` 테두리 + `::after` 정지 빛(`--glow-ring`), 처음 6초는 맥박(`opacity` .55↔1, `dur-pulse`), 이후 정지. 이름표·단추는 라벨 글씨가 700 + `brass-200`. 모션 줄이기면 맥박 없이 정지 빛만.
- 한 화면에 **한 종류**(같은 그룹)만 빛난다. 내가 그 도구를 쓰면(누르면·고르면) 즉시 꺼지고 되살아나지 않는다. 단계가 끝나도 꺼진다. 이미 열린 시트·입력 중에는 빛나지 않는다.
- 빛남 대상은 순수 함수 `callTargetsOf(view)` 가 view 로 만든다(문장과 같은 입력, 같은 키 표). 15페이즈는 반환 종류(`tag`·`tool`·`place`)에 항목만 더한다.
- 빛은 소리를 내지 않는다(소리는 띠가 바뀔 때 한 번뿐).

## 시간 막대 + 숫자 (TOOL-02)

- 모든 단계의 남은 시간은 띠의 막대 + "{n}초"(90초 토론도 "90초" 형식, `m:ss` 아님). 마감은 서버 `phaseEndsAt`·`phaseDurationMs` 기준(`useCountdown`, 서버 시각 보정 `offset`). 막대·숫자는 한 훅 값에서 나온다.
- 없애는 것: `PhaseHeader` 링·링 안 숫자, 역할 확인 `Timer`(m:ss), 결과 알림의 별도 시계. 차례 알약 계열은 13에서 이미 꺼짐.
- 막대가 없는 단계: 낮 시작(2초)·처형 앞머리·대기실·배정·결과(마감 없음). 이때 숫자도 없다.
- 헤더 오른쪽은 [내 역할] 하나만 남는다(링이 있던 자리가 비므로 단추가 오른쪽 끝으로 간다).

## HOST-05 — 누설 방지 규칙

- `hostLineOf(view)`·`callTargetsOf(view)` 는 **내 view 에 이미 있는 값만** 읽는다. 허용 목록: `phase`, `phaseEndsAt`, `phaseDurationMs`, `me.seat`·`me.role`(내 것)·`me.isHost`, `players[].{seat,nickname,alive}`, `day.candidate`, `day.verdict`(공개 집계), `day.morning`, 로비 인원 수, 내 카드를 열었는지(클라이언트 상태). `players[].job`(유령에게 오는 남의 직업)·`me.allies`·`records`·`day.turn` 등은 **읽지 않는다**(유령 줄도 직업을 말하지 않는다).
- **서버·프로토콜에 새 필드·새 메시지를 더하지 않는다.** 이 페이즈의 서버 diff 는 0 이다. (`shared/protocol.ts` 의 view 키 집합이 페이즈 전후 같음을 시험한다.)
- 역할별 문장(밤 마피아·경찰·의사, 역할 목표)은 그 역할 분기 안에서만 문자열을 꺼낸다(기존 `nightHintMafia` 선례, T-09-29). 한 화면의 DOM 에 다른 역할의 줄이 들어가지 않는다.
- 빛남 대상 집합은 공개 정보만으로 정해지는 것(산 사람 이름표, 변론자 본인 여부)과 내 역할에서 나온 것뿐이다. 마피아 밤 빛남을 만들지 않아 동료·대상이 빛으로 드러나지 않는다.
- 소리 신호 인자는 비어 있다(역할·좌석 없음).

## 알림음 (HOST-02, D-01)

- 새 닫힌 신호 `{ kind: "host" }`(인자 없음)를 `SIGNAL_KINDS` 에 더하고, 소리 감독이 `ui.host` 레시피 한 번을 낸다. 레시피는 `src/audio/recipes.ts` 의 합성(오실레이터) — 맑은 종 두 음 상승(예: 880 → 1318 Hz, 각 약 120ms, 감쇠 포함 총 약 350ms), `ui` 버스, 크기 `ui.card` 급(약 -24), `gapMs` 800 으로 연달아 바뀌는 경우(낮 시작 → 토론) 뭉침. 외부 샘플·음성 낭독 없음. `docs/audio.md` 레시피 지도에 행을 더하고 시험 페이지에서 들을 수 있게 한다.
- 울리는 때: 띠의 **단계 키**(서버 단계 id)가 바뀐 프레임 한 번. 안 울리는 때: 같은 단계 안 문장 변화(투표 중 선두 변화·카드 연 뒤), **재접속·처음 마운트의 첫 프레임**, 빛남 변화, 이전 키가 없을 때.
- 소리 끄기 단추·잠김(`unlock` 전)을 기존 엔진이 따른다(끄면 레시피가 실행되지 않음). 단계 전환의 배경·장면 소리(`BED_OF`·스크립트)와 별개 층이며 서로 막지 않는다.

## 접근성 · 모션 · 입력

- 누르기 영역 44 이상(이름표 단추 44 유지). 포커스 링 `gray-100` 2px. Tab 순서는 13 그대로(띠·독은 포커스를 받지 않는다. 소리 단추만 독 안에서 순서를 가진다: [내 역할] → 소리 → …).
- 빛남은 색만으로 알리지 않는다: 테두리 + 라벨 700 + 띠 문장이 같은 일을 말한다.
- `prefers-reduced-motion`: 띠 교체 즉시, 종 흔들림 없음, 빛 맥박 없음(정지 빛), 막대는 초 단위 계단.
- 폰 폭 360: 채팅 입력줄 = 동작 44 + 입력칸 + 보내기 44 + 유언 44(8 간격) → 입력칸 약 172. 헤더 `[내 역할] 52`. 가장자리 8자 이름표 잘림은 알려진 한계로 둔다(손보지 않음).

### 검사 가능하게 둘 것 (E2E)

- 표식: `data-host-band`·`data-host-line`(= `data-guide`, 값 없음)·`data-host-time`·`data-call`(빛남 대상)·`data-tool-label="{낱말}"`.
- **도구 이름표 검사**: 모든 방 화면(대기실·역할 확인·낮 6단계·밤·아침·유령·결과)에서 보이는 `button`·`[role=tab]` 중 보이는 글자(숫자 제외)가 비어 있는 것이 면제 E-1~E-3 밖에 0건.
- **띠 검사**: 각 단계 진입마다 `data-host-line` 이 있고 한 문장·3줄 미만. 시간이 있는 단계는 막대 + 숫자가 함께 보이고 링은 없다(`.mv-ring`·`.mf-timer` 0건). 기존 hint 줄(`.mv-phase__hint`) 0건.
- **누설 검사(필수)**: 역할 5종(마피아·경찰·의사·시민·유령) × 전 단계 봇 판에서 ① 한 화면의 띠·목표·빛남 DOM 에 다른 역할 전용 문장(마피아·경찰·의사 줄·목표)이 없다 ② 서버가 보낸 view 키 집합이 페이즈 전후 같다(서버 diff 0) ③ 같은 단계에서 "할 일 없음" 역할 둘의 띠 문장이 같다(밤 시민 vs 죽은 경찰 제외 규칙은 유령 줄) ④ `hostLineOf` 단위 시험: 허용 목록 밖 필드를 지운 view 로도 같은 줄이 나온다.
- **소리 검사**: 단계 전환마다 `ui.host` 가 한 번, 같은 단계 안 변화·첫 프레임·소리 끔에서는 0번(소리 시험 훅 `testHook`).
- 묶음 G(글자 14px 이상·가로 넘침·콘솔 오류 없음)·H(헤더 대비)를 띠·도구 줄에 적용. 폰 6종에서 띠가 이름표 버튼 영역을 가리지 않는지 투표 화면에서 확인(8명).
- 성능: 6페이즈 게이트(5분 평균 55fps)를 띠 갱신 + 빛 맥박 + 8명 투표 구간에서 다시 잰다. 실기기는 모든 개발이 끝난 뒤 한꺼번에(사용자 결정).
