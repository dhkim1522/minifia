# Phase 15 — UI Design Contract (낮 심부름·목격 기록·밤 흔적)

> 새 화면은 없다. 기존 맵 화면에 **심부름 단계 하나**(지도 위 장소 표지 + 아래 진행 줄), 토론에 **접히는 목격 기록 카드 하나**, 밤에 **모든 역할이 같은 얼굴 목록**, 아침에 **흔적 카드 하나**가 더해진다.
> 결정 0051·0073 을 그대로 따른다: 장소는 아이콘, 진행은 칩 3개 + 숫자, 읽을 글은 단계 이름 + **14페이즈 띠 한 줄**뿐(3초 규칙). 새 안내 문단·설명 카드·말풍선은 만들지 않는다.
> 14페이즈의 띠·빛남·이름표 계약은 바꾸지 않고 **행과 항목을 더하기만** 한다(`hostLine.ts` 예약 행 `errand`·`witness`·`trace`, `callTargetsOf` 의 `place` 종류).

시안과 **다르게 한 곳**(이유):
1. 시안의 이모지(🍸 🕰 🎷 🧤 🔔)는 자리 표시용이다. 실제는 `V2Icon` 선 아이콘(아래 "장소 아이콘 규격")을 쓴다. 이모지 금지(14 계약).
2. 시안은 끝낸 장소를 놋쇠로 채웠다. 14 의 색 약속(`brass` = 공개 투표 + 사회자, `gray-100` 눌림 면 = 내가 이미 한 것)을 지키려고 **`gray-100` 채움**으로 한다.
3. 시안은 [처리]를 폰 안 맵 위에 띄웠다. 실제는 아래 패널 안에 두어 맵 탭과 겹치지 않게 한다.
4. 시안의 기록 카드는 위쪽(top 100)이다. 실제로는 띠·소리 단추 줄과 겹치므로 아래 "영역 배치"의 자리로 옮긴다.

열지 못한 참고 자료 없음. 시안 B 두 장(위쪽 목록 카드 / 채팅 자동 한 줄)은 채택하지 않았다(맵을 가림 / 남의 말과 섞임). 쓰지 않을 것: 장소 이름 글자, 이모지, 보라·파랑 그라데이션, 새 알림 36px 글자.

## 심부름 화면 계약 (ERRAND-01~04, D-01~D-03)

**장소 표지**
- 장소 후보는 맵별 6~8곳이고 서버가 사람마다 3곳을 뽑는다. 화면에는 **내 3곳만** 표지가 있다(다른 장소는 그리지 않는다).
- 모양: 지름 36 원, 면 `night-700`, 테두리 2 `gray-300`, 안 아이콘 20 `gray-100`. 처리한 곳: 면·테두리 `gray-100`, 안 `check`(아이콘 `night-900`). 장소 이름 글자 없음. 접근성 이름은 "{장소} 장소"(예 "시계탑 장소", 낱말은 `PLACE_NAME` 표), 처리한 곳은 "{장소} 장소, 처리함".
- 빛남(`is-call` + `data-call`)은 U-3 의 "다음 장소" 하나만. 처리 반경 안에 들어오면 빛은 그 표지에서 꺼지고 [처리] 단추가 빛난다(한 화면 한 종류).
- 처리 직후: 원이 `dur-pop` 으로 채워지고 `check` 로 바뀐다. 거절·실패 토스트 없음(서버가 거절하면 아무 변화 없음, 칩도 그대로).

**근처 사람**
- 내 발밑에 점선 반경 링 하나(근처 반경, 가운데 = 나). 링 굵기 2, 색 `gray-50`(`TOKEN_COLORS.ring`) 불투명도 .35, 점선. 모션 줄이기와 무관(정지). 이름표·캐릭터는 반경 안에서 서버가 보내 준 사람만 있다. 벗어나면 U-17.
- 다른 사람의 위치를 유추하게 하는 보조 표시(발자국·소리·이전 위치 점)는 만들지 않는다(D-02).

**마피아도 같다 (D-03, ERRAND-04)**
- 마피아도 같은 모양의 목록 3곳·같은 표지·같은 패널·같은 [처리]를 받는다. DOM 구조·마크업·접근성 이름·애니메이션이 역할과 무관하게 같다(`data-fake` 같은 표식 금지). 처리 결과가 서버에서 어떻게 세어지든 화면은 같다. 마피아에게만 있는 줄·단추·색은 없다.

**빛남 우선순위 (심부름)**: 처리 반경 안 미처리 장소 있음 → [처리] 빛남. 없음 → 다음 장소 표지 빛남(화면 밖이면 화살표 칩이 빛남). 3곳 완료 → 빛 없음.

## 목격 기록 카드 계약 (ERRAND-05, D-04)

- 대상: 3곳을 모두 처리한 산 사람(마피아 포함, 같은 규칙) **본인에게만**. 못 마친 사람에게는 [기록] 단추도 카드도 DOM 에 없다.

- 시민 밤 어둠(`data-night-dark`·긴장 비네트)은 그대로(시민·경찰·의사만). 마피아 화면이 밝은 차이는 기존 한계로 둔다.

## 누설 방지 규칙 (D-08 — 14 의 HOST-05 확장)

- `hostLineOf`·`callTargetsOf` 가 새로 읽는 값은 **내 view 에 있는 것**뿐: 내 심부름 목록 장소 id·내 진행 수·내 위치·내 기록 유무(불리언)·`day.morning.trace`(공개, 의상 id 없이 조각 이름만). 허용 목록에 이 값들만 더한다. `players[].job`·`me.allies`·`me.records`·`day.turn` 은 여전히 읽지 않는다.
- 심부름: 같은 모양의 목록을 모든 산 사람이 받는다. 서버가 보내는 **다른 사람 위치는 근처 반경 안 사람뿐**(좌표·좌석). 반경 밖 좌표는 DOM·시험 훅(`__mfWorld`)에도 없다. 마피아 목록과 시민 목록의 필드 이름·개수·길이가 같다.
- 목격 기록: 본인에게만. 다른 사람 기록이나 "기록 있음" 불리언은 다른 사람 view 에 없다. 마피아도 같은 규칙.
- 밤: 모든 역할의 선택 메시지·응답(성공·무효)이 같은 모양(결정 0074). 마피아가 동료를 골라도 시민이 마피아를 골랐을 때와 같은 응답. 거절 문구 없음. 칸 수·높이가 같다.
- 흔적: 조각 이름·아이콘만. 역할·팀·의상 id·좌석·"마피아일 수 있음" 같은 문구를 싣지 않는다. 확정 증거가 아니라는 말 한 줄은 카드의 고정 문구다.
- 새 메시지·단계·view 필드는 누설 검사(leak)를 넓힌다: 역할 5종(마피아·경찰·의사·시민·유령) × 심부름·토론·밤·아침 봇 판에서 ① 같은 단계에서 시민·마피아 view 의 심부름 필드 키 집합이 같다 ② 밤 선택 후 응답 모양이 모든 역할에서 같다 ③ 흔적 view 에 역할 값이 없다.

## 접근성 · 모션 · 입력

- 누르기 영역 44 이상(표지 44, [처리] 104×48, [기록] 52×57, [닫기] 높이 44). 포커스 링 `gray-100` 2px. Tab 순서: 헤더 [기록] → [내 역할] → (독) 소리 → 아래 패널([처리]). 칩·화살표는 포커스를 받지 않는다. 장소 표지는 `button` 이라 Tab 대상(접근성 이름 "{장소} 장소")이고 Enter 는 걷기.
- 진행은 색만으로 알리지 않는다: 채움 + 체크 아이콘 + "n/3" 글자 + `aria-label="진행 n/3"`. 처리 직후 `aria-live="polite"` 로 "진행 n/3" 한 번(띠는 단계 바뀔 때만 읽으므로 겹치지 않음).
- 빛남은 색만이 아니다: 테두리 + 처리 단추 글자 700 + 띠 문장이 같은 일을 말한다.
- `prefers-reduced-motion`: 표지 채움·카드 등장·페이드 즉시, 빛 맥박 없음(정지 빛), 흔적 카드 이동 없음.
- 폰 폭 360: 심부름 패널 한 줄 약 316 ≤ 328. 가장자리 8자 이름표 잘림·360×560 위쪽 비좁음은 알려진 한계로 둔다(손보지 않음).

### 검사 가능하게 둘 것 (E2E)

- 표식: `data-errand-dock`·`data-errand-chip="{n}"`(`data-done`)·`data-errand-progress="n/3"`·`data-errand-act`(+`aria-disabled`)·`data-errand-place="{장소 id}"`(+`data-done`)·`data-errand-arrow`·`data-near-ring="{r}"`·`data-record-button`·`data-record-card`(+`data-record-rows="{n}"`)·`data-record-row`·`data-trace-card`. 값에 역할·좌석 비밀을 싣지 않는다(장소 id·진행 수·줄 수뿐).
- **영역 검사(필수, 폰 6종)**: 심부름·토론(기록 카드 열림)·아침(흔적 카드)에서 새 요소의 사각형이 ① 띠 면·독 줄·아래 패널과 교차 0 ② (심부름) 표지·화살표 칩이 서로·이름표 버튼 영역과 교차 0 ③ 카드가 `--mf-host-dock + 8` 위로 올라가지 않음. 360×560 포함. 카드가 열린 동안 이름표를 덮는 것(기록 카드)은 예외로 문서화한다.
- **심부름 검사**: 3곳 처리 → 칩 3개 채움·"3/3"·[처리] "완료"·띠 `errand.done`. 반경 밖 [처리] 무변화. 마피아·시민 판에서 목록·마크업 구조가 같다(`data-*` 이름·개수). 반경 밖 사람은 DOM·`__mfWorld` 에 없다. 반경을 나가면 페이드아웃 후 사라진다.
- **기록 검사**: 3곳 완료한 사람만 [기록]·카드 존재, 못 마친 사람은 0건. 비어 있으면 "0". 입력칸 포커스 시 카드 접힘. 다른 사람 화면에 내 기록이 없다.
- **밤 검사**: 마피아·경찰·의사·시민이 같은 칸 수·같은 높이의 `FaceList`, 동료 칸 포함 어떤 칸을 눌러도 알림 없음, `eye`·`heal` 아이콘 0건, `data-ring-kind="mafia"` 0건.
- **아침 검사**: 피해자 있는 아침 흔적 카드 1개(모든 사람), 없는 아침 0개. 카드 DOM 에 역할 값 없음. 피해자 알림과 카드가 동시에 보이지 않는다.
- 소리 검사: 심부름 → 토론 `ui.host` 한 번, 낮 시작 → 심부름 0번, 흔적 카드 `ui.card` 한 번.
- 묶음 G(글자 14px 이상·가로 넘침·콘솔 오류 없음)·H 를 새 요소에 적용. 성능: 심부름(근처 사람 페이드·표지 투영 갱신)과 8명 판에서 6페이즈 게이트(5분 평균 55fps)를 다시 잰다. 실기기는 v3.0 끝에 한꺼번에(D-10).

- **밤 선택 통일(U-10·U-11)은 서버·화면 모두에 영향이 큰 위임 기본값이다**: 마피아 걷기 접근·`approach`·`data-ring-kind="mafia"`·`aim` 효과와 마피아 밤 채팅 기록 칸의 처리, **의사의 자기 칸**(규칙을 먼저 확정) 세 가지를 계획 단계에서 서버 규칙과 함께 확정한다. 사용자가 돌아와 바꿀 수 있다.
- `grep -rn "nightMafia\|approach\|aim:\|ring-kind" src` 로 마피아 전용 밤 분기 지점을 확정한다(`GameMap`·`GamePanel`·`nightDark`). 시민 88 고정 패널(`nightCitizen`)은 얼굴 목록 분기로 합친다.
