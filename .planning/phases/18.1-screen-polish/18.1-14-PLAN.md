- 화면 적용은 CSS 한 규칙: `.mv-chat__log.is-open` 의 높이가 같은 식의 clamp 다. 재료는 CSS 변수 — `--mf-room-h`(방 화면 루트 높이)·`--mf-panel-rest` 는 `useMapInsets` 의 측정이 루트에 쓰고(대기실·게임 맵·결과가 모두 이 훅을 쓴다), `--mf-kb-lift`·`--mf-host-bottom` 은 이미 방 틀에 있다. 상수 셋은 ChatPanel 이 기록 상자에 CSS 변수로 넘긴다(숫자 한 곳 = chatUi.ts, 지금의 페이드 높이와 같은 방식). 키보드가 올라오는 동안 React 를 다시 그리지 않는다.
- 상태는 ChatPanel 안의 open 하나. 켜는 길: [data-chat-open] 누름(토글), 입력칸 포커스(켜기만). 끄는 길: [data-chat-open] 누름 하나 — 이때 입력칸에 포커스가 있으면 blur 한다. 단계가 바뀌거나 포커스가 풀려도 저절로 접지 않는다(닫기는 하나).
- [data-chat-open] 단추: 접힌 상태에서는 지금처럼 두 줄 창 전체가 누르는 영역이고, 늘어난 상태에서는 오른쪽 위 44×44 로 줄어 기록 칸을 스크롤·선택할 수 있다. `aria-expanded` 와 접근성 이름("채팅 기록 열기" ↔ `CHAT_TEXT.logClose` = "채팅 기록 접기")이 상태를 말하고 화살표는 늘어난 상태에서 아래를 향한다. 위쪽 페이드는 접힌 상태에만 있다.
