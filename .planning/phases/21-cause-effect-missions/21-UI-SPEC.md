# Phase 21 — UI Design Contract (원인→결과 하루 흐름: 저녁 등불 · 밤 집 찾기 · 아침 현장 조사 · 의심 보드)

> 확장판(`extended`, 마을 맵)의 하루 한 바퀴에 화면 네 곳이 새로 생기거나 바뀐다: **저녁 등불**(가로등 8곳 중 내 3곳을 켠다) → **밤 집 찾기**(고정 시점에서 집 하나를 누른다) → **아침 현장 조사**(피해자 집 앞 단서 지점 3곳을 살핀다) → **토론 의심 보드**(내가 아는 것 칩 + 얼굴 줄). 기본 마피아 화면은 한 픽셀도 바뀌지 않는다(아래 "기본 마피아는 바뀌지 않는다" 표).
> 결정 0051(글 최소·보고 누르기)이 먼저다: 정보는 장면(켜진 등불·창·발자국 그림)·아이콘·숫자로, 글은 단계 이름 + 한 줄 자막(공백 포함 19자 이하) + 단추 한 낱말뿐이다. 새로 생기는 글은 아래 "Copywriting Contract" 표가 전부다.
> 기준: ROADMAP Phase 21 성공 기준 **1~6**, 21-CONTEXT D-01~D-30, 승인 시안 `design/v3.0/lamp-house/`(저녁·밤·아침·보드 4장). 15~20 의 UI-SPEC(카메라·단계 조명·이름표·방장 줄·마을 3D 치수·컷어웨이)은 **그대로 이긴다**. 이 문서가 바꾸는 것은 아래가 적은 것뿐이다.
> 범위 밖: 서버 규칙·와이어·판정(21-CONTEXT D-01~D-23 이 맡는다 — 이 문서는 화면에 닿는 결과만 적고, 화면이 읽는 값 이름은 계획이 정한다), 소도시 블록, 집 안에 들어가기, 전체 지도 시트, 구역 채팅, 단서의 확정 증거화, 햅틱, 진행에 지장 없는 작은 화면 가장자리 문제(07-UI-SPEC UI Considerations 20 그대로).
> 사람을 부르는 말은 **'참가자'** 다(접근성 이름·시험 이름에도 '손님' 금지).

### 저녁 3D 상태와 겉보기 규칙

- 저녁 동안 **켜진 등불 = 켜짐**. 마피아가 자른 등불도 저녁 동안은 켜진 것으로 그려진다(D-06). 밤이 시작되는 순간 자른 등불과 안 켠 등불은 같은 모양으로 꺼진다(0.8초 `--dur-slow` ease-out, 모션 줄이기 즉시). 그래서 밤의 꺼진 등불은 "처리 못함"과 "자름"을 구별할 수 없다(D-08).
- 집 창은 등불에 연동: **창 켜짐 ⇔ 그 좌석 번호의 등불 켜짐**(P21-15) ∧ 그 좌석에 사람이 있음. 저녁 동안 사람이 켤 때마다 해당 집 창도 켜진다(원인 → 결과가 한 화면에 보인다).
- 새 날 저녁이 시작되면 등불·창은 모두 꺼진 상태에서 시작한다(어제의 상태가 남지 않는다).

## 겉보기 같음 규칙 (마피아 = 시민, 누설 금지)

화면은 서버가 준 view 만 그리고 역할을 읽지 않는다. 이 규칙은 구현·시험이 같이 지킨다.

1. 저녁 독·타일·진행 점·후광·배지·효과음·길게 누르기 채움은 **모든 역할이 같은 마크업·같은 타이밍**이다. [켜기] 단추는 하나뿐이고 `cut` 이라는 말·상태·속성·클래스가 `src/` 어디에도 없다(서버·시험 제외, 시험이 `git grep` 으로 막는다).
2. 마피아가 심지를 자르는 방법(P21-8)은 겉보기에 구별되지 않는 길게 누르기이고, 시민이 길게 눌러도 같은 모양·같은 결과(켜기)다. 거절 응답은 사유를 구별하지 않는다(L40).
3. 밤 집 판·독 높이·범례·안내 문장은 **네 역할이 같다**(밤 조명도 P21-10 으로 같다). 다른 것은 지금도 있는 두 가지뿐이다: 행동 줄 단추([쪽지] 마피아 / [유언] 그 밖, 같은 자리·같은 크기)와 산 마피아의 합의 배지(0074).
4. 아침 단서 지점 표식은 살피기 전 **모두 같다**. 살핀 뒤의 세 상태(살핌/먼저 손댄 흔적)와 카드 글은 내가 받은 서버 값만 반영한다. 마피아가 어떤 지점을 살필 때의 화면은 "살핌 + 평소 단서 카드"로, 시민이 먼저 살폈을 때와 같다.
5. 꺼진 등불·창 켜짐 여부는 공개된 사실(누구나 본다)이고 누가 껐는지는 어디에도 없다. 단서 decal 3은 모든 사람에게 같은 모양이다(발자국 개수·옷 조각 종류를 3D 에 그리지 않는다 — 그것은 나만 받는 단서다).
6. 자막 띠 문구는 역할을 읽지 않는 분기만 쓴다(아래 표, 14페이즈 HOST-05 허용 목록 규칙 그대로 + 확장판 분기는 `view.mode` 의 규칙 값만 더 읽는다).

## 튜토리얼 화면 변경 (D-28, 성공 기준 6)

17페이즈 "첫 사건"의 진입 두 길(혼자 하기 서버 0 · 방장 스위치)·8장 구조·진행 점 7·건너뛰기·마무리 카드는 **그대로**다. 장면 내용만 새 하루 흐름으로 바꾼다. 가짜 방 상태 출연 상수(`TUTORIAL_CAST`)의 `map` 을 `plaza` → **`town`** 으로 바꾼다(집 판·창·단서 지점이 마을에만 있다). 출연 좌석 6(`me: 5`, 피해 `2`, 용의 `1`)은 그대로이고 집 6채만 주인이 있다.

| 장면 | 지금 | 새 내용 |
|------|------|---------|
| 1 오프닝 | 램프 둘 꺼짐 + 비명 | 그대로(결과의 원인을 이어 보여 주는 첫 장면) |
| 2 아침 | "서연 님이 당했습니다" "이 중에 마피아가 있습니다" | 그대로 + 끝에 새 한 줄 `tutorial.secret` **"정체는 판이 끝나야 알아요"**(14자, D-20) |
| 3 심부름(`errand`) | 우체통에서 처리 | **저녁 등불**: 가로등 한 곳을 켠다. 자막 `tutorial.errand` **"등불을 켜 보세요"**. 포커스 대상 `errand`(가로등 타일 + 독 [켜기]) 그대로. 켜면 가로등 빛 + 서연 집이 아닌 한 집의 창이 켜지는 것까지 보인다 |

| 5 흔적(`evidence`) | 증거 카드 + 이름표 표시 | **현장 + 보드**: 서연 집 앞 단서 지점에서 옷 조각 하나를 살펴 "붉은 천 조각" 카드를 받고(자막 `tutorial.link` **"단서와 같은 옷을 찾아 보세요"**), 의심 보드가 자동으로 열려 **도윤(noir)** 칸에만 같은 옷 표시가 켜진다. 포커스 대상 `suspect` 그대로 |

| 7 역할 | 직업 카드 | 그대로("밤에는 저마다 할 일이 있어요") |

튜토리얼은 같은 새 부품(`ClueSpot`·`HousePick`·`SuspectBoard`·`ClueChip`)을 가짜 view 로 먹인다 — 튜토리얼 전용 모양을 따로 만들지 않는다. 튜토리얼에서 사용자가 누르는 단추([켜기]·집 판·[살펴보기])는 실제 부품이고 서버로 아무것도 보내지 않는다(서버 0). 자막 문구 키 `tutorial.witness` 는 `tutorial.house` 로 이름을 바꾼다(대본 표 한 곳). 소리·장면 시각 표는 계획이 17 의 표를 고친다.
