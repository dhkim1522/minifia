# Phase 21 — UI Design Contract (원인→결과 하루 흐름: 저녁 등불 · 밤 집 찾기 · 아침 현장 조사 · 의심 보드)

> 확장판(`extended`, 마을 맵)의 하루가 **저녁(원인 만들기) → 밤(원인 정하기) → 아침(결과 살피기) → 토론(단서 나누기)** 로 이어진다. 기본 마피아(`basic`)의 화면은 한 픽셀도 바뀌지 않는다(D-01).
> 결정 0051(글 최소·보고 누르기)이 먼저다: 정보는 **장면 · 아이콘 · 숫자**로, 글은 단계 이름과 한 줄 이하(3초 규칙), 행동은 **대상(등불·집·단서 지점·얼굴)을 직접 누르는 것**이다. 새 단추는 [켜기]·[살펴보기]·[건너뛰기] 세 낱말뿐이다.
> 기준: ROADMAP Phase 21 성공 기준과 21-CONTEXT D-01~D-30. 6~20 의 UI-SPEC(영역 배치·빛남 규칙·이름표·카메라·단계 조명·마을 맵)은 **그대로 이긴다**. 이 문서가 바꾸는 것은 아래가 적은 것뿐이고, 바꾼 곳은 '기본값 기록'에 이유를 적었다.
> 범위 밖: 소도시 블록, 집 안에 들어가기, 전체 지도 시트, 구역 채팅, "정통 판"(배지·귓속말·결선), 단서의 확정 증거화, 서버 판정·와이어(D-05~D-23 이 맡는다 — 이 문서는 화면에 닿는 결과만 적는다), 햅틱, 진행에 지장 없는 작은 화면 가장자리 문제(07-UI-SPEC UI Considerations 20 그대로).
> 사람을 부르는 말은 **'참가자'** 다(새 글·접근성 이름·시험 이름에 '손님' 금지). 낮도 마피아 분위기(낮은 명도·채도), 깔끔 담백.

## 누설 방지 규칙 (D-21, D-22 — 14 의 HOST-05 확장)

- **서버 전용 값**: 마피아의 등불 처리 기록 `cut`, 단서 지점의 "먼저 손댄" 여부, 밤의 선택은 view 에 싣지 않는다. 뷰에 싣는 것은 모든 역할이 같은 모양인 값뿐이다: 내 등불 목록·진행, 켜진 것으로 보이는 등불(저녁) / **밤 시작 이후의 켜짐·꺼짐 8개**(공개), 내가 살핀 지점 목록과 그 단서(나만), 단서 지점 3곳의 위치(공개), 받은 단서의 **종류와 값은 나만**.
- 화면은 `me.role` 을 읽지 않는다(`hostLineOf`·`callTargetsOf`·`HouseTag`·`ClueSpot`·`ClueCard`·`SuspectBoard`·`ErrandAct` 모두). 마피아 전용 DOM·`data-*`·접근성 이름·애니메이션·타이밍이 없다. 길게 누르기 감지는 모든 역할에 있다(P21-7).
- 지점 상태 4(새·살핌·어두워서 못 봄·먼저 손댄 흔적) 가운데 **두 점선 상태의 겉모양이 같다**(P21-10). 응답이 늦거나 빠르게 오는 것으로 갈라지지 않도록 응답은 모든 상태에서 같은 한 틱 안에 같은 모양으로 온다(서버 쪽 규칙, 화면은 대기 표시 없이 응답 모양대로만 바꾼다).
- 거절 응답(반경 밖·이미 살핀 지점·이미 처리한 등불·탈락자)은 사유를 구별하지 않는다(L40). 화면은 알림 없이 무변화.
- 개관 시점에서 **남의 위치**는 어느 모양으로도 보이지 않는다(밤에 걷지 않으므로 몸·이름표를 그리지 않는다). 모두가 자기 집 앞에 있다는 것은 공개 상태다.
- 누설 전수 시험(월드 프레임 + 뷰 키)에 새 단계를 넣는다: 역할 5종(마피아·경찰·의사·시민·유령) × 저녁·밤·아침·토론에서 ① 같은 단계의 시민·마피아 view 의 새 필드 키 집합이 같다 ② 저녁 등불 처리(켜기·긴 누르기) 응답이 같다 ③ 밤 선택 응답 모양이 모든 역할에서 같다 ④ 지점 살핌 응답이 같다(마피아가 이미 만진 지점 포함) ⑤ 단서 view 에 역할 값이 없다.

## 알림음

새 레시피·신호 없음. `ui.host` 가 단계 바뀜(위 규칙)에서 한 번, `ui.tap` 이 [켜기]·[살펴보기]·[건너뛰기]·집 문패·지점 표지에서, `ui.card` 가 단서 카드 도착마다 한 번. 소리 단추·잠김·끄기는 기존 엔진이 따른다. 등불 켜짐·꺼짐·창 불빛에 별도 효과음은 두지 않는다(밤 분위기 소리는 기존 그대로).

## 접근성 · 모션 · 입력

- 누르기 영역 44 이상(문패 44, 지점 표지 52, 가로등 표지 44, [켜기]/[살펴보기] 높이 44, [건너뛰기] 104×48, [보드] 52×57, [닫기] 높이 44). 포커스 링 `gray-100` 2px. Tab 순서: 헤더 [보드] → [내 역할] → 소리 → (스테이지의 표지·문패, 위→아래·왼→오) → 아래 패널 단추.
- 진행·상태는 색만으로 알리지 않는다: 채움 + `check` + 숫자 + `aria-label`. 켜짐/꺼짐은 채움 ↔ 속 빔 점 + 이름. 고른 집은 `check` 배지 + `aria-pressed`. 처리 직후 `aria-live="polite"` 로 "진행 n/3" 한 번.
- `prefers-reduced-motion`: 깜빡임은 **정지한 테두리 + 중간 번짐**(테두리는 항상 보인다), 등불 켜짐·카드 등장·어둠 가림·지점 등장·카메라 이어 붙임은 즉시. 빛 무리 크기 변화 없음.
- 깜빡임은 1Hz(초당 3회 미만). 한 화면에서 동시에 깜빡이는 대상은 같은 종류뿐이다.

## 남은 위험 · 플래너 확인 목록

- **발자국 수 공개 범위(P21-16)**: D-12 와 D-14 가 어긋나게 읽힌다. 화면은 "지점 ①을 살핀 사람만 수를 본다"로 정했다. 사용자가 공개로 바꾸면 아침 발표·띠에 숫자를 싣는 것이 아니라 보드 안 공개 칸을 하나 더하는 것이 가장 작은 변경이다.
- **마피아 심지 자르기 조작(P21-7)**: 긴 누르기가 위임 기본값이다. 대안(두 번 누르기·밤에 선택) 중 어느 것이든 "모든 역할이 같은 제스처·같은 DOM" 조건만 지키면 된다. 마피아가 이 조작을 발견하게 하는 한 줄은 마피아 역할 카드(본인 화면) 말고는 둘 곳이 없다.
- **밤 선택 바꾸기(P21-5)**: 시안은 "고른 집은 바꿀 수 있다". 서버 `pickTarget` 이 마지막 선택을 인정하는지 확인한다(15 는 "다시 눌러도 취소되지 않는다"만 정했다). 아니라면 시안의 바꾸기 부분만 버린다(화면은 한 번 고르면 다른 집이 눌리지 않게 `aria-disabled` 가 아니라 서버가 같은 응답으로 무시).
- **개관 카메라(P21-2)**: `camera.ts` 에 새 모드가 필요하다. 20 의 `PAN_BOX`·`PLATE_FAR` 규칙과 따로 두고, 배율 식과 6종 폰 × 띠 한 줄/두 줄 가시성 검사(문패 ≥ 44, 빈 배경 없음)를 같이 만든다.
- **밤 조명 통일**: 확장판 밤에서 `data-night-dark`·`nightCitizen` 의 "거의 깜깜"을 끄고 모든 역할이 같은 개관 장면을 본다는 것은 결정 0074-4 의 연장이지만 20 의 `houseOwned`/`nightCitizen = 0` 규칙과 부딪힌다. 이 페이즈가 `houseLit` 열로 대체한다(20 의 시험·팔레트 대조 갱신 필요).
- **공개 증거 카드 폐지(P21-15)**: `rules.trace` 와 `view.day.morning.trace`·`traceWindowOf`·`EvidenceCard` 사용처를 확장판에서 끄는 범위를 계획에서 확정한다.
- **가로등 id**: `PlaceId` 닫힌 집합(16개)에 가로등 8개를 어떻게 더할지(새 id 8개 vs 같은 `lamp` 그림 8곳) 계획이 정한다. 화면은 `placeLamp` 아트 하나로 그리고 접근성 이름 "가로등"을 쓴다. 단서 지점은 별도 id 공간(`footprint`·`cloth`·`window`)이다.
- **아침 발표 문구·길이(P21-20)**: 큰 글 발표 길이와 30초 시계 시작 시각, D-17(현장 없음) 토론 첫머리 발표의 위치는 구현 중 한 번 맞춘다.
- **한 판 길이**: 저녁 40 + 밤 + 아침 30 이 더해져 하루가 길어진다. [건너뛰기]와 단계 길이는 상수 한 곳이라 실테스트 뒤 이 줄만 고친다(고정 제한 아님).
- 새 결정 기록(D-01~D-30 의 화면 계약)은 `docs/decisions/` 다음 번호로 적고 `docs/screen-map.md` 에 "확장판 하루 흐름(21페이즈)" 절을 더한다.
