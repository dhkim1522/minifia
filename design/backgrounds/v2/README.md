# 배경 에셋 v2 (2026-10-25 사용자 결정, 결정 0029)

> 원본: 클로드 데스크톱 에셋 아티팩트 https://claude.ai/artifact/4dYpe74vxJHSnA4WhFSLTM 의 "배경 에셋"(set1)과 "배경 에셋 (NEW)"(set2). GSD 에이전트는 아티팩트를 열 수 없으므로 이 폴더가 기준 사본이다. 1080×2340 구도, 앱은 `background-size: cover`, 가운데 위쪽 기준.
> 기존 A_cute 4장면(`../A_cute`, 앱이 지금 `public/backgrounds/` 에서 쓰는 것)은 이 v2 가 앱에 들어가기 전까지 그대로 쓴다.

## 두 벌

- `set1/` (JPG, 장당 약 45KB): 기존 한 벌. 밤 → 아침 → 낮(오후) → 해질녘 → 투표·처형(낮/밤). 아침·낮은 하늘이 밝아 헤더 흰 글씨 대비가 2.5~2.9:1 로 부족해 **헤더 위쪽에 어두운 막**이 필요하다(시안 `Y3`, `Y5`, 캔버스 18차).
- `set2/` (PNG, 장당 300~600KB): NEW 한 벌. 모든 장면을 밤 색감·채도에 맞췄다. 헤더 흰 글씨 대비가 전 장면 5.2:1 이상이라 막이 필요 없다. 앱에 넣을 때 WebP 변환·장면별 지연 로딩이 필요하다(용량).

파일 이름: `bg_<구도>_<장면>.<확장자>`. 구도 `game`(테이블 화면) / `entry`(입구·큰 달).

## 사용 결정(사용자 확정)

| 앱 장면 | 구도 game | 구도 entry |
|---|---|---|
| 대기실·역할 배정 | `set2/bg_game_lobby` | `set2/bg_entry_lobby` |
| 밤 | `set2/bg_game_night` | `set2/bg_entry_night` |
| 아침 | `set1/bg_game_morning` + 헤더 어두운 막 | `set1/bg_entry_morning` |
| 낮 | `set1/bg_game_day` + 헤더 어두운 막 | `set1/bg_entry_day` |
| 해질녘(낮 → 밤 사이) | `set2/bg_game_dusk` | `set2/bg_entry_dusk` |
| 투표·처형(해질녘) | `set2/bg_game_verdict_dusk` | `set2/bg_entry_verdict_dusk` |

- 아침·낮만 set1 + 막이다(낮이 어두우면 낮 느낌이 안 난다는 사용자 판단). 나머지는 set2.
- 투표·처형 배경은 4페이즈에서 쓴다. `set1/bg_*_verdict_day`·`verdict_night`, `set2/bg_*_verdict_night` 는 참고용으로 보관한다.
- 아침·낮(set1)과 밤·해질녘(set2)은 하늘 색 차이가 커서 크로스페이드 때 튈 수 있다. 폰에서 보고 어색하면 낮 하늘 색만 남색 쪽으로 보정한다.
