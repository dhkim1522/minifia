# 배경 v4 — 실내 (2026-10-26, 결정 0032)

데스크톱에서 만든 실내 시안 "실내 시안 바닥 수정"(에셋 아티팩트 https://claude.ai/artifact/4dYpe74vxJHSnA4WhFSLTM 의 `Indoor3`)의 사본이다. GSD 에이전트는 아티팩트를 열 수 없으므로 이 폴더가 기준이다.

- 1080×2340 PNG, 불투명. 방(벽·커튼·마루·사다리꼴 러그·코트걸이)은 5장이 같고 창밖과 빛 색만 다르다.
- 마루 시작선 약 y=533~566, 러그 윗변 약 530·아랫변 약 1305~1337, 조명 중심 (540, 915)(처형은 기둥 끝 타원).
- 장면 5개: night(대기실·배정·역할 확인과 밤 공용), morning, day, dusk, verdict_dusk. 입구(entry) 그림은 v3 의 `bg_entry_lobby` 를 계속 쓴다.
- 헤더 글씨 대비는 막 없이 전 장면 ≥ 11.7:1 이라 헤더 어두운 막은 쓰지 않는다.
- 알려진 한계: 창 유리가 폰 y 72~159 이고 헤더가 119 까지라 창의 위쪽이 헤더 뒤로 간다(해·달이 일부 가려짐). 큰 폰(430×932)은 러그 아래가 비는데, 층 분리 에셋(벽·마루·러그·조명 따로)으로 나중에 푼다.
