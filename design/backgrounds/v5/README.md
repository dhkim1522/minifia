# 배경 v5 — 실내 V2 (2026-10-26, 결정 0033)

데스크톱 "실내 배경 레이어 V2"(에셋 아티팩트 https://claude.ai/artifact/4dYpe74vxJHSnA4WhFSLTM, 보드 `RoomLayersV2`)의 완성 모습 5장 사본이다.
- 창 유리와 커튼이 맨 위(y=0)까지 이어지고, 해·달·구름이 장면별로 다르다. 아침은 위가 어두운 동틀녘 하늘.
- 마루·러그·코트걸이·조명은 v4 와 같은 위치. 투표·처형은 위가 좁은 원뿔 스포트라이트(타원 중심 (540, 915)).
- 이 폴더는 완성 모습 5장만 둔다. 레이어 10종은 투명 PNG 가 아니라 체크무늬가 박힌 미리보기라서 쓰지 않는다.
- 앱은 배경 층에 `filter: brightness(0.85)` 를 걸고(`--mf-backdrop-dim`), 헤더 글씨 묶음 뒤에 약한 번짐(남색 45%)을 깐다. 그림 자체의 명도 조정은 폰에서 보고 정한다.
