# 미니피아 캐릭터 에셋 규격 (세트 C)

## 1. 크기
- 논리 크기 72×96 (가로 3 : 세로 4). 디자인 시스템의 64×96 칸 안에 가로 여백을 두고 넣어요
- 파일은 @2x(144×192), @4x(288×384) 두 가지 PNG, 배경 투명
- 발 끝은 아래에서 2px(논리) 위, 가로는 가운데 정렬
- 모든 캐릭터는 같은 배율로 줄여서 키 차이를 유지해요 (모자 있는 캐릭터가 조금 더 커요)

## 2. 폴더와 파일 이름
- table/ 테이블 인물 8종 (fig1_boy_brown … fig8_girl_tanhat)
- roles/ 직업 4종 (mafia, citizen, police, doctor)
- ghost/ 유령 1종 (ghost)
- extra/ 확장용 16종 (탐정, 스파이, 영매, 군인, 도둑 등)
- 이름 형식: `<id>_<상태>@2x.png`, 상태는 default, disconnected, dead
- manifest.json 에 전체 목록, 한글 이름, 상태, 좌석 색이 들어 있어요
- source/ghost_svg 는 유령 원본 SVG예요

## 3. 상태 3종
- default: 원본 색
- disconnected(끊김): 흑백 + 불투명도 60%
- dead(탈락): 흑백 + 불투명도 30%. 탈락하면 인물 대신 ghost 를 써도 돼요
- 상태 파일은 미리 만들어져 있지만 코드에서 grayscale + opacity 로 만들어도 같아요

## 4. 테이블 인물 (직업이 드러나면 안 돼요)
- 8종 모두 같은 회색 코트, 머리와 모자만 달라요
- 좌석 색은 넥타이로 표시해요: #7a8fb8 #8e7ab8 #6fa59a #b89a6f #6f8fa8 #9aa86f #b87a5c #a9aebb
- 직업 소품(총, 청진기, 배지, 선글라스)은 테이블 인물에 쓰지 않아요

## 5. 직업 인물 (직업 카드, 역할 공개 때만 써요)
- 마피아: 선글라스 + 검은 모자 + 크림슨 넥타이 #C8102E. 크림슨은 마피아에만 써요
- 경찰: 파란 제복과 배지
- 의사: 흰 가운, 십자 표시는 빨강 대신 청록 #2FA4A0
- 시민: 소품 없는 평상복

## 6. 유령
- 첫 에셋의 유령(천사 고리, X 눈) 하나만 써요. 좌석별 유형은 없어요
- 탈락한 사람의 자리에 인물 대신 놓아요

## 7. 확장 규칙 (새 캐릭터 추가할 때)
1. 72×96 캔버스, 같은 배율, 발 정렬 지키기
2. 같은 스타일: 둥근 큰 머리, 큰 귀, 점 눈, 볼터치, 윤곽선 없이 면 색만
3. id 는 영문 소문자와 밑줄, 상태 3종 × @2x/@4x 모두 만들기
4. 새 직업은 크림슨과 빨간 십자를 피하기
5. manifest.json 에 한 줄 추가하기
6. 총 같은 무기 소품이 있는 캐릭터는 스토어 심사 기준에 맞는지 확인하기

## 8. 참고
- 확장 16종 중 일부(의사 B, 경찰 의사)는 빨간 십자가 그대로 남아 있어요. 쓰려면 의사 4번처럼 청록으로 바꿔야 해요
- 마피아 C, 마피아 D, 탐정에 총이나 무전기 소품이 있어요
