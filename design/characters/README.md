# 캐릭터 에셋

직접 만든 캐릭터 원본을 여기에 둔다. 넣으면 디자인 시스템의 `Figure` 와 앱의 인물 그림을 이 그림으로 바꾼다(앱용 축소본은 `public/characters/` 에 만든다). 그 전까지는 임시 정장 실루엣을 쓴다.

| 항목 | 규격 |
|---|---|
| 파일 이름 | `01.png` ~ `08.png` (8종 이상이면 `09.png` 부터 이어서) |
| 비율 | 가로:세로 2:3 (화면 논리 크기 64×96). 원본 256×384 이상 권장 |
| 배경 | 투명 PNG |
| 기준점 | 발이 그림 아래 가운데에 닿는다. 머리 위·좌우 여백은 비슷하게 둔다 |
| 상태 | 기본 1장이면 된다. 끊김(흑백 60%)·탈락(흑백 30%)은 코드로 만든다. 전용 그림을 줄 때는 `01_disconnected.png`, `01_dead.png` |
| 자리 구분색 | 그림 안에 넣지 않아도 된다. 이름표 점으로 구분한다 |

규격과 다른 그림도 쓸 수 있지만 테이블 자리 간격과 이름표 위치를 다시 맞춘다. 참고 이미지는 `design/references/` 에 따로 둔다(앱 에셋 아님).
