# 캐릭터 에셋 (세트 C, 확정)

클로드 데스크톱에서 만든 "minifia 캐릭터 에셋" 캔버스(https://claude.ai/artifact/4dYpe74vxJHSnA4WhFSLTM)의 **세트 C 참고 이미지 그대로** 를 최종 캐릭터로 정했다(2026-10-22). 이 폴더가 원본 사본이다. 앱용 파일은 여기서 `public/characters/` 로 옮긴다.

## 규격

| 항목 | 값 |
|---|---|
| 화면 크기 | 72×96 (가로:세로 3:4) |
| 파일 | 2배 144×192 투명 PNG |
| 기준점 | 발 아래 가운데 |
| 끊김 | 기본 그림을 흑백 + 60% (코드) |
| 탈락 | 같은 자리 번호의 유령 그림 |

새 그림을 더할 때도 이 규격을 지킨다. 다른 비율이면 테이블 자리 간격과 이름표 위치를 다시 맞춘다.

## 폴더

| 폴더 | 내용 | 누가 보나 |
|---|---|---|
| `figures/01.png`~`08.png` | 테이블 인물 8종. 1 소년 갈색 머리, 2 소년 검은 머리, 3 소년 금발, 4 소녀 갈색 머리, 5 소녀 검은 머리, 6 소녀 적갈색 머리, 7 검은 중절모, 8 갈색 중절모. 넥타이 색이 자리 구분색 `seat-1`~`seat-8` 과 같다 | 모두 |
| `ghosts/01.png`~`08.png` | 탈락한 사람의 유령. 번호는 인물 번호와 같다(자리 색이 살짝 입혀짐). `00.png` 는 색 없는 기본, `dead-halo.png` 는 X 눈과 고리가 있는 유령(연출용 후보) | 모두 |
| `roles/mafia.png` · `police.png` · `doctor.png` · `citizen.png` | 직업 그림. 본인 역할 카드 앞면, 마피아 동료 표시, 경찰 조사 결과, 게임 끝 결과에만 쓴다. 밤 화면과 테이블에는 쓰지 않는다 | 본인, 게임 끝에는 모두 |
| `extras/` | 확장용 16종(탐정, 스파이, 도둑, 군인, 영매 등). v1 에는 쓰지 않는다. 직업 추가(v2) 때 고른다 | — |

다른 사람의 직업은 서버가 보내지 않으므로, 직업 그림은 받은 정보가 있는 화면에서만 그린다.
