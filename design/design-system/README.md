친구 4~8명이 각자 폰으로 들어와 5~10분 안에 한 판을 끝내는 마피아 게임의 디자인 시스템이다. 방향은 **"어둡지만 경쾌한 밤"**: 커튼 걷힌 창 너머로 달빛 마을이 보이는 방 안, 2~3등신 카툰 인물들이 크림 대리석 원탁에 둘러앉아 있다. 진홍은 마피아의 밤에만, 노랑(앰버)은 낮의 공개 투표에만 쓴다. 화면은 세로, 폰 폭 360~430px 이다. 실시간 3D 없이 원근 타원 테이블과 그림자·조명 층으로 입체감을 낸다(2.5D).

> **상태: v1.0 구현 기준 (2026-10-30).** 1~5페이즈 구현이 끝난 앱 코드와 같다. 값의 원천은 저장소 `design/tokens.json`(앱 `src/styles/tokens.css` 는 여기서 만든다)과 각 페이즈 UI-SPEC, 결정 기록 `docs/decisions/` 다. 구현된 화면 전체는 화면설계서 v1.0 을 본다.

## 말투와 문구

- 해요체로 짧게 쓴다. 문장 끝에 마침표를 찍지 않는다. 진행 중인 일은 말줄임표 `…` 로 끝낸다: "방장이 시작하기를 기다리는 중…".
- 사회자 문구는 정통 마피아 그대로 쓴다: "직업을 배정하고 있습니다", "밤이 되었습니다", "낮이 되었습니다", "아무 일도 없었습니다".
- 모든 단계 화면에 **지금 할 일 한 문장**과 남은 시간을 함께 둔다(`PhaseBar`, 결정 0038). 화면마다 안내 문장은 정확히 하나다.
- 오류는 문제와 다음 행동을 같이 말한다: "이미 있는 이름이에요", "방이 꽉 찼어요" + [처음으로].
- 확인은 질문 한 문장: "방에서 나갈까요?", "지호님을 내보낼까요?".
- 이모지와 느낌표는 쓰지 않는다. 반응은 `EmojiBar` 의 SVG 8종으로만 한다.
- 역할 이름: 마피아 · 경찰 · 의사 · 시민. 사람을 부를 때는 "{닉네임}님".
- 투표 안내 예: "아무도 고르지 않으면 무효표가 돼요", "빈 곳을 누르면 선택이 취소돼요"(결정 0040).

## 색

| 비율 | 토큰 | 쓰는 곳 |
|---|---|---|
| 60% | `night-900` | 모든 화면의 바탕 |
| 30% | `night-800`, `gray-800`, `gray-700` | 입력칸, 시트, 아래 패널, 카드 뒷면, 보조 버튼, 구분선 |
| 10% | `crimson-*`, `amber-*` | 진홍 = 마피아의 밤, 앰버 = 낮의 공개 투표. 아래 예약 목록 밖에서는 쓰지 않는다 |

- 글자는 `gray-50`(제목), `gray-100`(본문), `gray-300`(보조) 세 단계. `gray-500` 은 글자에 쓰지 않고 경계에만 쓴다(`night-900` 위 3.8:1).
- 주 버튼은 `gray-100` 면 + `night-900` 글자다. 진홍·앰버 버튼은 만들지 않는다.
- 포커스 링은 `gray-100` 2px, 오프셋 2px.
- 테이블 판은 크림 대리석 `felt-*` 세 단계와 `table-rim`·`table-hi`·`table-edge`(결정 0013).
- 자리 구분색 `seat-1`~`seat-8` 은 인물의 넥타이(그림에 들어 있음)와 이름표 점에만 쓴다. 의미 없는 구분용이다.

### 진홍 예약 — 마피아·위험·시간 끝

1. 타이머 마지막 5초: 막대 `crimson-500`, 숫자 `crimson-400`
2. 마피아 본인 화면의 동료 표시: 진홍 후광과 머리 위 마름모 `crimson-400`
3. 마피아 역할 카드 앞면의 그림(진홍 넥타이)과 동료 줄(`crimson-300`), 암살일지(`journal-mafia-*`)
4. 카드 뒷면 가운데 마름모 `crimson-500` (모두에게 같다)
5. 입력 오류 문장 `crimson-300`
6. 밤 탈락 발표
7. 마피아 팀 승리 결과 띠와 결과 목록의 마피아 글자 `crimson-300`
8. 관전자(탈락자) 화면의 모든 마피아 후광

작은 진홍 글자(14~16px)는 `crimson-300`(5.5:1), 큰 글자와 선·문양은 `crimson-400`, 면은 `crimson-500`. 밤 지목처럼 역할마다 화면이 같아야 하는 곳은 진홍을 쓰지 않는다(화면 캡처로 역할이 드러나지 않게).

### 앰버 예약 — 낮의 공개 투표 (4페이즈, 결정 0037)

1. '처형 투표' 카드: 면 `amber-700` → `amber-900`, 테두리·화살표 `amber-400`
2. 후보 선택 공개의 화살표(투표자 → 대상, 한 번에 하나)와 방금 오른 표수 칩
3. 최다 득표 후보의 앰버 후광, 과반 확정 큰 칩
4. 처형 카드의 띠
5. 안 읽은 기록 점(역할 카드 버튼)

처형 투표 장면과 처형 카드에는 진홍을 쓰지 않는다. 앰버는 글자색으로 쓰지 않는다. 최후 변론·처형의 원뿔 빛은 `cone-light`(위 55% → 아래 20%).

### 후광 (결정 0030·0037)

캐릭터 그림 윤곽을 따라 번지는 두 겹 `drop-shadow`(안쪽 2px 95% + 바깥 9px 75%, 진홍은 70%). 발밑 원과 이름표 반전은 쓰지 않는다. **한 화면 최대 3개.**

| 색 | 뜻 |
|---|---|
| 흰 `gray-50` | 말하는 차례(직업 주장), 내가 밤·투표에서 고른 대상 |
| 앰버 `amber-400` | 공개 중 방금 표가 닿은 대상, 최다 득표 후보, 변론 후보 |
| 진홍 `crimson-400` | 마피아 동료(마피아 본인 화면), 관전자 화면의 마피아 |

흰이 진홍보다 앞선다. 끊긴 사람은 흑백을 먼저 적용하고 후광을 붙인다. 내 자리는 후광 없이 이름표 테두리(`gray-100`)로만 표시한다.

## 글자

- 글꼴은 **Gowun Dodum** 하나(Google Fonts), 대체는 시스템 한글 글꼴(결정 0013).
- 크기 네 개, 굵기 두 개뿐이다: `display` 36, `heading` 24, `body` 16, `label` 14 / 400, 700.
- `display` 는 화면당 하나: 앱 제목, 방 코드, 단계 시작 문구, 카드 앞면 역할 이름, '처형 투표' 카드 제목.
- 입력칸 글자는 16px(iOS 확대 방지). 이름표는 자리 크기와 상관없이 항상 `label-strong` 14px.
- 한글은 `word-break: keep-all`. 숫자가 바뀌는 곳(타이머, 표 수, 방 코드)은 `tabular-nums`.

## 간격과 화면 틀

- 간격은 4의 배수: `space-xs` 4 · `sm` 8 · `md` 16 · `lg` 24 · `xl` 32 · `2xl` 48 · `3xl` 64.
- 누르기 대상은 최소 `tap-min` 44px. 버튼 `control-button` 52px, 입력칸 `control-input` 48px.
- 화면 틀은 폭 최대 430px 한 열. PC 에서는 가운데에 폰 폭으로 선다.
- 게임 화면은 360×640 에서도 스크롤 없이 한 화면이다: 위에 `PhaseBar`(단계·안내·타이머·[역할 카드]), 가운데 테이블 장면, 아래 행동 패널(빠른 메시지·이모티콘·투표 안내).
- 짧은 폰(장면 높이 299 미만, SE 급)은 테이블 세로를 최대 0.77배까지 압축한다. 이름표 글자는 줄이지 않는다(결정 0038).
- 반경: 이름표·배지 `radius-sm`, 버튼·입력칸 `radius-md`, 카드·시트 `radius-lg`, 칩·말풍선 `radius-pill`.

## 테이블 장면 (2.5D)

- 고정 원근 타원 테이블 하나에 최대 8자리(결정 0017, 시안 P2). 390폭 기준 테이블 면 216×108, 좌석 원 rx 146·ry 100, 캐릭터 72×96. 다른 폭은 같은 식으로 계산한다.
- 층: 이름표(z 1~11) → 캐릭터(z 12~22) → 어둡게 층(30) → 유령(31) → 이모티콘(60+). 이름표는 어떤 얼굴도 덮지 않는다.
- 자리 위 표시: 대기실 방장 배지(대기실에서만), 동료 마름모, 직업 주장 알약과 "말 바꿈", '…' 말풍선(48×26), 이모티콘, 공개 중 표수 칩.
- 캐릭터를 누르면 그 사람의 **유저 기록 카드**(주장·투표 이력)가 열린다(결정 0023).
- 끊긴 사람은 흑백 + 60% 와 이름표의 끊김 아이콘, 탈락한 사람은 유령 그림과 "탈락" 글자. 색만으로 구분하지 않는다.

## 배경 장면 (실내 V2, 결정 0029~0033)

방 안에서 커튼 사이 창 너머로 마을이 보이는 장면이다. 그림은 WebP 로 굽고, 게임 구도는 명도 0.8 로 구워 헤더 글씨를 읽히게 한다(헤더 글씨 뒤 남색 45%·흐림 8px 번짐).

| 장면 | 파일 | 쓰는 단계 |
|---|---|---|
| `lobby` | `bg_game_lobby.webp`, 입구 `bg_entry_lobby.webp` | 입장, 대기실, 역할 배정, 역할 확인 |
| `day` | `bg_game_day.webp` | 낮 시작, 직업 주장, 토론 |
| `dusk` | `bg_game_dusk.webp` | 처형 여부 투표, 후보 선택, 공개, 최후 변론, 처형 |
| `night` | `bg_game_night.webp` | 밤, 게임 종료 |
| `morning` | `bg_game_morning.webp` | 아침 결과 |

- 장면이 바뀌면 0.8초 교차 페이드(`dur-slow`). 해·달은 그림에 그려진 그대로 두고 따로 움직이지 않는다.
- **분위기 층**(결정 0038): 밤은 가장자리가 어두워지는 비네팅(`night-950`, 45%→0, 75%→.40, 100%→.72), 아침은 테이블 쪽에서 번지는 밝아짐(`dawn` 38%, 600ms). 둘 다 역할과 상관없이 같다.
- 장면 위 글자는 바탕이 있는 부품에 담는다. 바로 쓰는 것은 단계 시작 문구뿐이고 `shadow-text` 를 단다.
- 장면은 장식이다. 화면 읽기 도구에 숨긴다(`aria-hidden`).

| 역할 확인 | 15초 | 역할 카드 뒤집기 |
| 낮 시작 | 2초 | "N일차 / 낮이 되었습니다" |
| 직업 주장 | 한 사람 8초씩 차례로 | 차례 후광, 주장 알약 |
| 토론 | 40초 | 빠른 메시지·이모티콘 |

## 움직임

- `transform`·`opacity`·`filter` 만 움직인다. `prefers-reduced-motion` 이면 움직임은 끄고 상태 변화는 그대로 둔다.
- 참가자 등장 420ms, 배정 문구 맥박, 카드 뒤집기 600ms, 마지막 5초 숫자 튀기 220ms, 단계 시작 문구 2초, 장면 교차 페이드 0.8초.
- 투표: '처형 투표' 카드가 위에서 떨어져 3초 머문다. 공개 화살표는 1.2초에 걸쳐 투표자에서 대상까지 뻗고 표마다 2초 간격이다. 과반 확정 순간 칩이 ×1.3 로 두 번 두근(0.7초) 후 느린 박동 1.2초.
- 변론: 후보가 가운데로 ×1.7, 나머지 어둡게 45%·흐림 3px, 원뿔 빛 하나. 처형: 사람 → 유령 약 0.4초.
- 토스트를 쌓지 않는다. 결과 안내는 하나씩 2초.

## 아이콘

- `Icon` 의 직접 그린 SVG 만 쓴다: 24 격자, 선 2px, 둥근 끝, `currentColor`. 이모지와 아이콘 폰트는 쓰지 않는다.
- 역할 문양: 마피아는 페도라, 경찰은 별 방패, 의사는 청록 십자 원, 시민은 사람.
- 의미 있는 아이콘(방장 배지, 마름모, 끊김)은 접근성 이름을 단다.

## 캐릭터 (세트 C, 확정)

- 2~3등신 카툰 인물. 큰 머리, 둥근 볼, 회색 정장. 원본은 저장소 `design/characters/`, 규격 `ASSET_SPEC.md`.
- **외형 인물 8종**(`Figure`): 한 방 안에서 겹치지 않게 무작위로 받는다. 넥타이 색이 자리 구분색이다. 게임 능력 차이는 없다.
- **직업 그림 4종**: 직업이 드러나도 되는 곳에만 쓴다(본인 역할 카드 앞면, 마피아 본인 화면의 동료, 결과 화면, 관전자 화면).
- **유령**(v3, 결정 0031): 탈락하면 인물이 유령 하나로 바뀐다. 관전자는 모든 직업과 밤 행동을 본다(결정 0021).
- **방장 배지**(`host_badge.svg`): 대기실에서만 머리 왼쪽 위에 보인다.
- 규격: 화면 72×96(3:4), 파일 `@2x`·`@4x` 투명 PNG, 발 끝은 아래에서 2px 위.

## 역할을 드러내지 않는 화면

- 배정, 카드 뒷면, [역할 카드] 버튼, 밤 화면, 투표 화면은 역할과 상관없이 같은 모양이다.
- 다른 점은 마피아 본인 화면의 동료 표시, 역할 카드 안의 역할별 일지(수사·암살·치료, 결정 0026), 본인에게만 오는 조사·보호 결과뿐이다. 서버가 남의 역할을 살아 있는 사람에게 보내지 않는다.

## 참고한 방향

- 밤 남색과 달빛, 진홍 포인트, 회색 정장 인물, 이중 테두리 카드를 참고 이미지에서 가져왔다.
- 금테, 따뜻한 창문 불빛, 호박, 보라 네온, 보라·파랑 그라데이션, 의미 없는 유리 효과는 쓰지 않는다.
- 캐릭터 움직임·진동 같은 앱 전용 연출은 앱 전환 때 검토한다(결정 0038).

## 불러오는 법 (Consuming this system)

- 네임스페이스는 `Minifia`, 컴포넌트는 `window.Minifia` 에 있다. React 18 은 쓰는 쪽이 준다.
- 불러오는 순서: `tokens.css` → `components/bundle.css` → `components/bundle.js`.
- 캐릭터·배경 그림은 `assets/` 아래 파일이다(`assets/characters/{table,roles,ghost,host}/…`, `assets/backgrounds/bg_<game|entry>_<장면>.webp`). 저장소의 `public/characters/`, `public/backgrounds/` 와 같은 파일이다.
- 번들 컴포넌트: Button, Chip, TextField, Timer, PhaseBar, Notice, ReconnectBanner, ConfirmSheet, RoleCard, MyRoleButton, Figure, Table, Backdrop, EmojiBar, QuickMessagePanel, MessageLog, VerdictPicker, Announcement, ResultList, Icon. 속성은 `components/<이름>/README.md` 와 `components/index.d.ts`.
- 구현 참고 카드(번들 밖, 앱 코드가 원천): VoteParts(처형 투표 카드·화살표·표수 칩), Halo, Spotlight, ClaimTurn, Journal, UserRecord, Atmosphere, PhaseCards. 각 카드의 README 가 앱 파일 위치를 가리킨다.
