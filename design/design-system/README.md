친구 4~8명이 각자 폰으로 들어와 5~10분 안에 한 판을 끝내는 마피아 게임의 디자인 시스템이다. 방향은 **"어둡지만 경쾌한 밤"**: 거의 검은 남색 밤에 2~3등신 카툰 인물들이 달빛 아래 둥근 테이블에 둘러앉아 있고, 진홍은 위험한 순간에만 터진다. 화면은 세로, 폰 폭 360~430px 이다. 모든 화면 뒤에는 달빛 마을 광장 장면(`Backdrop`)이 깔린다. 실시간 3D 없이 원근 타원 테이블과 그림자·조명 층으로 입체감을 낸다(2.5D).

## 말투와 문구

- 해요체로 짧게 쓴다. 문장 끝에 마침표를 찍지 않는다. 진행 중인 일은 말줄임표 `…` 로 끝낸다: "방장이 시작하기를 기다리는 중…".
- 사회자 문구는 정통 마피아 그대로 쓴다: "직업을 배정하고 있습니다", "밤이 되었습니다", "낮이 되었습니다", "아무 일도 없었습니다".
- 모든 단계 화면에 **지금 할 일 한 문장**과 남은 시간을 함께 둔다(`PhaseBar`).
- 오류는 문제와 다음 행동을 같이 말한다: "이미 있는 이름이에요", "방이 꽉 찼어요" + [처음으로].
- 확인은 질문 한 문장: "방에서 나갈까요?", "지호님을 내보낼까요?".
- 이모지와 느낌표는 쓰지 않는다. 반응은 `EmojiBar` 의 SVG 8종으로만 한다.
- 역할 이름: 마피아 · 경찰 · 의사 · 시민. 사람을 부를 때는 "{닉네임}님".

## 색

| 비율 | 토큰 | 쓰는 곳 |
|---|---|---|
| 60% | `night-900` | 모든 화면의 바탕 |
| 30% | `night-800`, `gray-800`, `gray-700` | 입력칸, 시트, 아래 바, 카드 뒷면, 보조 버튼, 구분선, 테이블 |
| 10% | `crimson-*` | 아래 "진홍 예약" 일곱 곳뿐 |

- 글자는 `gray-50`(제목), `gray-100`(본문), `gray-300`(보조) 세 단계. `gray-500` 은 글자에 쓰지 않고 입력칸 테두리 같은 경계에만 쓴다(`night-900` 위 3.8:1).
- 주 버튼은 `gray-100` 면 + `night-900` 글자다. 진홍 버튼은 만들지 않는다.
- 포커스 링은 `gray-100` 2px, 오프셋 2px.
- 배경 장면(`Backdrop`) 그림은 남색·회청색 토큰(`sky-*`, `moon*`, `fog`, `town-*`, `ground*`, `dawn`, `spotlight`)만으로 그렸다. 보라·분홍·주황이 섞인 그라데이션은 쓰지 않는다.
- 낮·아침은 `dawn` → `morning` 회청빛 하늘, 밤은 `sky-night` 로 더 깊다. 테이블 판은 `felt-*` 세 단계.
- 자리 구분색 `seat-1`~`seat-8` 은 인물의 넥타이(그림에 들어 있음)와 이름표 점에만 쓴다. 의미가 없는 구분용이다.

### 진홍 예약

진홍은 "마피아·위험·시간 끝" 의 뜻만 갖는다. 아래 일곱 곳 밖에서는 쓰지 않는다.

1. 타이머 마지막 5초: 막대 `crimson-500`, 숫자 `crimson-400`
2. 마피아 본인 화면의 동료 표시: 발밑 링과 머리 위 마름모 `crimson-400`
3. 마피아 역할 카드 앞면의 그림(진홍 넥타이)과 동료 줄(`crimson-300`)
4. 카드 뒷면 가운데 마름모 `crimson-500` (모두에게 같다)
5. 입력 오류 문장 `crimson-300`
6. 처형·밤 탈락 발표의 띠(`Announcement` `danger`)
7. 마피아 팀 승리 화면과 결과 목록의 마피아 역할 글자 `crimson-300`

작은 진홍 글자(14~16px)는 `crimson-300`(5.5:1), 큰 글자와 선·문양은 `crimson-400`, 면은 `crimson-500` 을 쓴다. 버튼 면, 포커스 링, 방장 표시, 링크, 장식에는 쓰지 않는다. 밤 지목·투표 선택처럼 역할마다 화면이 같아야 하는 곳도 진홍을 쓰지 않는다(화면 캡처로 역할이 드러나지 않게).

## 글자

- 시스템 글꼴 `font-ui` 하나만 쓴다(웹 폰트를 내려받지 않는다). 한글은 Apple SD Gothic Neo, Noto Sans KR, 맑은 고딕 순.
- 크기 네 개, 굵기 두 개뿐이다: `display` 36, `heading` 24, `body` 16, `label` 14 / 400, 700.
- `display` 는 화면당 하나: 앱 제목, 방 코드, 단계 발표, 카드 앞면 역할 이름.
- 입력칸 글자는 16px 이다(iOS 확대 방지). 이름표는 자리 크기와 상관없이 항상 `label-strong` 14px.
- 한글은 `word-break: keep-all`. 숫자가 바뀌는 곳(타이머, 표 수, 방 코드)은 `tabular-nums`.

## 간격과 화면 틀

- 간격은 `space-xs` 4 · `sm` 8 · `md` 16 · `lg` 24 · `xl` 32 · `2xl` 48 · `3xl` 64 만 쓴다.
- 누르기 대상은 최소 `tap-min` 44px. 버튼 `control-button` 52px, 입력칸 `control-input` 48px.
- 화면 틀은 폭 최대 430px 한 열. 게임 화면 좌우 여백 `space-md`, 입장 화면 `space-lg`. PC 에서는 가운데에 폰 폭으로 선다.
- 게임 화면은 360×640 에서도 스크롤 없이 한 화면이다: 위에 `PhaseBar`, 가운데 `Table`, 아래에 행동(버튼·칩·메시지).
- 반경: 이름표·배지 `radius-sm`, 버튼·입력칸 `radius-md`, 카드·시트 `radius-lg`, 칩·말풍선 `radius-pill`.

## 테이블 장면 (2.5D)

- 원근 타원 테이블 하나에 8자리. 각자 폰에서 **내 자리가 맨 아래 가운데**로 돌아 앉는다. 맞은편은 0.62배로 작아지고 앞뒤가 겹친다.
- 층: 비네트 → 달빛 웅덩이 → 테이블 그림자 → 테이블 판(위 가장자리 달빛 하이라이트) → 자리.
- 빈 자리는 빈 의자 실루엣으로 항상 그린다. 사람 수를 문구 대신 의자로 보여 준다.
- 자리 위 표시: 방장 왕관(머리 왼쪽 위), 동료 마름모(오른쪽 위), 직업 주장 알약과 "말 바꿈", 말풍선, 반응, 받은 표 수. 이름표는 앞쪽 자리는 발 아래, 뒤쪽 자리는 머리 위.
- 끊긴 사람은 흑백 + 60%와 이름표의 끊김 아이콘, 탈락한 사람은 유령 그림과 "탈락" 글자. 색만으로 구분하지 않는다.

## 배경 장면

모든 화면은 단색 바탕 대신 `Backdrop` 위에 선다: 달빛 아래 작은 마을 광장이다. 그림은 둥글고 귀여운 면 색 그림체(A_cute)로 캐릭터(세트 C)와 결을 맞췄다. 원본은 저장소 `design/backgrounds/`, 규격 원문은 `BACKGROUND_SPEC.md`.

- 장면 4종 × 구도 2종 = 8장. 파일 `bg_<game|entry>_<lobby|night|day|verdict>`, 1080×2340. 앱은 가벼운 SVG(장면당 약 45KB)를 쓰고, PNG 는 원본 보관용이다.
- 구도: 게임 화면 `game` 은 위쪽 20% 하늘(단계 바), 가운데 아래 55% 광장(테이블). 입장 화면 `entry` 는 큰 달과 양옆 집, 아래 40% 광장(제목·입력칸).
- 장면은 진행 단계를 알려 준다: 대기·배정 `lobby`, 밤 `night`, 아침·낮 `day`, 투표·변론·처형 `verdict`(조명 기둥). 바뀔 때 0.8초 교차 페이드.
- 색은 토큰 계열 안에서만 그렸다(`sky-*`, `moon*`, `fog`, `town-*`, `ground*`, `dawn`, `spotlight`). 보라·분홍·주황, 따뜻한 창문 불빛, 진홍은 없다.
- 장면 위 글자는 바탕이 있는 부품에 담는다. 장면에 글자를 바로 쓰는 것은 표지와 단계 발표뿐이고, 이때 `shadow-text` 를 단다.
- 장면은 장식이다. 화면 읽기 도구에 숨기고(`aria-hidden`), 움직이지 않는다.

## 움직임

- `transform` 과 `opacity` 만 움직인다. `prefers-reduced-motion` 이면 움직임은 끄고 상태 변화(카드 공개, 화면 전환)는 그대로 둔다.
- 기본형(결정 0006): 참가자 등장 420ms(위에서 앉으며 커짐), 배정 문구 1.4초 맥박과 점 세 개, 카드 뒤집기 600ms, 마지막 5초 숫자 튀기 220ms, 단계 발표 0.8초 페이드, 아침빛 번짐 `dur-slow`.
- 토스트를 쌓지 않는다. 결과 안내는 `Notice` 하나가 2초 떴다 사라진다.

## 아이콘

- `Icon` 의 직접 그린 SVG 만 쓴다: 24 격자, 선 2px, 둥근 끝, `currentColor`. 이모지와 아이콘 폰트는 쓰지 않는다.
- 역할 문양: 마피아는 페도라, 경찰은 별 방패, 의사는 십자 원, 시민은 사람.
- 의미 있는 아이콘(왕관, 마름모, 끊김)은 접근성 이름을 단다.

## 캐릭터

- 2~3등신 카툰 인물이다(세트 C, 확정). 큰 머리, 둥근 볼, 회색 정장. 원본은 저장소 `design/characters/`.
- **외형 인물 8종**(`Figure`): 테이블, 결과 목록 등 모두가 보는 곳에 쓴다. 넥타이 색이 자리 구분색과 같다. 탈락하면 유령 하나로 바뀐다.
- **직업 그림 4종**(`ROLE_ART`): 직업이 드러나도 되는 곳에만 쓴다. 본인 역할 카드 앞면, 마피아 본인 화면의 동료, 경찰 본인의 조사 결과, 게임 끝 결과. 밤 화면과 테이블에는 쓰지 않는다. 마피아 그림의 진홍 넥타이는 "진홍 예약" 3번(마피아 카드 문양)에 속한다.
- 규격: 화면 72×96(3:4), 파일 `@2x`·`@4x` 투명 PNG, 발 끝은 아래에서 2px 위. 원문은 저장소 `design/characters/ASSET_SPEC.md`. 새 캐릭터도 이 규격과 확장 규칙(같은 화풍, 진홍·빨간 십자 피하기, 무기 소품 확인)을 지킨다.
- 의사 그림의 십자는 청록이다. 빨간 십자는 쓰지 않는다.
- 확장용 16종(탐정, 스파이, 군인, 영매 등)은 v2 직업 추가 때 쓴다.

## 역할을 드러내지 않는 화면

- 역할을 보기 전 화면(배정, 카드 뒷면, [내 역할] 버튼), 밤 화면, 투표 화면은 역할과 상관없이 같은 모양이다.
- 다른 점은 마피아 본인 화면의 동료 표시와 경찰 본인에게만 오는 조사 결과(`Notice` `private`)뿐이다.

## 참고한 방향

- 밤 남색과 달빛 하이라이트, 진홍 포인트, 회색 정장 인물, 인물 발밑 조명 타원, 이중 테두리 카드를 참고 이미지에서 가져왔다.
- 배경 장면은 달빛 골목(큰 달, 푸른 안개, 지붕 실루엣, 앙상한 나뭇가지)과 달밤 묘지(별, 박쥐) 참고 이미지에서 구도만 가져와 남색·회청색으로 다시 그렸다(클로드 데스크톱에서 제작, A_cute).
- 금테, 따뜻한 창문 불빛, 호박, 보라 네온, 보라·파랑 그라데이션, 의미 없는 유리 효과는 쓰지 않는다. 창문은 불 꺼진 유리에 달빛 반사만 둔다.

## 초안 표시

대기실·역할 확인·낮 화면 부품은 1페이즈 계약서(UI-SPEC)와 같다. 직업 공개, 빠른 메시지, 반응, 투표, 밤, 결과 부품(`Chip` 일부, `QuickMessagePanel`, `EmojiBar`, `MessageLog`, `VerdictPicker`, `Announcement`, `ResultList`)은 기획서를 근거로 한 초안이다. 해당 페이즈 논의에서 확정하고 이 문서를 고친다.

## 불러오는 법 (Consuming this system)

- 네임스페이스는 `Minifia`, 컴포넌트는 `window.Minifia` 에 있다. React 18 은 쓰는 쪽이 준다.
- 불러오는 순서(디자인 캔버스·앱 공통): `tokens.css` → `components/bundle.css` → `components/bundle.js`.
- 캐릭터·배경 그림은 `assets/` 아래 파일이다(`assets/characters/{table,roles,ghost}/*_default@4x.png`, `assets/backgrounds/bg_<game|entry>_<장면>.svg`). 번들은 자기 옆의 `assets/` 를 찾아 쓰므로 `tokens.css`·`components/`·`assets/` 를 함께 복사한다. 저장소에서는 `public/characters/`, `public/backgrounds/` 와 같은 파일이다.
- 색·간격 변수는 `tokens.css`(`tokens.json` 에서 만든 파일)에 있다. 화면 마크업은 `var(--night-900)` 처럼 이 변수를 쓴다.
- 컴포넌트: Button, Chip, TextField, Timer, PhaseBar, Notice, ReconnectBanner, ConfirmSheet, RoleCard, MyRoleButton, Figure, Table, Backdrop, EmojiBar, QuickMessagePanel, MessageLog, VerdictPicker, Announcement, ResultList, Icon. 속성은 `components/<이름>/README.md` 와 `components/index.d.ts`.
- 게임 화면 구성: `Backdrop`(화면 전체) 안에 위 `PhaseBar`, 가운데 `Table bare`, 아래 행동 영역. 게임 배경의 광장은 화면 높이 약 36% 아래부터라 테이블은 그 아래에 놓는다.
