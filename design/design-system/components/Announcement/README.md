# Announcement

단계 전환과 결과를 화면 가운데 크게 알리는 발표다.

- 문구는 정통 마피아 진행 그대로: "밤이 되었습니다", "낮이 되었습니다", "아무 일도 없었습니다".
- `danger` 톤만 진홍 띠를 쓴다: 처형, 밤 탈락 발표, 마피아 승리.
- 제목 36px, 보조 문장 16px `gray-300`. 0.8초에 걸쳐 나타난다.

| prop | 값 |
|---|---|
| `title`, `sub` | 문구 |
| `tone` | `neutral` · `danger` |
| `icon` | `moon` · `sun` 등 |
