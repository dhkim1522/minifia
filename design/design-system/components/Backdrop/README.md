# Backdrop

모든 화면 뒤에 까는 배경 장면이다. 달빛 아래 작은 마을 광장을 그린 그림 파일(A_cute 그림체)을 쓴다. 원본과 규격은 저장소 `design/backgrounds/`(`BACKGROUND_SPEC.md`), 앱용은 `public/backgrounds/bg_<구도>_<장면>.svg`.

- 그림은 1080×2340(약 9:19.5). `background-size: cover`, 기준은 가운데 위쪽이다. 폰 화면(390×844)과 비율이 거의 같아 잘리는 부분이 적다.
- **구도** `layout`
  - `game`(기본): 지평선이 높다. 위쪽 20% 는 하늘(단계 바 자리), 가운데 아래 55% 는 광장 바닥(테이블 자리).
  - `entry`: 입장 화면. 큰 달과 양옆 집, 아래쪽 40% 는 광장 바닥(제목·입력칸 자리).
- 장면 위에 올리는 `Table` 은 `bare` 로 자기 바탕을 지운다.
- 글자는 장면 위에 바로 올리지 않는다. 단계 바·시트·버튼처럼 바탕이 있는 부품 위에 둔다.
- 장식이라 화면 읽기 도구에 숨기고(`aria-hidden`), 움직이지 않는다. 장면이 바뀌면 0.8초 교차 페이드.

| `variant` | 쓰는 화면 | 차이 |
|---|---|---|
| `lobby` | 입장, 대기실, 역할 배정 | 달 쪽 하늘이 밝은 기본 밤 |
| `night` | 밤 행동, 밤 결과 대기 | 구름에 가린 작은 달, 박쥐, 짙은 안개 |
| `day` | 아침 결과, 낮 토론 | 달 없음, 회청빛 하늘, 지평선 쪽 흐린 빛 |
| `verdict` | 투표, 최후 변론, 처형 | 흐린 달, 위에서 떨어지는 조명 기둥과 바닥 조명 타원 |

| prop | 값 |
|---|---|
| `variant` | `lobby` · `night` · `day` · `verdict` |
| `layout` | `game` · `entry` |
| `position` | 그림 기준 위치. 기본 `center top`. 화면 비율이 크게 다를 때만(표지 등) |
| `children` | 장면 위에 올릴 화면 내용 |
