# Chip

직업 공개 선택지, 빠른 메시지 템플릿과 빈칸처럼 여러 개 중 하나를 고르는 알약 버튼이다.

- 선택되면 `gray-100` 면으로 바뀐다(`aria-pressed`). 선택 표시는 색만이 아니라 면 반전으로 한다.
- 역할 칩은 `icon` 에 역할 이름(`police` 등)을 준다.
- 칩 줄이 넘치면 가로로 밀어 본다(줄바꿈하지 않는다).

| prop | 값 |
|---|---|
| `selected` | 고른 상태 |
| `icon` | Icon 이름 |
| `disabled`, `onClick`, `children` | 표준 |
