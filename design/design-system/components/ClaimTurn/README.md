# ClaimTurn

매 낮 시작의 직업 주장 차례다(결정 0023 · 0027, 원천 `src/components/TurnPanel.tsx` · `src/components/ClaimPanel.tsx`).

- 서버가 정한 순서로 한 사람씩 8초(`CLAIM_TURN_MS`). 말하는 사람은 흰 후광 + 머리 위 '…' 말풍선(48×26, 점 깜박임 1.2초).
- 다른 사람 차례: 하단에 채팅 세 줄 + "○○님이 주장하는 중" 과 남은 초.
- 내 차례: "내 차례예요" + 칩 [마피아][경찰][의사][시민][말 안 함]. 안 고르면 말 안 함. 주장의 참 · 거짓은 서버가 확인하지 않는다.
- 주장은 채팅 줄("나 저는 경찰이에요"), 이름표 아래 알약, 유저 기록 카드에 남는다. 탈락한 사람은 차례에서 빠진다.
