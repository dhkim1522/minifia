# ConfirmSheet

되돌릴 수 없는 동작(방 나가기, 내보내기)을 확인하는 하단 시트다.

- 취소가 주 버튼(`gray-100`), 파괴 동작은 보조 버튼이다. 파괴 동작을 덜 눈에 띄게 둔다.
- 막(`scrim`)을 누르거나 Esc 를 누르면 취소. 열리면 포커스는 취소에.
- 제목은 질문 한 문장: "방에서 나갈까요?", "{닉네임}님을 내보낼까요?". 긴 닉네임은 줄바꿈한다.

| prop | 값 |
|---|---|
| `title` | 질문 |
| `body` | 선택. 결과 설명 |
| `confirmLabel` | 파괴 동작 이름 |
| `cancelLabel` | 기본 "취소" |
| `overlay` | 부모를 덮는 절대 배치 |
| `onConfirm`, `onCancel` | 표준 |
