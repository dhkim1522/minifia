# Icon

직접 그린 인라인 SVG 아이콘 묶음이다. 이모지·아이콘 폰트를 쓰지 않는다.

- 24 격자, 선 2px, 둥근 끝. 색은 `currentColor` 를 따른다.
- 의미 있는 아이콘은 `label` 을 준다(왕관 "방장", 마름모 "동료", 끊김 "연결 끊김"). 장식이면 비운다.
- 이름: crown, diamond, disconnected, mafia, police, doctor, citizen, share, check, close, abstain, eye, moon, sun, lock, react-* 8종.

| prop | 값 |
|---|---|
| `name` | 아이콘 이름 |
| `size` | px, 기본 24 |
| `label` | 접근성 이름 |
