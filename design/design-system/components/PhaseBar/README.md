# PhaseBar

모든 단계 화면 맨 위에 단계 이름, 지금 할 일 한 문장, 남은 시간을 함께 보여 준다(UX-01).

- 할 일 문장은 16px 굵게, 한 문장, 해요체. 예: "의심 가는 사람을 이야기하세요".
- 타이머가 없는 단계(대기실, 결과)는 `durationMs` 를 빼면 문장만 남는다.
- 방장 전용 동작(+30초, 넘기기)은 `extra` 자리에 텍스트 버튼으로 둔다.

| prop | 값 |
|---|---|
| `phase` | 단계 이름 |
| `instruction` | 지금 할 일 |
| `remainingMs`, `durationMs` | Timer 로 전달 |
| `extra` | 오른쪽 위 보조 요소 |
