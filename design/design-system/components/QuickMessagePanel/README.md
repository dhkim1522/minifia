# QuickMessagePanel

자유 채팅 대신 템플릿을 고르고 빈칸(사람·직업)을 채워 보내는 빠른 메시지 입력이다.

- 1줄: 템플릿 칩. 2줄: 빈칸 후보(생존자 이름 또는 직업). 3줄: 완성된 문장 미리보기와 [보내기].
- 빈칸이 다 차야 [보내기] 가 켜진다. 주장의 참·거짓은 확인하지 않는다.
- 템플릿 초안: "[○○] 의심돼요", "[○○] 믿어요", "저는 [직업]이에요", "[○○]는 [직업]이었어요", "저 아니에요", "[○○] 투표해요". 확정은 해당 페이즈 논의에서.

| prop | 값 |
|---|---|
| `templates`, `active` | 템플릿 목록과 고른 것 |
| `options`, `picked` | 빈칸 후보와 고른 것 |
| `preview` | 완성 문장 |
| `ready` | 보내기 가능 |
