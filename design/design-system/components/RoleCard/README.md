# RoleCard

역할 확인 단계에서 눌러서 뒤집는 내 역할 카드다.

- 뒷면은 모든 사람에게 같은 마크업이다(가운데 진홍 마름모, "눌러서 확인"). 역할 값을 읽지 않는다.
- 앞면: 직업 그림(`ROLE_ART`, 카드 폭의 48%), 역할 이름(36px), 설명. 마피아면 아래에 동료 줄(`crimson-300`) 또는 "이번 판 마피아는 당신 혼자입니다".
- 크기: 폭 min(72vw, 280px), 비율 2:3. 짧은 화면에서는 높이 56dvh 를 넘지 않게 부모가 줄인다.
- 뒤집기 600ms. 시작 5초 뒤 저절로 앞면.

| prop | 값 |
|---|---|
| `role` | `mafia` · `police` · `doctor` · `citizen` · 없음(뒷면만) |
| `face` | `back` · `front` |
| `mates` | 마피아 동료 이름 목록 |
| `onFlip` | 뒷면 누름 |
