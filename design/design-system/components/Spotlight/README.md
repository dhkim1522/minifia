# Spotlight

최후 변론과 처형 장면의 조명 연출이다(결정 0037, 원천 `src/screens/verdictScene.tsx` · `src/styles/verdict.css`).

- 최후 변론(10초): 후보가 테이블 가운데로 ×1.7 이동하고, 위에서 원뿔 빛 하나가 내려온다(`cone-light`, 위 55% → 아래 20%). 나머지 사람은 흐림 3px + 45% 어둡게. 배경 그림에는 조명을 굽지 않는다(`dusk`).
- 후보만 변론 칩을 보내고 나머지는 이모티콘만 보낸다.
- 처형(5초): 앰버 띠 카드에 처형 문구(여러 개 중 무작위), 후보 그림이 사람 → 유령으로 약 0.4초에 바뀐다. 직업은 공개하지 않는다. 진홍은 쓰지 않는다.
- iOS 에서 `backdrop-filter` 가 안 먹으면 흐림 대신 어둡게만 남는다. 소스에는 `backdrop-filter` 를 접두 없이 한 번만 쓴다(빌드가 접두를 지우는 문제).
