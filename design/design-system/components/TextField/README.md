# TextField

닉네임과 4자리 방 코드를 입력하는 칸이다.

- 글자는 16px(iOS 확대 방지). 라벨은 위, 오류는 칸 바로 아래 `crimson-300` 14px 한 문장.
- 코드 칸은 `code`: 숫자 키패드, 가운데 정렬, 자간 0.3em, 4자리에서 자른다.
- 테두리는 `gray-500`, 포커스는 `gray-100`, 오류는 `crimson-400`.
- 오류 문구는 문제와 다음 행동이 보이게 쓴다: "이미 있는 이름이에요".

| prop | 값 |
|---|---|
| `label`, `placeholder`, `value`, `id` | 표준 |
| `error` | 칸 아래 오류 문장 |
| `code` | 4자리 숫자 코드 칸 |
