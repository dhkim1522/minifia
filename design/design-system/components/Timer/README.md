# Timer

서버가 정한 마감까지 남은 시간을 막대와 초로 보여 준다.

- 화면 위쪽 가로 한 줄. 막대는 `gray-300`, 트랙은 `gray-700`.
- 남은 시간이 5초 이하면 막대 `crimson-500`, 숫자 `crimson-400` 으로 바뀐다. 진홍을 쓰는 다섯 곳 중 하나다.
- 숫자는 `tabular-nums` 라 폭이 흔들리지 않는다. 초마다 소리 내어 읽지 않는다(`aria-live` 없음).
- 앱에서는 `endsAt`·`offset` 으로 계산한 값을 넣는다. 이 부품은 단계 이름을 모른다.

| prop | 값 |
|---|---|
| `remainingMs` | 남은 시간 |
| `durationMs` | 단계 전체 시간 |
