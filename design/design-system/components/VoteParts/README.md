# VoteParts

낮의 공개 투표(4페이즈) 부품 묶음이다: '처형 투표' 카드, 공개 화살표, 표수 칩. 번들 밖 구현 참고 카드이고 원천은 앱 코드다(`src/components/ExecIntroCard.tsx`, `src/components/RevealLayer.tsx`, `src/styles/verdict.css`, 상수 `src/game/verdict.ts`). 결정 0034 · 0036 · 0037 · 0039.

- **'처형 투표' 카드**: 토론이 끝나면 위에서 떨어져 가운데 멈추고 3초 머문다(`EXEC_INTRO_MS`). 면 `amber-700` → `amber-900`, 이중 테두리 `amber-400`, 제목 36px + 질문 "오늘 처형을 할까요?". 끝에서 제목이 흐려지고 앰버 셰브런 셋이 아래 [찬성][반대]를 가리킨다. 카드는 터치를 통과시킨다. 모션 줄이기는 페이드만.
- **공개 화살표**: 직선 + 삼각 머리, 두께 5px(바깥 어두운 9px 윤곽), `amber-400` 번짐. 투표자 → 고른 대상으로 1.2초에 뻗고(`REVEAL_DRAW_MS`) 닿으면 사라진다. 화면에는 항상 하나, 표마다 2초(서버 `CANDIDATE_REVEAL_SLOT_MS`). 순서는 서버가 정한 무작위.
- **표수 칩**: 흰(`gray-50`) = 이미 오른 표, 앰버 = 방금 +1, 큰 앰버(24px, 외곽선 1.4px) = 과반 확정 · 최종 최다. 확정 순간 ×1.3 두 번 두근(0.7초) 후 느린 박동 1.2초.
- 투표 장면에는 진홍을 쓰지 않는다. 하단 안내: "○○님이 ○○님을 골랐어요 · N번째 표 · 모두 M표".
