# 폰트

- v3의 화면과 조작부는 기기의 시스템 산세리프를 쓴다. 종이 카드 등 인쇄물 표현에는 Gowun Batang을 사용한다.
- 홈 제목은 [Noto Serif KR](https://fonts.google.com/noto/specimen/Noto+Serif+KR) 900의 ‘미니피아’ 부분 폰트를 자체 호스팅한다. [라이선스](../../public/fonts/noto-serif-kr-home/OFL.txt)는 폰트와 함께 둔다.
- 이전 버전 공유 이미지용 부분 폰트 `GowunDodum-og-subset.ttf`의 라이선스는 `OFL-GowunDodum.txt`에 있다. 현재 초대 이미지 생성기는 홈 배경을 가로로 자른다.
