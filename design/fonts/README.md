# 폰트

- 홈 제목, 제시어, 중앙 결과 발표, 단계명, 버튼, 채팅, 이름표는 시스템 고딕을 쓴다. 유언과 쪽지 본문에는 Nanum Pen Script를 쓴다.
- 역할별 크기·굵기·행간은 [디자인 토큰](../tokens.json)에 있다. 토큰을 수정한 뒤 `npm run tokens`로 앱 CSS를 갱신한다.
- 시스템 고딕은 기기에 설치된 서체를 사용한다. [손글씨 라이선스](../../public/fonts/nanum-pen-script/OFL.txt)는 자체 호스팅하는 글꼴과 함께 둔다.
- 이전 버전 공유 이미지용 부분 폰트 `GowunDodum-og-subset.ttf`의 라이선스는 `OFL-GowunDodum.txt`에 있다.
