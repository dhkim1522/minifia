## 테이블과 좌석

- 테이블 면: 크림 대리석 타원 280×170, 무대 왼쪽 43, 위 `cy - 94`. 테두리 2px #6b7180, 그림자 `0 7px 0 #4a4f5c, 0 18px 24px rgba(0,0,0,.45)`.
- 자리 i(0 = 나)의 각도 `θ = π/2 + i/n · 2π`(나는 맨 아래 가운데, 시계 방향).
  - `x = cx + rx·cosθ`, `y = cy + ry·sinθ` — y 는 발 위치.
  - 깊이 `d = (sinθ + 1)/2`, 배율 `s = k0 + (1 - k0)·d`, z-index `round(d·10)`.
  - 캐릭터 상자: 폭 FW, 높이 FW·4/3, 왼쪽 `x - FW/2`, 위 `y - FH`, `transform-origin: 50% 100%` 로 `scale(s)`.
- 인원별 값(무대 366×448, 이름표 윗줄 최대 100×22·아랫줄 76×22 로 좌표 검사해 겹침 0):

## 이름표 (`.tg`)

- 발 아래 `top = y + 3`, 가운데 정렬, z-index `자리 z + 20`. 두 알약이 세로로 2px 간격.
- 윗줄 `.tg__n`: 높이 22, 둥근 알약, 바탕 rgba(14,19,38,.86), 테두리 rgba(42,55,96,.9), 14px 굵게 gray-50. 맨 앞 8px 색깔점(자리 색 seat-1..8). 내 이름표는 테두리 gray-100.
- 아랫줄 `.tg__c`: 같은 알약, 최소 폭 36, 주장 직업(마피아·경찰·의사·시민) 14px 굵게. **직업은 말줄임하지 않는다.**
  - 말 안 함: "-"(gray-300, 보통 굵기).
  - 말 바꿈: 알약 오른쪽 위(-7,-7)에 18px 원 배지, 바탕 gray-50, ↺ 아이콘 night-900, `role="img" aria-label="말 바꿈"`.
- 방금 빠른 메시지를 보낸 사람: 윗줄이 반전(바탕·테두리 gray-100, 글자 night-900). 시안에서 지속 시간은 정하지 않았다(말풍선 3초를 대신하므로 3초 권장).
- 닉네임은 최대 5자(결정 0017-4).

## 이모티콘

- 머리 위에만 뜨는 유일한 말풍선. 32px 원(gray-100 바탕, night-900 아이콘 22px), 아래로 5px 꼬리, 그림자 `0 6px 16px rgba(0,0,0,.45)`.
- 위치: 왼쪽 `x - 16`, 위 `max(0, y - FH·s - 36)`. 가로로 가두지 않는다. 약 2초.
- 빠른 메시지는 말풍선을 띄우지 않는다.
