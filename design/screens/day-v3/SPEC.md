# 낮 화면 v3 (결정 0017 승인본)

> 원본: Design 캔버스 https://claude.ai/artifact/P67TWk9cq6v27W4nwr7Fks 의 **9차** 줄(①~⑤)과 6차 U(채팅 내역 모달). 이 폴더의 `R9-*.dc.html`·`U-chat.dc.html`·`*.css` 는 그 원본 사본이다(`f5.css` 가 9차 덧붙임, `f4.css` 가 직업 공개 부품, `f3.css` 가 이름표·이모티콘·모달, `v2.css` 가 헤더·버튼). 그림은 `/_blob/…` 로 되어 있으니 앱에서는 `public/characters/`·`public/backgrounds/bg_game_day.svg` 를 쓴다.

## 판 구성

- 시안 기준 폰 390×664. 위에서부터 헤더 100 → 장면(flex 1, 시안에서 407) → 하단 패널 157.
- **하단 패널 높이는 직업 공개·공개 연출·낮 토론에서 같다**(157). 단계가 바뀌어도 테이블이 움직이거나 줄지 않는다. 테이블은 세 단계 사이에 다시 마운트하지 않는다(지금 `DayScene` 과 같음).
- 360×640 폰: 장면 352×383(좌우 4px). **글자 크기는 줄이지 않는다**(14px 하한). 무대 전체를 배율로 줄이지 않고, 좌석 가로 반지름만 장면 폭에 맞춘다.

## 헤더 (지금 앱 그대로)

- 1줄(52): `낮 · 토론` 또는 `낮 · 직업 공개`(24px 굵게) / `N일차`(14px gray-300), 오른쪽 [내 역할] 버튼.
- 2줄(32): 진행 막대(높이 10, gray-700 바탕·gray-100 채움) + 남은 시간(24px 굵게, tabular-nums). 공개 연출은 0:00·빈 막대.

## 테이블과 좌석 — 인원과 상관없이 하나로 고정

- 테이블 면: 크림 대리석 타원 **280×108**, 가로 가운데, 위 150(장면 기준). 360폰은 264×108. 테두리 2px #6b7180, 그림자 `0 7px 0 #4a4f5c, 0 18px 24px rgba(0,0,0,.45)`.
- 좌석 원(고정): `cx = 장면 폭/2`, `cy = 210`, `rx = 132`(360폰 124), `ry = 100`, 캐릭터 폭 `FW = 72`(높이 96), `k0 = 0.8`.
- 자리 i(0 = 나)의 각도 `θ = π/2 + i/n · 2π`(나는 맨 아래 가운데, 시계 방향).
  - `x = cx + rx·cosθ`, `y = cy + ry·sinθ` — y 는 발 위치.
  - 깊이 `d = (sinθ + 1)/2`, 배율 `s = k0 + (1 - k0)·d`, z-index `round(d·10)`.
  - 캐릭터 상자: 왼쪽 `x - FW/2`, 위 `y - FH`, `transform-origin: 50% 100%` 로 `scale(s)`.
- **겹침 허용**: 4명은 겹침이 없고, 5명부터 옆자리 이름표가 조금 겹친다(8명이 가장 많음). 실제 판은 대부분 4~5명이라 받아들였다. 화면 끝으로 잘리는 것은 허용하지 않는다(360폰에서 rx 124 인 이유).
- 나: 발밑 타원 링(폭 120%, 2px rgba(230,232,238,.6)).
- 방장: 캐릭터 왼쪽 위(-6,-6)의 22px 원 왕관 배지(night-900 바탕, gray-300 테두리, `aria-label="방장"`).
- 연결 끊김은 지금 앱처럼 캐릭터를 흐리게(시안에 없음, 기존 규칙 유지).

## 이름표 (`.tg`)

- 발 아래 `top = y + 3`, 가운데 정렬, z-index `자리 z + 20`. 두 알약이 세로로 2px 간격. 떠 있는 층을 따로 계산하거나 가두지(clamp) 않는다.
- 윗줄 `.tg__n`: 높이 22, 둥근 알약, 바탕 rgba(14,19,38,.86), 테두리 rgba(42,55,96,.9), 14px 굵게 gray-50. 맨 앞 8px 색깔점(자리 색 seat-1..8). 내 이름표는 테두리 gray-100. 닉네임 최대 5자.
- 아랫줄 `.tg__c`: 같은 알약, 최소 폭 36, 14px 굵게. **직업은 말줄임하지 않는다.** 단계별 내용:
  - 직업 공개 중: 고르는 중 `…`(gray-300, 보통 굵기), 고름 `✓ 완료`(반전: gray-100 바탕, night-900 글자, 앞에 14px 체크). 무엇을 골랐는지는 보이지 않는다(서버도 보내지 않음). 머리 위 완료 알약은 없앤다.
  - 공개 연출(약 2초): 모든 아랫줄이 동시에 주장으로 바뀌며 팝 + 흔들림(기존 연출 길이 그대로). 시안은 밝은 테두리·빛(`.tg__c--pop`)으로 표시. 머리 위 공개 말풍선은 없앤다.
  - 토론: 주장 직업(마피아·경찰·의사·시민), 말 안 함은 `-`(gray-300, 보통 굵기).
  - 말 바꿈: 알약 오른쪽 위(-7,-7)에 18px 원 배지, 바탕 gray-50, ↺ 아이콘 night-900, `role="img" aria-label="말 바꿈"`. 공개 연출 때 같이 뜬다.
- 방금 빠른 메시지를 보낸 사람: 윗줄 반전(바탕·테두리 gray-100, 글자 night-900) 약 3초.

## 이모티콘

- 머리 위에 뜨는 유일한 말풍선. 32px 원(gray-100 바탕, night-900 아이콘 22px), 아래로 5px 꼬리, 그림자 `0 6px 16px rgba(0,0,0,.45)`, z-index 60(이름표보다 위).
- 위치: 왼쪽 `x - 16`, 위 `max(0, y - FH·s - 36)`. 가로로 가두지 않는다. 약 2초. 이웃 위에 겹쳐 떠도 된다.
- 빠른 메시지는 말풍선을 띄우지 않는다.

## 하단 — 직업 공개·공개 연출 (같은 높이 157)
