# 테이블·캐릭터 위치 v1 (P2안 승인본, 2026-10-25)

> 원본: Design 캔버스 https://claude.ai/artifact/P67TWk9cq6v27W4nwr7Fks 의 **16차** 줄(P1~P5, 390×664). 사본 `P*.dc.html`. 승인된 것은 **P2**(낮 5명 안)의 테이블 구성과 캐릭터 위치이고, 사용자 요청으로 **모든 상황(대기실·역할 배정·낮·밤·아침)에서 이 틀로 고정**한다. 하단 패널이 사라지거나 바뀌어도 테이블·캐릭터 위치와 장면 높이는 늘어나지 않는다.

- 테이블 면: 390폭 기준 216×108(지금 280×108), 위 150, 가로 가운데. 좌석 원: cx = 장면 폭/2, cy = 210, rx = 146(지금 132), ry = 100, 캐릭터 72×96, k0 = 0.8. 양옆 캐릭터가 테이블 바깥에 선다(5명판 간격 12px, 8명판 6px, 계산값).
- 폭이 다른 화면은 같은 규칙으로 계산한다: rx = clamp(장면 폭/2 − 36.4, 124, 150), 테이블 폭 = 2·(rx − 32.4 − 6). 정확한 수치와 검증은 구현 계획이 정한다.
- 장면은 헤더(실측 119.2) 아래부터 하단 패널(157) 위까지의 같은 상자다. 대기실·역할 배정도 이 상자와 하단 패널 자리 157을 유지한다(패널이 비어 있어도 높이 157).
- P5(역할 배정): 같은 테이블 위에 어두운 막과 안내만 얹는다.
