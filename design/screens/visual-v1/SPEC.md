# 시각 개선 v1 (17·18차 시안, 2026-10-25 사용자 승인)

> 원본: Design 캔버스 https://claude.ai/artifact/P67TWk9cq6v27W4nwr7Fks 의 **17차**(Z1~Z6)·**18차**(Y1~Y5) 줄. 이 폴더의 `*.dc.html`·`f12.css` 는 사본이다(그림은 `/_blob/…` 라 앱에서는 `design/backgrounds/v2` 와 `public/` 를 쓴다). 승인된 결정은 아래, 숫자는 구현 계획이 정한다.

1. **발밑 원 제거 → 캐릭터 후광(Z4·Z5·Z6)**: 캐릭터 그림 윤곽을 따라 빛나는 후광. 흰 후광 = 지금 말하는 차례 + 밤에 고른 대상(공용). 진홍 후광 = 마피아 동료(마름모는 유지). 내 표시는 후광 없이 이름표 테두리만. 차례 링(앞뒤 층 분리)·내 링·동료 링은 모두 없앤다. 이름표 반전도 없앤다.
2. **말하는 중 "…" 말풍선(Z4)**: 지금 말하는 사람 머리 위에 말풍선, 점 세 개가 차례로 깜박임. 이모티콘이 오면 그 2초는 이모티콘이 풍선 자리를 대신한다.
3. **방장 왕관 제거**: 대기실만 유지, 낮·밤·아침(게임 중)에서는 없앤다.
4. **배경 전환(Z1·Z2·Z3)**: 낮·밤·아침을 따로 두고 **테이블 장면 위에서 배경만 바뀐다**(전용 화면 없음, 낮 시작 전용 `Day` 화면은 없앤다). 밤→아침 해가 떠오름, 아침→낮 해가 쨍하게(문구 "낮이 되었습니다"), 낮→밤 달이 뜨고 어두워짐(문구 "밤이 되었습니다"). 문구는 테이블 장면 위에 한 번 뜨고 사라진다. 전환 배경 목록·규칙은 4페이즈의 해질녘 투표·처형 배경이 끼워질 수 있게 일반화한다.
5. **배경 에셋(Y3·Y5)**: `design/backgrounds/v2/README.md` 의 표대로. 아침·낮은 set1 + **헤더 위쪽 어두운 막**(Y3·Y5 값: 위 66% → 0, 150px), 나머지는 set2. 가운데 문구 뒤에는 어두운 방사형 막을 깐다.
