# AwardPlate

칭호 패: 시상식(END-04, 결정 0054)에서 무대로 걸어 나온 사람 위에 뜬다. 한 명당 약 2.5초, 나머지는 박수.

- 놋쇠 테두리 + 아이콘(기본 `trophy`) + 칭호(`font-serif` 26px) + 이유 한 줄(14px) + 이름 점. 이유는 숫자·이름으로 짧게("수아 님을 찾아냄", "채팅 42번").
- 칭호는 서버 기록으로 정하고 모두 하나 이상 받는다. 순서는 점 진행(`DotProgress`)으로 보이고 각자 넘길 수 있다.
- 쓰는 쪽이 줄 것: `title`, `reason`, `icon`, `name`, `color`.
