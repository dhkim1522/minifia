# ChatPanel

채팅: 아래 패널에 사람 메시지와 시스템 메시지를 한 기록으로 보여 주고 입력을 받는다.

- 사람 메시지는 `body` 16px: 자리 구분색 점 + 이름(`gray-50`) + 글(`gray-100`).
- 시스템 메시지는 `label` 14px.
  - `system`: 단계 안내 `gray-300`
  - `vote`: 지목 기록 `gray-100`. "민준 님이 도윤 님을 지목했어요"
  - `hot`: 선두·과반 소식 `brass-200`. "지금 도윤 님이 가장 많이 지목받았어요", "도윤 님이 과반 표를 받았어요"
- 마피아 밤 채팅(`channel: 'mafia'`)은 마피아 본인 화면에만 보이고 이름이 `crimson-300`. 서버가 시민 편에게 보내지 않는다.
- 입력칸 글자는 16px(iOS 확대 방지), 100자까지. 보내기는 주 버튼 모양(`gray-100` 면).
- 쓰는 쪽이 줄 것: `messages`, `value`·`onChange`·`onSend`. `onSend` 가 없으면 기록만 그린다.
