# DressSheet

꾸미기 창: 로비 아래의 꾸미기 버튼(`hanger`) 하나로 연다. 방장은 [맵 | 의상] 두 탭, 다른 사람은 의상만 보인다(결정 0050·0051).

- 맵: 3D 맵 그림 카드를 좌우로 넘긴다(가로 스크롤 스냅, 카드 220px). 랜덤은 물음표 카드. 고른 카드는 `gray-100` 테두리 + 체크. 설명 글은 없다.
- 의상: 내 캐릭터가 그 의상을 입은 미리보기 9칸(3열), 이름은 한 단어. 누르면 장면 속 내 캐릭터가 바로 갈아입는다.
- 쓰는 쪽이 줄 것: `host`, `maps`(id·label·img, 랜덤은 img 없음)·`mapId`·`onMap`, `outfits`(id·label·img)·`outfitId`·`onOutfit`, `onClose`. 의상 미리보기 그림은 그 사람의 인물로 찍는다(아래 그림은 1번 인물).
