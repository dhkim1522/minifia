# FaceList

얼굴 목록: 깜깜한 밤에 경찰(조사)·의사(살리기)가 비친 얼굴을 눌러 대상을 고른다(NIGHT-09).

- 4열 격자, 얼굴 그림(그 사람의 인물·의상으로 찍은 머리 그림) + 자리 구분색 점 + 이름. 고른 얼굴은 밝아지고 테두리 + 행동 아이콘(경찰 `eye`, 의사 `heal`).
- 마감 전까지 바꿀 수 있다. 고를 수 없는 사람(경찰은 자기 자신)은 흐리게 막는다. 의사는 자기 자신도 고를 수 있다.
- 이 화면은 역할마다 생김새가 같아야 해서 진홍을 쓰지 않는다. 마피아는 이 부품 대신 장면에서 직접 다가가 고른다.
- 쓰는 쪽이 줄 것: `faces`(id·name·img·color·disabled), `value`, `onPick`, `icon`.
