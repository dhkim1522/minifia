# HeadStack

머리 위 쌓임: 위에서부터 입력 중 · "유력" 도장 · 득표 배지 · 이름표.

- 쓰는 쪽이 줄 것: 이름표 값(`name`, `color`, `me`, `away`, `mine`, `done`, `blink`)과 `typing`, `count`, `lead`, `sure`. 바닥 가운데를 캐릭터 머리 꼭대기에 `translate(-50%, -100%)` 로 놓는다.
- 지목 단계에서는 `HeadStack` 을 버튼으로 감싸 이름표를 누르면 그 사람을 가리키게 한다(직접 조작).
- 겹치면 선두를 `z-tags` + 10 으로 앞에 둔다. 머리 위에 다른 것을 더 올리지 않는다.
