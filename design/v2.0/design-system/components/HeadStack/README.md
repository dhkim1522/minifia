# HeadStack

머리 위 쌓임: 캐릭터 머리 위에 위에서부터 "유력" 도장 · 득표 배지 · 이름표를 쌓는다.

- 쓰는 쪽이 줄 것: 이름표 값(`name`, `color`, `me`, `away`)과 `count`, `lead`, `sure`. 바닥 가운데가 캐릭터 머리 꼭대기에 닿게 `translate(-50%, -100%)` 로 놓는다.
- 사이 간격 `space-xs`. 쌓임 순서를 바꾸지 않는다.
- 겹칠 때는 선두를 `z-tags` + 10 으로 앞에 둔다. 표가 있는 사람은 없는 사람보다 앞이다.
- 머리 위에 다른 것(말풍선 등)을 더 올리지 않는다. 지목 순간 알림은 `TopToast` 가 맡는다.
