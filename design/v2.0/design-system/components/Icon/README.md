# Icon

아이콘: 직접 그린 SVG(24 격자, 선 2px, 둥근 끝, `currentColor`). 이모지 대신 쓴다.

- 감정표현 9종(캐릭터 동작과 같은 이름): `throat` 목 긋기 · `deny` 나 아니야 · `clap` 박수 · `cry` 엉엉 · `handshake` 악수 · `point` 손가락질 · `praise` 최고 · `surprise` 깜짝 · `dance` 춤.
- 화면 아이콘: `face` 감정표현 열기 · `hanger` 꾸미기 · `map` 맵 · `skip` 토론 끝내기 · `check` 투표함 · `send` 보내기 · `close` 닫기 · `play` 시작 · `question` 랜덤 · `thumbUp` 찬성 · `thumbDown` 반대.
- 밤·아침·유령: `quill` 유언 · `note` 쪽지 · `target` 암살 고르기 · `ghost` 유령 · `eye` 조사 · `heal` 살리기.
- 판 끝: `trophy` 칭호(시상식) · `crown` 방장(방장 이양 알림).
- 직업: `roleMafia` 페도라 · `rolePolice` 별 방패 · `roleDoctor` 십자 원 · `roleCitizen` 사람(`RoleChip` 이 쓴다).
- 쓰는 쪽이 줄 것: `name`, `size`(기본 24), `label`. 혼자 뜻을 전하는 아이콘(글 없는 버튼 안)은 버튼에 `aria-label` 을 단다. 색은 부모 글자색을 따른다.
