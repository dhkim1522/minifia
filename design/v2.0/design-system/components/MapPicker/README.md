# MapPicker

맵 선택: 로비에서 방장이 지하 재즈 바 · 시계탑 광장 · 랜덤 가운데 맵을 고른다(결정 0050).

- 기본값은 랜덤. 랜덤이면 서버가 게임 시작 때 정해 모두에게 같은 맵을 보낸다.
- 방장만 고른다. 다른 사람은 "맵 · 랜덤 — 방장이 골라요" 처럼 글로만 본다(`host` false).
- 고른 칸은 `gray-100` 2px 테두리 + `night-700` 면. 칸 높이 64px 이상, 이름 `body-strong` + 한 줄 설명 `label`.
- 맵이 늘어나면 칸을 더한다. 3칸이 넘으면 두 줄로 감싼다.
- 쓰는 쪽이 줄 것: `maps`(id·label·desc), `value`, `onChange`, `host`.
