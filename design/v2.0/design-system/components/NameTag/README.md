# NameTag

이름표: 3D 장면 위 캐릭터 머리 위에 자리 구분색 점과 이름을 띄운다.

- 화면 겹침 층(DOM)에 그린다. 가구·캐릭터에 가려지지 않는다(결정 0047-4).
- 글자는 카메라 거리와 상관없이 항상 `label-strong` 14px, `gray-50` on `overlay-ink`.
- 쓰는 쪽이 줄 것: `name`, `color`(`seat-1`~`seat-8`), `me`(내 캐릭터), `away`(연결 끊김). 위치는 쓰는 쪽이 캐릭터 머리 꼭대기를 화면 좌표로 바꿔 놓는다.
- 혼자 쓰지 말고 `HeadStack` 안에서 쓴다. 표·도장과 쌓이는 순서가 정해져 있다.
