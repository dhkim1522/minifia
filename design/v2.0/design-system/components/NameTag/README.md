# NameTag

이름표: 3D 장면 위 캐릭터 머리 위에 자리 구분색 점과 이름을 띄운다.

- 화면 겹침 층(DOM)에 그린다. 글자는 항상 `label-strong` 14px, `gray-50` on `overlay-ink`.
- `me`: 내 캐릭터("(나)" + 테두리). `mine`: 지목에서 내가 가리킨 사람(이름표가 밝아지고 손가락 아이콘). `done`: 찬반에서 투표한 사람(체크 아이콘). `blink`: 누를 수 있다는 손짓(단계 시작 때 세 번 깜빡). `away`: 연결 끊김.
- 혼자 쓰지 말고 `HeadStack` 안에서 쓴다.
