# PhaseHeader

단계 머리: 화면 맨 위에 지금 단계 이름, 할 일 한 문장, 남은 시간을 보여 준다.

- 모든 단계 화면에 하나 둔다. 화면마다 안내 문장은 정확히 하나다(v1.0 결정 0038 유지).
- 쓰는 쪽이 줄 것: `title`(단계 이름), `hint`(할 일 한 문장), `time`(남은 초, 서버 기준), `urgent`(마지막 5초).
- 3D 장면 위에 얹을 때는 위쪽에 `night-900` 그라데이션 띠(불투명 85% → 0)를 깔고 그 위에 둔다. 좌우 여백 `space-md`.
- 마지막 5초만 숫자가 `crimson-400`. 다른 때 진홍을 쓰지 않는다.
