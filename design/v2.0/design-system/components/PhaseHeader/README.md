# PhaseHeader

단계 머리: 단계 이름과 시간 링. 안내 한 줄은 단계가 시작될 때 잠깐만 보이고 접힌다(결정 0051).

- 남은 시간은 링(`gray-100`)이 줄어드는 것으로 보여 준다. 숫자는 마지막 5초에만 링 안에 `crimson-400` 으로 뜨고 링이 `crimson-500`.
- 쓰는 쪽이 줄 것: `title`, `hint`(한 줄), `showHint`(단계 시작 뒤 약 2.5초 동안 true, 그다음 false), `time`·`total`(초, 서버 기준).
- 3D 장면 위에서는 위쪽 `night-900` 그라데이션 띠 위에 둔다. 좌우 여백 `space-md`.
