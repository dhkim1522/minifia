# RoleCard

역할 카드: v1.0 직업 카드를 그대로 쓴다. 뒷면(진홍 마름모)을 누르면 뒤집혀 직업 그림·이름·한 줄 설명이 나온다.

- 3D 캐릭터의 외형과 상관없이 역할만 알려 준다. 그림은 v1.0 직업 그림(`assets/` Roles: 마피아·경찰·의사·시민).
- 크기 폭 240px, 2:3. 뒤집기 `dur-slow`. 시작 5초 뒤 저절로 앞면(v1.0 그대로).
- 설명은 한 줄(v1.0 문구): 마피아 "밤에 함께 한 명을 지목해요" · 경찰 "밤마다 한 명을 조사해요" · 의사 "밤에 한 명을 살려요" · 시민 "대화와 투표로 마피아를 찾아요". 마피아면 동료 줄(`crimson-300`).
- 뒷면은 모든 사람에게 같은 마크업이다. 앞면은 앞면이 될 때만 그린다(역할이 DOM 에 미리 드러나지 않게).
- 쓰는 쪽이 줄 것: `role`, `name`, `desc`, `img`, `mates`, `face`(`back`·`front`), `onFlip`.
