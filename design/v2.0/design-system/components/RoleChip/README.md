# RoleChip

직업 표시: 머리 위 이름표 위에 작은 원 안의 직업 아이콘을 띄운다.

- 보이는 곳은 정해져 있다: 유령 관전 화면(모든 직업, 결정 0021), 마피아 본인 화면의 동료(마피아만). 살아 있는 사람에게 남의 직업을 보내지 않는다(서버가 정한다).
- 마피아는 `crimson-400` 테두리 + `crimson-300` 페도라, 나머지는 `gray-300` 테두리. 경찰 별 방패, 의사 십자 원, 시민 사람.
- `HeadStack` 의 `role` 로 켠다. 쓰는 쪽이 줄 것: `role`(`mafia`·`police`·`doctor`·`citizen`).
