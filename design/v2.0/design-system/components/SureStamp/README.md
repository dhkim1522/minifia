# SureStamp

과반 도장: 과반 표를 받은 사람 머리 위에 "유력" 도장을 찍는다(결정 0049).

- 명조 `stamp` 15px(`brass-200`), `brass-400` 테두리 2px, `radius-stamp`, -10° 기울임. `dur-med` 420ms 동안 크게 떨어지며 찍힌다.
- 과반이 확정된 그 사람에게 하나만. 같은 순간 3D 장면은 실내등을 절반으로 낮추고 카메라가 8% 다가간다(장면 코드).
- 쓰는 쪽이 줄 것: 없음(`label` 로 글자만 바꿀 수 있다). 혼자 쓰지 말고 `HeadStack` 의 `sure` 로 켠다.
