# TopToast

화면 위 지목 알림: 누가 누구를 지목했는지 단계 머리 아래 가운데에 한 줄로 띄웠다가 사라진다(결정 0049).

- 위치는 위에서 `toast-top` 88px, 가운데. `dur-toast` 1.5초 머물고 220ms 로 사라진다.
- 글은 "민준 → 도윤". 지목이 몰리면 줄을 세워 하나씩 보여 주고, 같은 사람을 찍은 표는 "지호·민준 → 도윤" 처럼 합친다. 지목을 바꾸면 "지호 → 서연(바꿈)".
- 기록은 `ChatPanel` 의 시스템 메시지가 맡는다. 알림은 쌓지 않는다(한 번에 한 줄).
- 쓰는 쪽이 줄 것: `text`, `visible`, 그리고 줄 세우기·합치기.
