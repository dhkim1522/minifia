# WillSheet

유언 쓰기: 역할과 상관없이 언제든 아래 패널의 깃펜(`quill`) 아이콘으로 열어 쓰고 고친다(WILL-01).

- 100자까지. 저장하면 버튼이 "저장됨"으로 바뀐다. 쓰는 동안 다른 사람에게 아무 신호도 가지 않는다(입력 중 "…" 을 띄우지 않는다).
- 죽으면(처형·암살) 아침에 채팅 카드(`ChatPanel` 의 `card`)로 모두에게 공개된다.
- 마피아 쪽지(NIGHT-12)도 이 부품으로 쓴다: `title="쪽지"`, `icon="note"`, `tone="mafia"`. 암살이 확정된 뒤에만 연다. 아침에 이름 없이 진홍 카드로 공개된다.
- 쓰는 쪽이 줄 것: `value`, `onChange`, `onSave`, `saved`, `onClose`, 쪽지면 `title`·`icon`·`tone`.
