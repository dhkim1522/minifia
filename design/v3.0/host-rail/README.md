규칙
- 방장 줄 단추는 48×48 원형, 간격 12, 왼쪽 여백 16, 위는 오른쪽 열과 같은 높이에서 시작한다.
- 방장 전용 = 금빛 테두리 1.5px + 금빛 아이콘. 켜짐(토글)은 금빛 채움 + 어두운 아이콘. 참가자 공용 단추(오른쪽 열)는 기존 그대로(`--night-600` 테두리, 밝은 회색 아이콘).
- [시작] 단추 자리·모양은 바꾸지 않는다. 기록 칸 위에 있던 튜토리얼 스위치 한 줄(0083-3)은 방장 줄의 토글로 옮긴다.
- `기본 마피아` 를 고르면 [튜토리얼 먼저] 토글은 숨는다(19-CONTEXT D-10).
- 결과 화면의 방장 조작(판 종류·맵)도 같은 왼쪽 줄 규칙을 따른다.
