# 미니피아 3D 개선 참고 시안

2026-11-19에 Codex ImageGen으로 제작한 원본 PNG다. 현재 게임의 동물과 재즈 바, 승인된 달빛 누아르를 참고했다. 이 그림은 추후 모델링·재질 작업에서 비교할 자료이며 브라우저가 받는 배포 파일과는 별도로 보관한다.

- [홈·초대 배경](entry-splash.png)에는 토끼·여우·코끼리가 의자 없이 원탁을 둘러싼 구도를 담았다.
- [재즈 바·시계탑 광장과 재질](maps-and-materials.png)에는 조명, 목재, 황동, 바닥 돌과 벽돌의 참고 표현을 담았다.
- [동물 12종과 초상](animals-and-portraits.png)에는 단체 구분과 작은 채팅 초상의 기준을 담았다.
- [역할 의상과 유령](role-outfits-and-ghost.png)은 개구리 한 종에서 시민·마피아·경찰·의사 의상을 비교한 그림이다.
- [역할 확인·토론·아침 유언](gameplay-visual-target.png)은 위 그래픽을 조합했을 때의 플레이 화면 시안이다.

3D를 개선할 때는 기존 실시간 장면과 같은 카메라·인원·기기에서 가독성, 모자·관절, 프레임을 비교한다. 초상과 의상 미리보기는 반영한 3D 모델에서 다시 렌더링한다.
