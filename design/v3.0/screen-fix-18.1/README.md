> `before/` 는 고치기 전 배포본(390×844, 780×1688 JPG), `after/` 는 승인한 바꾼 뒤 모습이다. `after/` 는 배포본 화면에서 바뀌는 부분만 고쳐 찍은 것이라 폰트·부품은 앱 그대로다.

## after 와 실제 구현이 다른 곳

- 유령은 그림을 화면에 얹은 것이다. 실제로는 3D 장면 안에 선다(크기·위치는 구현에서 맞춘다). `n7-result` 의 탈락자는 옛 모습이다 — 실제로는 `ghost_default`.
- `n3-chat-open` 에는 키보드가 없다. 기록 창 높이 300 은 임시 값이다.
- `n4-execution` 의 큰 글은 소리 단추와 겹치지 않게 폭을 맞춘다.
