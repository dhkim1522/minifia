- 캔버스(사람용): https://claude.ai/artifact/GtNAvoHFM3r22Efh23YRaf
- 사본: `index.html`(이 폴더). 세 묶음, 각 묶음의 A 를 채택(24 페이즈 UI-SPEC).
  1. 포스트잇이 붙는 자리: A 가슴 옆(채택, 세 장까지 겹쳐 쌓임) / B 어깨 쪽 / C 등 쪽

- 에셋 규칙(결정 0089-11): "의심" 글자, 살짝 기운 각도, 들린 모서리, 옅은 그림자, 색은 붙인 사람 좌석 색을 옅게, 얼굴·옷 특징·이름표를 가리지 않고 머리 위에 띄우지 않는다.
