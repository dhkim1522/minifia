## A 안의 좌표 (월드 단위, 가운데가 (0,0), x 오른쪽 · z 아래(카메라 쪽))

배치도는 1단위 = 28px, 왼쪽 위 (−10, −10) 이 (20px, 20px) 이다. 걷는 영역은 약 ±10(격자 48×48 · 칸 0.5 를 권한다. 정확한 원점·한계는 구현이 정한다).

| 무엇 | 자리 |
|---|---|
| 광장 바닥 | 지금 광장 그대로 ±5.8 (연단 원 반지름 1.4 @ (0,0), 시계탑 2.6×2.6 @ (−4.3,−4.3), 벤치·나무·가로등은 `shared/game/mapPlaza.ts` 의 `PLAZA_OBSTACLES` 그대로) |
| 우체국(북) | 바깥 벽 x −2.3…2.3 · z −10…−6.6, 문은 남쪽 벽(z −6.6) 가운데 폭 1.5 |
| 술집(동) | 바깥 벽 x 6.6…10 · z −2.3…2.3, 문은 서쪽 벽(x 6.6) 가운데 폭 1.5 |
| 진료소(남) | 바깥 벽 x −2.3…2.3 · z 6.6…10, 문은 북쪽 벽(z 6.6) 가운데 폭 1.5 |
| 경찰서(서) | 바깥 벽 x −10…−6.6 · z −2.3…2.3, 문은 동쪽 벽(x −6.6) 가운데 폭 1.5 |
| 집 8채 (2.4×2.4) | 가운데 (±5.0, ±8.4) 넷 + (±8.4, ±5.0) 넷. 문패는 광장을 향한 변 가운데 |

- 방 안쪽은 벽 두께 0.3 을 뺀 약 4.0×2.8. 방마다 벽 쪽 소품 2~3개(걷기를 막지 않게).
- 집과 방 사이, 집과 광장 사이의 띠(폭 약 0.8~1.2)는 걷는 골목이다. 집 문 앞까지 갈 수 있어야 한다(21의 현장 조사 자리).
- 좌석 n(0~7)의 집: 북서 모서리부터 시계 방향으로 (−5.0,−8.4)=0, (5.0,−8.4)=1, (8.4,−5.0)=2, (8.4,5.0)=3, (5.0,8.4)=4, (−5.0,8.4)=5, (−8.4,5.0)=6, (−8.4,−5.0)=7.

## 색·생김새

- 방 벽·지붕은 광장 건물과 같은 낮은 채도의 남색·회색 계열, 간판 그림만 램프 금빛(`--light-lamp` `#ffcf8a`). 간판: 우체국 봉투 · 술집 잔 · 진료소 십자 · 경찰서 방패. 글은 쓰지 않는다.
- 실내 바닥은 따뜻한 갈색 계열로 바깥과 구별하고, 방마다 따뜻한 등 하나.
- 집은 방보다 어둡고 작다. 문패는 주인의 좌석 색 원 + 얼굴 그림. 주인 없는 집은 불이 꺼지고 문패가 비어 있다.
- 컷어웨이: 지붕과 카메라 쪽 벽(카메라는 +x·+z 쪽에서 본다 — 남쪽 벽과 동쪽 벽)이 0.25초에 걷힌다. 모션 줄이기면 바로.
