# v2.0 위임 결정 요약 (아침 확인용)

> 사용자가 자는 동안 위임받아 내린 결정을 한 장으로 모았다. 각 행은 "어떤 선택지가 있었고, 무엇이 추천이었고, 무엇을 채택했는가"다. 원문은 각 페이즈 UI-SPEC의 결정/미결 표와 `docs/decisions/` 의 결정 기록이다. 이 문서는 요약이라 근거 문서가 우선한다. 문서에 없는 것은 "문서에 없음"으로 적었다.
> 바꾸고 싶은 값은 해당 결정 기록의 번호를 알려 주면 그 한 곳만 고친다. 모든 시간·세기·횟수·점수·레벨 값은 기본값이고 실기기·팀 테스트 뒤 조정한다.

경로 약칭: `U09.1` = `.planning/phases/09.1-play-feedback-b/09.1-UI-SPEC.md`, `U09.1.1` = `.planning/phases/09.1.1-politics-tension/09.1.1-UI-SPEC.md`, `U10` = `.planning/phases/10-character-motion-costume/10-UI-SPEC.md`, `U11` = `.planning/phases/11-result-rematch/11-UI-SPEC.md`, `U12` = `.planning/phases/12-sound-polish/12-UI-SPEC.md`. 결정 기록은 `0063`~`0070` = `docs/decisions/00NN-*.md`.
