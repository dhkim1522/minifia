# 0001 웹앱 먼저, 출시 때 같은 코드로 앱 감싸기

- 상태: 채택
- 날짜: 2026-10-21

## 배경

친구들이 각자 폰으로 같은 방에 들어오는 파티 게임이다. 한 명이라도 설치를 거쳐야 하면 "점심시간에 바로 한 판"이 어려워진다. 정식 출시 때는 스토어 앱도 필요하다.

## 결정

React + TypeScript 웹앱(PWA)으로 먼저 만든다. 정식 출시 때 같은 코드를 Capacitor 로 감싸 Android·iOS 앱으로 낸다. 웹 링크 참가는 앱 출시 후에도 유지한다.

## 결과

- 방장만 앱이 있어도 나머지는 링크·QR 로 참가할 수 있다.
- 처음부터 네이티브 앱으로 만드는 경우보다 개발·검증이 빠르다.
- 플레이테스트는 웹 URL 공유로 한다. TestFlight·스토어 심사·Apple 개발자 계정은 앱 출시 단계까지 필요 없다.
- iOS 심사에서 웹 감싼 앱으로 거절되지 않도록 출시 단계에 진동·공유·알림 같은 기기 기능을 붙여야 한다.
- 무거운 3D·고급 그래픽은 어렵다. 2D 캐릭터와 애니메이션 범위에서는 문제없다.
