# 0005 비대면 게임으로 하고, 소통은 빠른 메시지와 이모티콘으로 시작한다

- 상태: 채택
- 날짜: 2026-10-21

## 배경

- 초안은 4~8명이 한 공간에 모여 얼굴을 보고 말로 토론하는 게임이었다.
- 실제로는 친구들이 각자 다른 곳에서 음성 통화 없이 앱만으로 한다. 플레이어끼리 소통할 수단이 앱 안에 없으면 마피아가 성립하지 않는다.
- 폰 세로 화면에서 90초 토론 동안 키보드로 자유 채팅을 하면 화면 절반이 가려지고 흐름을 놓치기 쉽다. 자유 채팅은 도배 방지·글자 수·레이아웃 같은 일이 따라온다.

## 결정

- minifia 는 비대면 게임이다. 각자 폰(또는 PC 브라우저)에서 링크로 들어와 앱 안에서만 소통한다.
- v1 소통은 **빠른 메시지**와 **이모티콘**으로 한다.
  - 빠른 메시지는 대상 플레이어·직업을 골라 채우는 템플릿이다 (예: "[○○] 의심돼요", "저는 [경찰]이에요", "[○○]는 [마피아]였어요"). 주장의 참·거짓은 서버가 확인하지 않는다. 거짓말도 게임의 일부다.
  - 이모티콘은 6~8개, 보낸 사람 캐릭터 위에 잠깐 뜬다.
  - 낮 토론과 찬반 투표 중 생존자만 보낼 수 있다. 최후 변론 중에는 후보만 변론 메시지를 보내고 나머지는 이모티콘만 보낸다. 밤·아침·처형 중에는 보낼 수 없다. 탈락자는 보낼 수 없다.
  - 서버는 템플릿 ID 와 고른 값만 받아 검증한 뒤 방 전체에 보낸다. 자유 텍스트는 받지 않는다.
- **자유 채팅은 플레이테스트 피드백을 보고 v1.1 에서 정한다.**
- 화면은 세로 고정, 폰 폭(360~430px) 기준이다. PC 웹에서는 가운데에 폰 폭으로 보인다.
- 방 참가는 링크 공유(카카오톡 등, Web Share)와 4자리 코드로 한다. QR 은 뺀다.

## 결과

- 결정 0003 의 정통 진행·무거운 분위기는 그대로다. "말로 토론", "말로 변론" 은 앱 안 메시지로 바뀐다.
- 밤에 "누가 폰을 만지는지" 로 역할이 드러날 걱정은 없어졌다. 밤 화면은 역할과 관계없이 같은 구성으로 두고, 시민이 사람을 고르는 것은 선택(결과 없음)으로 바꾼다.
- 소리는 각자 폰에서 낸다. "모든 폰 vs 방장 폰" 미결정 항목은 사라진다.
- 로드맵을 게임 흐름 구간별로 다시 나눈다: 3페이즈 낮 토론(토론 진행 + 빠른 메시지·이모티콘), 4페이즈 처형과 승패(변론 메시지 포함). v1.0 은 6페이즈가 된다.
