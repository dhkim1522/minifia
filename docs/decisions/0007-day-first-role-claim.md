# 0007 역할 확인 다음은 낮부터 시작하고, 매 낮 시작에 직업 공개 단계를 둔다

- 상태: 채택
- 날짜: 2026-10-21

## 배경

- 초안의 진행은 역할 확인 → 밤 → 아침 → 낮 토론 순서였다. 오프라인에서는 밤에 마피아끼리 얼굴을 확인해야 해서 밤부터 시작하지만, 앱에서는 역할 카드에서 마피아 동료를 보여 주므로 그 이유가 없다.
- 낮부터 시작하면 첫 토론에 쓸 정보가 없다(아무도 죽지 않았고 경찰 조사도 없다). 첫 낮이 아무나 찍는 토론이 되기 쉽다.
- 비대면이라 누가 무엇을 주장했는지 말 대신 화면이 기억해 줘야 한다. 빠른 메시지의 "저는 [경찰]이에요" 는 흘러가는 메시지라 나중에 다시 확인하기 어렵다.

## 결정

- **낮 먼저**: 역할 확인 다음 첫 단계는 낮이다. 순서는 역할 배정 → 역할 확인 → [낮: 직업 공개 → 낮 토론 → 투표 → 최후 변론 → 찬반 투표 → 처형] → 밤 → 아침 → 낮… 이다.
- 첫 낮도 다른 낮과 같은 기본 시간으로 한다. 단계 시간은 플레이테스트 결과로 조정한다. 첫 낮을 짧게 하는 것 같은 특수 규칙은 두지 않는다.
- **직업 공개 단계**: 매 낮 시작에 고정 단계를 둔다. 화면에 직업 선택지와 [말 안 함]이 뜨고 각자 하나를 고른다. 시간이 넘으면 말 안 함으로 처리한다. 서버는 주장의 참·거짓을 확인하지 않는다(거짓말 가능). 고른 직업은 그 사람 자리에 주장으로 표시된다.
- 다음 낮에 다른 직업을 고르면 "말 바꿈" 으로 표시해 다른 사람이 알 수 있게 한다.
- 실시간 공개와 동시 공개 중 무엇으로 할지, 선택지 범위, 단계 시간, 빠른 메시지 직업 주장 템플릿과의 관계는 낮 토론 페이즈 논의에서 정한다.

## 결과

- 직업 공개가 첫 낮의 이야깃거리가 된다("경찰이 두 명이네?"). 낮 먼저로 생기는 정보 부족을 이 단계가 메운다.
- 기획서 진행 흐름 표, GAME-01, 로드맵이 바뀐다. 새 요구사항 DAY-02 를 추가한다.
- 로드맵 2·3페이즈 순서를 바꾼다: 2 낮 토론(직업 공개 포함), 3 밤과 아침. 페이즈마다 실제 게임 순서대로 뒤에 이어 붙인다. 4페이즈는 낮과 밤 사이에 투표·처형을 끼운다.
- 1페이즈는 역할 확인 다음 "낮이 되었습니다" 화면에서 멈춘다.
- 끊긴 사람이 직업 공개를 놓치면 말 안 함으로 처리한다(CONN-02).
- 한 판 시간은 낮 한 바퀴(약 3분)와 직업 공개 단계만큼 늘어날 수 있다. 플레이테스트에서 확인한다.
