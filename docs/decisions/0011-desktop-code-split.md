# 0011 사람용 산출물은 클로드 데스크톱에서, 디자인 시스템과 구현은 클로드 코드에서 만든다

- 상태: 채택
- 날짜: 2026-10-22

## 배경

- 결정 0010 으로 사람용 산출물은 클로드 아티팩트로 만들기로 했다. 진행해 보니 화면 설계서·화면 흐름·캐릭터·배경 에셋은 사용자가 클로드 데스크톱 프로젝트에서 만드는 편이 빨랐다.
- 클로드 데스크톱은 로컬 저장소를 읽지 못하고, GSD 에이전트는 아티팩트를 읽지 못한다. 클로드 코드 세션은 둘 다 읽는다.
- 같은 화면 설계를 데스크톱과 코드에서 따로 만들다가 중복이 생겼다(코드 쪽 캔버스는 삭제).

## 결정

- **클로드 데스크톱 프로젝트**: 사람용 산출물과 그림 에셋을 만든다. 화면 설계서, 화면 흐름, 캐릭터, 배경. 결과는 Design 캔버스 아티팩트나 zip 으로 넘긴다. 사람용 디자인 산출물은 항상 Design 캔버스로 만든다.
- **클로드 코드 세션(이 저장소)**: 받은 산출물을 저장소에 반영한다. 에셋 원본은 `design/`, 앱용은 `public/`. 디자인 시스템 아티팩트(토큰·컴포넌트)도 여기서만 고친다. 컴포넌트가 실제 앱 코드와 짝이기 때문이다. 데스크톱에서 바꾸고 싶은 점은 캔버스에 시안이나 메모로 남기면 이 세션이 반영한다.
- **정본 산출물**
  - 화면 설계서: https://claude.ai/artifact/QtbQYhk7ezy4fV7H98bZJz (화면 S-01~S-16, 공통 시트 C-01~C-03, 흐름도, 공통 규칙)
  - 화면 흐름(사용자 이야기 순서): https://claude.ai/artifact/NzZBqoJD8ut16J2VUwpn64
  - 캐릭터 에셋: https://claude.ai/artifact/4dYpe74vxJHSnA4WhFSLTM (세트 C, 원본 `design/characters/`)
  - 디자인 시스템: https://claude.ai/artifact/Tp175mmuxLAHycMUtwZJ9Q
- **IA 문서는 만들지 않는다.** 메뉴·탭이 없고 서버가 단계를 진행하는 앱이라, 화면설계서의 화면 목록과 흐름도가 그 역할을 한다(gsd-addons `docs/lifecycle.md` 구간 3 기준).
- **마피아 동료 표시**: 역할 카드와 [내 역할] 시트에 더해, 마피아 본인 화면의 테이블에도 동료 발밑 진홍 링과 머리 위 마름모로 표시한다. 서버가 동료 정보를 마피아에게만 보내므로 다른 사람에게는 새지 않는다. 화면설계서의 가정 "역할 확인 카드와 [내 역할] 시트에서만 보인다" 는 이 결정으로 바뀌었다(설계서 v0.2 반영).
- **투표 공개 방식**: 투표·찬반 투표 중에는 남의 선택을 숨기고, 시간이 끝나면 누가 누구를 찍었는지와 표 수를 동시에 공개한다. 일반적인 마피아 게임은 투표가 공개되고(오프라인은 동시 지목, 온라인은 실시간 공개가 흔하다) 그 기록이 추리 재료가 된다. 동시 공개는 눈치 투표를 막으면서 추리 재료를 남긴다. 화면설계서의 열린 질문 "투표 결과 공개"(후보 득표만 공개하는 안)는 이 결정으로 바뀐다. 투표·찬반이 끝나면 3초씩 결과 공개 상태 S-09b·S-11b 를 둔다(3초는 가정, 설계서 v0.2 의 07-1 보드).

## 결과

- 화면설계서를 승인하면 각 화면 PNG 를 `design/screens/` 에 사본으로 둔다. `01-UI-SPEC.md` 는 설계서와 디자인 시스템에 맞춰 고친 뒤 1페이즈 웨이브 3 이후를 다시 계획한다.
