# 0013 폰트 Gowun Dodum, 서비스 이름 영문 Minifia, 크림 대리석 테이블, OG 이미지

- 상태: 채택
- 날짜: 2026-10-23

## 배경

1페이즈 UAT 의 G-01-1a(폰트)·G-01-2(테이블이 배경과 겹침)·G-01-5(OG 이미지가 단순함)를 이 세션의 Design 캔버스 시안(폰트 6종·테이블 5종·OG 3종)으로 한 번에 골랐다.

## 결정

- 전체 글꼴은 **Gowun Dodum**. 서비스 이름은 화면·링크 미리보기·공유 제목 모두 한글 '미니피아' 대신 영문 **Minifia** 로 표시한다(정식 이름·상표는 여전히 출시 전에 정한다).
- 대기실 테이블은 **크림 대리석**: `felt-*` 를 크림 3단계로 바꾸고 `table-rim`·`table-hi`·`table-edge` 토큰을 더했다.
- OG 이미지는 입장 배경 + 인물 4명 + 'Minifia' + 부제, 같은 글꼴. `node scripts/make-og.mjs` 로 만든다(sharp, 부분 폰트 `design/fonts/`).
- 그림·폰트 시안도 이 세션의 Design 캔버스에서 만들 수 있음을 확인했다. 결정 0011 의 분업에서 "일러스트(인물·직업 그림)처럼 새로 그려야 하는 것만 클로드 데스크톱" 으로 좁힌다.

## 결과

- 글자 크기는 아직 그대로다(토큰 type 크기). 폰에서 보고 키울지 정한다.
- 개발자 코드명 `minifia`(저장소·Worker 이름)는 그대로다.
