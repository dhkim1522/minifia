# 0014 첫 화면은 버튼과 코드 칸만, 닉네임은 시트에서

- 상태: 채택
- 날짜: 2026-10-24

## 배경

- 첫 화면의 닉네임 칸이 [방 만들기] 전용처럼 보이는데 코드 참가에도 필요해서, 코드 4자리를 쳐도 [참가]가 꺼져 있는 이유를 알 수 없었다.
- 카드(닉네임·버튼·구분선·코드 칸)가 화면 가운데를 크게 가려 배경이 잘 안 보였다.
- 시안 5종(Design 캔버스 '첫 화면 구조 시안')에서 사용자가 2번(카드 없이 배경 위에) + 시트 A 를 골랐다.

## 결정

- 첫 화면: 제목, [방 만들기], 방 코드 칸과 [참가]만 둔다. 카드·"또는" 구분선·닉네임 칸은 없앤다.
- [참가]는 코드 4자리만 맞으면 켜진다. [방 만들기]는 항상 눌린다.
- 둘 중 무엇을 누르든 닉네임 시트(`NicknameSheet`, 제목 "내 닉네임")가 올라온다. 마지막에 쓴 닉네임이 미리 채워지고 열리면 입력칸에 포커스가 간다. 제출 글자만 [만들기]/[참가하기]로 다르다.
- 이 브라우저에 그 방의 입장 정보가 이미 있으면 닉네임을 묻지 않고 같은 자리로 돌아간다(D-07 유지).
- 오류 자리: 닉네임 오류는 열린 시트 안에, 코드 오류(없는 방·가득 참·시작됨)와 그 밖의 오류는 시트를 닫고 첫 화면의 코드 칸 아래나 토스트에 보인다.
- 링크 참가 화면(S-02)은 그대로다.
- 주 버튼은 밝은 회색(`--gray-100`)이다. 진홍은 처형·탈락 발표에만 쓴다.

## 결과

- 화면설계서 S-01·디자인 시스템 아티팩트에 반영해야 한다(아티팩트 동기화 때).
