# 0017 낮 화면은 둘러앉은 테이블을 유지하고, 말풍선은 이모티콘만, 채팅은 미리보기 1줄 + 모달로 둔다

- 상태: 채택
- 날짜: 2026-10-24

## 배경

- 2페이즈 UAT 테스트 1(8명, 폭 360px 폰)에서 이름·주장·말풍선·알약이 읽기 어렵고, 떠 있는 층이 자리에서 조금씩 어긋났다(UAT gap G-02-1). 원인은 원근 타원(rx40%·ry22%)에 8자리를 놓으면서 글자(14px 고정)와 캐릭터(scale .62~1)가 따로 움직이고, 떠 있는 층을 `clamp(70px, x%, 100%-70px)` 로 가둬 가장자리 자리의 말풍선이 30px 넘게 안쪽으로 밀린 것이다.
- 격자·무대·두 줄 좌석 등 6차례 시안을 Design 캔버스(https://claude.ai/artifact/P67TWk9cq6v27W4nwr7Fks)에서 비교했다. 실제 방은 4~5명이 대부분이고, 몰입감은 둘러앉은 테이블이 가장 낫다는 판단으로 6차 시안 S·T·U 를 승인했다.
- 승인본 사본: `design/screens/day-v3/`(`SPEC.md` 와 시안 원본).

## 결정

1. **둘러앉은 테이블을 유지한다.** 나는 맨 아래 가운데. 좌석 좌표는 화면 폭에 비례한 원근 타원이 아니라 장면(366×448 기준) 픽셀 좌표로 계산하고, 이름표·이모티콘은 같은 자리 좌표에서 나온다(따로 가두지 않는다). 인원별 반지름·캐릭터 크기는 좌표 검사(이름표·캐릭터·화면 끝 겹침 0)로 정한 표를 쓴다(`SPEC.md`).
2. **머리 위 말풍선은 이모티콘만 띄운다.** 빠른 메시지("[○○] 의심돼요" 등)는 말풍선을 띄우지 않고 채팅 미리보기에만 나온다. 보낸 사람은 이름표 윗줄이 잠깐 반전되어 표시된다. 말풍선 도배가 가장 큰 문제였다.
3. **이름표는 2줄이다.** 윗줄 `색깔점 + 이름`, 아랫줄 주장 직업. 말 안 함은 "-"(회색). 말 바꿈은 글자 대신 주장 알약 오른쪽 위의 ↺ 원 배지(`aria-label="말 바꿈"`).
4. **게임에 영향이 있는 글자는 줄이지 않는다.** 직업 이름은 말줄임하지 않는다. 대신 **닉네임 최대 길이를 8자에서 5자로 줄인다**(`NICKNAME_MAX_GRAPHEMES`).
5. **방장 전용 기능(+30초 연장, 넘기기)을 없앤다.** 방장만 다른 줄이 있으면 하단 영역을 정돈할 수 없다. 방장은 왕관 배지로만 구분한다. 서버의 `extend`·`skip` 메시지와 `extendUsed`·`ALREADY_EXTENDED` 도 함께 걷어낸다(결정 0016-5 의 연장 부분을 대체).
6. **하단은 채팅 미리보기 1줄 + [빠른 메시지][이모티콘] 한 줄이다.** 미리보기는 기존 메시지 로그 모양(night-700 면, 색깔점·굵은 이름·본문)의 최신 1줄이고, 오른쪽 ^ 버튼을 누르면 기존 시트(Sheet) 모양의 "채팅 내역" 모달에 같은 목록이 높이만 늘어 열린다. 별도 [채팅 내역] 버튼은 두지 않는다.
7. **채팅 내역은 서버에 저장하지 않는다.** 서버는 받은 메시지를 방송만 하고, 폰이 그날 받은 줄을 메모리에만 가진다. 재접속하면 지난 줄은 복원되지 않고 낮이 끝나면 비운다(결정 0016-7 의 `messages` 보관 20개를 대체).

## 결과

- 2페이즈 gap G-02-1 은 이 결정으로 갭 닫기 계획을 세운다. UAT 테스트 2(말풍선)·3(말 바꿈 알약)·4(방장 줄)·5(8자 닉네임)는 이 결정으로 대상이 없어져, 갭 닫기 후 새 화면 기준으로 다시 확인한다.
- 직업 공개 화면(완료 표시 포함)과 4·6·7명 배치는 같은 규칙으로 시안을 먼저 만들어 승인받은 뒤 계획에 넣는다.
- "-" 와 ↺ 배지는 처음 보는 사람에게 뜻이 낯설 수 있다. 첫 공개 연출에서 한 번 글자로 알려 주는 방식을 6페이즈 플레이테스트에서 본다.
- 디자인 시스템·화면설계서 S-06·S-08 아티팩트 동기화 목록에 이 결정을 더한다(디자인 세션 몫).
