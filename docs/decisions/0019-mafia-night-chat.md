# 0019 밤에는 마피아끼리만 빠른 메시지·이모티콘을 주고받고, 아침 탈락 문구는 여러 개 중 무작위로 보여 준다

- 상태: 채택
- 날짜: 2026-10-24

## 배경

- 결정 0005 는 "밤·아침·처형 중에는 메시지를 보낼 수 없다"고 했다. 그러면 마피아가 밤에 합의할 수단이 동료의 현재 선택을 보는 것뿐이어서 온라인에서 지목 합의가 어렵다.
- 3페이즈 논의에서 사용자가 마피아 전용 밤 채팅을 요청했고, 탈락 발표가 "탈락했습니다"처럼 밋밋하다며 여러 문구를 무작위로 쓰자고 했다.

## 결정

1. **밤에는 살아 있는 마피아끼리만 빠른 메시지와 이모티콘을 주고받는다.** 서버가 마피아 소켓에만 보낸다(다른 플레이어에게는 전달하지 않는다). 서버에 저장하지 않고 밤이 끝나면 비운다. 탈락한 마피아는 보낼 수 없다. 결정 0005 의 밤 메시지 금지에서 마피아를 예외로 한다.
2. **밤 전용 템플릿**만 쓴다: "[○○] 지목해요", "동의해요", "다른 사람을 지목해요". 낮 템플릿은 밤에 쓰지 않는다. 자유 텍스트는 없다.
3. **아침 탈락 문구는 8개 안팎의 묶음에서 무작위**로 보여 준다(서버가 골라 모든 폰이 같은 문구, 같은 판에서 연속 반복 없음, 받침에 따라 이/가). 목록은 `design/screens/night-v1/SPEC.md`. 의사가 살린 경우는 "아무 일도 없었습니다" 고정이다.
4. 낮 처형 문구("처형되었습니다" 등)는 4페이즈에서 따로 정한다.

## 결과

- 승인 시안: `design/screens/night-v1/`.
- COMM-04("밤·아침 메시지 거부")는 "밤에는 마피아끼리만 가능, 아침·처형은 불가"로 고쳐야 한다(3페이즈 계획에서).
- 와이어 계약에 밤 전용 템플릿 ID 와 마피아 한정 전달 규칙이 더해진다. 누출 테스트(`leak.test.ts`)에 "마피아가 아닌 소켓은 밤 chat·emoji 프레임을 받지 않는다"를 더한다.
