# 0021 탈락한 사람은 유령이 되어 게임 전체를 관전한다

- 상태: 채택
- 날짜: 2026-10-24

## 배경

- ELIM-01 은 탈락자가 "공개된 진행만" 보고 전체 역할을 보는 관전 화면은 v2 로 미뤘다.
- 3페이즈 논의에서 사용자가 "탈락하면 아무 행동도 못 하지만 모든 게임을 관전하고 직업도 노출되어야 관전 재미가 올라간다"고 했다. 온라인 게임은 탈락 뒤 이탈이 큰 문제라 관전 재미가 필요하다. 범위는 모든 직업 + 밤 행동 + 마피아 채팅으로 정했다.
- 디자인 시스템은 이미 "탈락하면 인물이 유령 그림 하나로 바뀐다, 흐림(흑백 + 60%)은 연결 끊김"을 정해 두었다.

## 결정

1. **탈락자는 유령 그림(`ghost_default`)이 되고, 아무 행동·메시지도 할 수 없지만 게임 전체를 관전한다.** (개정: 0063-2·0064-14, 2026-11-05 — 유령 시점에서 탈락자는 직업 의상을 입은 옅은 안개 유령이고 이름표는 불투명. 산 사람 화면은 그대로 · 0082(2026-11-11 — 산 사람 화면도 탈락자를 코트 안개 유령으로 남긴다. 직업은 여전히 비공개) · 0083(2026-11-11 — 어느 화면에서든 탈락자는 같은 유령 그림, 직업은 이름표 표식으로만))
2. **서버는 탈락자에게만** 모든 사람의 실제 직업, 밤 행동(마피아·경찰·의사의 선택), 마피아 밤 채팅을 보낸다. **살아 있는 사람에게는 보내지 않는다**(결정 0002 의 "남의 역할을 보내지 않는다"를 "살아 있는 사람에게는 보내지 않는다"로 좁혀 유지). 탈락 시점부터 보내며, 앞의 판 진행(이미 끝난 밤)의 지난 정보는 보내지 않는다.
3. 관전자 이름표 아랫줄에는 실제 직업이 점선 테두리로 보인다(공개 주장과 구분). 시안 `design/screens/night-v1/E1`.
4. 탈락하지 않은 사람 화면과 살아 있는 사람이 보는 탈락자 이름표는 그대로다(유령 + `탈락`, 직업 비공개).

## 결과

- ELIM-01, 3페이즈 컨텍스트(D-14·D-15), 시안 SPEC 을 고쳤다.
- 누출 테스트: 살아 있는 소켓은 직업·밤 행동·마피아 채팅을 절대 받지 않는다 / 탈락자 소켓만 받는다 / 앞의 소켓이 탈락하기 전에는 받지 않는다.
- 탈락자가 앱 밖에서 살아 있는 사람에게 정보를 알려 주는 것은 플레이어 매너에 맡긴다(결정 0018).
