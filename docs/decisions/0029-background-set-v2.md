# 0029 배경은 아침·낮은 기존 에셋 + 헤더 막, 나머지는 NEW 한 벌로 바꾼다

- 상태: 채택
- 날짜: 2026-10-25

## 배경

- 지금 앱은 예전 `day` 한 장(달 없음, 회청빛, 해 없음)을 아침과 낮에 같이 쓴다. 해가 없고 밤과 명도 차가 작다.
- 사용자가 데스크톱에서 아침·낮(오후)·해질녘·투표·처형(낮/밤)이 있는 한 벌(set1)과, 모든 장면을 밤 색감에 맞춘 새 한 벌(NEW, set2)을 만들었다.
- 측정: set1 의 아침·낮은 헤더 흰 글씨 대비가 2.5~2.9:1 로 기준(4.5:1)에 못 미친다. set2 는 전 장면 5.2:1 이상이다. 단 set2 의 낮은 어두워 "낮 느낌"이 약하다(사용자 판단).

## 결정

1. 앱 배경은 `design/backgrounds/v2/README.md` 의 표를 따른다: 대기·배정·밤·해질녘·투표·처형(해질녘)은 **set2**, 아침·낮은 **set1 + 헤더 위쪽 어두운 막**(시안 Y3·Y5).
2. 배경은 아침·낮·밤·해질녘·투표·처형으로 나누고 장면 전환은 크로스페이드(0.8초)와 해·달 움직임으로 한다(구현은 17차 묶음 계획). **(결정 0030-5: 해·달 움직임은 이미지에 맡겨 따로 움직이지 않는다.)**
3. "낮 투표·처형"은 낮 하늘이 아니라 **해질녘** 하늘에서 한다(낮 → 해질녘 투표 → 밤). 4페이즈 논의에서 연출을 확정한다.
4. 용량: set2 는 PNG 라 장면당 300~600KB 다. 앱에는 WebP 로 변환해 넣고 첫 화면에 필요한 장면부터 불러온다.
5. 기존 A_cute 4장면은 v2 가 앱에 들어갈 때까지 유지하고, 들어간 뒤 `design/backgrounds/A_cute`·`public/backgrounds` 의 옛 파일은 정리한다. **(결정 0030-4: 앱에 들어간 뒤 `public/backgrounds` 의 옛 SVG 는 지웠고, `design/backgrounds/A_cute` 는 CLAUDE.md 문서 지도가 가리키므로 남겼다. 해·달은 선택 B — 이미지에 맡김. 장면 전환 0.8초는 새 그림이 준비된 뒤 시작한다.)**

## 결과

- 아침·낮 하늘과 밤·해질녘 하늘의 색 차이는 폰에서 확인한다.
