# 0031. 배경 v3(지평선 18%)와 유령·방장 배지 새 에셋

- 날짜: 2026-10-26
- 상태: 코드 적용(미배포). 폰 확인 대기
- 이전: 0029(배경 v2), 0030(시각 개선 묶음)

## 배경

폰에서 보니 테이블과 맨 뒤 사람이 하늘에 떠 있는 것처럼 보였다. 옛 그림의 지평선(하늘과 바닥 경계)이 390폭 기준 y≈287(34%)이고 맨 뒤 사람 발끝이 y≈229~248이라 사람이 하늘 영역에 서 있었다. 그림과 테이블 구도가 따로 정해진 탓이다.

## 결정

1. **배경 v3**: 데스크톱에서 다시 만든 게임 구도 7장·입구 lobby 1장을 `design/backgrounds/v3/` 에 둔다. 지평선은 18%(390폭 y≈152). 맨 뒤 사람 발끝은 모든 인원·폭에서 지평선보다 61~107px 아래라 전원이 돌바닥 위에 선다(대기실 4~8명, 360·390·430폭 실측).
2. **조명 위치 요청**: 밤(대기실·밤)과 처형(해질녘)의 바닥 조명이 y≈1170(이미지 좌표)로 테이블(y≈915)보다 아래라 앞은 밝고 뒤는 어두웠다. 세 장만 (540, 915) 중심으로 다시 받았다. 아침·낮·해질녘은 요청하지 않았다(바닥이 고르거나 이미 테이블 쪽이 밝음).
3. **변환**: WebP 품질 90 → 86(합계 231.9KB, 상한 260KB). 장면당 상한 game 40KB·entry 52KB. v2 원본은 그대로 둔다.
4. **헤더 막**: 새 하늘이 더 밝아 막 알파를 .70/.58/.40/0 에서 **.80/.70/.55/0** 으로 올렸고(길이 150px 불변), 360폭 타이머 대비가 4.42 였던 **해질녘·처형에도 막**을 달았다. 헤더 글씨 대비 기준 4.5:1 은 그대로다.
5. **입구 구도**: 앱은 `bg_entry_lobby` 한 장만 쓴다. 나머지 입구 그림은 필요 없다.
6. **유령**: 새 그림(높이 330)은 바닥 그림자가 있고 발이 캐릭터보다 위였다. 그림자를 지우고 몸을 27px(@4x) 내려 발끝 y=374 로 맞춰 적용했다(원본은 데스크톱에 남아 있으니 다시 내보내면 같은 수정이 필요).
7. **방장 배지**: `host_badge.svg`(원형 배경 + 금색 왕관)를 22px 자리에 그대로 교체했다. 출처 메타데이터는 제거했다. 대기실에서만 보인다(0030-3).
8. **D3b-5 완화(5명판 98.0%)는 유지**: 새 유령으로 되돌릴 근거가 없다. 로컬 E2E 6회는 99.9%에서 통과했지만 유령이 이웃 이름표를 가리는 상황이 실제로 나왔는지 기록되지 않았고, 좌표 모델로는 옛 유령의 0.4% 겹침도 재현되지 않았다.

## 검증과 정정

- 이 세션에서 인자 없는 `npm run e2e` 는 **배포본**을 검사한다. 유령 교체 직후와 v3 적용 직후에 보고한 "E2E 통과"는 배포본 결과였다. 로컬 개발 서버(`--url http://localhost:5173`)로 다시 돌린 결과: 6개 흐름 × 3개 크기 통과(준비 단계 S4 흔들림 한 번은 재실행 3회 모두 통과).
- 단위 테스트 1895건 통과, E2E 단위 107건 통과.

## 알려진 한계

- 하늘이 보이는 구간이 헤더 밑 약 30~50px 뿐이라 해·달이 뜨는 연출(0030-5 A안)은 이 배경으로는 어렵다.
- 낮·아침은 막이 진해져 위쪽이 어둡다. 낮 느낌이 약해 보이면 하늘 색을 바꾼 그림이 필요하다.
- 낮·밤 바닥 색 차이가 커서 크로스페이드 때 튈 수 있다(폰 확인).
