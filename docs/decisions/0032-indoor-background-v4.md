# 0032. 실내 배경(v4)과 그림 주소 버전 값

- 날짜: 2026-10-26
- 상태: 코드 적용·배포, 폰 확인 대기
- 이전: 0029·0030·0031(야외 광장 배경)

## 배경

야외 광장 배경(v2·v3)은 하늘과 땅의 구분 때문에 테이블과 사람이 떠 보였고, 폰에서 계속 이질적이라는 판단이 나왔다(사용자). 벽·커튼·창과 마루, 러그가 있는 실내로 바꾸고 낮·밤·아침·해질녘은 창밖만 바꾼다.

## 결정

1. 게임 구도 5장(night, morning, day, dusk, verdict_dusk)을 `design/backgrounds/v4/`(데스크톱 시안 "실내 시안 바닥 수정")에서 WebP로 변환한다. 대기실(lobby)과 밤은 같은 그림이다. 입구(entry) 그림은 v3 의 `bg_entry_lobby` 를 그대로 쓴다. WebP 품질 86, 합계 208.4KB(상한 260KB).
2. 마루 시작선·러그 윗변이 맨 뒤 사람 발끝 위에 있어 사람과 테이블이 모두 러그·마루 위에 선다(390폭 4·5·8명판 앱 화면 확인). 조명 중심 (540, 915) 가 테이블 중심과 같다.
3. 위쪽이 어두운 벽이라 헤더 글씨 대비가 막 없이 전 장면 ≥ 11.7:1 이다. **헤더 어두운 막은 모든 장면에서 끈다**(`SCENES.scrim` 전부 false). 막 장치(`HEADER_SCRIM_STOPS`, `--mf-scrim`)는 남긴다.
4. **그림 주소 버전 값**: 배경·유령 주소 끝에 `?v=${ASSET_VERSION}`(src/net/assets.ts)을 붙인다. 정적 그림 캐시가 max-age 1일이라 같은 주소는 하루 동안 옛 그림이 나온다. 그림을 바꾸면 값을 올린다.

## 알려진 한계 (폰 확인 후 판단)

- 창 유리가 폰 y 72~159 이고 헤더가 119 까지라 창의 위쪽이 헤더 뒤로 간다. 대기실에서는 달이 방 코드 숫자와 입장 알림에 일부 가린다. 해결 후보: 해·달을 유리 아래쪽(이미지 y 380~430)으로 내리는 그림 수정.
- 큰 폰(430×932)은 러그 아래가 비고, 360·430폭에서는 러그가 폭에 비례해 커져 테이블과의 상대 위치가 조금씩 다르다. 벽·마루·러그·조명을 층으로 나눈 에셋으로 나중에 푼다.
- 그림과 화면 배치(영역)를 사전에 맞추는 영역 지도·가이드 이미지·에셋 자동 검사는 아직 GSD 흐름에 없다(별도 정리 예정).
