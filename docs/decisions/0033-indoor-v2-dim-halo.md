# 0033. 실내 배경 V2와 헤더 글씨 읽기(명도 0.8 + 약한 번짐)

- 날짜: 2026-10-26
- 상태: 배포, 폰 확인 대기
- 이전: 0032(실내 배경 v4)

## 결정

1. 게임 구도 배경을 데스크톱의 "실내 배경 레이어 V2" 완성 모습 5장(`design/backgrounds/v5/`)으로 바꾼다. 창 유리와 커튼이 맨 위까지 이어지고, 해·달·구름이 장면마다 다르다. 입구 그림은 v3 그대로. WebP 합계 206.0KB.
2. 그림을 더 고치지 않고 **화면 쪽에서 글씨를 읽히게 한다**(사용자 결정: 그림 위치·내용을 계속 바꾸기보다 UI 에서 해결).
   - 게임 구도 배경 층에 `filter: brightness(var(--mf-backdrop-dim))`, 값 **0.8**(색 값 0.8배, 채도·색상 그대로). 0.85 는 H1 4.2:1 로 모자랐고 0.8 에서 전부 통과.
   - 헤더 글씨 묶음(제목·안내, 대기실 방 코드) 뒤에 약한 번짐(남색 45%, 흐림 8px). 글씨 뒤의 별도 요소라 E2E H1 에 반영된다(text-shadow 는 반영되지 않음).
   - 헤더 어두운 막은 쓰지 않는다(`SCENES.scrim` 전부 false).
3. 배경 그림 주소 버전 값 `ASSET_VERSION` 을 `i2` 로 올렸다(0032-4).
4. 오프라인 대비 테스트(`backdropContrast.test.ts`)는 밝기 배율과 번짐 알파를 CSS 에서 읽어 합성한다.

## 비교한 시안

캔버스 "19차"(기준·약·중·강). 약은 대기실 3.3·낮 시작 3.2 로 4.5 에 못 미쳤다. 약 + 밝기 0.8 로 4개 화면 전부 통과.

## 알려진 한계

- 낮이 0.8배로 어두워져 칙칙해 보일 수 있다 → 폰에서 보고 `--mf-backdrop-dim` 만 바꾼다(낮만 따로 올리는 것도 가능).
- 대기실에서 달이 방 코드 번짐에 조금 흐려진다.
- 창이 커튼 사이 좁은 틈이라 해·달이 헤더와 일부 겹친다.
- 층 분리 에셋은 투명 PNG 가 아니라(체크무늬가 박힌 미리보기) 아직 쓰지 못한다.
