# 0035. 시안·산출물은 클로드 코드 세션에서 직접 만든다

- 날짜: 2026-10-26
- 상태: 확정
- 이전: 0011(데스크톱·코드 분담), 0013(Design 캔버스를 이 세션에서 쓸 수 있음 확인)

## 결정

1. 클로드 코드에서 할 수 있는 일은 클로드 데스크톱으로 넘기지 않는다. 시안·화면설계서·화면 흐름 등 사람용 디자인 산출물은 이 세션에서 Design 캔버스로 직접 만든다.
2. 사용자가 그림 에셋을 직접 가져오겠다고 할 때만 받아서 `design/`, `public/`에 반영한다.
3. 디자인 시스템 아티팩트를 이 세션에서만 고친다는 규칙은 유지한다.
4. 0011 의 데스크톱 분담은 이 결정으로 대체한다.
