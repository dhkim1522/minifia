# 0041 6페이즈(친구 플레이테스트)는 없애고, 실테스트 뒤 필요한 일은 사용자가 새로 요구한다

- 상태: 채택
- 날짜: 2026-10-30

## 배경

- 6페이즈는 친구들과 한 판을 해 보고 수치를 조정하는 일이라 코드로 만들 것이 없다. 논의를 시작했으나 정할 내용이 없다는 것이 확인됐다.
- 사용자: 6페이즈 자체가 필요 없고, 모든 페이즈를 마무리한 뒤 직접 실테스트하고 필요한 사항을 새로 요구하겠다.

## 결정

- ROADMAP 에서 6페이즈를 지운다. 페이즈 문서(CONTEXT 등)는 만들지 않는다.
- 요구사항 PLAY-01~03 도 지운다(v1 33건). 판 길이·소감은 사용자가 직접 확인한다. 소감은 앱 밖(카톡)에서 받고 판 시간은 사람이 잰다. 앱 변경 없음.
- 실기기 확인 ①~⑮ 는 기존대로 모든 개발이 끝난 뒤 한 번에 한다(통과 표시는 사람이 확인한 뒤에만).
- 실테스트 뒤 수정·개발은 사용자 요청을 받아 퀵태스크 등으로 처리한다. v2 후보(REMATCH-01·COMMX-01 등)도 그때 정한다.

## 결과

- v1.0 개발 범위는 1~5페이즈로 끝난다.
