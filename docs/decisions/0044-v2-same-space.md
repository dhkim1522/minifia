# 0044 v2.0 은 "같은 공간" — 맵 이동·자유 채팅·동작 캐릭터로 대면 마피아의 사교와 정치질을 옮긴다

- 상태: 채택
- 날짜: 2026-10-30

## 배경

- v1.0 팀 실게임 테스트(결정 0043) 피드백. 오프라인 마피아는 친한 사람끼리 하며 사교성이 생기고, 묘한 정치적 행동이나 거짓말할 때 달라지는 모습 같은 대면 감정과 순간이 몰입을 만든다. 온라인으로 옮긴 v1.0 은 이 부분을 담지 못해 단조롭고 재미없었다.
- 팀 피드백(사용자 원문 요약)
  1. 고정된 캐릭터 자리 대신, 방에 들어오면 캐릭터가 생기고 로비 맵 안에서 자유롭게 움직이게 한다.
  2. 제한된 채팅 템플릿이 오히려 지루하다. 자유 채팅으로 바꾸고 로비에서부터 채팅·이모티콘을 쓰게 해 기다리는 동안에도 놀 수 있게 한다.
  3. 이모티콘이 에셋도 아니고 재미없다. 감정 표현을 채팅형 이모티콘이 아니라 캐릭터가 직접 하는 동작(목 긋기, 나 아니라며 부정, 칭찬, 울기, 악수 등)으로 바꾼다. 코믹하고 킹받는 요소로 재미를 극대화한다.
  4. 로비에서 놀 거리가 필요하다. 예: 직업 의상을 누르면 외형이 바뀐다, 3의 동작을 자유롭게 쓴다.
- 사용자가 제안을 받아 범위를 정했다(질문 답). 레퍼런스: 구스구스덕(의상·이모트·텍스트 채팅), 마피아42(꾸미기·직업), Town of Salem(유언·Death Note), Among Us(시체 발견·회의).

## 결정

1. **v2.0 의 축**: 규칙 진행기에서 "같은 공간에 함께 있는 느낌" 으로 옮긴다. 이동(어디에 서 있나)·자유 채팅(무슨 말을 하나)·동작(어떤 반응을 하나)이 사람을 드러내는 통로다. 역할 구성(마피아·경찰·의사·시민)과 승패 규칙은 그대로다.
2. **맵과 이동**: 방에 들어오면 내 캐릭터가 맵에 생긴다. 맵은 세로 폰 한 화면보다 조금 넓고 카메라가 내 캐릭터를 따라간다. 터치한 곳으로 이동한다.
   - 이동 가능: 로비, 낮 토론.
   - 이동 불가: 지목 투표(모두 가운데로 모여 제자리), 최후 변론·찬반(변론자에게 시선이 모이게).
   - 밤: 마피아만 움직인다. 시민 편 화면은 완전히 깜깜하고 다른 사람이 보이지 않는다.
3. **처형 흐름은 정통 순서로 되돌린다**: 지목(가운데 집결 후 실시간 가리키기, 누가 누구를 가리키는지 모두 보인다) → 최후 변론(최다 지목자) → 찬반 → 처형. v1.0 의 처형 여부 투표 → 후보 선택 → 한 표씩 공개는 없앤다.
4. **밤 행동**: 마피아는 맵에서 대상에게 다가가 암살한다(시민 캐릭터는 낮이 끝난 자리에 있다). 경찰·의사는 깜깜한 화면에 비친 얼굴 목록에서 고른다. 시민은 그동안 유언을 쓴다. 시민 화면에 발소리·심장 소리 같은 긴장 연출을 둔다. 암살당한 사람은 깜깜한 화면에서 암살 이펙트를 본다.
5. **아침**: 당한 자리에 분필 윤곽이 그날 낮 동안 남는다. 마피아 쪽지(암살할 때 남기는 익명 쪽지)와 피해자 유언을 공개한다. 의사가 살렸으면 "누군가 살아났습니다" 를 알린다.
6. **자유 채팅**: 하단 채팅창. 입력 중이면 머리 위에 "…" 표시(입력 중 알림, 내용은 채팅창에만). 로비·낮(지목·변론·찬반 포함)은 산 사람 모두, 밤은 마피아끼리, 탈락자는 탈락자끼리. 순차 직업 주장과 빠른 메시지(템플릿)는 없앤다.
7. **동작 캐릭터**: 관절이 있는 공통 몸체 하나 + 머리·옷·소품 교체(파츠). 동작은 한 목록이고, 고르면 내 캐릭터가 그 자리에서 실행한다(목 긋기·손사래·칭찬·울기·악수 등). 상대에게 가는 동작·수락형 동작은 두지 않는다. 이동을 막는 구간에도 제자리 동작과 채팅은 된다.
8. **로비**: 다양한 직업 의상을 눌러 갈아입는다. 고른 외형은 게임 중에도 유지되고 실제 역할과 관계없다.
9. **탈락자**: 산 사람에게 보이지 않는 유령으로 맵을 떠다니고 유령 채팅을 하며 관전한다(결정 0021 의 전체 관전 유지).
10. **끝**: 결과 화면에서 마피아 밤 채팅·유령 채팅을 공개하고, 재미있는 칭호를 주는 시상식을 한다. 같은 멤버로 바로 다시 할 수 있다.
11. **소리**: 배경음, 밤·처형 효과음, 동작 효과음.
12. **안정성**: 방장 이양·이탈자 정리, 보류한 연결 경고(WR-01~04) 정리.
13. **시간 시작값**: 토론 90초(살아 있는 사람 과반이 누르면 일찍 끝냄), 지목 15초, 변론 20초, 찬반 10초, 밤 30초, 아침 8초. 팀 테스트 뒤 조정한다. (2026-11-03 결정 0061-13 으로 개정했다: 아침 길이는 공개되는 내용에 따라 5~15초)
14. **서버 원칙 그대로**: 위치·채팅·유령·밤 정보는 서버가 받는 사람별로 걸러 보낸다. 밤의 마피아 위치·채팅은 시민에게, 유령 위치·채팅은 산 사람에게 보내지 않는다. 화면에서 숨기는 것으로 대신하지 않는다.
15. 범위는 모두 v2.0 한 마일스톤에 넣는다(사용자 선택). 로드맵은 단계마다 배포·검증할 수 있게 나눈다. 배포는 v1.0 과 다른 Worker(`minifia-v2` 제안)에 한다.

## 리서치 후 확정 (2026-10-30)

리서치(`.planning/research/SUMMARY.md`)가 낸 규칙 질문에 사용자가 답했다. 나머지는 권장값으로 시작하고 팀 테스트 뒤 조정한다.

16. **렌더링**: three.js(react-three-fiber 포함)는 쓰지 않는다. React DOM + CSS transform 맵과 SVG 파츠 관절 리그(자체 구현)로 간다. 1페이즈에서 실기기 성능을 재고, 기준에 못 미치면 그리는 부분만 PixiJS 로 바꾼다. 이유: 요구가 3D 를 쓰지 않음, 첫 로딩 증가(three +136KB·R3F +248KB gzip), 혼자 AI 도구로 만들기 어려운 3D 파츠 의상·코믹 동작, iOS WebGL 끊김(결정 0008 의 이유 유지).
17. **이동 동기화**: 클라이언트는 목적지만 보내고 서버가 경로를 정해 구간으로 보낸다. 위치 스트림·서버 틱은 두지 않는다.
18. **밤 위치**: 밤이 되면 각자 토론이 끝난 자리(가운데로 모이기 전)로 돌아간다. 아침에는 밤이 끝난 자리에서 시작한다. (4항 "낮이 끝난 자리"의 해석) (2026-11-03 결정 0061-4 로 뒷문장을 개정했다: 아침에는 모두 밤이 시작된 자리(home)로 되돌린다 — UI-SPEC A1)
19. **유언**: 역할과 관계없이 누구나 언제든 쓰고 고칠 수 있고, 죽을 때 공개한다. 쓰는 동안 아무 신호도 다른 사람에게 가지 않는다. (4항 "시민은 유언을 쓴다"를 바꾼다. 시민은 밤에도 쓸 수 있다)
20. **마피아가 둘 이상일 때**: 살아 있는 마피아가 모두 같은 대상을 암살해야 확정된다. 논의는 마피아 채팅으로 한다. 밤이 끝날 때까지 맞추지 못하면 그 밤에는 아무도 죽지 않는다. 마피아 쪽지는 확정된 암살에만 붙는다.
21. **아침 길이**: 내용에 맞춰 서버가 정한다(아무 일 없는 밤은 짧게, 유언·쪽지가 있으면 길게, 최대 15초 안팎). 공개된 유언·쪽지는 채팅창에 카드로 남는다.
22. **보호 성공 발표**: "누군가 살아났습니다"만 알리고 누구인지, 쪽지는 공개하지 않는다. 보호받은 사람에게 밤에 따로 알리지 않는다. v1.0 의 의사 구출 비공개(4페이즈 D-13)를 바꾼다.
23. **그 밖의 시작값**: 지목 동률·0표는 처형 없이 밤, 자기 지목 불가, 마감 전까지 바꿀 수 있음. 처형·아침에도 채팅 허용. 게임 중 스스로 나가기 없음(끊김은 v1.0 처리). 다시 하기는 "준비"한 사람으로 새 판. 방장이 떠나면 30~60초 유예 뒤 가장 먼저 들어온 연결자에게 넘김. iOS 무음 스위치는 기본으로 존중.
24. **배포 이름**: `minifia-v2` 로 확정한다. 배포 설정과 검사 스크립트의 기본 주소를 같은 커밋에서 바꾸고 v1.0 을 덮어쓰지 않게 막은 뒤 첫 배포를 한다.
