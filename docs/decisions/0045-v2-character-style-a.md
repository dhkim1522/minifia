# 0045 v2.0 캐릭터는 "A 말랑 클레이" 스타일로 간다

- 상태: 채택 (스타일), 렌더 방식은 미결
- 날짜: 2026-10-31

## 배경

- 결정 0044-7 의 동작 캐릭터(공통 몸체 + 파츠 교체)의 생김새를 정하려고, 사용자가 3D 토이 레퍼런스 두 장을 주고 three.js 3D 캐릭터 시안을 요청했다.
- 시안 캔버스 https://claude.ai/artifact/725Naddf6wqXC2H3dnvcGi 에서 두 방향을 비교했다.
  - A 말랑 클레이: 둥근 머리, 점 눈, 볼터치, 무광 점토 질감, 2.3등신.
  - B 비닐 토이: 각진 머리, 큰 타원 눈, 굵은 눈썹, 입 생략, 반광 비닐 질감, 2.5등신.
- 사용자가 A 를 골랐고, 의상·동작을 늘려 최종 시안으로 정리하라고 했다.

## 결정

1. v2.0 캐릭터 스타일은 A 말랑 클레이다. 최종 시안은 https://claude.ai/artifact/PPLmn6koNKgJbiBUDiNmnc 다.
2. 최종 시안의 구성(승인 대상)
   - 로비 의상 10종: 시민, 갱스터, 경찰, 의사, 탐정, 기자, 요리사, 바텐더, 정비공, 마술사. 실제 역할과 관계없다(결정 0044-8).
   - 헤어 6종 × 색 6, 피부 5톤, 표정 8종(기본·신남·윙크·능청·화남·당황·시무룩·울음).
   - 동작 10종: 인사·박수·엄지척·나 아니야·너야·목 긋기·울기·어깨 으쓱·쉿·악수 청하기(ROADMAP 10페이즈의 8개 이상 기준을 채운다).
   - 방향: 정면·3/4 앞·옆·3/4 뒤·뒤, 걷기 4프레임. 아이소 맵 4방향은 3/4 앞·뒤 두 장을 좌우 반전한다.
   - 게임 속 상태: 내 캐릭터 링, 입력 중 "…", 지목 수 배지, 최후 변론 조명, 마피아 동료 점선 링, 끊김(흑백 60%), 유령(다리 대신 꼬리), 암살 자리 분필 윤곽.
   - 공통 몸체: 관절 17개, 파츠 슬롯 hair·hat·top·bottom·shoes·acc·face.
3. 시안은 SVG로 3D 음영을 흉내 낸 그림이다. 모델(3D) 또는 리그 파츠(2D)를 만들 기준 그림으로 쓴다.

## 미결

- **렌더 방식**: 결정 0044-16 은 three.js 를 쓰지 않고 SVG 2D 리그로 가기로 했다. 사용자의 이번 요청은 three.js 3D 다. 바꾸려면 0044-16 과 ROADMAP 6·10페이즈(성능 게이트, "three.js 는 쓰지 않는다")를 함께 고치는 결정이 필요하다. 2D 로 가면 3/4 앞·뒤 두 방향분 파츠를 따로 그려야 해서 의상·헤어 작업량이 두 배가 된다.
- 최종 시안 승인 뒤 승인본 사본(PNG·규격)을 `design/characters/v2.0/` 에 둔다.
