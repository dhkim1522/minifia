# 0047 v2.0 캐릭터는 1번 시안의 3D 조립 인물을 그대로 쓰고, 모이는 자리를 게임 장치로 쓴다

- 상태: 채택 (최후 변론 위치 하나는 사용자 확인 대기)
- 날짜: 2026-10-31

## 배경

- 0046-5·6 은 캐릭터를 2D 리그로 그려 3D 맵 위에 겹치기로 했다. 사용자는 캐릭터도 3D 로 알고 있었다.
- 두 시안을 비교했다.
  - 1번 구·원통 조립 3D: https://claude.ai/artifact/NP1XfUrYTTqQ5nAB1HKYT5
  - 2번 2D 겹치기 시험판: https://claude.ai/artifact/XWzXFKhvVVsiamPzTNC6Tr
  - 서버·배포·용량은 둘이 같고, 폰 성능은 최적화를 하면 될 것으로 판단했다(실기기 확인은 6페이즈). 사용자가 1번을 골랐다(2026-10-31).
  - 사용자 의도: 1번 시안의 캐릭터를 그대로 쓰고 의상·감정 표현만 마피아 게임에 맞춘다. (첫 에셋은 2D 시안 생김새를 3D 로 옮겨 잘못 만들었고, 같은 날 1번 인물로 다시 만들었다.)
- 사용자 요청: 가운데 소품(원탁·의자)이 실제 게임 장치였으면 한다. 지목 때 의자에 모여 앉고, 최후 변론은 조명이 꺼지고 변론자만 스포트라이트를 받는 흐름을 원한다.
- 에셋 시안: https://claude.ai/artifact/MExvQNQTCwZdJ79XYSLPQk (사본 `design/v2.0/3d/`)

## 결정

1. **캐릭터는 1번 시안의 구·원통 조립 인물을 그대로 쓴다.** 인물 5명(갈색 머리·금발·단발·검은 페도라·갈색 페도라)의 몸·머리·얼굴·관절은 1번 그대로 둔다. 키만 약 1.7 단위로 줄였다.
   - 바꾼 것은 마피아 게임에 맞춘 의상·표정·동작뿐이다. 1번 시안의 요리사·농부 의상은 뺐다.
   - 의상 8종(0046 목록 유지): 시민(기본 코트) · 마피아(검은 페도라 진홍 띠·선글라스·진홍 넥타이) · 경찰 · 의사 · 탐정 · 어르신(흰 머리·수염·지팡이) · 후드(앞이 트인 두건·장갑) · 기자. 어느 인물에게나 입힐 수 있다.
   - 표정 10종: 1번 시안 7종(기본·웃음·화남·울음·놀람·의심·기절)에 당황·윙크·시큰둥을 더했다.
2. **관절과 동작**
   - 관절은 1번 그대로다: 목·어깨(팔 한 마디)·다리. 손 모양 4종(기본·펼침·가리킴·엄지)을 더했다.
   - 동작 8종(0046 목록)은 1번 시안 키프레임을 손봐서 쓴다: 목 긋기·손사래·박수·울기·악수 내밀기·지목·엄지척·어깨 으쓱.
   - 동작마다 효과(반짝임·땀·눈물·속도선)가 붙는다. 방향은 연속으로 돈다.
3. **성능**
   - 관절마다 부품을 색 정점 메시 하나로 합친다. 캐릭터 1명이 약 12 드로우콜이다.
   - 캐릭터는 실시간 그림자를 만들지 않고 발밑 타원을 쓴다.
   - 맵 그림자는 장면이 바뀔 때만 다시 그린다.
   - 실기기 합격 기준은 6페이즈 성능 게이트가 정한다.
4. **이름표·말풍선은 화면 겹침 층(DOM)에 그대로 둔다.**
   - 캐릭터는 가구에 가려질 수 있다. 앞쪽에 높은 물체를 두지 않는 0046-3 으로 대부분 막는다.
   - 가려짐 표시가 필요한지는 6페이즈에서 정한다.
5. **모이는 자리를 게임 장치로 쓴다.**
   - 응접실
     - 지목 투표 때 모두 원탁 의자 8개에 앉는다(자리 = 입장 순서).
     - 누가 누구를 가리키는지 머리끼리 선으로 잇는다.
     - 최후 변론 때는 조명이 꺼지고 변론자만 스포트라이트를 받는다.
     - 3D 캐릭터에 맞게 의자 폭을 넓히고(0.44 → 0.56) 원탁·의자 둘레를 키웠다.
   - 광장
     - 시계탑은 게임 시계다. 바늘이 장면의 시각을 가리킨다.
     - 원판의 놋쇠 표시 8개는 지목 때 서는 자리다.
     - 원판 가운데를 한 단 높인 단은 변론 무대다.
   - 변론 위치는 두 안 가운데 하나를 고른다. 시안에서 비교해 사용자가 정한다.
     - ① 원탁(광장은 가운데 단) 위로 올라선다.
     - ② 자기 자리에서 일어선다.
6. **게임 장면은 8개다.**
   - 시간대 5개 + 최후 변론(해질녘 + 스포트라이트) + 밤·마피아 화면(진홍 기운) + 밤·시민 화면(깜깜함, 내 캐릭터만 보임).
   - 쓰임 제안:
     - 해뜰녘: 밤에서 아침으로 넘어가는 전환
     - 아침: 아침 발표
     - 낮: 토론
     - 해질녘: 지목
     - 저녁: 로비
   - 어느 맵에 어느 단계를 둘지는 8·9페이즈 UI 단계에서 확정한다.

## 대체하는 것

- 0046-5 의 2D 리그, 방향 그림 3벌, 걷기 프레임, 2D 캐릭터 시안의 생김새 → 1번 시안의 3D 조립 인물. 의상·동작 목록은 그대로다.
- 0046-6 합치는 방식(빌보드·DOM 겹치기) → 캐릭터는 3D 장면 안에 두고, 이름표만 DOM 에 둔다.
- REQUIREMENTS Out of Scope 의 "3D 모델 캐릭터" 줄 → 범위 밖은 glTF 같은 외부 모델 파일만이다. 코드로 조립한 3D 캐릭터는 범위 안이다.

## 결과

- 6페이즈 리서치의 캐릭터 부분과 UI-SPEC 을 다시 맞춘다.
  - 리서치: DOM 겹치기 권고, 2D 자리표시 72×96
  - UI-SPEC: 캐릭터 크기, "캐릭터는 항상 보인다" 규칙
- 리서치가 성능 결과 기록용으로 잡아 둔 결정 번호 0047 은 다음 번호로 민다.
- 10페이즈 계획 메모(SVG 파츠·Safari 회전·포즈 스트립)는 3D 조립 기준으로 바꾼다.
- 캐릭터 애니메이션 라이브러리(Rive·Lottie 후보)는 쓰지 않는다.
