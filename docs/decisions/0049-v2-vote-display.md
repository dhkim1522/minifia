# 0049 v2.0 지목 표시: 손가락 지목 + 머리 위 숫자 배지, 기록은 채팅, 선두·과반 연출

- 상태: 채택
- 날짜: 2026-10-31

## 배경

- 0047 은 지목 때 누가 누구를 가리키는지 머리끼리 선으로 잇기로 했다. 배경 시안 5안에서는 바닥 빛줄기로 그렸다.
- 사용자 판단: 바닥 선은 불필요하다. 8명이 동시에 지목하면 선이 엉켜 읽히지 않는다.
- 시안 비교: https://claude.ai/artifact/1hzgEyAufgnDPVMvPvxdhP (둘째 줄 `VoteHand.dc.html`, 사본 `design/v2.0/blockout/`)
  - 득표 표시 3안(손가락 아이콘·놋쇠 메달·투표 쪽지)을 만들었다.
  - 사용자는 손가락 대신 숫자를 원했고, 숫자 배지를 확정했다(2026-10-31).

## 결정

1. **지목은 손가락 동작으로만 보여 준다.**
   - 바닥 선·머리끼리 잇는 선은 쓰지 않는다(0047-5 의 선 잇기를 대체).
   - 지목한 사람은 지목받은 사람을 보고 가리킨다. 앉는 자리는 몸을 돌리지 않는다.
   - 맵에는 투표 장치(전구·명패·촛불·칩 등)를 두지 않는다. 맵은 모이는 자리와 조명 연출만 맡는다.
2. **득표 수는 지목받은 사람 머리 위 숫자 배지로 보여 준다.**
   - 화면 겹침 층(이름표와 같은 DOM 층, 0047-4)에 그린다. 가구에 가려지지 않는다.
   - 모양: 남색 바탕(`rgba(14,19,38,0.92)`), 놋쇠 테두리 2px(`#c9a46a`), 둥근 모서리 12px, 크림 명조 숫자 22px(`#f1e6cf`, Gowun Batang 700) + 놋쇠색 "표" 12px.
   - 처음 나타날 때 튀어나온다(260ms). 진홍은 쓰지 않는다(마피아 전용).
3. **누가 누구를 지목했는지는 하단 채팅 시스템 메시지로 남긴다.**
   - 예: "민준 님이 도윤 님을 지목했어요". 추리할 기록이 된다.
   - 지목을 바꾸면 바꾼 내용을 남긴다.
   - 순간 알림은 화면 위 가운데 한 줄로 띄웠다가(1.5초) 사라지게 한다. 예: "민준 → 도윤". 몰리면 줄을 세워 하나씩 보여 주거나 같은 사람을 찍은 표를 "지호·민준 → 도윤" 처럼 합친다.
   - 지목한 사람 머리 위 말풍선은 쓰지 않는다. 머리 위에 이름표와 숫자 배지가 이미 있어 겹친다(2026-10-31 사용자 확정).
4. **선두·과반 연출**
   - 선두(최다 득표가 한 명): 배지가 커지며 맥박처럼 뛰고(1.18↔1.34, 1.1초) 크림 빛이 번진다. 그 사람 위로 빛이 모이고(점광 0.9), 당황 표정에 손사래를 한 번 한다. 채팅 "지금 ○○ 님이 가장 많이 지목받았어요".
   - 동점: 선두 효과를 푼다.
   - 선두가 바뀌면 효과가 새 선두로 넘어간다.
   - 과반(8명 중 5표): "유력" 도장이 찍힌다(놋쇠 테두리·크림 글자, -10° 기울임, 420ms). 실내등을 절반으로 낮추고(점광 1.7), 카메라가 8% 다가간다. 채팅 "○○ 님이 과반 표를 받았어요". 최후 변론 스포트라이트로 이어진다. (2026-11-02 결정 0060-3 으로 보탰다: 과반이어도 마감까지 이어지고 바꿀 수 있다 — UI-SPEC A3. 과반이면 바로 최후 변론으로 넘어가지 않는다)
   - 움직임 줄이기 설정에서는 애니메이션을 끈다.

## 결과

- 배경 시안 5안에서 투표 장치를 뺐다. 배경은 공간·모이는 자리·조명 연출로만 비교한다.
- 6페이즈 리서치가 성능 결과 기록용으로 잡았던 번호는 쓰지 않는다. 성능 결과는 기록할 때의 다음 번호로 남긴다.
- 과반 기준은 생존 인원에 따라 달라진다. 실제 판정 규칙(동점·기권)은 처형 페이즈에서 정한다.
