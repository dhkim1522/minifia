# 0050 v2.0 맵은 캐릭터 비율로 새로 짓는다: 재즈 바·시계탑 광장 2개로 시작, 방장 선택(기본 랜덤)

- 상태: 채택
- 날짜: 2026-10-31

## 배경

- 0046 의 맵(달빛 응접실·시계탑 광장)은 2D 캐릭터(72×96) 시절 비율로 그렸다. 0048 의 3D 캐릭터(맵 위 키 약 1.7, 몸통 지름 약 0.65, 머리 지름 약 0.96)와 맞지 않는다.
  - 응접실 의자 폭 0.56 이 몸통보다 좁다.
  - 원탁 자리 간격 1.45 에서 머리끼리 닿고 페도라 챙(지름 약 1.4)이 겹친다.
- 지목·변론 배경 5안을 캐릭터 실제 크기로 블록아웃해 비교했다: https://claude.ai/artifact/1hzgEyAufgnDPVMvPvxdhP (사본 `design/v2.0/blockout/`)
  - ① 지하 재즈 바 ② 마을 법정 ③ 시계탑 광장 ④ 패밀리 만찬 식탁 ⑤ 카지노 룰렛 바닥
- 사용자 제안: 맵을 모두 쓰고 로비에서 방장이 고르게 하며 기본값은 랜덤. 맵 하나를 실제 게임용으로 짓는 비용(정식 그림·폰 성능·이동 격자·조명·실기기 확인)이 커서, v2.0 은 2개로 시작하고 나머지는 업데이트로 더하기로 했다(2026-10-31).

## 결정

1. **v2.0 맵은 2개다.**
   - ① 지하 재즈 바(실내): 가운데 낮은 원형 무대, 둘레에 서는 자리 8개. 밤은 영업이 끝난 바(의자를 탁자 위로, 블라인드 사이 달빛).
   - ③ 시계탑 광장(야외): 가운데 두 단 연단, 둘레 놋쇠 표시 8개, 시계탑 바늘이 게임 시계. 폰 화면에 시계가 보이게 탑을 낮고 굵게 원판 가까이 둔다.
   - 6~9페이즈는 재즈 바 하나로 만들고 확인한다. 광장은 맵 선택과 함께 들어온다.
2. **맵 선택**
   - 방장이 로비에서 재즈 바 · 시계탑 광장 · 랜덤 가운데 고른다. 기본값은 랜덤이다.
   - 랜덤은 서버가 게임 시작 때 정해 모두에게 같은 맵을 보낸다(결정 0002).
   - 맵은 목록에 등록하면 늘어나는 구조로 짓는다(맵마다 모이는 자리·이동 막힘·단계별 조명·카메라 값을 데이터로 둔다).
   - 로비를 어느 맵에서 열지는 로비 UI 단계에서 정한다.
3. **모이는 장치는 모든 맵의 공통 부품이다.**
   - 서는 자리 8개(반지름 2.4~2.6, 옆 사람과 2.0 이상 — 챙이 겹치지 않는 간격)와 가운데 변론 자리, 단계별 조명(토론·지목·최후 변론·밤), 스포트라이트.
   - 맵은 겉모습만 바꾼다. 지목 표시는 맵에 두지 않는다(결정 0049).
   - 최후 변론자는 가운데 무대·연단에 선다. 0047-5 의 변론 위치 두 안(원탁 위·자기 자리)을 대체한다.
4. **분위기**
   - 낮이든 밤이든 스산하게 간다. 실내는 밝기 대신 조명 상태로 단계를 나눈다.
   - 야외는 낮에 낮으로 알아볼 수 있게 한다(잔뜩 흐린 회색 하늘, 해 없는 빛, 옅은 안개).
   - 진홍은 마피아 전용이다.
5. **나중 업데이트**: ② 마을 법정, ④ 패밀리 만찬 식탁(앉는 자세가 필요하고 한쪽 줄이 등을 보인다), ⑤ 카지노 룰렛 바닥(지목된 칸이 솟는 연출).

## 대체하는 것

- 0046 의 맵 2종(달빛 응접실·달빛 시계탑 광장)과 실내 시간대 5개 → 위 맵 2개와 단계별 조명.
- 0047-5 의 모이는 자리(응접실 원탁 의자에 앉기, 광장 놋쇠 자리 8·가운데 단) → 3의 공통 장치. 광장의 시계탑 = 게임 시계, 가운데 단 = 변론 무대는 그대로 이어 간다.
