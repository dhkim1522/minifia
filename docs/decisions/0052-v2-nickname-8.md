# 0052 v2.0 닉네임은 1~8자

- 상태: 채택 (6페이즈에서 구현)
- 날짜: 2026-10-31

## 배경

- v1.0 은 고정 원탁 이름표를 말줄임 없이 보여 주려고 닉네임을 5자로 묶었다(결정 0017-4).
- v2.0 은 캐릭터가 맵을 돌아다니고 이름표가 머리 위에 떠서(결정 0047-4, `NameTag`) 자리 폭 제약이 없다. 사용자가 8자로 늘리자고 했다(2026-10-31).

## 결정

1. 닉네임은 1~8자(그래핌 기준)다. 0017-4 의 5자를 대체한다. 다른 규칙(보이지 않는 문자 거부, 비교 키, 중복 금지)은 그대로다.
2. 이름표는 8자에서도 말줄임하지 않는다(`label-strong` 14px 기준 약 130px). 8명이 모였을 때 겹침은 선두를 앞에 두는 `z-tags` 규칙으로 처리한다.
3. 테스트 봇 이름은 모두 8자로 채워 가장 넓은 이름표를 늘 시험한다(결정 0028 칼날 경계 유지).

## 적용

- `shared/nickname.ts` 의 `NICKNAME_MAX_GRAPHEMES`, 입력 안내 문구(`src/net/copy.ts`, `JoinByLink.tsx`), 입력칸 최대 길이(`TextField`), 봇 이름(`shared/game/bots.ts`, `scripts/bots.mjs`), 단위 테스트를 6페이즈에서 함께 바꾼다. 지금 `v2` 브랜치는 아직 v1.0 원탁을 그리므로 먼저 바꾸면 이름표가 넘친다.
