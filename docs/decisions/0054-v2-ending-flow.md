# 0054 v2.0 판 끝: 장면 위 결과 공개, 한 명씩 시상식, 채팅 탭 공개, 준비 + 방장 시작

- 상태: 채택 (11페이즈에서 구현)
- 날짜: 2026-10-31

## 배경

- 화면설계서 묶음 C(https://claude.ai/artifact/H3gEwciexb83CxEXK76YXs) 를 그리기 전에 END-03·END-04·REMATCH-01 의 화면 방식을 정해야 했다. 사용자가 네 가지 모두 추천안을 골랐다(2026-10-31). 결정 0051(장면·아이콘 먼저, 글 최소)을 따른다.
- 같은 날 유언 깃펜 위치도 정했다: 채팅 입력줄 감정표현 옆, 채팅 입력줄이 없는 시민 편 밤에는 아래 행동 버튼(WILL-01, 디자인 시스템 `ChatPanel` 의 `onWill`). (개정: 0062-1, 2026-11-03 — 낮 깃펜은 입력줄 오른쪽 끝) (유언 공개 개정: 0063-3·0064-8, 2026-11-05 — 암살 유언은 화면 가운데 편지 뒤 채팅 카드, 처형 유언은 채팅 카드 그대로)

## 결정

1. **결과는 장면 위에서 공개한다.** 판이 끝나면 모두 가운데 무대 둘레로 모이고, 머리 위 직업 표시(`RoleChip`)가 한 명씩 뒤집힌다(약 0.4초 간격). 이긴 팀은 조명을 받고 춤·박수 동작, 진 팀은 어둡게 남는다. 화면 글자는 "시민 승리"·"마피아 승리" 한 줄. 카드 목록은 쓰지 않는다.
2. **시상식은 한 명씩 무대로 불러낸다.** 결과 공개 뒤 자동으로 이어진다. 한 사람이 무대로 걸어 나오면 스포트라이트와 칭호 패(아이콘 + 짧은 칭호 + 이유 한 줄), 나머지는 박수. 한 명당 약 2.5초, 점 진행으로 순서를 보이고, 각자 자기 화면에서 넘길 수 있다. 칭호는 서버 기록으로 정하고 모두 하나 이상 받는다(END-04). 칭호 목록 초안은 화면설계서 C2 보드.
3. **마피아 밤 채팅·유령 채팅은 결과 화면 채팅창의 탭으로 공개한다.** [전체][마피아][유령] 아이콘 탭, 기본은 전체(지금 대화). 기록은 밤별 구분선으로 나눈다(END-03).
4. **다시 하기는 준비 + 방장 시작이다.** 결과 화면 아래 [준비] 버튼, 준비한 사람은 이름표에 체크와 점 진행. 준비한 사람이 4명 이상이면 방장의 [시작] 이 켜진다. 의상은 그대로, 준비하지 않은 사람은 방에 남아 다음 판 동안 로비에서 기다린다(REMATCH-01).

## 결과

- REQUIREMENTS END-03·END-04·REMATCH-01 에 위 방식을 적는다.
- 디자인 시스템에 `ChatPanel` 탭, 칭호 패 부품, `trophy`·`crown` 아이콘을 더한다. 방장 이양 알림(CONNX-01)은 화면 위 한 줄(`TopToast`)과 왕관 아이콘으로 한다.
