# 0055 v2.0 6페이즈 준비: three 0.186.1, 내 폰 + 크롬 스로틀로 성능 확인, 로비는 지하 재즈 바 고정

- 상태: 채택
- 날짜: 2026-10-31

## 배경

- 화면설계서 21화면(https://claude.ai/artifact/H3gEwciexb83CxEXK76YXs)을 사용자가 승인했다(2026-10-31). 6페이즈 계획 전에 남은 확인 대기 세 가지를 사용자가 정했다.

## 결정

1. **three.js 는 `0.186.1` 로 고정한다.** 시안은 r128(전역 `THREE`)로 그렸지만 앱은 npm 패키지 모듈로 쓴다. 올릴 때는 결정 기록을 남긴다.
2. **성능 확인은 갖고 있는 폰 + 크롬 CPU 스로틀로 한다.** 개발 중에는 사용자 폰으로 배포본을 열어 화면 FPS 표시로 재고, 저가폰은 크롬 개발자 도구 CPU 4배 느리게로 대신한다. adb 실기기 기록은 하지 않는다. 저가 Android·구형 iPhone·카카오톡 인앱 브라우저 실측은 9페이즈 팀 테스트 때 팀원 폰으로 확인한다.
3. **로비는 지하 재즈 바로 고정한다.** 방장이 맵을 바꿔도 로비는 재즈 바이고, 게임을 시작하면 고른 맵(랜덤이면 서버가 뽑은 맵)으로 옮긴다. 로비 성능은 한 맵만 맞추면 되고, 6페이즈 로비와 성능 게이트가 같은 맵이다.
   - 처음에는 로비 전용 공간(백스테이지 분장실)을 골라 시안까지 만들었으나, 같은 날 사용자가 재즈 바 고정으로 바꿨다. 분장실 시안은 쓰지 않는다(git 기록에만 남는다).
