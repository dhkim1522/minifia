# 0055 v2.0 6페이즈 준비: three 0.186.1, 내 폰 + 크롬 스로틀로 성능 확인, 로비는 백스테이지 분장실

- 상태: 채택
- 날짜: 2026-10-31

## 배경

- 화면설계서 21화면(https://claude.ai/artifact/H3gEwciexb83CxEXK76YXs)을 사용자가 승인했다(2026-10-31). 6페이즈 계획 전에 남은 확인 대기 세 가지를 사용자가 정했다.

## 결정

1. **three.js 는 `0.186.1` 로 고정한다.** 시안은 r128(전역 `THREE`)로 그렸지만 앱은 npm 패키지 모듈로 쓴다. 올릴 때는 결정 기록을 남긴다.
2. **성능 확인은 갖고 있는 폰 + 크롬 CPU 스로틀로 한다.** 개발 중에는 사용자 폰으로 배포본을 열어 화면 FPS 표시로 재고, 저가폰은 크롬 개발자 도구 CPU 4배 느리게로 대신한다. adb 실기기 기록은 하지 않는다. 저가 Android·구형 iPhone·카카오톡 인앱 브라우저 실측은 9페이즈 팀 테스트 때 팀원 폰으로 확인한다.
3. **로비는 전용 공간 "백스테이지 분장실" 에서 연다.** 조명 거울·옷걸이 랙·모자 선반이 있는 작은 분장실. 옷걸이를 누르면 꾸미기 창이 열리고, 문 위 맵 포스터 2장(재즈 바·광장) 가운데 방장이 고른 맵의 포스터에 불이 켜진다(랜덤이면 둘 다 깜빡). 게임을 시작하면 무대(고른 맵)로 나간다.
4. **분장실은 시안을 먼저 만들고 6페이즈부터 로비 맵으로 쓴다.** 시안은 블록아웃 캔버스(https://claude.ai/artifact/1hzgEyAufgnDPVMvPvxdhP)에, 화면설계서 로비 보드 2개도 분장실로 바꾼다. 성능 게이트는 가장 무거운 지하 재즈 바로 그대로 잰다.

## 결과

- REQUIREMENTS MAP-01, ROADMAP 6페이즈 성공 기준 2·4 를 고친다.
- 사용자 폰 기종을 받아 HANDOFF 에 적는다.
