# 0062 v2.0 사용자 테스트 묶음 A 의 편의·버그 12건을 정하고(깃펜 입력줄 오른쪽 끝, "현재 / 최대" 숫자, 단계 타이머 한 규칙, 역할 확인 3D 무대, 종료 버튼 아래 고정 등) 0051-4·0052-3·0054 일부를 개정한다

- 상태: 채택
- 날짜: 2026-11-03

## 배경

- 9페이즈 배포본 사용자 테스트(2026-11-03)에서 나온 14항목 중 묶음 A(편의·버그, 피드백 1·2·3·4·6·7·10·11·13)와 코드 리뷰(`09-REVIEW.md`) 경고 2건·참고 1건을 09-24~09-29 보완 계획이 고쳤다. 원본 목록은 `.planning/phases/09-night-morning/09-USER-FEEDBACK.md`.
- 열린 디자인 항목은 실행 전에 사용자가 확인했다: 첫 봇만 8자 고정·나머지 1~8자 무작위, 깃펜과 보내기 사이 16px, 역할 배정과 역할 확인 둘 다 3D 무대, 인원 표시는 "현재 / 최대" 숫자, 타이머는 10초 노랑(놋쇠)·5초 빨강(진홍), 결과 화면 [처음으로] 아래 고정.
- 이 문서는 코드 주석과 시험이 "결정 0062-N" 으로 가리키는 번호를 고정한다.

## 결정

0062-1. 낮 깃펜(유언)은 채팅 입력줄 **오른쪽 끝**에 둔다: [입력칸][보내기][깃펜], 보내기와 깃펜 간격은 16px(`--space-sm`). 0054 의 "감정표현 옆" 위치를 바꾼다. 채팅 입력줄이 없는 시민 편 밤의 [유언] 버튼은 그대로다.

0062-2. 인원·진행 표시는 점이 아니라 숫자 "현재 / 최대"다(대기실 [시작], 토론 [끝내기], 찬반 진행). 0051-4 의 점(●●●○○) 표기를 바꾼다. 득표 배지 숫자·타이머 링·막대는 그대로다.

0062-3. [시작] 은 서버 `checkStart` 의 최소 시작 인원 전에는 비활성 모양이고, 도달하면 활성이 된다. 비활성 모양은 기존 승인된 inactive 모양을 쓴다.

0062-4. 모든 단계 타이머가 한 규칙(`timerTone`)을 쓴다: 남은 10초 이하 경고(놋쇠 `brass-400` 막대·`brass-200` 숫자), 5초 이하 임박(진홍 `crimson-500` 막대·`crimson-400` 숫자). 단계 전체가 문턱 이하로 짧으면 그 색 단계는 건너뛴다.

0062-5. 역할 배정(카드 고르기)과 역할 확인 화면의 배경은 v2.0 3D 재즈 바 무대 위에 어두운 막을 얹은 모양이다(승인 보드 `Role.dc.html`). v1 배경 그림은 쓰지 않는다. 두 화면은 한 장면(`preGame`)을 쓴다.

0062-6. 결과 화면의 [처음으로] 줄은 아래 고정이고 그 위 영역만 스크롤한다. 폰 6종에서 스크롤 없이 화면 안에 보여야 한다(E2E `RS-FIT`). 작은 폰의 결과 카드 축소는 하지 않는다.

0062-7. 역할 카드 시트는 내용 높이로 줄이고 최대 `min(420px, 80dvh)` 다.

0062-8. 테스트 봇 이름 길이는 첫 봇만 8자 고정, 나머지는 1~8자 무작위다(시험 시드는 고정해 결정적). 0052-3 의 "모두 8자" 를 바꾼다. 가장 넓은 이름표는 첫 봇이 계속 시험한다.

0062-9. 봇은 채팅 줄을 보내기 1.5초 전에 같은 채널로 입력 중 신호를 켠다(새 메시지 종류 없음). 서버 안 `relayTyping` 이 사람과 같은 채널 규칙으로 중계한다. 밤 시민 편은 무프레임 유지다.

0062-10. 알람 따라잡기로 아침을 건너뛰어도 밤 키(`:night`)가 남아 있으면 home 으로 되돌리고 보는 사람별 snap 을 한 번 보낸다(코드 리뷰 WR-01).

0062-11. 경찰 결과 카드의 좌석 색은 `seatColorVar` 한 곳에서 정한다(WR-02). 얼굴 목록도 같은 함수를 쓴다.

0062-12. 쓰기 시트는 한글 조합 중에 들어온 대기 콜백(저장·닫기)을 차례로 실행한다(IN-01). 같은 키는 마지막 것만 남긴다.

## 이 결정이 정하지 않는 것

- 묶음 B(순차 지목·직업 의상 유령·유언 중앙 공개, 피드백 5·8·9·12)는 시안 뒤 별도 페이즈다. 여기서 결정하지 않는다.
- 한 판 평균 10~15분은 참고 목표이고 고정 제한이 아니다. 단계 시간을 줄이지 않는다.
