# 0065 마피아 밤 선택 효과: 후보 이름표에 붉은 점선, 고르면 3px 진홍 테두리와 몸 윤곽, 발밑 고리가 조여든다

- 상태: 채택
- 날짜: 2026-11-05

## 배경

- 사용자 버그 보고: 마피아가 밤에 죽일 대상을 고를 때 "선택하는 느낌"이 없다(눌러도 이름표가 거의 그대로고, 눌렀다는 것이 몸과 이름표에서 읽히지 않는다).
- 결정 0051(글을 줄이고 보고 누르는 조작 중심)에 따라 글이 아니라 테두리·윤곽·움직임으로 보여 준다. 시안은 Design 캔버스(https://claude.ai/artifact/VtRcJw7vUTUpRBe1J8vTQk 보드 C1, 사본 `design/v2.0/mockups-b/NightAim.dc.html`)에서 만들었고 사용자가 추천안으로 진행하라고 했다.

## 검토한 안

1. **몸 테두리 (채택, 추천)**: 이름표 둘레 붉은 테두리 + 고른 사람 몸의 붉은 윤곽 + 발밑 고리 조임. 누르는 순간·고른 뒤·고르기 전이 한 가지 언어(붉은 테두리)로 이어지고, 작은 화면에서도 이름표가 또렷하다.
2. 조준선: 고른 사람 몸 위에 붉은 조준선이 크게 돌며 조여 와 멈춘다. 가장 "노린다" 느낌이지만 게임 같은 인상이 강하고, 이름표와 몸 위에 요소가 하나 더 겹친다.
3. 붉은 조명: 고른 사람 머리 위에 붉은 빛이 켜지고 나머지는 어두워진다. 분위기는 가장 좋지만 작은 화면에서 누구인지 덜 또렷하고 조명 추가는 렌더 예산(호출·광원)을 건드린다.

## 결정

0065-1. **몸 테두리를 쓴다.** 산 마피아의 밤(`nightMafia`)에서만 켠다.
- 후보 이름표(나·동료를 뺀 산 사람): 옅은 점선 테두리(`is-cand`, crimson-400 35%).
- 누르는 동안: 실선 crimson-400 + 빛(`is-preview`). 포인터를 떼거나 벗어나면 취소.
- 고른 뒤(내 선택 `mine`): 3px 실선 crimson-500(`#c8102e`) 테두리 + 느린 맥박(1.1초) + 이름표 위 작은 진홍 표식(`is-picked`). 밤에는 낮 지목의 gray-100 면(`is-mine`)을 쓰지 않는다.
- 고른 사람의 몸: 부품마다 붉은 뒷면 껍질(배율 1.14, `#e0344b` = 동료 고리 색)로 윤곽. 의상·표정이 바뀌어도 껍질이 같은 지오메트리를 따라간다.
- 발밑 고리(기존 mafia 고리): 2.4배에서 420ms 에 걸쳐 1배로 조여든 뒤 1 ± 0.07 로 가볍게 맥박. 기존 "다가가기" 걷기는 그대로 따라온다.

0065-2. **움직임 줄이기(`prefers-reduced-motion`)**: 맥박·고리 조임·테두리 전환이 없고 정지 테두리와 몸 윤곽만 남는다(고리는 늘 1배).

0065-3. **누설 규칙**: 새 서버 데이터는 없다. 효과는 서버가 마피아에게만 보낸 `me.pick` 과 `me.role`, 그리고 이미 있는 `allyPicks` 고리에서만 나온다. 동료의 선택에는 테두리·윤곽이 없다(연한 고리만, 기존 그대로). 시민·경찰·의사·유령 화면에는 `data-night-pick`·표식·윤곽 호출이 없다(테스트·E2E 가 0개를 확인). 낮 지목 이름표와 차례 버튼 모양은 바뀌지 않는다.

0065-4. **구현 위치**: `WorldPick.aim`(GameMap 이 `nightMafia` 일 때만 켬) → WorldStage 가 이름표 래퍼에 `data-night-pick`(cand·preview·mine)과 버튼 클래스 → 런타임이 `mine` 인 이름표만 `handle.setPickMark` 로 캐릭터에 전달(바뀔 때만). 누르는 영역 44px 은 그대로(안쪽 패딩 11, 테두리는 `::after`).

## 이 결정이 정하지 않는 것

- 효과음·햅틱(앱 전환 때). 동료가 고른 사람에게 테두리를 주는 일(필요하면 사용자 피드백으로).
