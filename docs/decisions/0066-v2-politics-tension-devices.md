# 0066 v2.0 정치·박진감 장치: 직업 주장 배지·귓속말·찬반 기록·동점 결선·마지막 3인·마지막 지목자 조명·판결 연출

- 상태: 채택 (사용자가 장치 목록에서 고르고, 세부 규칙은 추천안으로 정함. 2026-11-05 취침 전 위임)
- 날짜: 2026-11-05

## 배경

- 사용자 피드백: 게임이 심심하고 박진감이 없다. 마피아 본래 재미인 "어색하게 티 나는 것"과 "정치로 몰아가기"가 약하다. 원인은 말할 거리(의심 근거)가 채팅뿐이라는 점이다.
- 장치 43개를 후보로 놓고 6개로 줄였고, 사용자가 1·2·4·6번과 연출 30·31·32·34번을 골랐다.
- 사용자 위임: 세부 규칙은 추천안으로 정하고 계획·실행·배포까지 자는 동안 진행한다. 바꾸고 싶은 것은 아침에 다시 요청한다.

## 결정

1. **직업 주장 배지(후보 1, 새 9.1.1 페이즈).** 낮(토론·지목)에 산 사람이 자기 이름표에 직업 배지를 건다. 선택지는 이번 판 구성에 있는 직업 + [말 안 함](결정 0015 와 같은 공개 정보). 거짓 주장도 된다. 직업을 바꾸면 "말 바꿈"만 표시하고 이전 이력은 보이지 않는다. 서버는 주장을 공개 값으로 저장·방송한다(실제 역할은 보내지 않는다). (개정: 0072-1, 2026-11-07 — 기본판에서 꺼짐, 코드는 남김)
2. **귓속말(후보 2).** 산 사람이 낮에 하루 1번, 산 다른 사람 한 명에게 한 줄(최대 30자소)을 보낸다. 내용은 보낸 사람·받은 사람에게만 가고, 모두에게는 "A → B 귓속말" 사실만 시스템 줄로 간다. 유령은 보내지도 받지도 못한다. 내용은 판이 끝난 뒤 결과 화면에서 공개한다(11페이즈). (개정: 0072-1, 2026-11-07 — 기본판에서 꺼짐, 코드는 남김)
3. **찬반 기록 공개(후보 4).** 찬반 투표가 끝나는 순간 누가 찬성·반대했는지 얼굴 두 묶음으로 공개한다(변론자는 투표하지 않음). 결정 0053 의 "수만 공개" 를 개정한다. 이유: 편든 기록이 다음 날 몰아갈 근거가 된다.
4. **동점 결선(31).** 지목 결과 득표 최다가 정확히 둘로 동점이면, 두 사람이 가운데 마주 서고 나머지 산 사람이 5초 안에 둘 중 하나를 누른다. 많이 받은 사람이 최후 변론으로 간다. 결선도 동점이거나 최다 동점이 셋 이상이면 지금 규칙(처형 없음)을 따른다. (개정: 0072-1, 2026-11-07 — 기본판에서 꺼짐, 코드는 남김)
5. **마지막 3인 결전(32).** 산 사람이 셋이 되는 낮에는 토론 대신 특별 단계를 둔다. 셋이 차례(자리 순서)로 8초 "마지막 한마디"(빠른 문구 칩 또는 짧은 한 줄)를 하고, 곧바로 셋이 동시에 한 명을 지목한다. 과반이면 최후 변론·찬반 없이 처형한다(처형 뒤 승패 판정은 그대로). 동점이면 처형 없음. (개정: 0072-1, 2026-11-07 — 기본판에서 꺼짐, 코드는 남김)
6. **마지막 지목자 조명(34).** 순차 지목(결정 0063) 중 지금 지목하는 사람 머리 위에 핀 조명이 켜지고 나머지는 한 단계 어두워진다. 고르는 순간 빛이 대상 쪽으로 0.9초 동안 옮겨 간다. 0063 이 뺀 선두·과반 연출은 되살리지 않는다. (개정: 0072-5, 2026-11-07 — 동시 투표에는 해당 없음)
7. **판결 순간 연출(30의 화면 부분).** 찬반 투표가 끝나 결과가 나오는 순간 변론자에게 핀 조명, 카메라 0.6초 느린 확대. 소리는 12페이즈가 붙인다.

## 뺀 것(결정)

- 위기 게이지(33): 남은 마피아 수·시민 수를 드러내 처형된 사람의 직업을 거꾸로 알게 한다. 사용자가 뺐다.
- 유령 저주(35): 직업을 아는 유령이 산 사람에게 마피아를 알리는 통로가 된다. 사용자가 뺐다.
- 단서 오브젝트(3): 진짜·헛단서가 섞이면 의미가 없다. 진짜 단서만 주는 안으로 고쳤지만 이번에 고르지 않았다(후보로 남김).

## 다른 페이즈에 붙는 것

- 6번(결과 타임라인·칭호): 11페이즈. 귓속말 내용과 직업 주장 이력을 결과 화면에 공개한다.
- 30번 소리(심장박동 등): 12페이즈.

## 누설 규칙

- 직업 주장·찬반 기록·귓속말 사실은 공개 정보다. 실제 역할은 어디에도 새지 않는다.
- 귓속말 본문은 보낸 사람·받은 사람 소켓에만 간다(다른 프레임·재접속 복원·유령 화면에도 가지 않는다). 누설 시험을 더한다.
- 마지막 3인 단계는 인원수로만 정해지는 공개 정보다.
