# 0068 v2.0 캐릭터·동작·의상 계획 값: 새 메시지는 emote·dress 뿐, 동작은 몸으로만 보인다

- 상태: 채택
- 날짜: 2026-11-05

## 배경

- 10페이즈 UI-SPEC(`.planning/phases/10-character-motion-costume/10-UI-SPEC.md`)의 결정 D-1~D-20 과 미결 O-1~O-12 를 사용자 위임(2026-11-05 취침 전)에 따라 추천안·기본값으로 정했고, 계획(10-01~10-09)이 구현했다. 바꾸고 싶은 값은 플레이 뒤에 다시 요청한다.
- 실행 중 각 계획 SUMMARY 가 바꾼 값이 있으면 바뀐 값을 적었다(높이 밴드 0068-9, 동작 칸 폭 0068-10). 시간·세기·횟수·배율 값은 모두 기본값이고 실기기·팀 테스트 뒤 조정한다.
- 결정 0064-16 의 "감정표현은 몸 동작만, 머리 위 표시 없음"을 이어받는다.

## 결정

0068-1. **와이어는 최소로: 새 메시지는 `emote`·`dress` 둘, 새 프레임은 `{t:"emote",seat,id,n}` 하나다(D-12, D-19).**
- `emote` 는 `id` 와 `pk`(채팅과 같은 단계 키)를 싣는다. 채널·수신자·시각은 서버가 정한다. 클라이언트가 채널을 지정하지 않는다(결정 0002).
- 버려진 동작에는 오류·`chatReject`·`state` 가 없다(조용히 버림, D-11, L26·L30). 알림은 정보를 새게 하는 오라클이 된다.
- `dress` 는 `look`(의상 아홉 개 중 하나)만 싣는다. 거절(간격 안·로비 밖·규칙 거절)은 오류 없이 보낸 소켓에만 자기 최신 `state` 한 프레임을 돌려준다.
- 의상은 공개 값 `players[].look` 이다. 모든 단계·모든 viewer 에게 같고 역할과 무관하다. 키가 없으면 클라이언트가 `coat` 로 읽는다. 게임 시작·다시 하기 뒤에도 남는다(다시 하기 화면 연결은 11페이즈).

0068-2. **UI-SPEC 문구에서 벗어난 곳 네 가지.**
- ① **`n` 은 채널(all·mafia·ghost)별로 따로 센다.** UI-SPEC A-3 은 방 전체 하나였다. 방 전체 하나로 세면 받지 못한 프레임의 틈이 시민 편에 새어 마피아 동작이 있었음을 알린다. 채팅 `seq` 를 채널별로 세는 것과 같은 이유다. 그래서 클라이언트는 `n` 이 아니라 받은 프레임 순서(도착 순서)로 재생하고, 렌더 상한의 "가장 오래된 것"도 도착 순서다. `n` 의 틈으로 무엇도 추정하지 않는다.
- ② **의상 거절 응답 규칙**은 0068-1 의 마지막 항목이다(UI-SPEC 은 거절 응답을 정하지 않았다).
- ③ **클라이언트도 260ms 간격으로 마지막 선택만 보낸다**(`DRESS_SEND_GAP_MS`). 서버 간격은 250ms 다(O-8). 카드를 빠르게 넘겨도 서버에 거절당하지 않는다. 선택이 서버 값과 같으면 보내지 않고, 서버가 되돌리면 1200ms 안에 서버 값에 맞춘다.
- ④ **성능 측정 구성**: 5분 nightload 한 번, 그리고 8명 서로 다른 의상(탐정 포함)·동시 동작 4개·걷기 시나리오 2분 한 번(실행 시간 단축 요청). 5분 실기기 측정은 `10-DEVICE-CHECKS.md` 의 몫이다.

0068-3. **UI(동작): 입력줄 맨 왼쪽 버튼에서 5+4 아이콘 판을 연다(D-1, D-2, D-3, O-6).**
- 칸 순서는 박수·최고·악수·춤·깜짝 / 엉엉·손사래·손가락·목긋기다. 동작 9종 그대로(새 동작 없음).
- 한 칸을 누르면 판이 닫히고, 판이 열려 있는 동안 떠 있는 버튼은 숨는다.
- 화면에는 문구를 거의 두지 않는다(결정 0051). 칸 이름은 접근성·짧은 이름 한 줄이다.

0068-4. **UI(의상): 로비의 떠 있는 `hanger` 버튼 → 채팅 패널을 덮는 한 줄 카드 띠(D-4, D-5, D-6, O-3, O-9).**
- 의상 선택은 완전 자유이고 중복을 허용하며 기본은 전원 `coat` 다. 의상으로 역할이 새지 않게 역할과 무관하다.
- 카드 그림은 승인 1번 인물 9장만 쓴다(인물별 45장을 만들지 않는다). 장면 속 내 캐릭터가 진짜 확인이다(0051-6).
- 방장 [맵 | 의상] 탭은 두지 않는다(11페이즈). 게임 단계에는 버튼·시트가 없다.

0068-5. **동작 규칙.**
- 연타(O-1): 앞 동작이 끝나야 다음, 마지막 수락과 최소 1000ms, 10초에 5번. 모든 동작 길이(1060ms 이상)가 최소 간격보다 길어 화면의 비활성 시간(`EMOTE_MS`)이 이미 서버 간격을 덮는다(0068-11).
- 동시 렌더 상한 4. 5번째가 오면 가장 오래된 것을 끝낸다(O-2, D-13). 서버가 거절하지 않는다.
- 모션 줄이기(O-5): 다른 사람 동작은 재생하되 반복 2회 이하, 진폭은 절반으로 한다.
- 표정 병합 선행(O-10): 유휴 시간에 병합해 4배 스로틀에서 첫 동작 직후 프레임 간격 50ms 이하를 합격선으로 본다.
- 서버 봇은 동작하지 않는다(O-7).
- 막힌 구간(지목 중·변론·모이는 동안 제외)에서도 항상 허용한다. 걷는 중에는 칸이 비활성이고 서버가 버린다(D-14, D-10).
- 화면이 낙관적으로 재생하지 않는다. 서버 프레임이 올 때만 재생한다(D-9).
- 채널은 채팅 채널 규칙을 따른다: 낮은 모두, 밤 마피아는 산 마피아+유령, 유령은 유령. 밤 시민 편은 보낼 수 없고 버튼이 없다(D-12, D-20).

0068-6. **의상 규칙.**
- 의상 변경은 250ms 간격만 제한한다(O-8). 변경 횟수 제한은 없다.
- 유령 직업 의상 안개가 고른 의상을 덮고, 안개가 끝나면 고른 의상으로 복원한다(D-7). 산 사람 화면에는 안개 경로가 없다.
- 걷기·방향은 현행을 유지한다(D-8). 의상을 바꾸면 이전 의상의 병합 지오메트리를 정리한다(최근 의상 1개만 캐시).

0068-7. **동작 효과(반짝임·땀·눈물·속도선)는 만들지 않는다(D-17).** 결정 0064-16 의 머리 위 표시 금지를 이어받는다. 결정 0047 의 동작 효과 줄을 개정한다. 동작은 몸 키프레임의 품질로 전달한다.

0068-8. **에셋·성능.**
- 새 부품 0개, 표정 10종·손 모양 4종은 이번에 제외한다(O-4, D-16). 현행 절차적 프리미티브 조립을 유지한다.
- 포즈 스트립은 개발 빌드와 `?e2e=1` 에서만 켜진다(O-11).
- 정적 예산 시험은 매 계획 돌리고 실측은 마지막 계획에서 한 번 돈다. 시험 범위는 바꾼 흐름 × 폰 1~2종, 마지막 계획에서 폰 6종 회귀다(D-15, D-18). 합격선(평균 55fps·끊김 5회·draw call 120·점광원 3)은 낮추지 않는다.

0068-9. **높이 밴드 상한을 1.9 에서 1.92 로 올린다(실행 중 확정, 10-06 이월).** UI-SPEC 의 높이 밴드는 1.5~1.9 였다. 기자 모자를 여자 머리(인물 2·4)에 얹으면 1.918 이다. 부품 모양을 다시 만들지 않고 상한만 올린다. 하한과 다른 문턱(메시 8·삼각형 15,000·구성 14)은 그대로다. 기자 카메라 소품이 작아 몸에 붙어 보이는 점과 함께 실기기 확인 후보다.

0068-10. **동작 판 칸 폭은 360 폭에서 55.6px 로 둔다(실행 중 확정, 10-05).** UI-SPEC 은 59.2 였다. 눌러서 쓸 수 있는 하한 44 를 E2E 가 통과한다. 실기기에서 엄지로 누르기 어렵다면 그때 다시 정한다.

0068-11. **서버 최소 간격 1000ms 와 화면 비활성 시간의 차이는 코드 변경 없이 닫는다(10-05 이월).** 서버 간격은 "마지막 수락"부터 센다. 모든 동작 길이(`EMOTE_MS`)가 1060ms 이상이라 동작이 끝나 칸이 풀릴 때는 간격이 이미 지났다. 그래서 화면 비활성 시간을 늘리지 않는다. `test/unit/emote.test.ts` 가 "모든 `EMOTE_MS` ≥ `EMOTE_MIN_GAP_MS`"를 고정해 둔다(동작 길이나 간격을 바꾸면 이 시험이 알려 준다). 10초에 5번 한도는 칸을 막지 않아 연타 끝에 조용히 버려질 수 있다.

0068-12. **밤 시민 편에 동작 버튼이 없는 것(O-12)은 플레이 뒤에 다시 본다.** E2E(`avatar-phases-night`)가 현재 모양을 고정했다. 시민 편 화면이 허전하다는 반응이 있으면 그때 정한다.

  - 경찰·의사 얼굴 목록을 각자의 의상 얼굴로 바꾸기: 지금은 `src/net/assets.ts` 의 `faceSrc` 임시 그림이다.
