# 0070 v2.0 소리와 마무리 계획 값: 전부 합성하고, 소리는 숨은 정보를 나르지 않는다

- 상태: 채택
- 날짜: 2026-11-06

## 배경

- 12페이즈 UI-SPEC(`.planning/phases/12-sound-polish/12-UI-SPEC.md`)의 결정 D-1~D-30 과 미결 O-1~O-16 을 사용자 위임(2026-11-05 취침 전)에 따라 추천안·기본값으로 정했고, 계획(12-01~12-12)이 구현했다. 바꾸고 싶은 값은 플레이 뒤에 다시 요청한다.
- 실행 중 각 계획 SUMMARY 가 UI-SPEC 문구에서 벗어난 곳은 0070-1~0070-7 에 이유와 함께 적었다. 소리 레벨·음색·시간 값은 모두 첫 초안이고 폰으로 듣고 조정한다.
- 결정 0044-11(소리 항목), 0057·0061-15(밤 정보 비누설), 0066-7·0067(판결 순간), 0069(결과·시상 시간표)를 이어받는다. 구현 기록은 `docs/audio.md`(출처·레시피 지도)와 `docs/architecture.md` 의 `src/audio/` 절에 있다.

## 결정

0070-1. **방식: 소리 56개를 모두 Web Audio 로 합성한다. 외부 소리 자산과 소리 라이브러리는 0이다(D-1, D-2, D-18~D-20).**
- 배경음(침대) 7 + 효과음 49 = 56 `SoundId`. 레시피는 `src/audio/recipes.ts` 한 표(`RECIPES`·`BEDS`)가 단일 정의이고 외부 파일을 읽지 않는다. 래퍼는 `src/audio/`(엔진·합성기·감독·대본)이며 Howler 등 라이브러리를 쓰지 않는다.
- 합성 음색의 한계는 알고 있다. 마음에 들지 않는 id 는 id 단위로 레시피를 고치고, 그래도 부족하면 그 id 만 CC0 샘플로 바꾸는 하이브리드(O-4)를 연다. 이번에는 샘플 코드를 만들지 않았다. 연구 문서(STACK.md)의 샘플 전제는 이 결정으로 바뀐다.
- 시험은 세 겹이다: 순수 레시피 단위 시험(한계·id 일치·노드 수), `OfflineAudioContext` 렌더 검사(피크·NaN·무음·길이, E2E `sound-render` 56개 합격), 훅 로그 E2E(`window.__mfSound` 요청 로그, 실제 소리 출력에 기대지 않는다).
- 출처 기록은 `docs/audio.md`. 외부 파일·라이브러리가 생기면 표에 행이 있어야 통과하는 시험(`soundProvenance`)이 지킨다. 알려진 곡의 선율 인용 없음.
- 합성 단계에서 바꾼 값: gainDb −24 아래 행은 레시피 레이어 이득에 접었고(들리는 크기는 같다), 드론 D1(36.7Hz)은 폰 스피커가 못 내서 D2 로 올렸다. 렌더 검사로 `will.quill` 하나만 −30 → −22 로 고쳤다.

0070-2. **구조·누설: 소리는 감독(director) 한 곳이 공개 view 차이와 닫힌 로컬 신호로만 정한다(D-3, D-10~D-13, LS-1~LS-11).**
- 서버는 소리를 모른다. 새 메시지·프레임·view 키가 없다(`test/unit/soundProtocol.test.ts`가 shared·worker 소스의 소리 단어 0, 클라이언트 메시지 종류 불변, `src/audio` 네트워크 API 0 을 고정한다).
- 감독의 입력은 `AudioView`(허용 필드만)와 닫힌 로컬 신호뿐이다. 선택값·역할·좌석은 입력에 없고 정적 가드가 읽는 경로 목록을 고정한다.
- 밤 소리는 모든 역할이 같은 대본을 듣는다(서버 이벤트 입력 0, 각자 난수). 암살음(`kill.slash`)은 당한 본인만. 판결 앞머리(심장 박동)는 결과와 무관하고 결과는 2600ms 까지 소리에 나타나지 않는다. 받지 못한 프레임은 소리가 없고, 재접속·첫 스냅샷은 침대만 깐다.
- 시작 시각은 공개 단계 시각(`phaseEndsAt` 에서 환산)이다. 예외: 아침 소리와 편지는 view **도착 기준**이다 — 화면 시계가 같은 기준이고 가변 길이라 단계 시각에서 역산할 수 없다.
- 밤 시각 큐와의 박자: 시민 편은 시각 큐(`tension.ts` `onCue`)를 구독해 진홍 맥박과 맞고, 그 밖과 모션 줄이기는 소리 전용 스케줄러가 같은 간격 규칙을 따른다(D-11). 어느 갈래든 서버 입력 0이다.

0070-3. **켜기·끄기·잠금(D-4~D-9, O-1·O-2·O-11~O-13).**
- 소리 단추: 방 화면 오른쪽 위 떠 있는 단추 하나, 누르기 44·시각 36, 위치 top 70(헤더 아래 끝 62 + 8)·right 16, **`z-index: calc(var(--z-overlay) + 1)` = 51**, 시각 뷰포트 오프셋 따라감. 상태는 on·off·locked 셋. 알약(locked)은 116.9×44이고 8초 뒤 아이콘 단추로 접힌다. 겹침이 생기면 소리 단추가 위(재접속 띠·토스트·[테스트]). 단, 시트(유언·쪽지·배지)가 열려 있는 동안은 단추가 숨는다 — 시트가 `.mf-game` 의 쌓임 맥락 안이라 `z-modal` 이어도 단추 위로 오르지 못해 폭 360×높이 560 에서 시트 [닫기]를 가렸다(12-12 회귀에서 발견·수정). 아이콘 `sound`·`soundOff` 는 직접 SVG.
- 기본 켜짐, `localStorage`(`minifia:sound`) 영속, 기기 설정이라 서버로 보내지 않는다. 한 단추는 전체 on/off 만이다(볼륨·배경음/효과음 분리 없음, O-9). 끈 사람에게 알약으로 다시 권하지 않는다(O-12).
- 잠금 해제는 참가·만들기 제출 탭 핸들러 **맨 앞에서 동기** 호출하고(비동기 뒤는 제스처가 아니다), 재접속은 알약·아무 탭(`pointerup`·`touchend`·`click`·`keydown`)에서 `resume()` 한다.
- 오디오 세션은 `ambient`(무음 스위치 존중, 다른 앱 음악과 섞임, O-13). `playback` 우회와 무음 HTMLAudio 트릭은 쓰지 않는다. 앱 안에 무음 스위치 안내 글은 없다(O-11, `12-TEAM-TEST.md` 안내에만).
- 탭 숨김은 suspend, 복귀는 resume 하고 놓친 일회성 소리는 틀지 않는다(현재 단계 침대만 되살림).

0070-4. **믹스·성능(D-16, O-3·O-5·O-6·O-10).**
- 버스 3개(bgm 0.3·sfx 0.7·ui 0.45) + 마스터 0.7 + compressor(−18dB, 4:1) + 동시 보이스 8 + 노드 48 + 우선순위 끊기(우선 0 은 끊지 않음) + 덕킹. 같은 id 는 `max` 2·간격 제한(timer.tick 800ms, emote 250ms, vote.cast 120ms, ui.tap 80ms). 동작 소리는 남의 것 −6dB·초당 3개·동시 4(O-5). `timer.tick` 은 켠다(O-6). 저사양 `lite` 는 두지 않는다(O-10, 실기기 55fps 미달이 확인될 때만).
- 모든 레벨(침대 포함)은 첫 초안이다. 시험 페이지(`/?sound-lab=1`)로 듣고 id 단위로 조정한다.
- 소리 켠 5분 nightload(4배 스로틀, 390×844, 합격선 평균 55fps·끊김 5회·draw call 120·점광원 3, 소리 끈 기준선 대비 2fps 이내): 재즈 바 평균 59.9fps·끊김 2·draw call 34→31, 광장 평균 59.9fps·끊김 1·draw call 34→31, 둘 다 점광원 4(알려진 `perfbudget` B2 4>3, 10페이즈 이전부터)이고 `sound.state` running·요청 300. 소리 끈 기준선(59.92/59.93)과 0.02fps 이내라 합격선·기준선 모두 통과했고 `--sound off` 대조는 필요 없었다(숫자는 `.planning/phases/12-sound-polish/perf/`). 실기기 확인은 `12-TEAM-TEST.md` S5.

0070-5. **계획이 추가로 정한 규칙.**
- **닫힌 로컬 신호 종류**: `tap`·`card`·`deny`·`vote`·`emote`·`tensionCue`·`result` 일곱. 인자에 선택값·역할·좌석을 넣지 않고, 종류를 늘리려면 `SIGNAL_KINDS`·`LocalSignal`·`directSignal` 분기를 함께 고친다.
- **결과 소리는 사건 기반**: 11페이즈 결과 시계의 사건(뒤집기 1200+400i ms·승패 조명 4600ms·시상 패 창 시작+900ms)에 붙는다. 시간표를 바꾸면 `script.ts` `RESULT_AT` 한 곳을 고치고 시험이 대조한다. 건너뛰기·일시정지·재접속은 예약을 취소하며 소급하지 않는다. 박수 소리는 3개(80ms 간격).
- **판결 grace 250ms**(`GRACE_MS`): 도착이 늦은 view 는 이 안에 든 항목만 지금 내고 지난 항목은 버린다. 처형 중간 합류는 침대만이다.
- **찬반 기록이 있을 때** 판결 대본이 `BALLOT_END_AT` 에 `ui.card` 한 번(채팅 카드 신호는 ballots 카드에 보내지 않아 중복 없음).
- **시각 큐 갈림 불리언**: `visualCues = nightDarkOf(view) && !reducedMotion` 로 밤 진입 때 정해진다. 밤 중 모션 줄이기를 바꿔도 소리 갈래는 그 밤 동안 그대로다.
- **시험 페이지 게이트**: 개발 문맥(`?sound-lab=1`, 개발 빌드·`?e2e=1`)에서만 열리고 배포 진입 번들에 `data-sound-lab` 이 0이다. `window.__mfSound` 훅도 같은 문맥에서만 켜진다.
- **첫 스냅샷에서는 `timer.tick` 도 예약하지 않는다**(새로고침 뒤 그 단계 카운트다운은 무음).
