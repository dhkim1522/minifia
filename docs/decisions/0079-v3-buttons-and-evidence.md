- `RULESET` 에는 새 스위치가 없다. 16 계획 직전 커밋(`9d6dba72`) 대비 `shared/game/ruleset.ts` diff 는 0이다. 가짜 장소·마지막 목격은 기본판에서 항상 켜져 있다.

## 결정

0079-1. **아이콘 단추의 한글 이름표를 모두 없앤다. 새 불변 규칙: 눌리는 아이콘 단추는 글 이름표 없이 접근성 이름(`aria-label`)만 갖는다(0073-나 개정, 0077-1).**
- `data-tool-label` 속성과 아이콘 아래 이름표 줄이 없다. `ToolButton` 은 이름 하나(`name`, 필수)만 받는다. `FloatAction` 의 `word`, `SoundButton`·`MapChip` 의 `TOOL_WORD`, `CHAT_TEXT.label` 은 지웠다.
- 접근성 이름에는 좌석·nonce·토큰·역할 영문 id 가 들어가지 않는다(전 화면 모아 시험). 이름표 허용 목록 시험은 속성이 없어지면 공허해지므로 "접근성 이름은 고정 문구·비어 있지 않음" 시험으로 바꿨다.
- 탭 안의 글(결과 탭 4: 전체·마피아·유령·기록, 꾸미기 탭 2: 맵·의상)과 글 단추([시작]·[처리]·[넘기기] 숫자)는 이름표가 아니므로 그대로 둔다(V-7).
- E2E 의 `toolLabelChecks` 는 `{ labelAttrs, labelEls }` 개수를 받고 개수가 없으면 "측정값 없음"으로 실패한다(공허 통과 금지). 이름표가 키우던 높이 보정(`TOOL_ROW_EXTRA` 11.6 등)은 모두 지웠다.

0079-2. **단추는 한 규칙이다: 머리 44 정사각, 입력줄 48 원, 닫기 ×, 도구 열 52 원(0077-3, V-1·V-2·V-6·V-7).**
- 머리 단추(나가기·공유·내 역할·기록)는 44×44 정사각(모서리 12, 아이콘 24, 사이 8). 입력줄 [동작]·[보내기]는 48 원. 모든 시트·카드의 닫기는 `close` × 44×44.
- 오른쪽 열의 단추는 지름 52 원(아이콘 24, 간격 12). 떠 있는 게임 단추(직업 주장·귓속말 — 기본판에서 꺼짐)와 시상식 [넘기기]는 48 원(상자가 곧 면)이고 `data-side-button` 이 붙은 단추만 52 다.
- 입력줄이 이름표 보정 없이 돌아와 아래 패널은 250 / 306(방장 +56 은 17페이즈 튜토리얼 스위치 몫)이다. 키보드 열림 패널 150(`KB_PANEL_H`).

0079-3. **오른쪽 세로 열: 손님은 둘(소리·옷장), 방장은 넷(소리·맵·봇·옷장). 높이가 모자라면 두 번째 열이 왼쪽에 생긴다(V-2~V-5).** (0086 으로 바뀜 — 방장도 둘(소리·옷장)이고 맵·봇은 방장 전용 왼쪽 줄로 갔다)
- 위치: 오른쪽 16, 위 = `--mf-host-bottom + 12`. 순서 위 → 아래: 소리 · 맵(방장) · 봇(방장) · 옷장. 손님에게는 맵 칩이 없다(V-5).
- 칸 나누기는 CSS 열 wrap 이 아니라 순수 함수 `splitSideColumn(n, maxH, cell 52, gap 12, min 2)` 가 정한다(열마다 칸 수, 오른쪽 열부터). 한 열에 들어가는 칸 수 `k = max(2, floor((maxH + 12) / 64))` 이고 `maxH` 는 `useMapInsets` 가 재서 `sideMaxH` 로 돌려준다(측정 전 Infinity).
- 소리 단추는 `HostBand` 독에 남아 열의 첫 칸이다(게임·결과 화면과 같은 자리). 그래서 독 아랫변은 `D = B + 64`(B = 띠 아랫변 123 / 두 줄 144 → 187 / 208)다. 15 의 기록 카드·흔적 카드 윗선도 이 D 로 다시 계산된다(기록 카드 D + 8, 증거 카드 D + 16).
- 꾸미기 시트·키보드가 열려 있는 동안 열은 그려지지 않는다. 결과 화면에서는 시상식이 끝난 뒤에만 나온다(시상 중 [넘기기]는 제자리 48 원). (0083-7 로 시상식 삭제 — 결과 연출이 끝나면 나온다)
- 360×560 방장 대기실은 단추 4 + 패널 때문에 열이 둘로 접힌다. 열 겹침 판정 예외는 `SIDE_COLUMN_EXCEPTIONS` 에 문서화했으나 실제 측정에서는 교차가 없었다(알려진 한계 항목 참고).

0079-4. **심부름 화면: 시작 카드 · 64 타일 · 후광 · 발밑 화살표 · 장소 위 [처리] · 진행 점. 아래 독은 없앤다(0077-4, V-19~V-24).**
- 시작 카드: 단계 시작 후 `ERRAND_CARD_MS` 2초, 막 + "오늘 갈 곳" 제목(serif) + 내 장소 3 타일(84, 아트 60) + 한 줄. 터치는 통과하고(걷기 가능) 첫 누름에 닫힌다. 40초 시계는 카드와 상관없다. 표시 조건은 서버 시계 기준 `now < (phaseEndsAt − ERRAND_MS) + ERRAND_CARD_MS` 이고 닫은 단계는 `phaseEndsAt` 로 구분해 다음 판에는 다시 뜬다(`useErrandStartCard`). 유령·목록 없는 사람에게는 없다.
- 장소 표지는 64×64 타일(모서리 16, 면 `night-800`, 컬러 아트 44). 처리한 곳은 불투명 .55 + 오른쪽 아래 체크 배지 + 놋쇠 테두리 3. 남은 곳은 정지 후광(테두리 2 + 번짐 14)이고 가장 가까운 곳만 `is-call` 램프 빛이다.
- 화살표: 가장 가까운 곳을 향한 40 글리프, 내 발밑에서 그 방향 56 떨어진 자리(눌림 통과, 스테이지 안쪽 8 + 20 안으로 가둠). 처리 반경 안에서는 화살표·`is-call` 이 꺼지고 그 장소 타일 위 8에 [처리] 알약(높이 44)이 뜬다. 위가 막히거나(띠·열·화면 위 안쪽 8·다른 장소 타일에 걸림 — 아래가 비어 있을 때) 아래로 뒤집고 좌우는 안쪽 8 안으로 민다. 반경 밖에는 알약이 없다(눌러도 무변화인 알약 삭제).
- 아래 패널 `ErrandDock`(84, 칩·n/3·[처리])은 통째로 지웠다. 화면 아래 가운데 진행 점 3(지름 20, 간격 12, 아래 변 = 화면 아래 − 40)만 있고 보이는 "n/3" 글은 없다(`aria-label="진행 n/3"` + `aria-live`). 심부름 단계에는 아래 패널 section 자체가 없고 스테이지가 맨 아래까지 넓다(`useMapInsets(turnActive, panelless)`).
- 피할 사각형(avoid)은 `[data-side-button]` 전부 + 띠 면 + 진행 점 줄 + 이름표 버튼이다. 표식: `data-errand-start-card` · `data-errand-dots` · `data-errand-dot` · `data-errand-act`(알약).

0079-6. **마피아는 처리되지 않는 가짜 장소 하나를 받는다. 목록 모양·개수는 시민과 같다(0077-6, A1, ERRAND-08, 0074 D-03 개정).**

- 처리는 기존 거절 경로를 탄다(후보 순회에서 `id === actor.errandFake` 건너뜀). 거절 응답은 이유와 역할이 새지 않는 같은 응답이다.

- 봇 마피아의 목표 순서: 가짜가 아닌 미완료 장소 중 가장 가까운 곳, 없을 때만 가짜(그렇지 않으면 가짜 곁에 서서 움직이지 않는 겉보기 차이가 근처 사람에게 보인다). 봇 계획과 난수는 바뀌지 않았다.
- 화면은 가짜를 모른다(V-25): 마피아의 [처리]가 가짜 곁에서 켜져도 안 차는 것은 마피아 본인만 보고, 마크업·마커 수·`data-*` 는 시민과 같다. E2E `errandParityChecks`(ER1)가 마피아 판과 시민 판의 마크업 동일을, client 시험이 "새 문구·알림 없음"을 지킨다.

0079-7. **아침에 피해자를 마지막으로 근처에서 본 사람을 공개한다(0077-6, A2, EVID-02).**

- 목격자가 없으면 증거 카드 2행은 눈 아이콘 + "0"이고 장소 칸이 없다. 증거 카드는 1행 흔적 + 2행 마지막 목격이고(폭 328, 높이 128) 구분선은 행 사이 헤어라인이다.

0079-8. **같은 옷 표시와 조각 색: 흔적 조각과 같은 옷을 입은 산 사람의 이름표에 낮 끝까지 표시한다(0077-6, A4·R-3, EVID-01).**
- 의상 일치는 클라이언트가 이미 공개된 의상(`view.players[].look`)과 `TRACE_OF_OUTFIT` 역표로 계산한다(`sameOutfitSeats`, 서버가 새 값을 싣지 않는다). 대상은 산 사람만(나 포함, 죽은 피해자 제외, 유령 viewer 도 같은 규칙 — 표시는 viewer 역할과 무관한 공개 값의 함수).

0079-9. **사회자 문구를 근거를 가리키는 말로 바꾼다(0077-6, D-11).**
- `trace`: "흔적이 남았습니다. 같은 옷을 입은 사람을 표시했습니다." 새 키 `discussion.evidence`: "토론입니다. 같은 옷과 엇갈린 목격을 살펴보세요." 우선순위는 기록을 아직 안 연 사람 → `witness`, 흔적이 있는 날 → `discussion.evidence`, 그 밖 → `discussion.act`. `errand.act`: "심부름 시간입니다. 빛나는 곳을 찾아 처리해 주세요."
- 금지 낱말('범인'·'증거'·'확정')을 쓰지 않고 공개된 두 근거(같은 옷·목격)만 말한다. 이 분기들은 역할(`me.role`)을 읽지 않는다. 읽는 값은 `day.evidence.trace` 의 유무뿐이다(조각 값·`seen`·`look` 은 읽지 않는다 — Proxy 시험이 고정). 증거 카드 보조 줄 "누구의 것인지는 모릅니다"(`TRACE_NOTE`)는 새 보조 줄로 바뀌어 지웠다.
