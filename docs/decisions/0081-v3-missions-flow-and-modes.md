# 0081 v3.0 할 일 재설계: 원인→결과 하루 흐름, 등불·집 찾기·현장 조사, 방장이 고르는 기본/확장 판

- 상태: 채택(방향). 세부 값은 이 결정을 받는 페이즈의 SPEC·UI-SPEC 에서 정한다
- 날짜: 2026-11-09
- 근거: 17페이즈 UAT 피드백, 조사 문서 `docs/research-v3-missions-ux.md`
- 바꾸는 것: 0007(역할 확인 다음은 낮), 0072·0074 의 하루 순서와 낮 심부름, 0074-4(밤은 얼굴 목록), 0078-8(배경 흐림·어둠 없음). 0072 의 "판 고르기 화면 없음(D-01)"

## 배경

17페이즈 UAT 에서 사용자가 지적한 문제는 다음과 같다.
- 맵이 좁아 심부름 동안 다 근처에 있게 되므로, 목격에 의미가 약하다.
- "아무 데나 가서 처리"는 왜 하는지 당위성이 없어 억지스럽다.
- 흔적과 의심을 무슨 기준으로 찾는지 알 수 없다.
- 하이라이트가 있어도 [다음] 버튼이 눈에 들어오지 않는다.
- 배경이 모두 같은 어둠이다.

조사(관점 6개)에서 근본 원인이 나왔다. 범행은 밤인데 심부름은 낮이라 둘이 끊겨 있고, 마피아에게 낮에 할 일과 들킬 위험이 없다. 로컬 플레이에서는 다음 두 가지도 확인됐다.
- 기본 옷 `coat` 가 겹쳐서 흔적 표시가 전원에게 붙는다.
- 실제 판의 낮 조명도 남색이라 어둡게 보인다.

## 결정

0081-1. **실테스트 전에 바로 고칠 것 네 가지**(미션 방향과 무관)
  1. **옷 중복 해소**: 흔적이 한두 명으로 좁혀지게 한다(조사 4-4 #1).
  2. **낮·밤 조명 대비**: 낮은 채도를 낮게 유지한 채 명도와 색온도만 바꾼다.
  3. **튜토리얼 손보기**
     - 대상 밖을 어둡게 하는 스포트라이트. 흐림은 쓰지 않는다.
     - [다음]을 아래 가운데의 글 단추로 바꾼다.
     - 채팅 칸과 입력줄을 숨긴다.
     - 장면 5 연결선이 화면 안에서 끝나게 한다.
     - 시민 문구를 실제 판과 같게 한다.
  4. **낡은 문구 정리**: "밤 대화가 공개돼요", 밤 띠의 "이름표", "눈 0".

  0078-8 은 "배경 흐림 없음, **대상 밖 어둡게는 허용**"으로 바뀐다.

0081-2. **하루 흐름은 원인 → 결과 순서다.**
  - 처형(또는 처형 없음) → 저녁 할 일 → 밤 → 아침 증거 → 바로 토론 → 투표.
  - 첫날: 역할 확인 → 저녁 할 일 → 첫 밤 → 첫 아침부터 토론.
  - 토론이 시작되면 모두 광장 가운데로 모이고, 증거는 의심 보드(얼굴 줄 + 표시) 한 곳에 모은다(조사 4-4 #2·#3).

0081-3. **할 일은 세 가지가 한 줄로 이어진다.** 저녁 할 일이 밤의 목격을 정하고, 밤의 동선이 아침 현장의 단서가 된다.
  - **저녁 등불 당번**
    - 지금 심부름(배정, 근처 표본)을 다시 쓴다.
    - 마피아는 같은 단추로 심지를 자른다. 겉보기엔 켜지고 밤에만 꺼진다.
  - **밤 집 찾기**
    - 모든 역할이 같은 조작으로 지도에서 집을 누른다. 실시간으로 걷지 않으므로 0074-4 의 누설 문제를 피한다.
    - 아침에 발자국 수와 이웃 창문 목격이 생긴다.
  - **아침 현장 조사**
    - 단서는 나만 본다.
    - 마피아가 만진 지점은 흐려지고 "먼저 손댄 흔적"이 남는다.
    - 구출된 밤에는 미수 현장으로 쓴다.

0081-4. **맵은 단계적으로 넓힌다.**
  - 먼저: 지금 광장 + 가장자리 실내 방 4곳(지붕을 걷어 내는 방식) + 집 8채.
  - 실테스트로 효과를 확인한 뒤 소도시 블록(조사 3장 1안)으로 넓힌다.

0081-5. **처형된 사람의 정체는 계속 판 끝까지 비공개다.** 튜토리얼에서 "정체는 판이 끝나야 알아요"를 미리 보여 준다.

0081-6. **방장이 판 종류를 고른다.**
  - **기본 마피아**: 역할 → 낮 토론·투표·처형 → 밤 얼굴 고르기 → 아침 발표. 할 일과 흔적이 없다.
  - **확장판**: 0081-2·0081-3 의 흐름이다.
  - 기본값은 확장판이다. 튜토리얼은 확장판을 기준으로 한다.
  - 구현 방식: 지금 전역 상수인 `shared/game/ruleset.ts` 의 `RULESET`(12개 파일에서 읽음)을 방마다 고르는 값으로 바꾸고, 대기실 방장 패널에 선택을 더한다.
  - 0072 가 예약해 둔 "정통 판"(배지, 귓속말, 결선 등 정치 장치)은 이 선택과 별개로 남겨 둔다.
  - 이후 기능은 두 판 모두에서 시험한다.

## 정하지 않은 것

- 저녁 할 일의 시간과 개수, 등불 개수, 집 배치, 현장 단서의 종류와 표.
- 의심 보드의 표시 세트(실, 눈, 투표 손가락), 토론 모이기의 카메라.
- 판 종류의 이름. 기본/확장은 임시 이름이다.
- 튜토리얼을 실제 판의 축소판으로 다시 짜는 범위(조사 4-4 #6).
- 대질 신문 등 보조 장치는 실테스트 뒤에 정한다.
