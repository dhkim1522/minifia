- 날짜: 2026-11-11
- 근거: 18페이즈 UAT 중 사용자 요청 다섯(R1~R5), 계약서 `.planning/phases/18.1-screen-polish/18.1-UI-SPEC.md`
- 바꾸는 것: 0021-1(산 사람 화면도 탈락자를 유령으로 남김), 0051-2(역할 카드 문구는 사용자 확정으로 2~3줄 — 예외), 14페이즈 TOOL-03(목표 줄 → 문구 한 덩어리가 겸함), 07-UI-SPEC 기록 칸 96/152·키보드 72(→ 68 한 값), 11-07 결과 탭 패널(D-2·D-3 — 결과 화면에서 숨김, 서버 0027·0058 그대로)

## 배경

18페이즈 UAT 에서 사용자가 요청한 다섯 가지다.

- R1: 역할 카드에서 설명과 목표가 같은 말을 되풀이한다. 겹침은 3D 이름표가 아니라 카드 안 글 내용이었다.
- R2: 채팅 기록 칸이 너무 커서 맵을 가린다. 두 줄만 보이게 하고 싶다.
- R3: 죽은 사람이 산 사람 화면에서는 연출 뒤 사라진다. 죽으면 유령으로 보이게 하고 싶다.
- R4: 지금이 아침·낮·저녁·밤 중 언제인지 아이콘으로 알고 싶다.
- R5: 결과 화면에서 역할별 채팅 내역과 기록은 숨긴다.

모두 서버 규칙이 아니라 화면의 문제라 서버(`worker`·`shared`)는 바뀌지 않았다.

## 결정 (P181-0~P181-7, 사용자 확정 표시)

- **P181-0 역할 카드의 글(사용자 확정 문구 넷).** 카드에는 직업 이름 + 글 한 덩어리만 뜬다. 첫 문장("당신은 {직업}입니다.") 뒤에서 줄이 바뀌어 2~3줄. 목표 줄·"목표" 칩은 카드와 [내 역할] 시트에서 그리지 않는다. 문구의 원천은 `ROLE_TEXT[role].desc` 한 곳이다.
- **P181-1 (보조) 역할 확인·배정에서 3D 이름표 층은 그리지 않는다.** `visibility: hidden` 이라 DOM 은 남는다.
- **P181-2 (보조) 역할 카드 위 끝은 소리 단추 독 아랫변 + 8.**
- **P181-3 기록 칸 높이는 모든 폰에서 68 한 값(사용자 확정: 두 줄 창).** 방 높이로 96/152 를 가르던 규칙과 키보드용 72 는 폐지했다.
- **P181-4 지난 기록은 기록 칸을 누르면 아래에서 올라오는 기록 시트로 본다(사용자 확정).** 칸 안에서 스크롤하지 않는다. 닫으면 포커스가 [data-chat-open] 으로 돌아온다.
- **P181-5 시간대 배지 4종(아침·낮·저녁·밤, 사용자 확정).** 게임 맵 헤더 [역할 카드] 왼쪽 44×44 하나(`data-tod`), 날씨 그림 4장(`public/weather/`). `lightingOf` 와 같은 값이라 투표·변론은 저녁이다. 튜토리얼에서는 끈다.
- **P181-6 산 사람 화면에도 탈락자는 유령(코트 안개)으로 남는다(사용자 확정).** 직업 칩·새 표식은 없다. 직업은 여전히 비공개다(살았는지는 공개 정보, 의상은 코트 하나).
- **P181-7 결과 화면은 전체 대화 하나뿐(사용자 확정).** 마피아·유령·귓속말·기록 탭과 탭 행을 그리지 않는다. 서버 보관·전송·`resultLog` 프레임은 그대로다.

## 계획 단계에서 고른 것

- 유령 위치는 `WorldStore.lastSegOf`(마지막 자리)를 쓴다. 재접속·새로고침 뒤에는 그 전 유령을 그리지 않는다.
- 산 사람 밤·심부름은 유령을 그리지 않는다(0074 겉보기 같음·근처만 보임). 직업 정보가 새지 않게 하려는 것이다.
- spectate 전 순간의 유령도 코트 안개로 그린다.
- `data-ghost-seat` 는 유령 시점에서만 붙는다. 이름표가 겹칠 때 순위는 내 것 > 산 사람 > 유령.
- 결과 탭은 `RESULT_TABS_SHOWN` 한 상수로 끄고 탭 부품은 남겼다(되돌리기 쉽게).
- 역할 확인의 이름표 층은 `visibility: hidden`(DOM 유지)이다.
- E2E 사본 `ROLE_LINES` 를 새 문구로 바꾸고 새 흐름 `polish-reveal` 을 더했다.

## 실행 중 달라진 곳

- 01: 폐지된 목표 표식 검사 선택자를 조각으로 이어 붙여 시험에서 같은 검사를 하면서 grep 기준도 지켰다. preGame 시험 한 개를 둘로 나눴다.
- 02: 산 사람 화면 유령에는 입력 중 표시를 그리지 않는다(유령 채널 신호 차단). 이름표가 연출 끝에 깜빡이던 문제를 고쳤다.
- 03: 시간대 변환 `todOf` 를 닫힌 switch 로 바꿔 nightCitizen·nightGhost 가 낮으로 새지 않게 했다.
- 04: 로비 시험이 새 [data-chat-open] 단추를 행동 버튼으로 세어 제외 선택자를 더했다. 패널 안 새 글 알약을 전제한 시험 두 곳을 맞췄다.
- 05: 결과 화면 탭 단언·클릭은 08 에서 새 판정으로 바꾸기로 넘겼다.
- 06: 스테이지가 커져 카메라 이동 한계 `PAN_BOX` 5.7 → 5.4, 연장 바닥 `PLATE_FAR` 17 → 17.5 로 다시 정했다. E2E 행동 버튼 수 선택자 이월.
- 07: 옛 기록 칸 이름 정리. 주석에 남은 사라진 훅 이름 한 줄을 지웠다.
- 08·09: E2E 판정(문턱 불변). 08 의 튜토리얼 장면 7 TC2(360×560 아랫줄 카드 약 5.9px 넘침)와 09 의 B3(시트를 닫은 뒤 포커스가 body)를 앱 결함으로 넘겼다.
- 10: 위 두 결함을 앱에서 고쳤다. B3 은 시트 `onClose` 안에서 포커스를 주면 모달 `<dialog>` 가 아직 열려 있어 옮겨지지 않았다 — 언마운트 뒤 effect 에서 준다. TC2 는 높이 600 이하에서 튜토리얼 카드 그림을 72×96 → 63×84 로 한 단계 더 줄였다(문구·문턱 불변).
