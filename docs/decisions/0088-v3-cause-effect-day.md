# 0088 v3.0 원인→결과 하루: 저녁 등불 → 밤 집 찾기 → 아침 현장 → 토론 (확장판 전용)

- 상태: 채택(계획) — 21-01~21-16. 구현·배포가 끝나면 이 줄을 고친다
- 날짜: 2026-11-14(결정은 계획 단계에서 열린 질문의 추천안을 위임 채택)
- 근거: 결정 0081-2·3, `.planning/phases/21-cause-effect-missions/21-CONTEXT.md` D-01~D-30, `21-UI-SPEC.md` P21-1~, `21-RESEARCH.md` 열린 질문 1~10·가정 A1~A8
- 바꾸는 것: 확장판 하루의 순서(`roleReveal → errand → night → morning → discussion → … → execution → errand`), 공개 증거 카드(아침 흔적 조각·마지막 목격) 폐지, 마피아의 가짜 장소 대신 등불 심지 자르기. 기본 마피아는 그대로다(`dayAnnounce` 경유, 단계 id 도 같다).

## 결정

하루 순서와 규칙

- **0088-1 하루 순서와 일차(D-01·A6).** 확장판은 규칙 플래그 `Ruleset.cause` 가 켜진 판이다. 단계 id 는 늘리지 않고 같은 id 의 자리만 바뀐다(`nextPhaseOf`): 역할 확인 → errand(저녁) → night → morning → discussion, 처형(또는 처형 없음) 다음도 errand 다. `dayAnnounce` 는 확장판에서 지나지 않는다. 일차는 errand 진입 때 한 번 오르므로 첫 저녁·첫 밤·첫 아침·첫 토론이 모두 1일차이고, 처형 없음 이유(`noExecutionOf`)는 저녁 단계가 지난 낮(일차 − 1)의 줄에서 읽는다.
- **0088-2 시험 잠금 방식(A1).** 바꿀 수 있는 표 `CAUSE_MODES`(제품 값 `["extended"]`)에 없는 판은 같은 판의 `cause` 만 꺼진 얼린 규칙을 받는다(`maps.ts` 의 `MODE_MAPS` 와 같은 방식). 훅 표는 규칙 객체마다 한 번 만든다. 단위·워커·화면 setup 이 잠근 채 시작하고(옛 확장판 순서) 새 흐름 시험만 `openCause()` 로 켠다. 잠금을 걷고 옛 순서 시험을 옮기는 일은 21-13(단위·워커)·21-14(화면)가 한다.
- **0088-3 아침 길이와 건너뜀(D-03·D-17).** 피해자도 미수(의사 구출)도 없는 밤은 현장이 없어 morning 길이가 0 이고, 한 번의 tick 안에서 곧바로 토론까지 간다(승패 판정은 여전히 morning 마감 훅이다). 현장이 있으면 morning 은 지금 발표 길이에 현장 30초(`MORNING_SCENE_MS`)를 더한다. 저녁 40초·토론 90초는 그대로다. 한 판 길이는 참고 목표라 상수 한 곳(`phases.ts`)에서 플레이테스트 뒤 고친다.
- **0088-4 공개 증거 끄기(P21-15).** 확장판 morning 은 흔적 조각·마지막 목격(`morning.trace`·`morning.seen`·`day.evidence`)을 만들지 않고, 저녁 표본도 마지막 목격 줄(`errandLast`)을 쌓지 않는다. `rules.trace`·`rules.witness` 의 뜻은 그대로다(목격 기록 `me.record` 는 계속 쓰인다). 단서는 현장에서 사람이 직접 찾는다(21-04).
- **0088-5 가짜 장소 끄기(A4).** 확장판 errand 진입은 `assignErrandFake` 를 부르지 않는다. 마피아의 비밀 행동은 심지 자르기(`cut`, 21-03)이고 마피아도 3곳을 끝내면 목격 기록을 받는다(밸런스 변화이니 실테스트에서 본다).
- **0088-6 심부름 키를 토론까지 유지(D-09·D-19).** 확장판 `enterNight` 는 심부름 목록·진행·목격 표본(`errandPlaces`·`errandDone`·`errandSeen`)을 지우지 않는다(다음 저녁 `enterErrand` 가 키째 지운다). view 는 허용 목록 게이트(저녁 `me.errand`·토론 `me.record`, 산 본인만) 그대로라 밤·아침 view 에는 두 키가 없다.

등불·현장·보드(이 계획 이후 21-02~21-05 가 따른다)

- **0088-7 가로등 id 는 새 8개 `lamp0`~`lamp7` 이고 마을 `MapDef.lamps` 에 둔다(열린 질문 1).** 기존 `lamp` 한 곳과 마을 `places`(방 안 심부름 장소)는 건드리지 않아 기존 시험이 안 깨진다. 이름·그림은 `lamp` 의 별칭 한 줄이다.
- **0088-8 켠 등불과 자른 등불이 겹치면 자르기가 이긴다(A3).** 한 명이라도 심지를 자른 등불은 밤에 꺼진다. 판정은 한 함수라 바꾸기 쉽다.
- **0088-9 저녁 중 남이 켠 등불은 밤부터 공개한다(A2).** 저녁에는 내 등불만 보이고 전원 방송을 하지 않는다(쓰기·누설 면이 작다). P21-8 의 "모두 같은 가로등 8곳"은 위치이고 켜짐은 밤에 공개된다.
- **0088-10 창문 단서는 지점 기준이다(열린 질문 7).** 피해자 집 이웃의 `houseLit` 한 값이 ③ 결과를 정하고 살피는 사람은 누구든 같다. "내 집이 이웃일 때만"을 원하면 판정에 조건 하나를 더한다.
- **0088-11 흐려짐 해석.** 마피아가 살핀 지점은 그 뒤에 살피는 사람이 누구든 단서 대신 "먼저 손댄 흔적"을 받는다. 마피아가 살피기 전에 먼저 살핀 사람의 단서는 그대로다. 마피아 자신은 평소처럼 단서를 받는다.
- **0088-12 발자국 수는 지점 ①을 살핀 사람만 본다(P21-16).** 수는 그 밤 그 집을 고른 산 사람 수(본인 제외)이고 누구인지는 없다.
- **0088-13 [건너뛰기]는 과반이다(열린 질문 5).** 토론 끝내기와 같은 `majorityOf` 규칙이라 마피아 한 명이 늘 막지 못한다. 공개 값은 누른 수뿐이다. 전원 기준은 한 줄만 바꾸면 된다.
- **0088-14 아침 걷기는 근처만 보인다(A5).** 아침 world 프레임·snap 도 저녁과 같이 근처(+같은 구역) 사람만 받는다.
- **0088-15 토론 시작 모이기 뒤 걷기는 허용한다(열린 질문 8).** 토론 시작 때 둘레 자리로 모이고 이후 걷기는 지금처럼 허용·카메라는 따라가기다(변경 최소). 걷기 금지는 `canMoveIn` 한 줄이다.
- **0088-16 길게 누르기 0.6초 = 자르기 시도(P21-7).** 마피아의 [켜기] 단추 길게 누르기가 심지 자르기이고 화면 응답은 켜기와 같다.
- **0088-17 집 없는 맵에서는 현장이 없다.** 마을이 아닌 맵(재즈 바·광장)에는 집이 없어 확장판이어도 현장 지점이 생기지 않고 morning 은 길이 0 으로 건너뛴다.
- **0088-18 닫힌 방 안 분필은 생기지 않는다(P20-18).** 암살은 집 앞(바깥)에서만 일어나므로 실내 분필 문제가 없다.

배포·호환

- **0088-19 진행 중이던 방(A7).** 새 상태 키는 이 페이즈에 없고 정규화 작업도 하지 않는다. 배포 시점에 진행 중이던 확장판 방은 다음 마감부터 새 순서를 따르므로 순서가 바뀔 수 있다(방 만료 3시간). 배포 시각을 조율하거나 새 판부터 확인한다.

사용자가 돌아와 한 줄씩 바꿀 수 있다.
