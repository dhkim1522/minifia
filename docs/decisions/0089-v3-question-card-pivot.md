# 0089 v3.0 방향 전환: 질문 카드(라이어게임 + 마피아)를 기본 마피아의 중심으로

- 상태: 채택(방향만 확정 — 세부 값은 새 페이즈의 discuss·UI-SPEC 에서 정한다)
- 날짜: 2026-11-16
- 근거: 사용자 제안 "미니피아 개선 방향"(아래 요약), `docs/playtest-v2.0-feedback.md` 문제 1·2, 21 배포본 플레이 피드백 "등불이 와닿지 않는다"(`.planning/phases/21-cause-effect-missions/21-PLAYTEST-NOTES.md`)
- 바꾸는 것: 결정 0081·0087·0088 의 확장판(마을·저녁 등불·밤 집 찾기·아침 현장 조사·의심 보드)을 더 키우지 않는다. 21 은 완료·배포된 그대로 두고, 21-PLAYTEST-NOTES 의 등불 재검토(강화·교체·제거)는 이 결정으로 대신한다.

## 문제

- 오프라인 마피아의 재미는 눈빛·긴장·침묵 같은 표정과 분위기에서 나온다. 음성 없는 온라인에는 이 신호가 없어 의심할 근거가 없고, 토론과 정치가 생기지 않는다.
- v3.0 은 이 문제를 어몽어스식 공간 증거(심부름·등불·창문·발자국·옷 조각·흐려짐)로 풀었다. 단서 하나를 이해하려면 규칙 서너 개를 알아야 해서 문제 2("무엇을 해야 할지 모른다")와 부딪힌다. 사람이 해 본 적도 아직 없다.

## 결정

- **0089-1 질문 카드를 증거 장치의 중심으로 둔다.** 모두 같은 질문에 한 줄로 답하고, 마피아만 비슷하지만 다른 질문을 받는다. 답의 어긋남이 의심의 단서다. 질문 쌍은 "여름/겨울 휴가지"처럼 답이 겹칠 수 있는 것으로 고른다.
- **0089-2 망설임 표시.** 답을 내기까지 걸린 시간을 공개한다("갑자기 말이 없어지는" 순간의 대신).
- **0089-3 의심 스티커.** 🤔/😇 를 공개적으로 붙여 누가 누구를 몰아가는지 드러낸다.
- **0089-4 공개 투표 기록.** 라운드별 투표 내역을 남겨 "너 저번에 걔 감쌌잖아" 같은 추궁이 가능하게 한다.
- **0089-5 판 결과 기록.** 승리 진영, 마피아가 잡힌 라운드, 질문 카드 직후에 잡혔는지를 저장해 밸런스 근거로 쓴다.
- **0089-6 후속(조건부): 미끼 시민.** 시민 1명에게도 마피아용 질문을 준다. 마피아 승률이 30% 미만이거나 질문 카드 직후에 잡히는 비율이 높을 때 넣는다.
- **0089-7 목표 기준.** 마피아 승률 40~50%, 4~8명, 라운드당 2~3분(참고 목표, 고정 제한 아님).
- **0089-8 기존 작업 처리.** 코드는 지우지 않는다. 확장판(`extended`)은 방장 선택에서 숨기고, 3D 캐릭터·광장·바·조명·몸동작·유령·결과판은 질문 카드 판의 무대로 그대로 쓴다. 버리는 것은 "걸어서 증거 줍기" 고리다.

## 새 페이즈에서 정할 것(검토 때 나온 추천안)

| 항목 | 우려 | 추천안 |
|---|---|---|
| 답 공개 방식 | 동시 제출이면 마피아가 시민 질문을 모른 채 찍어야 해 첫 라운드에 쉽게 잡힌다 | 낸 순서대로 바로 공개. 마피아는 남의 답을 보고 맞출 수 있지만 기다리면 망설임이 드러난다 |
| 질문 쌍 | 너무 비슷하면 단서가 없고, 너무 다르면 바로 잡힌다 | 한국어 질문 쌍 50개 이상을 다듬어 넣고, 쌍별 잡힌 비율을 0089-5 로 기록한다 |
| 망설임 단위 | 카톡 확인·한글 입력 속도 같은 잡음 | 초 단위 대신 빠름·보통·늦음 세 단계 |
| 마피아 2명 | 같은 대체 질문이면 둘의 답이 닮아 함께 드러난다 | 우선 같은 질문, 너무 쉬우면 마피아끼리도 질문을 다르게 |
| 한 줄 입력 | 지금은 템플릿 메시지뿐(자유 채팅 없음) | 답 한 줄만 자유 입력 허용 |
| 스티커 | 결정 0051(글 최소) | 빠른 메시지 "의심돼요/믿어요"를 한 번 누르는 스티커로 |
| 통계 | 친구끼리 판 수로는 30판 넘어야 의미 | 기록은 바로 시작, 봇이 낀 판은 통계에서 뺀다 |

- 코드 전에 카카오톡 종이 테스트(사회자가 개인 메시지로 질문, 단톡방에 한 줄 답, 투표)로 질문 쌍의 재미와 잡히는 속도를 먼저 볼 수 있다.
