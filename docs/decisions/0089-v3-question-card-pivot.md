## 결정

첫날 키워드 문제

- **0089-1 첫날에만 키워드 문제를 낸다.** 마피아 게임의 첫날은 근거가 없어 느낌으로 처형하므로, 그 빈자리를 키워드 문제가 채운다. 둘째 날부터는 원래 마피아(자유 채팅 토론 → 투표 → 처형 → 밤)다. 매일 내면 주객이 바뀐다.
- **0089-2 장르와 키워드는 서버가 무작위로 고른다.** 장르 6~8개(영화·음식·동물·장소 등), 장르마다 누구나 아는 키워드 30개 이상. 한 글자 키워드는 넣지 않는다. 키워드마다 별칭(한국어·영어·짧은 이름)을 둔다. 목록은 Claude 가 초안을 만들고 사용자가 검토한다.
- **0089-3 키워드 카드.** 화면에 문제 카드로 띄운다: 맨 위 `장르 : 영화`, 가운데 키워드를 크게, 아래 각주 `* 직접적인 키워드는 언급하면 안 됩니다.` 마피아에게는 키워드 자리가 `???` 로 보인다(서버가 마피아에게 키워드를 보내지 않는다 — 결정 0002·누설 규칙). 카드를 읽는 3초는 답 시간에서 뺀다.
- **0089-4 답은 10초 · 20자 한 줄.** 시민도 곱씹지 못하게 짧게 둔다(즉답에 버릇이 묻어난다). 수치는 플레이 후 조정한다.
- **0089-5 키워드와 우회 표기는 쓸 수 없다(마피아 포함 모두 검사).** 답에서 글자가 아닌 것(공백·`.`·`_`·`-`·이모지 등)을 지우고 소문자로 바꾼 뒤 키워드·별칭이 들어 있으면 막는다(`해.리.포.터`, `해리_포터`, `Harry Potter`, `해리potter` 모두 막음). 3글자 이상 키워드는 초성도 막는다. 철자를 일부러 틀린 우회(`hery foter`)는 막지 않고 매너에 맡긴다.
- **0089-6 마피아는 검사로 떠볼 수 있다.** 마피아가 찍은 단어가 막히면 그것이 키워드다. 떠보는 대가는 시간이며 제출 순서로 드러난다(0089-7). 너무 자주 맞히면 그때 "막힌 횟수 공개"를 검토한다.
- **0089-7 모두 내면 한꺼번에 공개하고, 낸 순서를 ①②③으로 붙인다.** 망설임 시간은 따로 재지 않는다.
- **0089-8 시간 안에 못 내면 쓰던 글을 그대로 낸다.** 비어 있거나 금지어가 있으면 "답 없음"(맨 끝 순서).
- **0089-9 첫날 흐름: 역할 확인 → 키워드 카드 → 답 → 공개 → 토론 → 투표·처형 → 정답 공개 → 밤.** 정답은 첫날 처형 뒤 밤 직전에 모두(마피아 포함)에게 공개한다("아, 그래서 안경이었구나"). 첫날 답은 기록 카드에 남아 판 내내 추궁 재료가 된다.
  - 메모(채택 아님): 4~5명 판에서 마피아가 첫날에 너무 자주 잡히면 "키워드 → 바로 밤(첫날 처형 없음)"으로 바꾼다.

의심 포스트잇(둘째 날 이후의 위트 있는 정치 장치)

- **0089-10 낮에 의심 가는 사람 앞으로 가서 "의심" 포스트잇을 붙인다.** 투표·판정에는 영향이 없다. 가까이 가야 붙일 수 있다. 하루에 한 사람당 한 장, 붙인 사람은 다른 사람에게 옮길 수 있고 받은 사람은 뗄 수 없다. 다음 날 아침에 떨어지고 그날 기록은 기록 카드에 남는다.
- **0089-11 포스트잇 에셋은 디테일이 좋아야 한다.** "의심" 글자가 적힌 작은 포스트잇이 캐릭터 몸에 실제로 붙은 모양(살짝 기울기, 들린 모서리, 옅은 그림자). 얼굴·옷 특징·이름표처럼 더 중요한 것을 가리지 않는다. 머리 위에 띄우지 않는다. 색은 붙인 사람의 좌석 색을 옅게 — 누가 붙였는지 지나치게 드러낼 필요는 없다. 여러 장이면 살짝 겹쳐 쌓인다.

판 종류·제거·유지

- **0089-12 판 종류 구분(기본 마피아/확장판)을 없애고 이 시나리오 하나로 고정한다.** 방장 줄의 판 종류 단추·시트를 지운다.
- **0089-13 확장판 기능을 모두 제거한다**: 심부름, 등불(심지 자르기), 마을 맵(실내 방·집 여덟·벽 시야), 밤 집 찾기, 아침 현장 조사(발자국·옷 조각·창문), 의심 보드, 목격 기록, 아침 밤 흔적, 건너뛰기.
- **0089-14 유지**: 밤 살해 뒤 피해자 자리의 흰 분필 윤곽(결정 0061-14), 재즈 바·시계탑 광장 맵, 3D 캐릭터·걷기·몸동작·의상, 단계 조명, 자유 채팅, 유령 관전, 결과판, 봇, 방장 줄, 소리.
- **0089-15 튜토리얼은 새 시나리오 기준으로 다시 만든다**(첫날 키워드 문제 → 토론·투표 → 밤 → 포스트잇).
- **0089-16 판 결과를 기록한다**: 승리 진영, 마피아가 잡힌 날, 첫날에 잡혔는지, 장르·키워드, 마피아가 키워드를 떠봐서 맞혔는지. 봇이 낀 판은 통계에서 뺀다. 밸런스 판단의 근거다(목표 마피아 승률 40~50%, 4~8명).

함께 고칠 것

- **0089-17 유령을 줄이고 걷는 방향으로 돌린다(0084-3 개정).** 3D 유령이 산 캐릭터와 키가 같고 몸이 통통해 너무 크다 → 산 캐릭터의 약 75%. "늘 카메라를 본다" 때문에 이동할 때 옆·뒷모습이 안 보인다 → 산 캐릭터처럼 이동 방향으로 몸을 돌린다(사용자 피드백 2026-11-16).

낮 투표·유언·시상 (2026-11-16 추가 확정)

- **0089-18 낮 투표는 찬반 → 차례 지목 → 처형이다.** 토론 → 찬반(집계 수만 공개, 던진 표의 과반이 찬성이면 진행, 아니면 바로 밤) → 한 명씩 차례로 지목(0063-1 순차 지목을 다시 켠다. 고르는 순간은 모두 보지만 기록으로 남기지 않는다 — 각자 기억한다) → 최다 득표자 처형. 동점이면 처형 없이 밤. 0072-2·3(동시 투표·`day.points` 공개)과 0066-3(찬반 기록 카드)을 개정한다. 누가 무엇을 골랐는지 정리해 보여 주는 화면(지목 기록·찬반 기록 카드·기록 카드의 투표 기록)은 없앤다. 서버는 판정에 필요한 만큼만 내부에 둔다.
- **0089-19 최후 변론과 유언을 "유언" 하나로 통일한다.** 처형자는 스포트라이트 아래 10초 동안 유언을 쓰거나 고친다(미리 쓴 글이 채워진 채 시작). 다 쓰면 모두에게 보이고 처형된다. 밤 피해자는 살아 있을 때 미리 쓴 유언이 아침에 같은 장면으로 보인다(죽은 뒤에 쓰면 유령 관전 정보가 샐 수 있어 새로 쓰지 않는다). 별도의 최후 변론 단계는 없앤다.
- **0089-20 시상식을 없앤다.** 서버 칭호 계산(`shared/game/awards.ts`)까지 지운다(화면은 0083 에서 이미 지움). 억울상도 넣지 않는다. 필요해지면 나중에 붙인다.
- **0089-21 첫 판 로그(0089-16)는 Cloudflare D1 표에 판당 한 줄**로 남기고 npm 명령 하나로 조회한다. 열: 승리 진영, 마피아가 잡힌 날, 첫날에 잡혔는지, 장르·키워드, 마피아 떠보기 성공 여부, 인원, 봇 수, 판 길이, 이탈 수, 포스트잇 수, "답 없음" 수, 튜토리얼을 켰는지. 닉네임·채팅·답 글은 저장하지 않는다. 봇이 낀 판은 표시해 통계에서 뺀다. 행동별 이벤트 로그는 남기지 않는다.
- **0089-22 봇은 키워드 답을 내지 않는다**(늘 "답 없음").
- **0089-23 키워드 목록은 Claude 가 만들어 넣고 진행하며, 사용자가 나중에 검토한다.** 목록은 한 파일에 모은다.

단계 넘기기 (2026-11-16 추가)

- **0089-26 버튼을 늘리지 않고 "전원이 끝내면 자동으로 넘어간다."** 개인 행동 단계(찬반·밤 고르기·키워드 답)는 산 사람 전원이 끝내면 남은 시간과 상관없이 다음 단계로 간다(번복 여유로 찬반은 마지막 표 뒤 1.5초). 공동 시간 단계(토론)는 지금처럼 과반 끝내기, 유언은 [남기기]. 연출 단계(처형·아침 발표)는 넘길 수 없다. 개인 [넘기기] 버튼은 만들지 않는다. 밤 조기 마감은 누설 시험으로 타이밍이 역할을 흘리지 않는지 확인한다. 구현은 23페이즈.
