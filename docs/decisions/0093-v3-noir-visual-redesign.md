# 0093 v3 그래픽과 화면을 달빛 누아르로 전환

- 날짜: 2026-11-18
- 기준: [승인된 B안](../../design/v3.0/redesign/b-noir.png)

재즈 바 조명과 맵 카드 시범에 이어 현재 v3에서 쓰는 3D 모델, 이미지 에셋, UI를 같은 디자인으로 전환한다. 기능과 디자인을 합친 로컬 빌드를 검증한 뒤 `minifia-v3`에 한 번 배포한다.

- **맵** — 재즈 바는 창살 사이의 서늘한 빛과 따뜻한 무대등, 실내 소품으로 공간을 읽게 한다. 시계탑 광장은 옅은 바깥빛과 따뜻한 가로등으로 색온도를 달리한다. 맵마다 모델과 채광을 바꾸고 카메라·이동 규칙과 조작 UI는 공유한다.
- **인물과 그림** — 무대 캐릭터와 카드·선택 목록의 인물 비율과 재질을 맞춘다. 역할 소품은 비공개 역할 카드에만 쓰며, 공개 의상과 실제 역할은 독립적으로 유지한다.
- **화면** — 남색·상아색, 가는 선과 각진 모서리를 공통 요소로 쓴다. 첫날 키워드는 종이 카드, 실제 선택은 대비와 간격으로 알아볼 수 있게 한다. 좁은 화면에서는 이름표와 채팅·선택 버튼을 먼저 읽을 수 있어야 한다.
- **검증** — 로컬에서 두 맵, 작은 폰과 키보드, 8인 장면의 가독성과 성능을 확인한다. 배포 뒤에는 상태 응답, 정적 이미지, 4인 스모크와 D1 기록을 확인한다.
