# 0094 v3 첫 추리와 토론 흐름 개선

2026-11-18. [팀 플레이 피드백](../playtest-v2.0-feedback.md)에서 텍스트로 의심할 근거를 발견하기 어렵다는 문제가 나왔다. 첫날 키워드와 공개 답, 둘째 날 이후의 유언과 의심 포스트잇을 토론에서 다시 쓰기 쉽게 만든다.

- **첫날 답**을 채팅 위에서 읽고 접을 수 있다. 공개 답 한 줄을 누르면 작성자와 답이 채팅 초안에 들어간다. 전송 여부와 덧붙일 질문은 플레이어가 정한다. 답 전체와 제출 순서는 기록 카드에서 다시 볼 수 있다.
- **아침 유언**은 해당 날에 공개된 자료를 토론에서 인용할 수 있게 한다. 유언의 원문은 기존 공개 채팅 기록을 사용한다.
- **튜토리얼**은 모두 답을 낸 상황에서 시작한다. 그럴듯한 답도 질문을 받으면 허점이 드러나는 장면을 지나 실제 토론·지목·밤 선택과 의심 포스트잇을 경험한다.
- **캐릭터**는 여덟 좌석의 3D 외형과 인물 그림을 맞춘다. 공개 의상과 비공개 역할은 계속 독립적으로 정한다.

실제 팀 플레이에서 답을 근거로 질문이 나온 시점, 지목이 길게 느껴진 판과 인원, 같은 멤버의 재경기 여부를 확인한다. 지목 제한 8초와 6초 비교 여부는 그 결과로 정한다.

Chrome에서 360×560과 390×844의 답 인용·한글 입력을 검사했다. 4인 로컬 판에서 둘째 날 아침 유언 선택과 인용을 확인했다. 8인 토론 15초 측정에서 두 맵 모두 약 59.9fps, 50ms를 넘는 프레임 0개, 점광원 3개였다. 아침을 보지 못하고 재접속한 경우 해당 유언은 공개 채팅 기록에서 읽는다.
