# 0095 v3 첫날과 첫 아침 플레이테스트

기존 판에서 역할과 목적을 이해하고 첫 선택을 내리기 전에 화면이 여러 번 바뀐다는 플레이 피드백을 받았다. 재즈 바에서 역할 확인, 답을 근거로 한 질문, 한 번의 지목, 밤 행동, 첫 아침의 순서로 검증한다.

- **역할 확인**은 카드를 읽은 뒤 쓰는 준비 단추를 둔다. 참가자가 모두 준비하거나 상한에 도달하면 첫 질문으로 이어진다.
- **키워드와 토론**에는 답을 생각할 시간과 공개 답에 되물을 시간을 둔다. 토론에서 답을 누르면 기존 채팅 초안에 바로 인용된다. [투표]는 최소 토론 시간 뒤에 나온다.
- **첫 투표**에서 사람을 지목하거나 오늘을 보류한다. 모두에게 보이는 결과는 선택된 사람과 집계다. 보류가 앞서거나 동률이면 처형 없이 밤으로 이어진다.
- **밤과 아침**에는 경찰·의사·마피아가 각 역할의 대상을 고른다. 시민은 아침을 기다리고 모두 같은 공개 마감을 본다. 아침 결과를 읽을 시간을 확보한다.
- **화면과 조명**은 한 단계에서 쓸 조작을 먼저 보여 준다. 역할·기록·소리·나가기는 메뉴에 모은다. 낮과 투표의 주변광을 공유하고 밤과 아침은 2.8초 동안 전환한다. 비공개 경찰 카드는 경찰 제복으로 그린다. 실험방에서 기본 외형인 사람은 좌석 외형과 기본 코트를 쓴다.

실험방은 [v3 시험판의 별도 링크](https://minifia-v3.dhplay.workers.dev/?playtest=1) 또는 로컬 `?playtest=1`에서 만들고 일반 초대 경로로 합류한다. 기본 주소에서 만든 방은 기존 규칙을 쓴다. 처음 참여한 사람이 설명을 듣지 않고 첫 질문과 투표 이유를 말할 수 있는지 실기기로 본다.

실험 수치는 역할 확인 상한 55초, 키워드 33초, 첫 토론 45~120초, 첫 투표 28초와 결과 7초, 밤 30초다. 첫 아침에는 기존 발표 시간에 3초를 더한다. 4인 Chrome에서 마지막 참가자의 준비, 답을 인용한 질문, 한 번의 투표, 같은 밤 마감, 첫 아침 결과를 연속해서 확인했다.

360×560과 390×844에서 후보와 메뉴·입력 영역을 확인했다. 390×844, DPR 2, CPU 4배 감속의 재즈 바 8인 토론을 15초 측정했을 때 평균 59.94fps, 50ms가 넘는 프레임 0개, 최대 드로 콜 69개, 점광원 3개였다.

공개 v3에 `2026-11-18T13:45:08Z+3e050a46`을 배포했다. 기본 방의 생성과 참가, 실험방의 별도 링크와 일반 초대, 운영 4인 실험방의 첫 아침 도달을 검증했다. 교체 인물 이미지 11개는 공개 응답과 빌드가 일치했다.
