# 0097 게임 문구와 실험방 연습

화면에서 받는 단어는 ‘제시어’, 참가자가 쓰는 글은 ‘단서’, 카드 위에 표시되는 분류는 ‘주제’라고 부른다. 단서는 ‘모두의 단서’와 역할 카드의 ‘단서와 의심’에서 다시 읽는다. 실제로 인물에게 붙는 종이는 안내와 접근성 이름에서도 ‘의심딱지’라 부른다.

토론의 [투표 요청]은 투표 단계로 넘어가자는 뜻이다. 첫 투표는 참가자를 한 명 고르거나 [오늘은 안 뽑기]를 누른다. 시민은 밤의 [아침 준비]로 본인의 준비를 마친다. 아침에는 탈락과 보호의 결과를 구분해 말한다. 역할 카드에는 각 역할의 첫 행동을 한 문장으로 쓴다.

홈은 연습 버튼을 [혼자 연습하기]로 표시한다. 기본 주소에서는 기본 규칙을 연습하고 실험방 주소에서는 제시어와 단서, 의심딱지, 투표 요청, 첫 투표와 시민의 아침 준비를 실제 조작으로 익힌다. 실험방의 첫 토론은 전원이 동의하면 바로 투표하고, 45초 뒤부터 과반 동의로도 넘어간다. 연습에서 누르는 게임 행동은 브라우저 안에서 처리한다.
