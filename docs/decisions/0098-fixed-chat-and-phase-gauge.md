# 0098 고정 채팅과 상단 시간 게이지

[토론 조작 A안](../../design/v3.0/redesign/fixed-chat-controls.webp)을 일반방과 실험방에 적용한다. 채팅 내역과 입력은 무대 아래 한곳에 고정한다. 키보드가 열리면 내역 높이를 줄여 입력과 전송을 계속 사용할 수 있게 한다. 내역을 위로 스크롤해 읽는 중에는 새 글이 와도 위치를 유지한다.

- 채팅 위 왼쪽에 단서, 감정표현, 의심딱지를 둔다. 유언을 남길 수 있는 때에는 깃펜이 같은 줄에 나타난다. 오른쪽에는 투표함과 요청 인원수를 둔다. 공개 단서를 인용하면 같은 채팅 입력에 추가된다. 조작의 이름은 화면 읽기 도구에 제공한다.
- 단계의 남은 시간은 머리 가운데 고정 폭의 막대로 표시한다. 서버 마감과 전체 길이의 비율에 따라 왼쪽으로 줄어든다. 남은 10초부터 황색, 5초부터 적색이다. 길이가 짧거나 조기 진행으로 마감이 앞당겨진 단계는 기존 예외를 따른다. 화면 읽기 도구에는 남은 초를 제공한다.
- 준비, 제출, 메뉴와 완료 확인은 알아보기 쉬운 아이콘으로 표시한다. 투표 인원수, 역할명, 단서, 채팅과 결과는 읽을 수 있게 둔다. ‘오늘은 안 뽑기’와 방 나가기 확인은 결과를 알 수 있도록 문구를 유지한다.
- 일반 단계의 반복 안내는 화면 읽기 지원용으로 남긴다. 게임 규칙과 마감, 집계와 참가자에게 공개하는 정보는 서버가 정한다.

## 토론 화면 디자인

채팅은 A안의 청회색 바탕과 얇은 구분선을 쓴다. 메시지는 공개 좌석 초상화 옆에 발신자와 말풍선을 두 줄로 배치한다. 배경에서 기록 상자의 테두리를 빼고, 44px 사각 전송 버튼을 입력칸과 같은 높이로 둔다. 도구는 아이보리 선 아이콘과 둥근 사각 타일로 표시한다.

토론 머리에는 제목, 남은 시간 게이지, 점 세 개 메뉴를 둔다. 역할과 기록, 소리, 방 나가기는 메뉴에서 접근한다. 무대 위 이름표는 어두운 면을 쓰고 자신의 이름만 밝은 면으로 표시한다. 무대 구도는 실제 플레이 위치를 따라간다.
