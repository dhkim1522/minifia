# 0099 홈에서 결과까지 공통 화면 디자인

달빛 누아르의 무대와 토론 A안의 청회색 조작부를 첫 진입부터 한 판이 끝날 때까지 함께 사용한다. 단계별 정보와 행동의 순서는 기존 게임을 따른다.

- 홈 제목은 ‘미니피아’, 부제는 ‘우리 중 누가 마피아일까?’다. 새 배경은 재즈 바 테이블에 모인 세 사람을 보여 준다. 초대 링크 미리보기도 같은 장면을 쓴다.
- 홈 하단에 방 코드 입력과 참가, 방 만들기를 둔다. 기본·실험방 모두 혼자 연습하기 진입점을 거둔다. 초대 링크, 재입장, 실험방 생성은 계속 제공한다.
- 청회색 패널, 어두운 입력 면, 상아색 선 아이콘, 선택·주요 행동의 따뜻한 강조색을 사용한다. 아이콘의 접근성 이름과 시간 게이지의 경고 색을 유지한다.
- 대기실에서는 네 자리 코드와 공유를 함께 표시한다. 토론에서는 채팅과 도구가 고정된다. 다른 단계에는 같은 말풍선과 입력 면을 적용하면서 해당 단계의 채팅 권한과 기록 열기를 유지한다. 결과에서는 승리 진영, 공개된 역할, 준비·다시 시작을 무대와 패널에서 확인한다.

다음 작업은 신규 참가자의 실제 플레이 흐름 검토다. 투표 요청의 인원수와 실제 투표 구분, 공개 단서 열람 아이콘, 의심딱지와 대상 선택·이동 순서를 우선 확인한다. 발견 사항을 한 번에 모아 기능 변경 범위를 정한다.

## 공통 글꼴과 위계

- 홈 제목부터 결과까지 시스템 고딕을 공유한다. 처형 결과와 정답처럼 제목과 내용이 있는 발표는 제목 20px, 내용 16px를 쓴다. 아침과 승패처럼 한 문장이 곧 발표 제목이면 32~36px·900·행간 1.2를 쓴다. 홈 제목은 별도 크기 범위를 사용한다.
- 카드와 시트 제목은 20px, 단계명은 18px, 본문과 입력은 16px, 채팅 목록과 보조 정보는 14px로 조판한다. 제목·단계명·조작에는 굵기 700을 쓰고 일반 본문은 400으로 읽는다.
- 유언과 쪽지는 제목에 시스템 고딕, 내용에 나눔손글씨 펜을 쓴다. 유언 본문은 작성 22px, 처형 때 공개 24px, 채팅 기록 21px로 조판한다. 아침 편지는 제목 20px, 본문 19~24px를 쓰며 작은 화면에선 편지 폭을 넓혀 긴 유언이 들어가게 한다. 쪽지의 작성·기록은 18px·16px다.
- 글꼴과 글의 역할은 `design/tokens.json`에서 관리한다. 손글씨 파일은 자체 호스팅하며 글자 범위별로 필요한 파일을 불러온다.

## 검증

- 모바일 Chrome 에뮬레이션 320×568, 360×560, 390×844에서 직접 조작과 화면 배치 55개를 확인했다. 7명이 먼저 들어온 초대에서 마지막 참가자의 닉네임과 제출 버튼도 확인했다.
- 일반방·실험방의 역할 확인과 제시어, 토론·투표, 일반방 밤 행동과 시민 승리 결과를 검수했다. 360×560 대기실·채팅·제시어·밤·아침의 브라우저 검사 125개가 통과했다.
- 타입 검사, 클라이언트·단위 7,360개, 게임 서버 567개가 통과했다. 실제 휴대폰 키보드·터치와 신규 참가자의 적응은 다음 플레이 검토에서 확인한다.
- `minifia-v3` 공개 버전은 `2026-11-18T18:36:27Z+ff470bb1`이다. 홈 원화와 초대 이미지의 실제 응답이 로컬 파일과 일치하며, 공개 주소에서 방 생성과 코드 터치 공유, 다른 브라우저의 초대 참가를 확인했다. 같은 공개 버전의 4인 게임에서 토론·투표·밤을 거쳐 마피아 승리가 났고, 재접속 후 채팅 복원도 확인했다.
- 공통 글꼴 버전 `2026-11-19T07:51:10Z+9a846bdf`에서 타입 검사와 단위·클라이언트 테스트 7,366개를 통과했다. 로컬 Chrome 320·390px에서 제시어·토론·유언 흐름과 긴 발표, 유언·쪽지의 실제 손글씨를 확인했다. 공개 홈과 초대 참가, 일반방 제시어·채팅, 별도 완료 판의 시민 승리 발표에서 새 글꼴을 확인했다. 실제 휴대폰 검수는 남아 있다.
- 시스템 고딕 위계 버전 `2026-11-19T08:07:51Z+a18ec3b9`에서 타입 검사와 단위·클라이언트 테스트 7,365개를 통과했다. Chrome 320·390px에서 발표와 카드의 글자 크기 차이, 50자 유언 전체 표시와 필기체 로딩을 확인했다. 공개 홈, 초대 참가, 승패 발표와 아침 유언·쪽지를 확인했다. 처형 발표의 반응형 크기 검사도 320px에서 재실행해 통과했다.
- 제목과 본문을 나눈 `2026-11-19T08:20:46Z+3c77d41c`에서 320·390px의 처형, 제시어 공개와 유언·쪽지를 검수했다. 긴 닉네임과 50자 유언은 본문을 잘라내지 않고 표시했다. 공개 320px 처형·제시어 공개와 390px 유언·쪽지에서 제목이 본문보다 큰 것을 확인했다.
- 글자를 키운 뒤 320·390px Chrome에서 50자 유언 작성·처형 공개·아침 편지·채팅 기록을 다시 확인했다. 320px에서 접힌 도크 위에 편지 안내와 진행 막대가 들어오고 쓰기 연출이 끝나면 마지막 글자까지 보인다.
