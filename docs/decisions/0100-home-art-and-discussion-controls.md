# 0100 실제 게임 모델로 만든 홈과 토론 도구의 표현

첫 화면에서 본 인물을 대기실에서도 알아볼 수 있게 홈 배경에 실제 좌석 모델 세 명과 재즈 바를 사용한다. 카메라와 조명은 홈의 제목과 하단 입력 영역에 맞춰 배치한다. 렌더링은 그림을 만들 때 한 번 실행하고, 홈과 초대장은 정적 이미지를 읽는다.

홈 촬영에서 테이블 양옆 의자 두 개를 빼고, 동물 세 마리가 테이블을 둘러싼 구도를 사용한다. 홈 제목은 [공통 시스템 고딕](0099-unified-game-ui.md)으로 조판하고, 제목과 부제 사이에 재즈 바 벽 장식을 닮은 얇은 황동색 선을 둔다. 홈과 초대 미리보기의 새 이미지는 별도 캐시 버전으로 읽는다.

홈 테이블 왼쪽의 도윤과 마피아 의상 미리보기, 역할 카드에는 선글라스와 빨간 띠 중절모를 쓴 같은 인물을 사용한다. 어느 좌석에서 마피아 의상을 골라도 이 인물이 된다. 역할을 확인한 마피아는 자기 화면에서도 이 모습으로 플레이한다. 다른 참가자의 화면에는 각자가 고른 공개 의상만 보이고, 판이 끝나면 살아남은 마피아의 직업 의상을 모두에게 보여 준다.

대기실 하단은 모든 참가자가 같은 위치에서 읽고 입력하는 채팅 전용 영역이다. 방장만 쓰는 시작 버튼은 채팅 위에 따로 배치한다. 참가자에게 별도 행동이 없는 대기 상태는 ‘대기실’ 제목으로 전달한다. [마피아 모델과 방장·참가자의 대기실 비교](../../design/v3.0/redesign/mafia-lobby.webp)

토론의 채팅과 도구 타일을 공통 조작부의 기준으로 삼는다. 기본 버튼은 청회색 면과 가는 선, 단계를 진행하는 행동은 따뜻한 윤곽과 글자, 이미 고른 선택지는 밝은 테두리로 표시한다. 역할 카드와 유언 편지에는 각 콘텐츠의 종이 재질을 유지한다.

토론 도구에서 단서 열람과 채팅 인용을 제거했다. 소리는 공통 스피커 아이콘으로 켜고 끈다. 처음 브라우저에서 재생을 허용해야 할 때도 같은 위치에서 같은 크기의 버튼을 누른다. 화면 읽기 도구에는 동작 이름과 현재 상태를 제공한다. 여러 사람이 동의해야 진행되는 토론 스킵처럼 아이콘만 보고 결과를 짐작하기 어려운 게임 조작에는 짧은 글을 쓴다.

‘토론 스킵’을 누르면 토론을 일찍 끝내는 데 동의한다. 버튼에는 현재 동의 인원과 필요한 인원, 선택 후에는 ‘스킵 취소’를 표시한다. 일반방은 생존자 과반, 실험방 첫날에는 사람 참가자의 전원 동의 또는 45초 뒤 과반이 기준이다. 다음 단계의 실제 투표는 기존 절차를 따른다.

## 전 구간 공통 규격

대기실, 게임, 관전, 결과는 같은 하단 기록·입력 영역을 쓴다. 기록은 제자리에서 스크롤한다. 키보드가 열리면 기록 칸을 줄여 입력줄을 키보드 위에 둔다. 채팅 권한이 없는 역할 확인과 밤 선택에는 해당 단계의 조작을 표시하고, 유언처럼 기록 열람만 가능한 곳에서는 입력을 잠근다. 밤 관전 채팅도 같은 하단에서 읽고 쓴다.

헤더 오른쪽 메뉴에 소리를 두고, 게임 중에만 내 역할과 기록을 제공한다. 시간은 헤더 중앙의 게이지로 보여 준다. 역할 카드는 카드 자체의 강조와 뒤집기로 조작을 전달한다. 지목에서는 차례 상태와 고를 대상을 표시한다.

채팅 위에는 맵이 보이도록 하고 버튼마다 남색 바탕을 둔다. 현재 쓸 수 있는 반응·의심·유언·꾸미기 도구가 왼쪽부터 일정한 간격으로 이어진다. 토론 스킵과 다음 판 준비는 오른쪽에 둔다. 버튼이 없는 단계는 도구 줄이 접힌다. 찬반 투표와 밤 대상 선택은 [중앙 단계 카드](0103-phase-events.md)에서 진행한다.

공용 도구 타일의 터치 영역은 44px, 조작부의 모서리는 11px, 일반 카드·시트의 모서리는 16px이다. 입장 양식은 키보드로 작성하기 편한 48px 입력을 쓴다. 발표 카드, 유언, 결과 연출에는 내용에 맞는 재질을 유지하고, 공간별 색온도는 각 맵 조명이 정한다.

## 배포 검증

[공개 v3에서 캡처한 홈·대기실·토론 스킵·찬반 투표](../../design/v3.0/redesign/game-model-controls.webp). 배포 버전은 `2026-11-19T01:10:26Z+50026a5a`다. 공개 홈·초대 미리보기 파일을 저장소의 그림과 대조하고 브라우저 두 개로 초대 참가를 확인했다.

로컬 일반방·실험방·공개할 단서가 없는 방의 모바일 브라우저 검사 51개가 통과했다. 단서 인용, 스킵 동의와 취소, 필요 인원 충족 뒤 실제 투표 집계까지 확인했다. 320px·390px에서 조작부의 너비와 터치 영역을 검사했다. 클라이언트·단위 시험 7,361개, 서버 시험 567개가 통과했다.

공개 일반·실험 4인 검수방의 브라우저 검사 36개도 통과했다. 서로 다른 참가자의 화면에서 스킵 요청·취소가 반영되고, 필요한 인원에 도달한 뒤 실제 찬반 또는 인물 선택이 서버에 반영됐다. 실기기 터치·키보드는 추후 팀 플레이에서 확인한다.

공용 화면의 공개 버전은 `2026-11-19T04:48:23Z+c4d1ddc8`이다. Chrome 320px의 두 참가자로 대기실부터 결과까지 한 판을 돌려 메뉴 좌표, 채팅 송수신·유언 잠금, 밤 관전 채널과 결과를 확인했다. 브라우저 오류는 없었다. 로컬 일반방 320·390px, 실험방 320px, 8자 닉네임 아침 알림과 키보드 배치도 확인했다. 새 얼굴 20개와 의상 미리보기 9개는 공개 응답과 로컬 파일이 일치했다.

맵 위 도구를 적용한 `2026-11-19T05:07:32Z+5d7cbbd2`는 로컬 320px 광장·390px 재즈 바와 공개 320px 광장에서 대기실부터 결과까지 검수했다. 버튼 사이로 맵이 보이고 빈 영역의 입력이 맵에 닿는다. 조작 아이콘과 이름표는 겹치지 않았고, 채팅 위치와 찬반·밤 대상 선택도 확인했다.

홈 개편 버전 `2026-11-19T07:33:16Z+bb45caa5`를 공개 Chrome 320·390·430px와 데스크톱에서 검수했다. 제목이 한 줄로 표시되고, 배경과 하단 입장 양식이 겹치지 않았다. 320px 방 만들기와 별도 390px 브라우저의 초대 참가를 확인했다. 홈 배경·공유 미리보기·제목 폰트의 공개 응답이 배포 파일과 일치했다.

원탁 양옆 의자를 뺀 `2026-11-19T07:37:44Z+9f24989c`는 같은 네 화면 크기에서 공개 홈, 방 만들기와 초대 참가를 검수했다. 재즈 바 단위 테스트와 배경·캐시 검사도 통과했다.

데스크톱은 홈 배경을 창 높이와 그림 비율에 맞춰 넓혀 동물 세 마리를 모두 보여 준다. 제목과 입장 양식은 가운데 최대 430px 폭을 유지한다. 세로로 긴 좁은 창에서는 그림 위아래를 배경색으로 이어 준다. 터치 화면에는 기존 배치를 적용한다.

공개 `2026-11-19T12:13:30Z+104261c0`에서 데스크톱 1032×1174, 1280×800, 400×1000 홈과 대기실·낮을 PC E2E 12건으로 확인했다. 390×844 모바일 Chrome은 이전판과 구도가 같았다. 전체 시험의 정적 가드 3건은 Windows 경로 비교에서 실패했다.

폭 430px 이하이며 높이 600px 이하인 대기실은 감정 표현판을 도구 아래에 연다. 360×560 Chrome에서 얼굴과 이름이 보이고, 감정 표현 9칸을 탭하면서 채팅 기록을 스크롤하거나 입력할 수 있음을 확인했다. 320×568과 360×640에서도 감정 표현과 키보드 전환을 검수했다.
