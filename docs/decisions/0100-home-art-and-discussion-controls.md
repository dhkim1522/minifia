# 0100 실제 게임 모델로 만든 홈과 토론 도구의 표현

첫 화면에서 본 인물을 대기실에서도 알아볼 수 있게 홈 배경에 실제 좌석 모델 세 명과 재즈 바를 사용한다. 카메라와 조명은 홈의 제목과 하단 입력 영역에 맞춰 배치한다. 렌더링은 그림을 만들 때 한 번 실행하고, 홈과 초대장은 정적 이미지를 읽는다.

홈 테이블 왼쪽의 도윤과 마피아 의상 미리보기, 역할 카드에는 선글라스와 빨간 띠 중절모를 쓴 같은 인물을 사용한다. 어느 좌석에서 마피아 의상을 골라도 이 인물이 된다. 역할을 확인한 마피아는 자기 화면에서도 이 모습으로 플레이한다. 다른 참가자의 화면에는 각자가 고른 공개 의상만 보이고, 판이 끝나면 살아남은 마피아의 직업 의상을 모두에게 보여 준다.

대기실 하단은 모든 참가자가 같은 위치에서 읽고 입력하는 채팅 전용 영역이다. 방장만 쓰는 시작 버튼은 채팅 위에 따로 배치한다. 참가자에게 별도 행동이 없는 대기 상태는 ‘대기실’ 제목으로 전달한다. [마피아 모델과 방장·참가자의 대기실 비교](../../design/v3.0/redesign/mafia-lobby.webp)

토론의 채팅과 도구 타일을 공통 조작부의 기준으로 삼는다. 기본 버튼은 청회색 면과 가는 선, 단계를 진행하는 행동은 따뜻한 윤곽과 글자, 이미 고른 선택지는 밝은 테두리로 표시한다. 역할 카드와 유언 편지에는 각 콘텐츠의 종이 재질을 유지한다.

토론 도구에서 단서 열람과 채팅 인용을 제거했다. 소리는 공통 스피커 아이콘으로 켜고 끈다. 처음 브라우저에서 재생을 허용해야 할 때도 같은 위치에서 같은 크기의 버튼을 누른다. 화면 읽기 도구에는 동작 이름과 현재 상태를 제공한다. 여러 사람이 동의해야 진행되는 토론 스킵처럼 아이콘만 보고 결과를 짐작하기 어려운 게임 조작에는 짧은 글을 쓴다.

‘토론 스킵’을 누르면 토론을 일찍 끝내는 데 동의한다. 버튼에는 현재 동의 인원과 필요한 인원, 선택 후에는 ‘스킵 취소’를 표시한다. 일반방은 생존자 과반, 실험방 첫날에는 사람 참가자의 전원 동의 또는 45초 뒤 과반이 기준이다. 다음 단계의 실제 투표는 기존 절차를 따른다.

로컬 일반방·실험방·공개할 단서가 없는 방의 모바일 브라우저 검사 51개가 통과했다. 단서 인용, 스킵 동의와 취소, 필요 인원 충족 뒤 실제 투표 집계까지 확인했다. 320px·390px에서 조작부의 너비와 터치 영역을 검사했다. 클라이언트·단위 시험 7,361개, 서버 시험 567개가 통과했다.

공개 일반·실험 4인 검수방의 브라우저 검사 36개도 통과했다. 서로 다른 참가자의 화면에서 스킵 요청·취소가 반영되고, 필요한 인원에 도달한 뒤 실제 찬반 또는 인물 선택이 서버에 반영됐다. 실기기 터치·키보드는 추후 팀 플레이에서 확인한다.
