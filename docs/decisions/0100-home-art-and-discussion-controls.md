# 0100 실제 게임 모델로 만든 홈과 토론 도구의 표현

첫 화면에서 본 인물을 대기실에서도 알아볼 수 있게 홈 배경에 실제 좌석 모델 세 명과 재즈 바를 사용한다. 카메라와 조명은 홈의 제목과 하단 입력 영역에 맞춰 배치한다. 렌더링은 그림을 만들 때 한 번 실행하고, 홈과 초대장은 정적 이미지를 읽는다.

토론의 채팅과 도구 타일을 공통 조작부의 기준으로 삼는다. 기본 버튼은 청회색 면과 가는 선, 단계를 진행하는 행동은 따뜻한 윤곽과 글자, 이미 고른 선택지는 밝은 테두리로 표시한다. 역할 카드와 유언 편지에는 각 콘텐츠의 종이 재질을 유지한다.

토론에서 돋보기를 누르면 공개된 답이나 유언을 다시 읽을 수 있었다. 기록에 읽을 말이 있을 때만 ‘첫날 단서’ 또는 ‘아침 유언’을 표시하고, 눌러 읽거나 채팅에 인용할 수 있게 한다. 첫날 제시어와 단서 작성은 추리의 재료로 유지한다.

‘토론 스킵’을 누르면 토론을 일찍 끝내는 데 동의한다. 버튼에는 현재 동의 인원과 필요한 인원, 선택 후에는 ‘스킵 취소’를 표시한다. 일반방은 생존자 과반, 실험방 첫날에는 사람 참가자의 전원 동의 또는 45초 뒤 과반이 기준이다. 다음 단계의 실제 투표는 기존 절차를 따른다.
