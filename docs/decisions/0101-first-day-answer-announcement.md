# 0101 첫날 라이어 게임의 답안 발표

라이어 게임은 첫날 의심을 시작하는 장치다. 각자 답을 쓰고 토론에 들어가면 화면 중앙에 참가자 이름과 답안을 함께 보여 준다. 표시할 답이 없는 참가자는 ‘미제출’로 표시한다. 발표는 서버 기준 최대 10초 동안 열리며, 먼저 읽은 사람은 확인을 눌러 토론으로 돌아갈 수 있다. 재접속 시에는 발표가 끝나기 전 남은 시간만 표시한다.

토론이 계속되면 역할 메뉴는 공개 의심딱지 기록과 역할별 활동을 보여 준다. 첫날 정답 공개는 답안 목록과 별개의 마무리 장면이다. 첫날 밤부터는 해당 판의 답안과 정답을 참가자 화면에 다시 보내지 않는다. 게임이 첫날 바로 끝나면 결과는 승패와 실제 역할을 보여 준다.
