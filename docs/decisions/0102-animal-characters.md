# 0102 미니피아의 동물 캐릭터

달빛 누아르의 재즈 바에 12종의 동물 미니어처가 등장한다. [토끼·코끼리·악어·펭귄·여우·돼지 원화](../../design/v3.0/redesign/animals/lineup-1.png)와 [사자·숫양·개구리·앵무새·고슴도치·박쥐 원화](../../design/v3.0/redesign/animals/lineup-2.png)를 기준으로 삼는다. 토끼의 얼굴과 귀는 흰색, 귀 안쪽과 목 부분의 포인트는 연보라다.

- 처음 입장하면 사용 중인 동물을 제외하고 무작위로 하나를 받는다. 참가자는 대기실에서 빈 동물을 선택할 수 있다. 같은 방의 참가자와 봇은 서로 다른 동물을 쓰고, 재접속하거나 같은 방에서 다음 판을 해도 자신이 고른 동물은 유지된다.
- 전신 모델과 초상화는 머리 모양, 색, 귀·뿔·코·부리를 공유한다. 채팅과 모두의 답, 투표는 같은 얼굴과 닉네임을 쓴다. 초상화는 3D 모델에서 렌더링한다. 대기실과 결과 옷장에는 현재 동물이 입은 9개 의상의 그림을 사용한다.
- 역할은 동물과 별도로 배정한다. 마피아의 빨간 띠 중절모와 선글라스, 경찰의 모자와 배지, 의사의 가운과 십자 표식은 자기 동물 위에 입힌다. 옷을 입어도 동물을 찾을 수 있게 머리 외곽선을 남긴다. 실제 역할 의상은 본인 역할 화면과 역할 공개가 허용된 화면에서 보여 준다.
- 동물 모델은 기존 이동·이름표·감정표현과 같은 관절과 조명을 쓴다. 코트와 소매는 끝을 둥글게 만들고, 걷거나 팔을 들 때 몸통과 맞닿게 한다. 모자는 종별 이마와 정수리에 맞춰 챙과 각도를 조정한다. 역할 카드에 필요한 이미지는 본인 동물의 네 역할 모두 미리 받아, 요청 패턴이 역할에 따라 달라지지 않게 한다.

## 이미지 재생성

로컬 개발 서버를 켠 뒤 `node scripts/render-noir-assets.mjs http://127.0.0.1:5173 --animal-portraits-only`로 얼굴·전신·역할과 12종 × 9개 옷장 이미지를 만든다. 홈과 초대 링크 미리보기는 `node scripts/render-entry-scene.mjs http://127.0.0.1:5173`와 `node scripts/make-og.mjs`를 순서대로 실행한다.

`--faces-only`로 채팅·답안·기록의 200×200 초상화 20개를 재생성할 수 있다. 실제 모델의 머리를 가운데 배치하고, 화면의 이름 옆에서는 동일한 25px 초상화 부품으로 표시한다. 표준 의상 파일은 동물과 구형 인물 모두 작은 그림 144×192를 쓴다. 확대 전신과 역할 그림은 같은 3:4 비율의 288×384다.

## 배포 검증

공개 v3 `2026-11-19T02:39:27Z+0e21e39c`에서 8인 중복 방지, 선택 변경과 잠금, 본인 마피아 그림, 12종 얼굴과 48개 기본·역할 그림 로드를 확인했다. 일반방·실험방 로컬 검수는 320px와 390px에서 채팅·답안·재접속을 포함했다. 4인판에서는 종료 화면의 역할 의상과 탈락자의 유령 전환을 확인했다.

같은 390×844, DPR 1의 Mac Chrome 헤드리스 8인 재즈 바 비교에서 15초 평균은 두 버전 모두 60fps였고 50ms 초과 프레임은 없었다. 동물 12종과 공용 의상 9종을 조합해 관절 메시와 삼각형 예산을 검사했다. 실물 휴대폰 측정은 남아 있다.

관절과 모자 보정 뒤 12종의 의상 9개를 정면과 옆면에서 확인했고, 기본 코트로 걷기와 가리키기 자세를 확인했다. 같은 8인 장면에서 평균 60fps, 프레임당 삼각형 95,298개를 기록했다. 공개 v3 `2026-11-19T03:16:40Z+18678e20`의 옷장 그림 108개가 로컬 파일과 일치했다. Chrome 모바일 화면 320px와 390px에서 개구리의 탐정·기자·후드·마피아 착용과 걷기·가리키기, 코끼리로 바꾼 뒤 의상 9개와 기자 착용을 확인했다.
