# 0103 게임 단계의 핵심 행동과 결과를 중앙에 배치

토론에서 계속 쓰는 조작은 맵 아래에 모이고, 서버가 특정 단계에서 요구하는 행동은 그 단계의 중앙 장면에서 완료한다. 화면 상단에는 단계와 시간 게이지를, 하단에는 허용된 채팅과 보조 도구를 둔다.

- 찬반은 질문, 선택, 공개 집계를 한 카드로 보여 준다. 관전자는 집계를 읽는다. 실험방 첫날 지목은 후보 얼굴과 보류를 함께 보여 주고, 집계가 끝나면 같은 위치에서 결과를 발표한다.
- 첫날 제시어 카드에는 답안 작성과 제출 상태까지 포함한다. 실험방 역할 카드는 본인의 역할과 확인 행동을 같은 카드에 둔다.
- 밤에는 본인에게 허용된 대상이나 아침 준비를 중앙에 보여 준다. 순차 지목과 결선처럼 맵에서 상대를 직접 고르는 단계는 이름표를 써서 선택하고, 단계의 끝에 결과를 발표한다.
- 처형 대상자의 마지막 유언은 해당 참가자에게만 중앙에서 작성하게 한다. 공개 처형과 유언, 정답과 아침 결과는 각 단계에서 한 번 보여 준다. 경찰의 조사 결과는 경찰 본인에게만 표시한다.
- 선택 가능 범위, 마감, 조기 진행, 공개 범위는 서버가 정한다. 채팅을 입력할 때 키보드가 차지한 높이를 반영하고, 캔버스가 가려지는 영역은 카메라 계산에서 제외한다.
