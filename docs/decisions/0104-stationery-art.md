# 0104 달빛 누아르의 종이 소품

유언장, 봉랍, 역할 카드 앞·뒷면, 제시어와 답 모음의 종이, 역할 일지, 쪽지의 재질을 바꾼다. 맵·동물 모델과 홈 배경은 현재 버전을 사용한다. [3D 개선 참고 시안](../../design/v3.0/redesign/imagegen-3d-reference/README.md)은 향후 비교를 위해 보관한다.

- `public/stationery/`의 WebP 9개를 사용한다. 역할 카드의 초상과 글, 유언의 제목·줄·본문, 일지 기록은 화면이 그린다. 종이 이미지에는 글자와 고정 줄이 없어 실제 글의 길이에 맞춰 배치할 수 있다. 봉랍과 편지는 기존 등장·찍힘·접힘 시점을 따른다.
- Codex 내장 ImageGen에서 승인된 보드를 참고해 미세한 면지 결, 음각 모서리와 작은 부채꼴 장식을 지닌 평평한 상아 유언지를 만들었다. 봉랍은 색이 짙은 와인색 초승달을 찍은 정면 이미지로 생성하고 투명 알파를 내보냈다. 남색 카드·일지 표지·쪽지는 같은 승인 보드의 해당 부분을 내보냈다.
- 종이 소품은 역할 정보와 관계없이 방 입장 뒤 함께 미리 받는다. 배경 이미지가 늦거나 실패해도 동적 내용은 읽을 수 있다. 역할별 일지 제목과 기록은 서버가 허용한 화면에서만 표시한다.
- Chrome 모바일 에뮬레이션 320×568·390×844에서 역할 카드, 50자 유언과 봉랍, 쪽지, 일지 및 대기실 이동을 검수했다. 390px의 아침 발표와 유언 간격은 전후 버전에서 동일 조건으로 다시 재생해 확인했다. 실기기 검수는 남아 있다.
- 최초 공개판 `ef5cd4b0`에서 암살일지 ‘사망’의 글자 대비가 3.76:1로 낮아져 붉은 결과 글자를 밝힌 `5d7cd272`를 다시 배포했다. 로컬 320·390px 실제 기록에서 암살일지 5.70:1, 수사일지 ‘마피아’ 5.13:1·5.12:1을 확인했다. 최종 공개판의 390px 암살일지도 5.70:1이었다.
