# 0105 하단 채팅과 게임 조작

채팅 내역과 입력을 하나의 얇은 테두리와 둥근 모서리로 감싼다. 조작 도구는 채팅 위의 무대에 둔다. 대기실·토론·투표·관전·결과에서 같은 하단 위치를 사용한다. 기록 칸은 기존 92px에서 화면 높이에 따라 116~144px로 넓히고, 키보드가 열리면 42px로 접힌다. 달라진 무대 크기에 맞춰 카메라의 이동 반폭을 5.7로 조정했다. 상단 시간 게이지는 단계 이름과 오른쪽 조작 도구를 빼고 남는 폭을 채운다.

방장 전용 조작은 위치와 접근성 이름으로 구분한다. 상단 점 세 개 메뉴와 방 나가기 확인은 중앙 모달로 표시한다. 메뉴에는 게임 중의 내 역할과 기록, 소리 아이콘, 방 나가기를 마련한다.

의심딱지를 고르면 붙일 수 있는 캐릭터의 몸 윤곽과 이름표를 함께 강조한다. 화면에서 캐릭터의 몸을 눌러 붙이며, 키보드나 화면 읽기 도구로는 이름표의 버튼에 접근한다. 옷 위의 종이는 붉은 색조로 보이고, 부착 가능 거리와 시점은 서버 규칙을 따른다.

[종이 소품과 3D 참고 시안 보관](0104-stationery-art.md)은 별도 결정에 기록했다.

Chrome 모바일 에뮬레이션에서 320·360·390px의 맵 이동, 채팅과 중앙 이벤트를 검수했다. 재즈 바와 시계탑 광장에서 실제 3D 캐릭터를 눌러 딱지가 서버에서 반영되는 것을 확인했다. 재즈 바 8인에 딱지 8장을 붙인 15초 측정에서는 변경 전후 평균 60fps, 50ms 초과 프레임 0개였다. 실기기 확인은 남아 있다.
