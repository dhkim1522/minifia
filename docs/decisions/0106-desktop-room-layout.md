# 0106 데스크톱 방 화면의 공통 폭

데스크톱 브라우저에서 게임에 들어가면 방 화면이 430px 폭에 머물러, 시계탑 광장의 밤처럼 세로로 긴 화면에서 맵의 양옆이 가려졌다. 방 전체에 최대 960px 폭을 적용해 대기실, 역할 확인, 제시어, 게임, 관전, 결과가 같은 무대 틀을 쓴다. 캔버스는 실제 폭에 맞춰 그린다. 기존 카메라의 픽셀 배율을 사용하므로 같은 위치에 있는 캐릭터 크기는 유지된다.

상단 헤더와 하단 채팅·조작은 가운데 최대 600px 열에 둔다. 중앙 선택 카드, 메뉴, 기록은 읽기 편하게 폭을 제한한다. 데스크톱 규칙은 마우스처럼 정밀하게 가리키고 호버할 수 있는 입력 환경에 적용한다. 홈과 초대 화면은 같은 입장 배경 규칙을 써서 긴 데스크톱 창에서도 그림의 좌우가 보인다. 터치 조작의 모바일 레이아웃은 기존과 같다.

시계탑 광장의 밤 장면으로 DPR 1에서 15초씩 측정했다. 430×1221과 960×1221 모두 평균 143.6fps, 50ms 초과 프레임 0개였다. 드로 콜은 57개에서 70개로 늘었다.
