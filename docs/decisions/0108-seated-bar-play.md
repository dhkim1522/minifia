# 0108 재즈 바 눈높이와 탈락자 시야

[4~8인 고정 좌석 시안](../../design/v3.0/seated-camera-review/index.html)을 재즈 바의 낮 토론과 순차 지목에 적용한다. 대상 선택과 자유로운 둘러보기는 각 플레이어의 화면에서 이루어진다.

- 서버는 판 시작 명단의 논리 좌석마다 물리 의자를 한 번 배정한다. 의자 여덟 개를 두고 4인은 한 칸씩, 5~7인은 빈자리가 연속되지 않게 앉는다. 탈락과 재접속 후에도 처음 정한 자리를 쓴다. 의자 출입점과 테이블 충돌 범위는 같은 좌표를 사용한다.
- 두 가지 시점은 자기 자리 눈높이와 테이블 전체 보기다. 내 의자에 도착하면 같은 눈높이 확대를 쓰며, 수평으로 밀거나 화면에 보이는 얼굴을 눌러 방향을 바꾼다. 참가자 목록에서 화면 밖의 상대에게도 접근할 수 있다.
- 재즈 바의 의심딱지는 거리에 관계없이 서버가 허용한 상대를 고른다. 화면과 일차별 기록은 받은 사람과 장수를 보여 준다. 공개 순차 지목은 확정 구간에 가리키는 동작을 보인다.
- 새 공개 채팅을 받은 시점의 단계와 연결을 확인해 듣는 캐릭터가 발화자를 잠시 본다. 자신이 고른 상대와의 맞눈길은 자기 화면에만 보인다.
- 마지막 유언과 처형 동안 중앙 무대를 드러낸다. 첫날 투표와 밤의 역할별 조작, 아침 결과, 유령 이동, 광장 카메라는 각 단계와 기존 접근 권한을 따른다.
- 공개 퇴장 연출 후 생존자의 장면에서 탈락한 몸과 이름표를 거둔다. 탈락 관전자에게는 머리 위 이름표와 직업 아이콘 없이 같은 동물의 실제 직업 의상을 보여 준다. 탈락한 몸은 반투명하게 그리고, 밤의 선택 고리는 발밑에 남긴다. 직업·채팅·이동의 공개 범위는 서버가 정한다.
