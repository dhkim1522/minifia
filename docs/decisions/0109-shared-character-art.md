# 0109 화면 전체에 공용 동물·재즈 바 에셋 적용

로비에서 걷고 있을 때부터 착석, 동작, 관전, 결과까지 같은 동물의 얼굴 조형을 쓴다. 자세·표정과 공개 의상은 각 화면의 상태에 따라 달라진다. 재즈 바는 개선한 테이블과 소품을 홈·초대 이미지와 대기실·게임 장면에서 공유한다. 각 맵의 조명과 단계에 맞는 연출을 적용한다.

채팅·대상 선택·참가자 목록은 공용 얼굴 이미지, 초대 입장은 전신 이미지, 옷장과 역할 카드는 해당 의상 이미지를 쓴다. 이 이미지들은 모두 같은 12종 Three.js 모델에서 렌더링한다. 정적 관전 그림을 쓰는 경우에도 본래 캐릭터에 투명도를 적용한다.

개발 서버에서 `node scripts/render-noir-assets.mjs http://127.0.0.1:5173 --3d-art-refresh`를 실행하면 동물 이미지 168개, 재즈 바 맵 카드와 배경, 홈과 초대 미리보기를 함께 만든다. 공용 이미지와 홈의 캐시 버전을 올리고 초대 메타데이터도 같은 버전을 쓴다. 배포 전에 홈, 초대 입장, 로비, 옷장, 역할 카드, 게임, 결과에서 해당 모델과 이미지가 읽히는지 확인한다.
