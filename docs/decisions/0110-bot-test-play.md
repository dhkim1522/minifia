# 0110 4~8인 봇 연습과 기본 봇 행동

- 방장은 [대기실 채팅 위의 봇 아이콘](0117-room-control-width-and-lobby-bots.md) 또는 테스트 도구를 열어 전체 4~8명 중 하나를 눌러 인원을 맞춘다. 서버는 실제 참가자를 유지하고 봇 수만 조절한다. `testBots` 메시지와 방장에게 보내는 `me.testBots`를 공유하며, 한 명씩 조절하는 버튼도 쓸 수 있다.
- 기본 봇은 첫날 키워드의 공개 장르에 맞춰 서로 다른 짧은 답을 낸다. 답은 일반 제출 검사를 거치고 조기 종료는 사람의 제출에 따라 진행한다. 낮 토론은 문구와 발언 시점이 다르고, 둘째 날부터 재즈 바의 일부 봇은 의심딱지를 붙인다. 재즈 바에서 딱지에는 대상과 장수가 보이고 공개 지목 때 가리키는 연출을 쓴다.
- 마피아 봇은 동료가 고른 유효한 대상을 따르고, 먼저 고를 때는 방·판·일차에 따라 대상이 달라진다. 경찰·의사와 찬반·지목은 각 단계의 서버 판정을 따른다. 테스트 도구에서 봇의 찬반이나 지목 대상을 고정한 방은 기존 재현용 동작을 유지한다.
