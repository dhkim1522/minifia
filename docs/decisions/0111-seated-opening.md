# 0111 재즈 바 착석 후 역할 확인

재즈 바에서는 게임을 시작하면 플레이어가 배정된 원탁 의자로 모인다. 역할 확인은 착석 뒤에 열린다. 역할 카드, 첫날 라이어게임, 첫 토론이 같은 자리와 눈높이에서 이어진다.

- 서버는 역할 배정 시간에 기존 4~8인 의자로 이동을 시작한다. 이동 목적지와 역할 공개 시점은 서버가 정한다. 재접속과 다시 하기에도 같은 흐름을 적용한다.
- 배정 중에는 역할을 공개하지 않는다. 역할 카드와 라이어게임의 기존 입력과 서버 마감 규칙을 적용한다. 두 단계 동안 테이블은 조작이 없는 배경으로 쓰고, 토론에서 참가자 조작을 연다.
- 광장에서는 원래의 역할 확인 무대를 쓴다. 밤·유언·결과는 해당 단계의 구도를 적용한다.
