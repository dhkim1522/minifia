# 0112 재즈 바 한 곳과 착석 시점

대기실과 게임은 재즈 바에서 진행한다. 맵을 정하는 조작은 없으며 예전 방에 저장된 선택값도 재즈 바로 정리한다.

- 대기실에서는 캐릭터가 걸어 다닌다. 게임을 시작하면 서버가 4~8인 명단에 의자를 배정한다. 착석이 끝나면 각자의 자리 높이로 전환하고 역할 카드를 공개한다.
- 라이어게임, 투표, 유언, 처형, 밤과 아침, 결과는 자기 자리의 눈높이로 이어진다. 플레이어는 자리에서 고개를 돌려 상대를 볼 수 있다. 탈락한 사람도 같은 자리를 기준으로 보고, 유령과 밤 정보는 권한이 있는 사람에게 표시한다.
- 탈락 관전 화면에서는 머리 위 이름표와 직업 아이콘을 숨기고 서버가 이미 관전자에게 공개한 직업을 실제 3D 의상으로 보여 준다. 관전자는 밤에도 의상을 보고, 살아 있는 참가자의 밤은 공개 후드 연출을 따른다.
- 다시 하기는 새 참가 명단을 기준으로 착석부터 시작한다. 결과의 승패, 직업 공개, 채팅과 다시 하기 조작은 같은 원탁 위에 표시한다.
- 결과 연출이 끝나면 하단에서 방장은 ‘다음 판 시작’, 손님은 ‘다음 판 준비’를 읽는다. ‘메인으로’는 퇴장을 확인한 다음 홈으로 이동한다.
- Chrome 320·1280px 결과 화면에서 메인 이동 확인·취소를 검수했다. 360px 방장과 430px 손님으로 같은 방에서 준비를 마치고 다음 판의 역할 확인 화면까지 진행했다.
- 390×844 Chrome에서 처형 후 관전부터 밤·아침과 다음 낮을 확인했다. 관전자의 의상과 이름표 생략, 생존자에게 관전 정보가 전달되지 않는 조건을 포함한 86개 검사가 통과했다.
- 공개 v3 `2026-11-22T18:28:28Z+942c52e4`에서 모바일·데스크톱 첫날 지목, 유언, 탈락 관전, 양쪽 승리 결과와 재경기 E2E 185개가 통과했다.
