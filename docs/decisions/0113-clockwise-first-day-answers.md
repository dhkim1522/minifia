# 0113 원탁 순서대로 라이어 답 발표

첫날 라이어게임은 각자 단서를 작성하고 제출하는 시간과, 원탁을 돌며 답을 듣는 시간으로 이어진다. 가장 먼저 유효한 답을 제출한 사람부터 시작하고, 다음 답은 실제 의자 배치의 시계방향으로 진행한다. 빈 의자는 건너뛴다.

- 순서의 기준은 서버가 받은 확정 제출이다. 작성 중인 초안은 첫 발표자를 정하는 데 쓰지 않는다. 확정 제출이 없으면 원탁의 기준 의자부터 시작한다. 마감에 남은 유효한 초안은 해당 의자의 답으로 읽고 답이 없으면 ‘미제출’로 표시한다.
- 한 차례는 5초다. 서버는 지금 발표하는 사람과 답만 보내며 재접속할 때도 남은 차례를 이어 준다. 발표 화면은 자기 의자 눈높이에서 상대 발표자 쪽으로 돌아간다. 자기 차례에는 자기 답을 읽는다.
- 다른 사람이 발표하는 동안 답 옆에서 의심딱지를 붙일 수 있다. 기존 하루 한 장을 사용하며 다른 대상에 붙이면 옮겨진다. 딱지는 첫 토론으로 이어지고 지목 투표와 승패는 기존 규칙에 따라 별도로 결정한다.
