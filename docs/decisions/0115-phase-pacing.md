# 0115 시간 게이지, 지목 얼굴판, 전원 스킵

- 상단 헤더의 둘째 줄에 시간 게이지를 둔다. 브라우저의 연속 애니메이션을 서버 마감 시각에 맞춰 재생한다. 새 단계와 차례마다 새로 시작하며 마감 변경, 시계 보정, 탭 복귀 때 다시 맞춘다. 기존 경고색과 접근성용 남은 초를 유지한다.
- 재즈 바의 처형 지목은 얼굴판에서만 보낸다. 내 선택은 얼굴판의 해당 칸에 남는다. 후보 이름표의 깜빡임과 지목된 캐릭터로 움직이는 조명을 지운다. 현재 차례인 사람의 표식과 캐릭터가 가리키는 동작은 계속 보인다.
- 역할을 전원이 확인하거나 키워드 답안, 찬반, 첫날 특별투표, 밤 선택을 마치면 서버가 조기에 진행한다. 순차 지목은 선택한 차례부터 진행하고, 대상자가 마지막 유언을 제출하면 처형 단계로 간다.
- 건너뛸 수 있는 단계와 차례에는 보통 시작 3초 뒤 헤더 메뉴 옆에 `스킵 0 / 6`이 나타난다. 같은 버튼을 다시 누르면 동의를 취소한다. 생존한 사람 전원이 동의하면 해당 단계나 차례를 서버의 마감 규칙으로 끝낸다. 테스트 봇과 유령은 필요한 인원에서 빠지며, 연결이 끊긴 생존자는 재접속해 참여할 수 있다. 다른 사람의 동의 여부는 합계로만 보인다.
- 건너뛰기 표는 단계와 차례가 바뀔 때 초기화된다. 스킵은 첫날 투표 결과가 뜬 뒤 3초, 처형 단계 시작 뒤 5초에 열린다. 아침에는 발표를 볼 수 있게 단계 시작 뒤 4.6초, 피해자 유언 편지가 있으면 8.1초에 열린다. 스킵이 열린 뒤 마감까지 0.8초를 확보할 수 없는 구간과 착석·인트로·정답 공개는 시간표대로 이어진다.
