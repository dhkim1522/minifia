# 0117 방 조작부 폭과 대기실 봇 버튼

- 방은 화면 폭을 최대 960px까지 써서 원탁과 캐릭터를 보여 준다. 공통 방 레이아웃의 상·하단 조작부는 최대 480px로 가운데에 놓고, 그보다 좁은 화면에서는 가용 폭을 쓴다. 화면 폭을 기준으로 하므로 터치 태블릿에도 같은 규칙을 적용한다.
- 채팅 위 기능 줄에서 방장은 꾸미기 옆의 로봇 아이콘으로 봇 시트를 연다. 인원 설정과 한 명씩 추가·제거하는 조작은 같은 시트에 있다. 별도 테스트 메뉴에서 제공하는 재현용 조작도 계속 쓸 수 있다.

## 로컬 검수

- 타입 검사, Vitest 7,877개, 브라우저 검사 스크립트 단위 시험 535개를 통과했다.
- Chrome 터치 에뮬레이션 320·390·430·768px에서 하단 탭 25/25씩, 1280px 데스크톱에서 23/23을 확인했다. 390·768px 봇 인원 설정 9/9와 대기실에서 역할·키워드까지 이어지는 흐름 33/33을 각각 통과했다. 데스크톱 입장부터 밤·결과까지 32/32를 통과했다.
- 실제 두 참가자로 320·390·1280px에서 봇 인원 4→8→4 변경과 참가자의 버튼 숨김을 확인했다. 봇 시트를 닫은 뒤 버튼에 초점이 돌아왔고, 모바일 키보드를 닫은 뒤에도 채팅 초안이 유지됐다.
