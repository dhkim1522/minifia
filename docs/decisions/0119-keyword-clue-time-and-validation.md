# 0119 첫날 단서 시간과 제시어 검사

일반방과 실험방에서 제시어 카드가 보이면 바로 단서를 쓸 수 있다. 제한 시간은 35초이며 입력칸 옆에 남은 초를 표시한다. 사람 참가자가 모두 제출하면 기존 조기 진행 규칙을 적용한다.

제시어와 등록된 별칭이 포함된 단서는 공개할 수 없다. 띄어쓰기, 기호, 대소문자, 한글 자모의 표기 차이를 정리해 판정한다. 한글 세 글자 이상인 제시어는 초성만 직접 입력한 표현도 검사한다. 예를 들어 제시어가 고양이면 `고양이처럼 조용해요`, `고 양 이`, `ㄱㅇㅇ`는 걸리고 `가을이`는 허용된다.

- 제시어를 아는 플레이어에게는 수정 안내를 자신이 쓴 단서 아래에 표시한다. 판정은 서버가 맡고 다른 참가자에게는 입력하거나 고친 사실을 보내지 않는다.
- 마피아의 제출 접수는 제시어 일치와 무관하다. 서버가 공개 전에 제출과 남은 초안을 검사하고, 금지 단서는 `미제출`로 표시한다. 판 기록의 떠보기 성공은 기존에 저장한 값을 읽는다.
- 첫 유효한 확정 제출자의 자리부터 원탁의 시계방향으로 답을 발표한다.

[결정 0091](0091-v3-keyword-day-one.md)의 입력 시간, 금지어 검사, 금지 단서의 접수·공개 기준을 갱신한다. 발표 순서는 [결정 0113](0113-clockwise-first-day-answers.md)을 따른다.
