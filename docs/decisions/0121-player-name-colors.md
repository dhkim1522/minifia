# 0121 참가자 닉네임 고유색

- 같은 참가자의 닉네임은 공개 좌석 번호로 정한 고유색을 쓴다. 무대, 채팅, 참가자 목록, 기록에서 같은 색을 쓰며 의상, 역할, 선택에 따라 색을 바꾸지 않는다.
- 닉네임 옆의 식별용 색 점을 제거한다. 본인, 선택, 채널과 의심 개수는 글자·아이콘·테두리로 구분한다. 밝은 닉네임의 바탕은 어둡게 유지한다.
- 닉네임은 본문에 비해 짧은 식별 정보로 쓰고, 이미 표시 권한이 있는 공개 좌석에만 색을 부여한다. 자리 정보가 없는 시스템 문구에는 공통 글자색을 쓴다.

## 검수

- 320·390·1280px Chrome에서 무대, 참가자 탭, 채팅, 의심 기록의 같은 좌석색과 채팅 미리보기 색을 비교했다. 참가자 탭 E2E 88건을 통과했다. 8인 목록 두 페이지, 의상과 무관한 색, 키보드 초안 유지, 밤의 대상 선택과 공개 범위를 확인했다.
- 320px 로비 이동 검사의 목적지 탐색 실패는 이 변경 전 공개판에서도 재현됐다. 390px 로비 움직임과 이름표 검사는 통과했다.
