# 0121 부드러운 동물 캐릭터 외형

[밤 지목 시안](../../design/v3.0/redesign/night-hood-selection.png)의 둥근 얼굴과 차분한 색감, 부드러운 코트를 미니피아의 공용 3D 캐릭터에 적용한다. 현재 동물 12종의 실루엣과 구분되는 특징을 유지한다. 시안의 개구리, 고슴도치, 여우는 색과 표정, 볼과 입 주변의 조형을 직접 대조한다.

- 같은 모델에서 채팅·발표 얼굴, 참가자 상반신, 전신, 역할 카드와 공개 의상 그림을 만든다. 참가자 카드는 귀와 모자를 포함해 가슴까지 보이는 프레임으로 따로 렌더한다. 홈과 초대 그림도 같은 모델에서 다시 만든다.
- 목과 코트, 어깨와 소매, 소매와 손이 정면·측면·후면에서 자연스럽게 이어지는지 확인한다. 걷기, 앉기, 가리키기, 팔을 드는 동작과 모자·안경 의상도 확인한다.
- 작업 기준은 `v3`의 `45e10d41`이며 별도 `design/soft-animal-characters` 브랜치에 둔다.

## 검수

- 기본 코트, 공개 후드와 주요 모자 의상을 3D로 확인했다. 반대편을 가리킬 때 소매가 가슴 안으로 들어가는 부분과 고슴도치의 윗가시가 마피아 모자띠를 가리는 부분을 보정했다.
- 참가자 카드에는 투명 배경의 224×224 WebP를 쓴다. 12종과 공개 의상 9개의 조합을 모두 렌더하면서 가장자리 알파와 빈 그림을 검사했다.
- 전체 자동 시험 7,886개, 타입 검사와 빌드가 통과했다. 로비 꾸미기 버튼 배치 관련 E2E `AD1a`는 320·390px에서 공개 기준판과 동일하게 실패한다. 실제 꾸미기와 옷장 이미지는 정상 경로에서 다시 확인했다.
- 재즈 바 정상 진입점에서 모바일 390×844와 데스크톱 1280×800의 입장·옷장·역할 확인·낮과 밤의 참가자 지목·결과를 확인했다. 데스크톱 결과는 고정 4인 방에서 시민·마피아 승리와 관전을 검수했다. 320×568에서도 밤 후드, 새 카드 네 장, 두 줄 이름과 하단 조작의 배치를 확인했다.
- 390×844 헤드리스 Chrome, CPU 4배 감속, 8명 토론 15초를 공개 기준판과 로컬에서 비교했다. 재즈 바·광장 모두 평균 60fps, 50ms 초과 끊김 0회였다. 프레임 시간 p95는 재즈 바 16.7→16.8ms, 광장 16.7→16.7ms였다. 휴대폰 실기기 확인은 남아 있다.
