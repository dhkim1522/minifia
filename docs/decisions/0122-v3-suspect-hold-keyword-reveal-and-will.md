# 0122 참가자 딱지 조작과 첫날 공개 흐름

## 참가자와 답안 발표

- 낮 토론의 참가자 카드는 짧게 누르면 상대를 바라본다. 의심 가능한 카드를 700ms 누르면 붉은 테두리가 차오르고, 시간이 지난 뒤 손을 뗄 때 한 장을 붙인다. 같은 상대에 반복하면 떼고, 다른 상대에 하면 옮긴다. 배치나 단계가 바뀌거나 손가락이 이동하면 진행 표시를 취소한다. 가로 밀기는 기존 참가자 페이지를 넘긴다.
- 공개 받은 수는 기존 카드 배지에 남는다. 내 화면에서 내가 붙인 상대의 딱지 아이콘만 속을 채워 표시한다. 바라보는 상대는 기존 금색 테두리로 표시한다. 다른 페이지에 대한 딱지 안내나 자동 이동은 추가하지 않는다. 도구 탭은 키보드와 길게 누르기 대체 경로로 유지한다.
- 답안 발표에서는 해당 발표자에게 기존 버튼을 한 번 눌러 붙인다. 홀드 테두리와 같은 진홍 계열의 `의심!`과 중립 회색의 `의심 해제`를 사용한다. 회색 버튼은 밝은 글자·테두리와 채워진 딱지로 구분한다.

## 첫날 라이어게임

- 단서 입력 화면에서 상시 안내 문장을 걷고 `단서 입력`을 표시한다. 제시어 직접 입력 제한과 오류 안내는 유지한다.
- 마지막 답안이 끝나면 모든 사람에게 제시어를 3초 동안 한 번 보여 주고 낮 토론을 연다. 공개 전에는 마피아에게 제시어를 보내지 않으며 발표 중에는 현재 답 한 줄만 보낸다. 공개 후에는 `답과 의심` 기록에서 제시어와 답안을 다시 읽을 수 있다. 이전 버전에서 이미 첫날 토론에 들어간 방은 시작한 순서대로 진행한다.
- [결정 0091](0091-v3-keyword-day-one.md)의 제시어 공개 시점을 갱신한다. 참가자 답안 순서는 [결정 0113](0113-clockwise-first-day-answers.md), 금지 단서 판정은 [결정 0119](0119-keyword-clue-time-and-validation.md)을 따른다.

## 공개 유언

- 사망 후 공개 편지 본문은 28px에서 시작해 공간에 맞춰 25px 또는 22px을 쓴다. 글씨를 줄이기 전에 편지 공간을 늘리고, 짧은 화면에서 긴 유언은 인장을 제목 옆으로 올려 본문 폭을 확보한다. 처형 때 공개하는 유언 인용도 28px을 쓴다.

## 로컬 검수

- 실제 브라우저에서 320×568·390×844·1280×800 참가자 조작과 지목 126/126을 확인했다. 답안 발표·입력은 36/36, 처형 없는 밤은 29/29, 밤·유언·관전은 149/149였다. 테스트 방의 첫날부터 다음 낮까지 통합 검사 41/41을 통과했다.
- 320×568의 실제 4인방 사망자 유언이 28px 세 줄로 보였고, 50글자와 인장이 모두 편지지 안에 분리되어 있었다. 편지가 접힌 뒤 같은 문장이 채팅에도 남았다.
- Chromium 자동화에서 합성 스와이프 직후의 합성 탭이 클릭을 만들지 않는 현상은 이전 버전과 일반 HTML 버튼에서도 재현됐다. 스와이프와 페이지 화살표 작동은 각각 확인했고 휴대폰 실기기 연속 입력은 확인 대기다.
