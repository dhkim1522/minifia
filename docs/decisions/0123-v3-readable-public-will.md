# 0123 공개 유언의 가독성

## 화면

- [결정 0122](0122-v3-suspect-hold-keyword-reveal-and-will.md)의 글자 확대에 이어, 아침 유언 본문은 22~24px 반굵기 고딕과 1.5배 행간을 쓰고 왼쪽에 맞춘다. 종이는 수평이고, 제목은 16px이며 인장은 제목 줄 오른쪽에 작게 둔다. 본문 영역에 줄무늬와 회전 효과를 두지 않는다. 넓은 화면에서도 편지는 최대 480px이다.
- 편지를 보여 주는 동안 사망 알림은 상단의 작은 상태 줄로 표시한다. 편지는 그 아래, 하단 조작부 위에 놓인다. 처형 때의 인용과 채팅에 남는 공개 유언도 고딕과 왼쪽 정렬을 쓴다.
- 편지가 올라오면 본문이 한꺼번에 보인다. 인장과 접힘 소리는 모션의 시각과 맞춘다. 접히고 채팅에 남는 시각, 아침 페이즈 시간과 유언 글자 수는 기존 계약을 따른다. 이 결정은 [결정 0063](0063-v2-play-feedback-b.md)의 글자별 필기 연출을 갱신한다.

## 검수

- Chrome의 320×568 피해자·390×844 모션 감소 관전자·1280×800 관전자 화면에서 실제 게임의 50자 유언을 확인했다. 본문 크기는 모바일 22px, PC 24px이며 나타나는 모션이 안정됐을 때 모든 문장이 보였다. 모션 감소에서는 처음부터 보였다.
- 본문은 제목과 인장, 상단 알림과 하단 조작부를 가리지 않았다. 편지가 접힌 뒤 채팅과 320px 처형 인용에서도 50글자가 들어왔다. 실제 휴대폰은 확인 대기다.
- 타입 검사, 단위·클라이언트 7,310건과 브라우저 검수 스크립트 464건을 통과했다.
- 유언 입력·공개, 밤·아침·관전 흐름을 확인하는 브라우저 E2E 293/293을 통과했다. 320px와 390px의 최대 유언 검수에서 편지가 등장한 뒤 1초 안에 본문 전체를 읽을 수 있었다.
