# 0124 공개 유언 편지의 읽기 시간과 닫기

- [결정 0063](0063-v2-play-feedback-b.md)의 줄이 있는 편지지, 살짝 기울인 종이, 가운데 정렬한 손글씨와 붉은 인장을 복원한다. 이전 편지보다 본문을 크게 표시하고, 문장은 편지가 올라올 때 한꺼번에 보여 준다.
- 아침 유언의 읽기 게이지를 유지하고 표시 시간을 5초에서 10초로 늘린다. 게이지가 차면 자동으로 접히고, 닫기 버튼을 누르면 먼저 접힌다. 먼저 닫는 동작은 개인 화면에만 적용하며, 공개 시각이 지나면 채팅 기록에서도 같은 유언을 읽을 수 있다.
- 방의 단계 전환과 유언 작성 마감은 기존 시계로 진행한다. 아침에 열린 편지는 단계가 바뀌어도 남은 읽기 시간 동안 개인 화면에 표시한다.
- 편지 본문은 폰 30px부터 PC 32px까지 사용한다. 화면 공간이 작아지면 사망 알림과 인장을 줄이고, 글꼴을 받지 못한 상태에서 본문이 넘치면 직접 스크롤할 수 있게 한다.
