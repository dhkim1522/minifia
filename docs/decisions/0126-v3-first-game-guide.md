# 0126. 실제 첫 게임에서 조작을 안내한다

- 역할 카드 확인, 첫 단서 제출, 의심 표시, 찬반 투표, 지목 투표, 밤 행동, 유령 채팅을 실제 플레이에서 처음 쓸 수 있을 때 안내한다. 답안 발표의 `의심!`과 참가자 카드의 길게 누르기는 조작이 달라 각각 알려 준다.
- 도움말은 해당 조작을 노란색 테두리와 짧게 움직이는 손가락으로 가리킨다. `ⓘ` 옆에 행동과 결과를 한두 줄로 표시한다. 찬반과 투표 후보는 함께 강조해 선택을 유도하지 않는다. 의심 고깔을 씌울 때 차오르는 테두리는 적색 `#F2556A`다.
- 답안 발표 중에는 발표자의 답과 `의심!`을 읽을 공간을 확보한다. 참가자 카드의 길게 누르기 안내는 발표가 끝난 뒤 이어지며, 발표 중 이미 해 본 경우에는 표시를 생략한다.
- 안내는 배너와 연출 뒤에 한 번에 하나씩 표시한다. 게임 시간은 계속 흐르고 조작을 마치거나 단계가 바뀌면 안내가 사라진다. 기기의 동작 줄이기 설정을 따른다.
- 안내 대상 판과 본 항목은 브라우저에 저장한다. 이미 본 항목은 같은 판에 재접속해도 반복하지 않는다. 새 브라우저 또는 저장 데이터를 지운 브라우저는 처음으로 열린 실제 게임에서 안내를 제공한다.
- 역할과 밤 행동은 각자의 화면에서 이미 공개된 정보와 활성 조작에만 맞춘다. 지목 투표는 본인 차례에, 유령 채팅은 탈락 연출이 끝나고 해당 채널을 쓸 수 있을 때 표시한다. 유언 읽기와 제시어 공개는 기존 연출을 사용한다.
