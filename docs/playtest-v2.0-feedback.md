# v2.0 팀 모의 플레이 피드백과 v3.0 방향 메모

- 날짜: 2026-11-07
- 상태: 기획 메모(결정 전). v3.0 마일스톤 기획(`/gsd-new-milestone`)의 입력으로 쓴다.
- 근거: 팀 모의 플레이 2방식 — 같은 공간에서 한 판, 서로 떨어져 텍스트로만 한 판. 두 방식 모두 아래 문제가 같았다.

## 한 줄 진단

게임이 **확인할 수 있는 사실**과 **지금 할 일**을 주지 않는다. 그래서 의심은 사람의 연기에만 기대고, 규칙을 모르는 사람은 처음부터 끝까지 멈춰 있다.

## 문제와 후보

### 문제 1. 정치 장치가 와닿지 않는다(증거가 없다)

- 오프라인 마피아의 재미는 말투·표정·머뭇거림 같은 무의식 신호에서 나온다. 텍스트에는 이 신호가 없고, 같은 공간에서는 실제 대화가 앱 장치(귓속말 등)보다 낫다.
- 귓속말은 숨은 대화라 남이 확인할 수 있는 사실을 만들지 않는다.
- 어몽어스류는 임무·동선으로 **게임이 증거를 만든다**. 말솜씨가 없어도 관찰로 참여한다.
- 후보
  - A. 낮 심부름(추천, 작게 실험): 토론 전 30~40초, 각자 지도 위 2~3곳을 눌러 처리. 마피아는 가짜 목록. 동선은 근처 사람에게만 보인다. 기존 걷기·지도를 쓴다.
  - B. 밤 행동 흔적: 모든 역할이 같은 동작을 하고, 아침에 일부 흔적만 공개.
  - C. 음성 대화: 비용이 크고 친구끼리는 통화로 대신할 수 있어 뒤로 둔다.
- 방향: 실시간 액션 살해까지 가지 않는다. 짧은 판·턴제는 유지하고 증거 장치만 빌린다.

### 문제 2. 시작부터 끝까지 무엇을 해야 할지 모른다

- 오프라인의 사회자("밤이 되었습니다, 마피아는…")가 규칙을 가르치는 역할을 하는데, 앱에는 없다. 결정 0051(글 최소)로 단계 이름만 남았다.
- 낮 한 번의 단계(모이기·토론·순차 지목·변론·찬반·결선·결전·처형·유언)와 장치(직업 주장·귓속말·핀)가 많아 처음 하는 사람이 따라가기 어렵다.
- 후보(추천 순)
  1. 사회자 진행을 기본 구조로: 단계마다 "무슨 일이 일어나는지 + 내 할 일" 한 줄, 누를 대상이 빛남, 할 일이 없는 사람에게도 지금 무슨 시간인지 알려 준다. 음성 낭독은 별도 결정(현재 소리는 합성만, 결정 0070).
  2. 역할 카드에 목표 한 줄.
  3. 진행 단계 단순화(기본판).
  4. 첫 판 말풍선 안내, 봇과 연습 판 — 보조.

### 문제 3. 화면 도구가 무엇인지, 언제·왜 쓰는지 모른다

- 채팅·유언·역할 카드·남은 시간이 아이콘뿐이라 눌러 봐야 안다. 도구가 항상 함께 떠 있어 지금 쓸 것과 아닌 것이 구분되지 않는다.
- 후보(추천: A+B+C 묶음)
  - A. 아이콘 + 한 단어 이름표("채팅", "유언", "내 역할").
  - B. 필요할 때 나타나기·빛나기(지목되면 유언, 밤 시작에 역할 카드).
  - C. 사회자 멘트가 도구를 부른다("유언을 남길 수 있어요" + 단추 빛남).
  - D. 남은 시간을 숫자로 함께.
- 결정 0051은 폐기하지 않고 "글 최소, 기능 이름은 한 단어로 붙인다"로 보완하는 안을 낸다.

## 기존 확장 기능 처리(추천안)

기준: 확인할 수 있는 공개 사실을 만드는가, 사회자 진행을 돕는가. 둘 다 아니면 기본판에서 뺀다. 코드는 지우지 않고 설정으로 끈다.

| 기능 | 추천 | 이유 |
|---|---|---|
| 찬반 기록 카드 | 유지 | 모두가 확인하는 사실 |
| 직업 주장(배지) | 유지·개선 | 공개 주장이라 거짓이 드러나면 증거. 사회자가 쓸 때를 알린다 |
| 유언 | 유지·개선 | 필요할 때 빛나고 사회자가 부른다 |
| 감정표현(몸동작) | 유지·강화 | 몸짓 대체. 심부름 구간에서 쓸모가 커진다 |
| 의상·결과·시상·다시 하기·유령 관전 | 유지 | 헷갈림의 원인이 아니고 몰입을 더한다. 시상은 새 증거 반영 검토 |
| 귓속말 | 기본판에서 끔(정통 판 옵션) | 증거를 만들지 않는 숨은 대화 |
| 순차 지목·결선·마지막 3인 결전 | 기본판은 토론→지목→투표→처형, 나머지는 정통 판 옵션 | 단계를 늘리는 주범 |

- 판 종류: 기본판(사회자·단순 흐름·증거 장치) / 정통 판(+귓속말·결선·결전). 방장이 방 만들 때 고른다.

## 버전 결정(추천)

- **v3.0 새 마일스톤**으로 간다. 게임의 중심 고리(진행·증거·판 종류)가 바뀌고, 결정 0051·09.1.1 정치 장치·진행 단계를 고치며, 조사와 디자인 시안이 먼저 필요하다. v2.0 은 12페이즈까지 끝났으니 마무리 절차로 닫는다.
- v3.0 순서 제안
  1. 사회자 진행 + 도구 이름표 + 역할 목표(문제 2·3) — 먼저 배포해 팀 테스트 재실시
  2. 기본판 / 정통 판 분리
  3. 낮 심부름 / 밤 흔적(문제 1) — 1·2 결과를 보고 설계
- v2.0 마무리: 실기기 확인(`.planning/phases/12-sound-polish/12-TEAM-TEST.md`), 마일스톤 완료 처리, 레포 재생성 결정(D-29, 재생성한다면 v3.0 시작 전이 적기).

## 정하지 않은 것

- 사회자 멘트를 소리로 읽을지(녹음·기기 TTS·글만).
- 심부름 시간·개수·동선 공개 범위, 마피아의 방해 행동 여부.
- 기본판에서 직업 주장을 둘지.
- 판 종류 이름과 고르는 화면.
