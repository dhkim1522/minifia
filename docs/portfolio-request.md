# 포트폴리오 페이지 요청 (2026-11-02)

이력서에서 링크할 미니피아 포트폴리오 페이지를 만든다. v2.0 이 마무리된 뒤에 만든다(개발 중에 만들면 화면·구조 설명이 금방 낡는다).

## 형식과 배포

- 이 레포의 GitHub Pages 로 배포한다. 레포는 public 이다.
- 형식은 런마고치 포트폴리오(https://dhkim1522.github.io/runmagochi/)와 맞춘다. 한 장으로 보는 소개 페이지와, 필요하면 화면설계서·설계 문서로 이어지는 링크.

## 담을 내용

- 앱 소개: 친구들이 각자 폰으로 한 방에 들어와 5~10분 안에 끝내는 실시간 마피아 웹 게임
- 화면 이미지: 첫 화면, 로비(3D 맵), 낮 토론·채팅, 밤 행동, 처형, 결과
- 기획: 왜 만들었는지, 핵심 규칙, 범위 결정
- 시스템 아키텍처: 방마다 Durable Object 하나, 서버 권위(단계·타이머·판정·이동), 플레이어별로 공개 가능한 정보만 보내는 전송 규칙, 토큰 재접속, WebSocket Hibernation
- 설계 결정: `docs/decisions/` 에서 핵심 몇 개를 골라 요약
- 개발 과정: AI 에이전트(Claude Code)로 개발하며 결정 기록·단위/E2E 테스트·배포 가드로 품질을 관리한 방식

## 주의

- 회사 관련 표현을 넣지 않는다.
- 이력서 쪽 링크는 페이지가 생기면 바꾼다. 그 전까지 이력서는 이 레포와 배포 주소를 링크한다.
