# 화면 영역 지도와 자동 검사

> 게임 화면 표는 v1.0 구현 기준(2026-10-30), 대기실은 v2.0 맵 로비(6페이즈, 결정 0044·0050·0055). 숫자의 원천은 코드다: 테이블 기하 `src/game/dayTable.ts`, 장면 표 `src/game/scenes.ts`, 검사 `scripts/e2e/lib.mjs`(상수 `HEADER_H`·`PANEL_H`·`DEFAULT_SIZES`). 값이 바뀌면 코드를 먼저 고치고 이 문서를 맞춘다. 화면 그림은 `design/screens/v1.0/`(S-번호).

## 게임 화면 세 영역

역할 확인·낮·투표·밤·아침 화면은 같은 세 영역이다. 결과 화면만 헤더·타이머 없는 세로 스크롤 한 장이다. 대기실은 이 틀을 쓰지 않고 아래 '대기실 (맵 로비)' 의 층 구조를 따른다.

| 영역 | 높이 | 내용 |
|---|---|---|
| 헤더 | 119.2 (실측, `HEADER_H`) | 단계 이름 · 일차 · 안내 한 문장, 타이머 막대와 숫자, [역할 카드], 테스트 방이면 [테스트] |
| 장면 | 나머지 | 배경 그림 위 고정 원근 테이블과 최대 8자리, 카드 연출 |
| 하단 패널 | 157 (`PANEL_H`), 변론 후보 본인만 236 | 지금 할 일 제목 + 보조 한 줄, 채팅 세 줄 · 빠른 메시지 · 이모티콘, 또는 투표 버튼 · 알약 · 변론 칩 |

## 대기실 (맵 로비)

숫자의 원천은 코드다: 화면 `src/screens/Lobby.tsx`·`src/components/WorldStage.tsx`, 맵·런타임 `src/world/`, 규칙 `shared/game/map.ts`·`world.ts`. 계약서는 `.planning/phases/06-world-skeleton/06-UI-SPEC.md`. v1.0 고정 테이블 로비(자리 슬라이드 · 방장 왕관 · 입장/퇴장 전이)는 06-16 에서 지웠다. 역할 배정부터는 위의 세 영역 틀이다.

캔버스 한 장이 화면 전체를 채우고(`inset: 0`, 헤더 · 패널 · 키보드로 크기가 줄지 않는다) 나머지가 그 위에 얹힌다.

| 층 (아래 → 위) | 위치 · 크기 | 내용 |
|---|---|---|
| 캔버스 (`z-world`) | 화면 전체 | three.js 지하 재즈 바 + 3D 캐릭터 최대 8명. 입력은 바닥 탭 하나 |
| 위쪽 가림막 | 위 0, 높이 120 | `night-900` 88% → 0%. 헤더 글씨 4.5:1 |
| 이름표 층 (`z-tags`) | 캔버스와 같은 크기, 터치 통과 | 머리 위 DOM 이름표. 내 이름표 맨 위, 나머지는 발 y 순서로 쌓음 |
| 헤더 (`z-toast`) | 위 18, 좌우 16, 높이 44 | [나가기] · '대기실' + 접히는 안내 · [공유] |
| TopToast (`z-toast`) | 위 88, 가운데 | 입장 · 퇴장 · 방장 · 시작 조건 한 줄 알림 |
| [테스트] · 재접속 띠 (`z-overlay`) | 헤더 아래 8 / 위 72 (높이 52) | 재접속 띠는 맵 위에 떠서 맵 크기를 바꾸지 않는다 |
| 아래 패널 (`z-overlay`) | 맨 아래, 행동 줄 하나, 높이 88 + 안전 영역 | 방장 [시작] + 점 진행 / 손님 '방장을 기다리는 중…' |
| 상태 카드 · 시트 (`z-modal`) | — | 맵 불러오기 · 오류 카드, 확인 · 공유 시트 |

스테이지 사각형 = 헤더 블록 아래 끝(62) ~ 아래 패널 위 끝 = 높이 − 62 − 88. 카메라는 이 사각형 가운데에 내 캐릭터를 둔다. 카메라 배율은 폰 크기와 무관하게 고정(`PX_PER_UNIT` 58.2)이라 작은 폰은 보이는 맵 영역만 줄어든다.

| 폰 크기 | 스테이지 사각형 | 비고 |
|---|---|---|
| 360×640 | 360 × 490 | E2E 기본 |
| 390×664 | 390 × 514 | E2E 기본 |
| 430×932 | 430 × 782 | E2E 기본 |
| 360×560 | 360 × 410 | E2E 짧은 폰 (7페이즈 채팅이 들어오면 줄어듦) |
| 390×844 | 390 × 694 | 승인 보드 기준 |
| 402×874 | 402 × 724 | iPhone 16 Pro 시각 비교용 |

검사 계약 (E2E 가 읽는 값):

| 값 | 위치 | 뜻 |
|---|---|---|
| `data-world-stage` | 이름표 층 루트 | 맵 로비가 떠 있다 |
| `data-seat` · `data-me` · `data-away` | 이름표마다 | 자리 번호 · 나 · 연결 끊김 |
| `data-front="true"` | 이름표마다 | 다른 이름표와 겹친 것 가운데 맨 앞 하나 — 면이 `overlay-ink-strong`. 겹치지 않으면 속성 없음 |
| `data-ring="x,z"` | 이름표 층 루트 | 목적지 링 위치. 링이 없으면 속성 없음 |
| `data-lobby-start` | [시작] 버튼 | 방장 행동 줄 |
| `window.__mfWorld` | 전역 | `sample(seat, t)` 로 걷는 중 위치를 읽음. `?e2e=1` 또는 개발 빌드에서만 생김 |

3D 캐릭터는 DOM 에 위치가 없으므로 위치 비교는 `__mfWorld.sample` 로 한다. 자동 검사 묶음 G · H 를 폰 크기 6종에 적용한다(H 는 위쪽 가림막 위에서 잰다). 이 계약으로 E2E 를 바꾸는 일은 06-17.

## 폰 폭별 장면 · 테이블

390폭이 승인 시안 P2(결정 0017 · 0028) 기준이고, 다른 폭은 같은 식(`rx = clamp(floor(장면 폭/2 + 여백 − 49), 124, 150)`, 면 폭 = `2·(rx − 38)`)으로 계산한다.

| 폰 폭 | 장면 폭 × 높이 | 장면 좌우 여백 | 좌석 원 rx | 테이블 면 폭 |
|---|---|---|---|---|
| 360 | 352 × 363.8 | 4 | 131 | 186 |
| 375 | 367 × 390.8 | 4 | 138 | 200 |
| 390 | 366 × 387.8 | 12 | 146 | 216 |
| 430 | 406 × 655.8 | 12 | 150 | 224 |

- 장면 높이가 시안(407)보다 짧으면 테이블 전체를 같은 만큼 올린다(관계 불변).
- 장면 높이 299 미만(SE 급 짧은 폰)은 좌석 원 세로 반지름 · 캐릭터 배율 · 면 높이를 같은 배율 `f = (높이 − 26) / 276.8` 로 줄인다. 하한 0.77, 지원 하한 방 높이 516(장면 240). 이름표 글자와 가로 치수는 줄이지 않는다(결정 0038).
- 같은 짧은 화면에서 [테스트] 버튼은 폭 88 → 44 로 좁힌다.
- 캐릭터 72×96, 이름표 한 줄 높이 22(상자 26). 층: 이름표 z 1~11 < 캐릭터 12~22 < 어둡게 30 < 유령 31 < 이모티콘 60+.
- PC 는 가운데에 폰 폭(최대 430)으로 선다.

## 자동 검사 (배포본 E2E, 결정 0025)

`npm run e2e` 가 시스템 Chrome 으로 배포본을 열어 네 크기(360×640, 390×664, 430×932, 360×560)와 고정 흐름 두 개(pc 1280×800, wakelock 360×640)를 돈다. 결과는 열 흐름 × 네 크기 표다. 기준값은 낮추지 않고, 승인된 예외만 `APPROVED_RELAXATIONS` 에 이유와 함께 둔다.

| 묶음 | 무엇을 재나 |
|---|---|
| G | 공통: 글자 14px 이상, 누르기 대상 44px, 가로 넘침 없음, 콘솔 오류 · 다른 출처 요청 없음, 글꼴 로드 |
| H · B | 헤더 글씨 대비 4.5:1(배경 명도 0.8 + 번짐 포함), 단계에 맞는 배경 장면 |
| T · L · D | 단계가 바뀌어도 테이블 고정, 제목 · 버튼 한 줄, 이름표 장면 안 · 겹침 없음, 세로 스크롤 없음, 하단 패널 157 |
| K | 후광은 윤곽 filter 두 겹 · 한 화면 3개 이하 · 발밑 원 없음, 주장 차례 말풍선 하나, 주장 채팅 줄 |
| N · M | 밤 · 낮 시작 문구 한 번, 아침 카드 범위 · 어둡게 층 · 사라짐 |
| R · V | [역할 카드] 버튼 · 탭 · 일지 · 새 기록 점, 관전자만 직업 그림, 살아 있는 사람 화면에 남의 역할 없음 |
| P | 처형 구간: 여부 투표 익명 집계, '처형 투표' 카드 3초 · 터치 통과, 후보 선택 후광 · 알약, 공개 화살표 하나 · 칩, 변론 스포트라이트, 처형 카드, 처형 무효 카드, 결과 화면, 칩 배치, 안내 줄(P11), 빈 곳 탭 취소(P12) |
| UX · AT · WL | 화면마다 안내 문장 하나(`data-guide`), 밤 비네팅 · 아침 밝아짐, Wake Lock 요청 · 해제 |

서버 쪽은 `scripts/smoke.mjs`(4 · 5 · 8명 한 판), `scripts/uat-*.mjs`(낮 · 밤 · 투표 · 테스트 방 · 봇 시나리오)가 배포본 소켓으로 확인한다. 역할 누출은 `test/worker` 의 누출 검사가 막는다.

## 에셋 자동 검사

- `npm run backdrops`(`scripts/make-backdrops.mjs`): 원본 PNG → WebP, 게임 구도 명도 0.8 굽기, 결정적 출력, 용량 상한을 넘으면 실패.
- `npm run tokens`(`scripts/gen-tokens.mjs`): `design/tokens.json` → `src/styles/tokens.css`. 테스트가 둘의 일치를 확인한다.
- `test/unit/backdropContrast.test.ts`: 헤더 글씨 대비를 오프라인으로 재합성.
- smoke: 배포본 배경이 `image/webp` · `max-age=86400` · RIFF/WEBP 머리 · 용량 상한인지 확인.
- 그림을 바꾸면 `ASSET_VERSION`(`src/net/assets.ts`)을 올린다.
- 화면 사진 다시 찍기: `node scripts/e2e/run.mjs --shots --sizes 390x844`, `node scripts/gallery.mjs <폴더> police 5` · `mafia 7`.
